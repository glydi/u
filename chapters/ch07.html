    Limits

    A limit asks: as $x$ crowds in on a point, where do the values $f(x)$ head? Not what $f$ is at the point — what it is approaching. The whole of calculus is built on this one idea: derivatives and integrals are both limits.

    Definition $\lim_{x\to a} f(x) = L$ means $f(x)$ can be made as close to $L$ as desired by taking $x$ close enough (but not equal) to $a$. The value $f(a)$ — even whether it exists — is irrelevant to the limit.
    Worked example $f(x) = \dfrac{x^2 - 9}{x - 3}$ is undefined at $x = 3$, yet for $x \ne 3$, $f(x) = x + 3$. So $\lim_{x\to3} f(x) = 6$: the values 5.9, 5.99, 5.999… (from $x = 2.9, 2.99, \dots$) and 6.1, 6.01… (from above) both squeeze onto 6.
    Pitfall "Plug it in" only works for continuous functions. Limits exist where functions don't ($\frac{x^2-9}{x-3}$ at 3) and fail to exist where functions do ($\lim_{x\to0}\sin\frac1x$ oscillates forever).
    Drill
    1. EASY $\lim_{x\to2}\dfrac{x^2-4}{x-2} = ?$
      Solution
      Factor: $x + 2 \to 4$.
    2. MED $\lim_{h\to0}\dfrac{(2+h)^2 - 4}{h} = ?$
      Solution
      $\frac{4 + 4h + h^2 - 4}{h} = 4 + h \to 4$. (This is a derivative in disguise: $\frac{d}{dx}x^2$ at 2.)
    3. HARD $\lim_{x\to0}\dfrac{\sqrt{x+4} - 2}{x} = ?$
      Solution
      Multiply by the conjugate: $\frac{(x+4)-4}{x(\sqrt{x+4}+2)} = \frac{1}{\sqrt{x+4}+2} \to \frac14$.

    Epsilon-delta definition of limits

    "As close as desired" needs teeth. The ε–δ definition is a challenge game: you name a tolerance ε around $L$; I must produce a radius δ around $a$ so that every $x$ within δ (except $a$ itself) lands within ε. If I can always win, the limit is $L$.

    Definition $\lim_{x\to a} f(x) = L$ iff: for every $\varepsilon > 0$ there exists $\delta > 0$ such that $$0 < |x - a| < \delta \implies |f(x) - L| < \varepsilon.$$
    Worked example Prove $\lim_{x\to3}(2x + 1) = 7$. Given $\varepsilon > 0$, we need $|2x + 1 - 7| = 2|x - 3| < \varepsilon$. Choose $\delta = \varepsilon/2$: then $|x-3| < \delta$ gives $2|x-3| < 2\cdot\tfrac\varepsilon2 = \varepsilon$. $\blacksquare$
    Explore

    Shrink ε and find a δ that keeps the whole tube of the curve inside the band — for f(x)=x² at a=1, L=1.

    Drill
    1. EASY For $f(x) = 5x$, $a = 2$, $L = 10$: what δ works for $\varepsilon = 0.1$?
      Solution
      $|5x - 10| = 5|x-2| < 0.1$ needs $|x - 2| < 0.02$: take $\delta = 0.02$.
    2. MED Prove $\lim_{x\to a} c = c$ for a constant function.
      Solution
      $|f(x) - c| = 0 < \varepsilon$ always: any δ (say δ = 1) works for every ε. $\blacksquare$
    3. HARD Prove $\lim_{x\to2} x^2 = 4$.
      Solution
      $|x^2 - 4| = |x-2||x+2|$. First restrict $\delta \le 1$, so $|x - 2| < 1 \Rightarrow x \in (1,3) \Rightarrow |x+2| < 5$. Then $|x^2-4| < 5|x-2|$, and choosing $\delta = \min(1, \varepsilon/5)$ gives $|x^2 - 4| < 5\cdot\tfrac\varepsilon5 = \varepsilon$. $\blacksquare$

    One-sided limits

    Approach from the left and from the right separately. A two-sided limit exists exactly when both one-sided limits exist and agree — a step function fails precisely because its two sides disagree.

    Definition $\lim_{x\to a^-} f(x)$ uses only $x < a$; $\lim_{x\to a^+} f(x)$ uses only $x > a$. Then $\lim_{x\to a} f(x) = L \iff \lim_{x\to a^-} f(x) = \lim_{x\to a^+} f(x) = L$.
    Worked example $f(x) = \dfrac{|x|}{x}$: for $x > 0$, $f = 1$; for $x < 0$, $f = -1$. So $\lim_{x\to0^+} f = 1$, $\lim_{x\to0^-} f = -1$: the two-sided limit at 0 does not exist.
    Drill
    1. EASY $\lim_{x\to0^+}\sqrt{x} = ?$ (Why only one side?)
      Solution
      $0$. $\sqrt x$ has no values for $x < 0$, so only the right limit is meaningful.
    2. MED $f(x) = \begin{cases} x^2 & x < 1 \\ 3x - 2 & x \ge 1\end{cases}$. Does $\lim_{x\to1} f$ exist?
      Solution
      Left: $1^2 = 1$. Right: $3 - 2 = 1$. Equal: limit exists, $= 1$.
    3. HARD Compute $\lim_{x\to2^-}\lfloor x\rfloor$ and $\lim_{x\to2^+}\lfloor x\rfloor$ and conclude.
      Solution
      From the left, $x \in (1,2)$ gives $\lfloor x\rfloor = 1$; from the right, $\lfloor x\rfloor = 2$. One-sided limits 1 and 2 differ: no two-sided limit at 2 (and similarly at every integer).

    Limits at infinity

    What does $f$ settle toward as $x$ marches off to $+\infty$ or $-\infty$? The answer describes end behavior: horizontal asymptotes, the long-run of a training curve, the saturation of a sigmoid.

    Definition $\lim_{x\to\infty} f(x) = L$ means: for every $\varepsilon > 0$ there is an $M$ with $x > M \Rightarrow |f(x) - L| < \varepsilon$. For rational functions, divide by the highest power of the denominator; only the leading terms matter. Key fact: $\lim_{x\to\infty}\frac1{x^p} = 0$ for $p > 0$.
    Worked example $\lim_{x\to\infty}\dfrac{3x^2 - x + 5}{2x^2 + 7}$: divide top and bottom by $x^2$: $\dfrac{3 - \frac1x + \frac5{x^2}}{2 + \frac7{x^2}} \to \dfrac{3}{2}$.
    Pitfall $\lim_{x\to-\infty}\frac{\sqrt{x^2+1}}{x}$: $\sqrt{x^2} = |x| = -x$ when $x < 0$, so the limit is $-1$, not $1$. The sign of $x$ hides inside the square root.
    Drill
    1. EASY $\lim_{x\to\infty}\dfrac{5x + 1}{x - 2} = ?$
      Solution
      Leading terms: $5$.
    2. MED $\lim_{x\to\infty}\dfrac{x^2 + 1}{x^3 + x} = ?$ and $\lim_{x\to\infty}\dfrac{x^3}{x^2 + 1} = ?$
      Solution
      First: degree of bottom wins, limit 0. Second: top wins, $\to +\infty$ (no finite limit).
    3. HARD $\lim_{x\to\infty}\big(\sqrt{x^2 + 6x} - x\big) = ?$
      Solution
      Conjugate: $\frac{x^2 + 6x - x^2}{\sqrt{x^2+6x} + x} = \frac{6x}{x(\sqrt{1 + 6/x} + 1)} \to \frac{6}{2} = 3$.

    Infinite limits

    Sometimes the function doesn't settle — it explodes. Writing $\lim f(x) = \infty$ is shorthand for "grows beyond every bound"; the limit does not exist as a number, but the blow-up pattern is precise information: it draws vertical asymptotes.

    Definition $\lim_{x\to a} f(x) = \infty$ means: for every $M$ there is $\delta > 0$ with $0 < |x - a| < \delta \Rightarrow f(x) > M$. If either one-sided limit is $\pm\infty$, the line $x = a$ is a vertical asymptote. Near a zero of the denominator not cancelled by the numerator, check signs on each side.
    Worked example $f(x) = \dfrac{1}{(x-2)^2}$: both sides of 2 give positive blow-up, $\lim_{x\to2} f = +\infty$. But $g(x) = \dfrac1{x-2}$: from the right $+\infty$, from the left $-\infty$ — the signed sides differ, and we only say $x=2$ is a vertical asymptote.
    Drill
    1. EASY $\lim_{x\to0^+}\dfrac1x$ and $\lim_{x\to0^-}\dfrac1x$?
      Solution
      $+\infty$ and $-\infty$.
    2. MED Find the vertical asymptotes of $\dfrac{x+1}{x^2 - x - 6}$.
      Solution
      Denominator $(x-3)(x+2)$ has zeros 3, $-2$; neither cancels with $x + 1$. Asymptotes $x = 3$ and $x = -2$.
    3. HARD Evaluate $\lim_{x\to(\pi/2)^-}\tan x$ and $\lim_{x\to0^+} x\ln x$.
      Solution
      $\tan x = \sin x/\cos x$ with $\sin \to 1$, $\cos\to 0^+$: $+\infty$. For $x\ln x$: write $\frac{\ln x}{1/x}$, L'Hôpital (later in this chapter): $\frac{1/x}{-1/x^2} = -x \to 0$. So $0$ — the $x$ wins against the $\ln$.

    Limit laws

    Limits respect arithmetic: the limit of a sum is the sum of limits, and so on — provided the pieces' limits exist. These laws let you split a complicated limit into boring ones you know.

    Definition If $\lim_{x\to a} f = L$ and $\lim_{x\to a} g = M$: $\lim(f\pm g) = L \pm M$; $\lim(fg) = LM$; $\lim\frac fg = \frac LM$ if $M \ne 0$; $\lim c f = cL$; $\lim [f]^n = L^n$; $\lim \sqrt[n]{f} = \sqrt[n]{L}$ (when defined). Also: if $f$ is continuous at $L$ then $\lim f(g(x)) = f(M)$... more precisely $f(\lim g)$.
    Worked example $\lim_{x\to2}\dfrac{x^2 + 3x}{\sqrt{x + 7}}$: numerator $\to 4 + 6 = 10$ (sum/product laws), denominator $\to \sqrt9 = 3 \ne 0$ (root law): limit $= \tfrac{10}3$.
    Pitfall The laws need the sub-limits to exist. $\lim_{x\to0}\big[x\cdot\frac1x\big] = 1$, but you cannot split it into $0 \times \infty$. Indeterminate forms ($\frac00$, $\frac\infty\infty$, $0\cdot\infty$, $\infty - \infty$) need algebra or L'Hôpital, not the laws.
    Drill
    1. EASY Given $\lim f = 3$, $\lim g = -2$ at $x = a$: find $\lim(2f - g^2)$.
      Solution
      $2(3) - (-2)^2 = 6 - 4 = 2$.
    2. MED Why can't the quotient law evaluate $\lim_{x\to1}\frac{x^2-1}{x-1}$ directly, and what is the limit?
      Solution
      Denominator limit is 0, so the law's hypothesis fails. Cancel first: $x + 1 \to 2$.
    3. HARD True or false: if $\lim_{x\to a}[f(x) + g(x)]$ exists, then both $\lim f$ and $\lim g$ exist.
      Solution
      False. $f(x) = \frac1x$, $g(x) = -\frac1x$ at $a = 0$: sum is 0 everywhere, limit 0, but neither piece has a limit.

    Squeeze theorem

    Trap a wild function between two tame ones. If both fences converge to the same value, the prisoner has nowhere else to go. This is how the crucial limit $\frac{\sin x}{x} \to 1$ is proved.

    Theorem If $g(x) \le f(x) \le h(x)$ near $a$ (except possibly at $a$) and $\lim_{x\to a} g = \lim_{x\to a} h = L$, then $\lim_{x\to a} f = L$.
    Worked example $\lim_{x\to0} x^2\sin\frac1x$: since $-1 \le \sin\frac1x \le 1$, we have $-x^2 \le x^2\sin\frac1x \le x^2$. Both fences $\to 0$, so the limit is 0 — even though $\sin\frac1x$ oscillates infinitely fast.
    Think first Why does $\frac{\sin x}{x} \to 1$ as $x \to 0$? Sketch the unit circle: compare the areas of the small triangle, the circular sector, and the big triangle at angle $x$.
    Reveal
    For $0 < x < \tfrac\pi2$: $\tfrac12\sin x\cos x \le \tfrac12 x \le \tfrac12\tan x$. Divide by $\tfrac12\sin x$: $\cos x \le \frac{x}{\sin x} \le \frac1{\cos x}$. Invert: $\cos x \le \frac{\sin x}{x} \le \frac{1}{\cos x}$. Both fences $\to 1$; squeeze. (Even function ⇒ same from the left.)
    Drill
    1. EASY $\lim_{x\to0} x\cos\frac1x = ?$
      Solution
      $-|x| \le x\cos\frac1x \le |x|$, both $\to 0$: limit 0.
    2. MED $\lim_{x\to0}\dfrac{\sin 5x}{x} = ?$
      Solution
      $\frac{\sin 5x}{x} = 5\cdot\frac{\sin 5x}{5x} \to 5\cdot1 = 5$.
    3. HARD $\lim_{x\to0}\dfrac{1 - \cos x}{x^2} = ?$
      Solution
      Multiply by $\frac{1+\cos x}{1+\cos x}$: $\frac{1-\cos^2x}{x^2(1+\cos x)} = \big(\frac{\sin x}{x}\big)^2\cdot\frac{1}{1+\cos x} \to 1\cdot\frac12 = \frac12$.

    Continuity

    A function is continuous where you can draw it without lifting the pen: no holes, jumps or explosions. Formally, the limit equals the value. Continuity is the license to "plug in" — and the hypothesis behind nearly every big theorem in this chapter.

    Definition $f$ is continuous at $a$ iff (1) $f(a)$ exists, (2) $\lim_{x\to a} f(x)$ exists, (3) they are equal: $\lim_{x\to a} f(x) = f(a)$. Continuous on an interval = continuous at each point. Polynomials, $\sin$, $\cos$, $e^x$ are continuous everywhere; rational functions, $\ln$, $\tan$ wherever defined. Sums, products, quotients (nonzero denominator) and compositions of continuous functions are continuous.
    Worked example Choose $c$ so $f(x) = \begin{cases} x^2 + c & x < 2 \\ 3x & x \ge 2 \end{cases}$ is continuous. Match at the seam: left limit $4 + c$, value/right limit $6$. Need $4 + c = 6$: $c = 2$.
    Drill
    1. EASY Where is $f(x) = \dfrac{x+1}{x^2 - 4}$ continuous?
      Solution
      Everywhere except $x = \pm2$.
    2. MED Is $f(x) = \begin{cases}\frac{\sin x}{x} & x \ne 0\\ 1 & x = 0\end{cases}$ continuous at 0?
      Solution
      Yes: $\lim_{x\to0}\frac{\sin x}{x} = 1 = f(0)$. The hole has been patched.
    3. HARD Show $f(x) = \lfloor x \rfloor + \lfloor -x\rfloor$ equals $0$ at integers and $-1$ elsewhere; where is it continuous?
      Solution
      Integer $x = n$: $n + (-n) = 0$. Non-integer: $\lfloor x\rfloor = n$ where $n < x < n+1$, and $\lfloor -x \rfloor = -n - 1$: sum $-1$. So $f$ is $-1$ except at integers, where it spikes to 0: continuous exactly on $\mathbb{R}\setminus\mathbb{Z}$.

    Types of discontinuity

    Not all breaks are equal. A removable hole can be patched with one value; a jump cannot be patched but stays bounded; an infinite or oscillating break is wilder still. Naming the break tells you what's fixable.

    Definition At $a$: removable — $\lim_{x\to a}f$ exists but $\ne f(a)$ (or $f(a)$ undefined); jump — both one-sided limits exist but differ; infinite — a one-sided limit is $\pm\infty$; essential/oscillating — a one-sided limit fails to exist even allowing $\pm\infty$ (e.g. $\sin\frac1x$).
    Worked example $f(x) = \dfrac{x^2 - 1}{x - 1}$ at 1: removable (limit 2, no value) — define $f(1) = 2$ and it heals. $g(x) = \dfrac{|x-1|}{x-1}$ at 1: jump ($-1$ vs $1$). $h(x) = \dfrac{1}{x-1}$ at 1: infinite.
    Drill
    1. EASY Classify the discontinuity of $\lfloor x\rfloor$ at $x = 3$.
      Solution
      Jump: left limit 2, right limit 3.
    2. MED Classify $f(x) = \dfrac{x^2 - 4}{x^2 - 2x}$ at $x = 0$ and $x = 2$.
      Solution
      $f = \frac{(x-2)(x+2)}{x(x-2)} = \frac{x+2}{x}$ for $x \ne 0, 2$. At 2: removable (limit $\tfrac42 = 2$). At 0: infinite.
    3. HARD Classify $f(x) = \sin\frac1x$ at 0 and $g(x) = x\sin\frac1x$ at 0 (both undefined at 0).
      Solution
      $f$: essential — it oscillates through $[-1,1]$ forever, no one-sided limit. $g$: removable — squeeze gives limit 0; set $g(0)=0$ to heal.

    Intermediate Value Theorem

    A continuous function cannot teleport: to get from $f(a)$ to $f(b)$ it must pass through every value in between. This innocent statement finds roots, prices options, and guarantees bisection search always works.

    Theorem If $f$ is continuous on $[a, b]$ and $N$ is strictly between $f(a)$ and $f(b)$, then there exists $c \in (a, b)$ with $f(c) = N$. In particular if $f(a)$ and $f(b)$ have opposite signs, $f$ has a root in $(a,b)$.
    Worked example Show $x^3 + x - 1 = 0$ has a root in $(0, 1)$: $f(0) = -1 < 0$, $f(1) = 1 > 0$, $f$ continuous (polynomial) — IVT gives a root. Bisect: $f(0.5) = -0.375$: root in $(0.5, 1)$. $f(0.75) \approx 0.172$: root in $(0.5, 0.75)$. Each halving doubles precision (the actual root is $\approx 0.6823$).
    Pitfall Both hypotheses matter. $\frac1x$ has $f(-1) = -1$, $f(1) = 1$ but no root — it isn't continuous on $[-1,1]$. And IVT proves existence, not uniqueness.
    Drill
    1. EASY Show $\cos x = x$ has a solution in $(0, 1)$.
      Solution
      $g(x) = \cos x - x$: $g(0) = 1 > 0$, $g(1) = 0.540 - 1 < 0$; continuous, so a root exists.
    2. MED A hiker walks up a hill from 6am to 6pm, and down the same trail the next day 6am–6pm. Show there is a spot she occupies at exactly the same clock time both days.
      Solution
      Let $u(t), d(t)$ be positions along the trail; $g(t) = u(t) - d(t)$ is continuous with $g(6\text{am}) = \text{bottom} - \text{top} < 0$ and $g(6\text{pm}) > 0$: some $t^*$ has $g(t^*) = 0$.
    3. HARD Show every odd-degree polynomial with real coefficients has a real root.
      Solution
      WLOG leading coefficient positive. As $x\to+\infty$, $p(x)\to+\infty$; as $x\to-\infty$, $p(x)\to-\infty$ (odd degree). So there are points where $p<0$ and where $p>0$; polynomials are continuous; IVT gives a root. $\blacksquare$
    $f$ is continuous on $[0,2]$ with $f(0)=3$, $f(2)=3$. Must $f$ take the value 0 somewhere on $[0,2]$?
    IVT only guarantees values between $f(0)=3$ and $f(2)=3$ — that's just {3}. $f$ could stay near 3 the whole way, e.g. $f \equiv 3$.

    Derivative intuition

    The derivative is instantaneous rate of change: how fast $f$ is changing right now. Speedometer, not trip average. Zoom into any smooth curve far enough and it looks like a straight line — the derivative is that line's slope.

    Definition Average rate of change of $f$ over $[a, a+h]$: $\frac{f(a+h) - f(a)}{h}$ (slope of the secant line). The derivative is what these averages approach as the window shrinks: the slope of the curve itself at $a$. Units: (units of $f$) per (unit of $x$).
    Worked example A ball's height is $s(t) = 20t - 5t^2$ m. Average velocity over $[1, 1.1]$: $\frac{s(1.1) - s(1)}{0.1} = \frac{15.95 - 15}{0.1} = 9.5$ m/s. Over $[1, 1.01]$: $9.95$. Over $[1, 1.001]$: $9.995$. The instantaneous velocity at $t=1$ is evidently 10 m/s — and indeed $s'(t) = 20 - 10t$ gives $s'(1) = 10$.
    Where this goes Training a neural network is following derivatives: the gradient (Ch 9) is a vector of them, and gradient descent (Ch 15) steps downhill along it.
    Drill
    1. EASY $f(x) = x^2$. Average rate of change over $[3, 3.1]$?
      Solution
      $\frac{9.61 - 9}{0.1} = 6.1$ (heading toward $f'(3) = 6$).
    2. MED Water drains so volume is $V(t) = 100(1 - t/10)^2$ liters, $0\le t\le 10$ min. Estimate the flow rate at $t = 5$ using windows 0.1 and 0.01.
      Solution
      $V(5) = 25$; $V(5.1) = 100(0.49)^2 = 24.01$: rate $\approx -9.9$. $V(5.01) = 100(0.499)^2 = 24.9001$: rate $\approx -9.99$ L/min. True: $V'(t) = -20(1 - t/10)$, $V'(5) = -10$.
    3. HARD Sketch (mentally) $f(x) = |x|$. Why does no single slope exist at 0?
      Solution
      Secants from the right have slope $+1$; from the left $-1$. The zoom never straightens the corner: one-sided derivatives differ, so $f'(0)$ does not exist. Smoothness fails at kinks — relevant to ReLU (Ch 21), which is exactly this function.

    Derivative definition

    Freeze the intuition into a formula: the derivative is the limit of secant slopes. Every derivative rule you will ever use is proved from this one limit.

    Definition $$f'(a) = \lim_{h\to0}\frac{f(a+h) - f(a)}{h} = \lim_{x\to a}\frac{f(x) - f(a)}{x - a},$$ when the limit exists ($f$ is then differentiable at $a$). Notations: $f'(x)$, $\frac{df}{dx}$, $\dot f$, $D_x f$. Differentiable $\Rightarrow$ continuous (but not conversely: $|x|$).
    Worked example $f(x) = \frac1x$, from the definition: $$f'(a) = \lim_{h\to0}\frac{\frac{1}{a+h} - \frac1a}{h} = \lim_{h\to0}\frac{a - (a+h)}{h\,a(a+h)} = \lim_{h\to0}\frac{-1}{a(a+h)} = -\frac{1}{a^2}.$$
    Explore

    Shrink h and watch the secant line rotate into the tangent of f(x) = x³/3 − x at the point a.

    Drill
    1. EASY From the definition, compute $f'(x)$ for $f(x) = 3x + 5$.
      Solution
      $\frac{3(x+h)+5 - 3x - 5}{h} = 3$ for all $h$: $f' = 3$.
    2. MED From the definition, $f(x) = x^2 - 4x$: find $f'(x)$.
      Solution
      $\frac{(x+h)^2 - 4(x+h) - x^2 + 4x}{h} = \frac{2xh + h^2 - 4h}{h} = 2x + h - 4 \to 2x - 4$.
    3. HARD From the definition, $f(x) = \sqrt x$: find $f'(x)$ for $x > 0$. Is $f$ differentiable at 0?
      Solution
      $\frac{\sqrt{x+h}-\sqrt x}{h} = \frac{h}{h(\sqrt{x+h}+\sqrt x)} \to \frac{1}{2\sqrt x}$. At 0: $\frac{\sqrt h}{h} = \frac1{\sqrt h}\to\infty$ — not differentiable (vertical tangent).

    Geometric meaning of derivative

    $f'(a)$ is the slope of the tangent line — the unique line that kisses the curve at $(a, f(a))$ and matches its direction. Positive derivative: the curve climbs; negative: falls; zero: momentarily flat (a candidate peak or valley).

    Definition The tangent line to $y = f(x)$ at $a$: $$y = f(a) + f'(a)(x - a).$$ The normal line is perpendicular: slope $-1/f'(a)$ (if $f'(a)\ne0$).
    Worked example Tangent to $y = x^2$ at $x = 3$: $f(3) = 9$, $f'(3) = 6$: $y = 9 + 6(x - 3) = 6x - 9$. Check by touching: $x^2 - (6x - 9) = (x-3)^2 \ge 0$ — the parabola sits on the line, touching only at $x = 3$. ✓
    Drill
    1. EASY Tangent line to $y = x^3$ at $x = 1$ (use $y' = 3x^2$).
      Solution
      $y = 1 + 3(x - 1) = 3x - 2$.
    2. MED At which points does $y = x^3 - 3x$ have a horizontal tangent?
      Solution
      $y' = 3x^2 - 3 = 0 \Rightarrow x = \pm1$: points $(1, -2)$ and $(-1, 2)$.
    3. HARD Find all tangent lines to $y = x^2$ passing through the external point $(1, -3)$.
      Solution
      Tangent at $a$: $y = a^2 + 2a(x - a) = 2ax - a^2$. Through $(1,-3)$: $-3 = 2a - a^2 \Rightarrow a^2 - 2a - 3 = 0 \Rightarrow a = 3, -1$. Lines: $y = 6x - 9$ and $y = -2x - 1$.

    Derivative rules

    Nobody computes limits all day. A handful of rules — linearity, product, quotient, chain — turn differentiation into mechanical bookkeeping that always works. Autodiff frameworks (Ch 18) implement exactly these rules on computation graphs.

    Definition Given differentiable $f, g$ and constant $c$: linearity $(cf + g)' = cf' + g'$; product $(fg)' = f'g + fg'$; quotient $\big(\frac fg\big)' = \frac{f'g - fg'}{g^2}$; chain $(f\circ g)'(x) = f'(g(x))\,g'(x)$. Base cases: $(x^n)' = nx^{n-1}$, $(e^x)' = e^x$, $(\ln x)' = \frac1x$, $(\sin x)' = \cos x$, $(\cos x)' = -\sin x$.
    Worked example $f(x) = \dfrac{x^2 e^x}{1 + x}$. Product for the top: $(x^2e^x)' = 2xe^x + x^2e^x$. Quotient: $$f'(x) = \frac{(2x + x^2)e^x(1+x) - x^2e^x}{(1+x)^2} = \frac{e^x\,x(x^2 + 3x + 2 - x)}{(1+x)^2} = \frac{x e^x (x^2 + 2x + 2)}{(1+x)^2}.$$
    Drill
    1. EASY Differentiate $f(x) = 4x^3 - 2x + 7$.
      Solution
      $12x^2 - 2$.
    2. MED Differentiate $f(x) = x^2\sin x$.
      Solution
      $2x\sin x + x^2\cos x$.
    3. HARD Differentiate $f(x) = \dfrac{e^{2x}}{x^2 + 1}$ and evaluate $f'(0)$.
      Solution
      $f' = \frac{2e^{2x}(x^2+1) - e^{2x}\cdot 2x}{(x^2+1)^2} = \frac{2e^{2x}(x^2 - x + 1)}{(x^2+1)^2}$. At 0: $\frac{2\cdot1\cdot1}{1} = 2$.

    Power rule

    The most used rule in calculus: bring the exponent down, knock it down by one. It holds for every real exponent — integers, fractions, negatives — which covers polynomials, roots, and reciprocals in one stroke.

    Definition $$\frac{d}{dx}x^n = n x^{n-1}, \qquad n \in \mathbb{R}.$$ Special cases: $(\sqrt x)' = \tfrac12 x^{-1/2} = \frac1{2\sqrt x}$; $\big(\frac1x\big)' = -x^{-2}$; $(x)' = 1$; $(c)' = 0$.
    Worked example $f(x) = \sqrt[3]{x^2} = x^{2/3}$: $f'(x) = \tfrac23 x^{-1/3} = \dfrac{2}{3\sqrt[3]{x}}$. And $g(x) = \dfrac{5}{x^3} = 5x^{-3}$: $g'(x) = -15x^{-4} = -\dfrac{15}{x^4}$.
    Pitfall The power rule needs a constant exponent and variable base. $x^x$ is neither: use logarithmic differentiation. And $(2^x)' \ne x2^{x-1}$ — that's an exponential, $(2^x)' = 2^x\ln 2$.
    Drill
    1. EASY $\frac{d}{dx} x^{10} = ?$
      Solution
      $10x^9$.
    2. MED Differentiate $f(x) = \dfrac{x^2 + 3\sqrt x}{x}$ by simplifying first.
      Solution
      $f = x + 3x^{-1/2}$: $f' = 1 - \tfrac32 x^{-3/2}$.
    3. HARD For which $p$ is $f(x) = |x|^p$ differentiable at 0?
      Solution
      For $p > 1$: the difference quotient $\frac{|h|^p}{h} = |h|^{p-1}\,\text{sgn}(h) \to 0$. For $p = 1$ (the corner) and $p < 1$ (cusp/blow-up) it fails. Answer: $p > 1$.

    Constant rule

    Constants don't change, so their rate of change is zero — and a constant factor rides along for free. Small facts, used in every single differentiation you'll ever do.

    Definition $\frac{d}{dx} c = 0$ for any constant $c$, and $\frac{d}{dx}[c\,f(x)] = c\,f'(x)$ (constant multiple rule).
    Worked example $\frac{d}{dx}\big[7x^3\big] = 7\cdot 3x^2 = 21x^2$, and $\frac{d}{dx}[\pi^2] = 0$ — $\pi^2$ is a number, not a function of $x$, even though it wears an exponent.
    Drill
    1. EASY $\frac{d}{dx}[5e^x] = ?$
      Solution
      $5e^x$.
    2. MED $\frac{d}{dx}\big[\frac{x^4}{8}\big]$ at $x = 2$?
      Solution
      $\tfrac18\cdot4x^3 = \tfrac{x^3}{2}$; at 2: $4$.
    3. HARD Differentiate $f(x) = e^2 x^3 + \ln(5)\, x + \sin(\pi/7)$.
      Solution
      All of $e^2$, $\ln 5$, $\sin(\pi/7)$ are constants: $f'(x) = 3e^2x^2 + \ln 5$. Spotting frozen constants is the whole game.

    Sum rule

    The derivative of a sum is the sum of derivatives: rates of change add. A car's total speed of separation from two directions, revenue from two products — differentiation distributes over $+$.

    Definition $(f + g)' = f' + g'$ and $(f - g)' = f' - g'$. Extends to any finite sum: $\big(\sum_i f_i\big)' = \sum_i f_i'$ — which is why you can differentiate polynomials term by term.
    Worked example $f(x) = x^3 - 4x^2 + 6x - 2$: differentiate each term: $f'(x) = 3x^2 - 8x + 6$.
    Drill
    1. EASY $\frac{d}{dx}[x^2 + \sin x] = ?$
      Solution
      $2x + \cos x$.
    2. MED $f(x) = e^x + \ln x - \sqrt x$. Find $f'(1)$.
      Solution
      $f' = e^x + \frac1x - \frac{1}{2\sqrt x}$; at 1: $e + 1 - 0.5 = e + 0.5 \approx 3.218$.
    3. HARD Loss functions add: $L(w) = (w - 3)^2 + (w - 7)^2$. Find the $w$ minimizing $L$ using $L' = 0$.
      Solution
      $L'(w) = 2(w-3) + 2(w-7) = 4w - 20 = 0 \Rightarrow w = 5$ — the mean of 3 and 7. Squared-error losses always minimize at the mean; this scales to all of least squares (Ch 13/19).

    Product rule

    The derivative of a product is not the product of derivatives. Picture a rectangle with growing sides: the area gains a strip from each side — $f'g$ from one, $fg'$ from the other.

    Definition $$(fg)' = f'g + fg'.$$ Three factors: $(fgh)' = f'gh + fg'h + fgh'$ — one term per factor differentiated.
    Worked example $f(x) = x e^x$: $f' = 1\cdot e^x + x e^x = (1 + x)e^x$. Iterate: $f'' = e^x + (1+x)e^x = (2 + x)e^x$ — a pattern worth remembering: $\frac{d^n}{dx^n}[xe^x] = (n + x)e^x$.
    Pitfall $(fg)' \ne f'g'$. Test: $f = g = x$ gives $(x^2)' = 2x$, but $f'g' = 1$. Wrong rule, wrong answer.
    Drill
    1. EASY Differentiate $x^2\cos x$.
      Solution
      $2x\cos x - x^2\sin x$.
    2. MED $f(x) = (x^2 + 1)(x^3 - 2x)$: find $f'$ two ways (product rule; expand first) and check they agree.
      Solution
      Product: $2x(x^3 - 2x) + (x^2+1)(3x^2 - 2) = 2x^4 - 4x^2 + 3x^4 + x^2 - 2 = 5x^4 - 3x^2 - 2$. Expand: $f = x^5 - x^3 - 2x$, $f' = 5x^4 - 3x^2 - 2$. ✓
    3. HARD Given $f(2) = 3$, $f'(2) = -1$, $g(2) = 5$, $g'(2) = 4$: compute $(fg)'(2)$ and $(f^2 g)'(2)$.
      Solution
      $(fg)' = f'g + fg' = (-1)(5) + (3)(4) = 7$. $(f^2g)' = 2ff'g + f^2g' = 2(3)(-1)(5) + 9(4) = -30 + 36 = 6$.

    Quotient rule

    For ratios: low d-high minus high d-low, over low squared. It is the product rule applied to $f \cdot g^{-1}$, packaged for direct use.

    Definition $$\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}, \qquad g \ne 0.$$ Special case (reciprocal rule): $\big(\frac1g\big)' = -\frac{g'}{g^2}$.
    Worked example Derive $(\tan x)'$: $\tan = \frac{\sin}{\cos}$, so $$(\tan x)' = \frac{\cos x\cos x - \sin x(-\sin x)}{\cos^2 x} = \frac{\cos^2 + \sin^2}{\cos^2 x} = \sec^2 x.$$
    Pitfall Order matters in the numerator: $f'g - fg'$, not $fg' - f'g$. Get it backwards and every sign flips.
    Drill
    1. EASY Differentiate $\dfrac{x}{x+1}$.
      Solution
      $\frac{(1)(x+1) - x(1)}{(x+1)^2} = \frac{1}{(x+1)^2}$.
    2. MED Differentiate the sigmoid-like $f(x) = \dfrac{e^x}{1 + e^x}$ and show $f' = f(1 - f)$.
      Solution
      $f' = \frac{e^x(1+e^x) - e^x e^x}{(1+e^x)^2} = \frac{e^x}{(1+e^x)^2}$. And $f(1-f) = \frac{e^x}{1+e^x}\cdot\frac{1}{1+e^x}$ — equal. ✓ (This identity makes backprop through sigmoids cheap, Ch 21.)
    3. HARD Differentiate $\sec x$ via the reciprocal rule.
      Solution
      $(\sec x)' = \big(\frac{1}{\cos x}\big)' = \frac{\sin x}{\cos^2 x} = \sec x\tan x$.

    Chain rule

    For nested functions — a function of a function — rates multiply. If $y$ changes 3× as fast as $u$, and $u$ changes 2× as fast as $x$, then $y$ changes 6× as fast as $x$. This is the rule of deep learning: a network is a deep nest, and backpropagation is the chain rule run in reverse.

    Definition $$\frac{d}{dx} f(g(x)) = f'(g(x))\cdot g'(x), \qquad \text{or} \qquad \frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}.$$ Chains compose: three layers give three factors.
    Worked example $y = (3x^2 + 1)^5$: outer $u^5$, inner $u = 3x^2+1$: $y' = 5(3x^2+1)^4 \cdot 6x = 30x(3x^2+1)^4$. Deeper: $y = e^{\sin(x^2)}$: $y' = e^{\sin(x^2)}\cdot\cos(x^2)\cdot 2x$ — peel from the outside in, multiplying as you go.
    Where this goes Backpropagation (Ch 9, Ch 21) is this rule organized over a computation graph, reusing shared factors so a million-parameter gradient costs one extra forward pass.
    Drill
    1. EASY Differentiate $\sqrt{1 + x^2}$.
      Solution
      $\frac{2x}{2\sqrt{1+x^2}} = \frac{x}{\sqrt{1+x^2}}$.
    2. MED Differentiate $\sin^3(2x)$.
      Solution
      $3\sin^2(2x)\cdot\cos(2x)\cdot2 = 6\sin^2(2x)\cos(2x)$.
    3. HARD $L(w) = \big(\sigma(wx) - y\big)^2$ with $\sigma(z) = \frac{1}{1+e^{-z}}$, and $\sigma' = \sigma(1-\sigma)$. Compute $\frac{dL}{dw}$ at $w=0$, $x=2$, $y=1$.
      Solution
      Chain: $\frac{dL}{dw} = 2(\sigma(wx) - y)\cdot\sigma'(wx)\cdot x$. At $w=0$: $\sigma(0) = \tfrac12$, $\sigma'(0) = \tfrac14$: $\frac{dL}{dw} = 2(\tfrac12 - 1)\cdot\tfrac14\cdot 2 = -\tfrac12$. (Negative: increasing $w$ decreases the loss — a one-neuron backprop.)
    $\frac{d}{dx}\,e^{3x} = ?$
    Chain rule: outer $e^u$ (derivative $e^u$), inner $3x$ (derivative 3). The third option misapplies the power rule to an exponential.

    Implicit differentiation

    Some curves refuse to be $y = f(x)$ — the circle $x^2 + y^2 = 25$ defines $y$ only implicitly. No matter: differentiate both sides treating $y$ as a function of $x$ (so $\frac{d}{dx}y^2 = 2y\,y'$ by the chain rule) and solve for $y'$.

    Definition Given a relation $F(x, y) = 0$, differentiate both sides with respect to $x$, applying the chain rule to every $y$-term, then solve the resulting linear equation for $\frac{dy}{dx}$ (the answer may involve both $x$ and $y$).
    Worked example $x^2 + y^2 = 25$: $2x + 2y\,y' = 0 \Rightarrow y' = -\frac xy$. At $(3, 4)$: slope $-\tfrac34$ — perpendicular to the radius of slope $\tfrac43$, exactly as circle geometry demands (Ch 5). ✓
    Drill
    1. EASY $xy = 6$: find $y'$ implicitly.
      Solution
      $y + xy' = 0 \Rightarrow y' = -\frac yx$.
    2. MED Find the tangent to $x^3 + y^3 = 9$ at $(1, 2)$.
      Solution
      $3x^2 + 3y^2y' = 0 \Rightarrow y' = -\frac{x^2}{y^2} = -\tfrac14$. Tangent: $y = 2 - \tfrac14(x - 1)$.
    3. HARD For the curve $x^2 - xy + y^2 = 3$ (an ellipse), find all points with horizontal tangent.
      Solution
      $2x - y - xy' + 2yy' = 0 \Rightarrow y' = \frac{y - 2x}{2y - x}$. Horizontal: $y = 2x$ (and $2y \ne x$). Substitute: $x^2 - 2x^2 + 4x^2 = 3x^2 = 3 \Rightarrow x = \pm1$. Points $(1, 2)$ and $(-1, -2)$.

    Logarithmic differentiation

    Take ln of both sides first: products become sums, powers become multiples, and monsters like $x^x$ become tame. Then differentiate implicitly. In ML we almost always work with log-likelihoods for exactly this reason.

    Definition To differentiate $y = f(x)$: write $\ln y = \ln f(x)$, simplify with log laws, differentiate ($\frac{y'}{y} = \dots$), then $y' = y \cdot(\dots)$. Also gives the general exponential rule: $(a^x)' = a^x\ln a$, and $\big(u^v\big)' = u^v\big(v'\ln u + v\frac{u'}{u}\big)$.
    Worked example $y = x^x$ ($x>0$): $\ln y = x\ln x$, so $\frac{y'}{y} = \ln x + 1$, giving $y' = x^x(\ln x + 1)$. Minimum where $y' = 0$: $\ln x = -1$, $x = 1/e$ — the curious dip of $x^x$ at $x \approx 0.368$.
    Drill
    1. EASY Differentiate $y = 2^x$.
      Solution
      $2^x\ln 2$.
    2. MED Differentiate $y = \dfrac{(x+1)^3\sqrt{x}}{(x^2+1)^2}$ logarithmically.
      Solution
      $\ln y = 3\ln(x+1) + \tfrac12\ln x - 2\ln(x^2+1)$. $y' = y\Big[\frac{3}{x+1} + \frac{1}{2x} - \frac{4x}{x^2+1}\Big]$.
    3. HARD Differentiate $y = x^{\sin x}$ for $x > 0$.
      Solution
      $\ln y = \sin x\ln x$: $\frac{y'}{y} = \cos x\ln x + \frac{\sin x}{x}$, so $y' = x^{\sin x}\big(\cos x\ln x + \frac{\sin x}{x}\big)$.

    Trigonometric derivatives

    Sine and cosine differentiate into each other in a four-step cycle — the analytic fingerprint of rotation. All six trig derivatives follow from these two plus the quotient rule. (Everything assumes radians.)

    Definition $$(\sin x)' = \cos x \quad (\cos x)' = -\sin x \quad (\tan x)' = \sec^2 x$$ $$(\cot x)' = -\csc^2 x \quad (\sec x)' = \sec x\tan x \quad (\csc x)' = -\csc x\cot x$$ Cofunctions carry the minus sign. Cycle: $\sin \to \cos \to -\sin \to -\cos \to \sin$.
    Worked example Prove $(\sin x)' = \cos x$ from the definition: $$\frac{\sin(x+h) - \sin x}{h} = \frac{\sin x\cos h + \cos x\sin h - \sin x}{h} = \sin x\,\frac{\cos h - 1}{h} + \cos x\,\frac{\sin h}{h}.$$ As $h\to0$: $\frac{\cos h - 1}{h}\to 0$ and $\frac{\sin h}{h}\to1$ (squeeze theorem), leaving $\cos x$. $\blacksquare$
    Drill
    1. EASY Differentiate $f(x) = 3\sin x - 2\cos x$.
      Solution
      $3\cos x + 2\sin x$.
    2. MED Differentiate $f(x) = \sin(x^2)$ and $g(x) = \sin^2 x$; compare.
      Solution
      $f' = 2x\cos(x^2)$; $g' = 2\sin x\cos x = \sin 2x$. Different functions, different chains.
    3. HARD Find the 100th derivative of $\sin x$.
      Solution
      Derivatives cycle with period 4; $100 = 4\times25$: the 100th derivative is $\sin x$ itself.

    Inverse function derivatives

    An inverse function's graph is the original reflected across $y = x$, so its slopes are reciprocals: where $f$ climbs steeply, $f^{-1}$ climbs gently. This one idea yields the derivatives of ln, arcsin, arctan without new limits.

    Definition If $f$ is differentiable and invertible near $a$ with $f'(f^{-1}(a)) \ne 0$: $$\big(f^{-1}\big)'(a) = \frac{1}{f'\big(f^{-1}(a)\big)}.$$ Standard results: $(\ln x)' = \frac1x$; $(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}$; $(\arccos x)' = -\frac{1}{\sqrt{1-x^2}}$; $(\arctan x)' = \frac{1}{1+x^2}$.
    Worked example Derive $(\arctan x)'$: let $y = \arctan x$, so $\tan y = x$. Differentiate: $\sec^2 y\cdot y' = 1$, $y' = \cos^2 y$. With $\tan y = x$, the right triangle gives $\cos y = \frac{1}{\sqrt{1+x^2}}$: $y' = \frac{1}{1 + x^2}$. $\blacksquare$
    Drill
    1. EASY $f(x) = x^3$, so $f^{-1}(8) = 2$. Compute $(f^{-1})'(8)$.
      Solution
      $\frac{1}{f'(2)} = \frac{1}{12}$. (Check: $(x^{1/3})' = \tfrac13 x^{-2/3}$ at 8: $\tfrac13\cdot\tfrac14 = \tfrac1{12}$. ✓)
    2. MED Differentiate $\arcsin(2x)$.
      Solution
      Chain: $\frac{2}{\sqrt{1 - 4x^2}}$.
    3. HARD Derive $(\ln x)' = \frac1x$ from $(e^x)' = e^x$ via the inverse rule.
      Solution
      $f = e^x$, $f^{-1} = \ln$. $(\ln)'(a) = \frac{1}{f'(\ln a)} = \frac{1}{e^{\ln a}} = \frac1a$. $\blacksquare$

    Higher-order derivatives

    Differentiate again: the second derivative is the rate of change of the rate of change — acceleration, curvature, the bend of a loss surface. Third and beyond appear in Taylor series, where each order adds one more layer of local detail.

    Definition $f'' = (f')'$, $f''' = (f'')'$, and in general $f^{(n)}$. Notations: $\frac{d^2y}{dx^2}$, $\ddot y$. Physics: position $s$, velocity $s'$, acceleration $s''$, jerk $s'''$. Sign of $f''$: positive = concave up (smile), negative = concave down (frown).
    Worked example $f(x) = x^4 - 2x^3$: $f' = 4x^3 - 6x^2$, $f'' = 12x^2 - 12x = 12x(x-1)$, $f''' = 24x - 12$, $f^{(4)} = 24$, $f^{(5)} = 0$ — an $n$th-degree polynomial dies after $n$ differentiations.
    Drill
    1. EASY $f(x) = \sin x$: find $f''(x)$.
      Solution
      $-\sin x$.
    2. MED $s(t) = t^3 - 6t^2 + 9t$ (position, meters, seconds). When is acceleration zero, and what is the velocity then?
      Solution
      $s'' = 6t - 12 = 0$ at $t = 2$; $s'(2) = 12 - 24 + 9 = -3$ m/s.
    3. HARD Find a formula for $f^{(n)}(x)$ where $f(x) = \frac1x$.
      Solution
      $f' = -x^{-2}$, $f'' = 2x^{-3}$, $f''' = -6x^{-4}$: pattern $f^{(n)}(x) = (-1)^n\, n!\, x^{-(n+1)}$. Verify by induction: differentiating multiplies by $-(n+1)$ and lowers the power. ✓

    Related rates

    When two quantities are tied by an equation, their rates of change are tied too: differentiate the relation with respect to time. Inflating balloons, sliding ladders, filling cones — one known rate buys the other.

    Definition Method: (1) write the equation relating the quantities at all times, (2) differentiate implicitly with respect to $t$, (3) substitute the known instant's values and rates, (4) solve for the unknown rate. Never plug in frozen values before differentiating.
    Worked example A spherical balloon inflates at $\frac{dV}{dt} = 100$ cm³/s. How fast is the radius growing when $r = 5$? $V = \tfrac43\pi r^3 \Rightarrow \frac{dV}{dt} = 4\pi r^2\frac{dr}{dt}$. So $\frac{dr}{dt} = \frac{100}{4\pi\cdot25} = \frac{1}{\pi} \approx 0.318$ cm/s.
    Pitfall Substituting $r = 5$ into $V = \tfrac43\pi r^3$ before differentiating turns $V$ into a constant and every rate into 0. Differentiate first, freeze later.
    Drill
    1. EASY $y = x^2$ and $\frac{dx}{dt} = 3$. Find $\frac{dy}{dt}$ when $x = 4$.
      Solution
      $\frac{dy}{dt} = 2x\frac{dx}{dt} = 24$.
    2. MED A 10 m ladder slides: its foot moves away at 1 m/s. How fast does the top descend when the foot is 6 m out?
      Solution
      $x^2 + y^2 = 100$: $2x\dot x + 2y\dot y = 0$. At $x = 6$: $y = 8$, $\dot y = -\frac{x\dot x}{y} = -\frac{6}{8} = -0.75$ m/s.
    3. HARD Water fills an inverted cone (radius 3 m, height 6 m) at 2 m³/min. How fast does the water level rise when 4 m deep?
      Solution
      By similar triangles $r = \frac h2$: $V = \frac\pi3 r^2 h = \frac{\pi h^3}{12}$. $\frac{dV}{dt} = \frac{\pi h^2}{4}\frac{dh}{dt}$: $\frac{dh}{dt} = \frac{2\cdot4}{\pi\cdot16} = \frac{1}{2\pi} \approx 0.159$ m/min.

    Linear approximation

    Near a point, a smooth curve is essentially its tangent line — so use the line to estimate the curve. This "zoom until straight" move is the first term of Taylor, the heart of Newton's method, and the local model every gradient step trusts.

    Definition The linearization of $f$ at $a$: $$L(x) = f(a) + f'(a)(x - a), \qquad f(x) \approx L(x) \text{ for } x \text{ near } a.$$ Error shrinks like $(x-a)^2$ (the next Taylor term).
    Worked example Estimate $\sqrt{99.8}$. Take $f(x) = \sqrt x$, $a = 100$: $f(100) = 10$, $f'(100) = \frac{1}{20} = 0.05$. $L(99.8) = 10 + 0.05(-0.2) = 9.99$. True value: $9.98999\ldots$ — the linear estimate is off by about $5\times10^{-6}$.
    Drill
    1. EASY Linearize $f(x) = e^x$ at 0 and estimate $e^{0.1}$.
      Solution
      $L(x) = 1 + x$: $e^{0.1} \approx 1.1$ (true 1.10517).
    2. MED Use linearization to estimate $\sin 31^\circ$.
      Solution
      Radians! $a = \tfrac\pi6$, $x - a = \tfrac{\pi}{180}$: $\sin 31^\circ \approx \tfrac12 + \cos\tfrac\pi6\cdot\tfrac{\pi}{180} = 0.5 + 0.8660\times0.01745 \approx 0.5151$ (true 0.51504).
    3. HARD The relative error version: show that for small relative change $\epsilon$, $(1+\epsilon)^n \approx 1 + n\epsilon$, and use it to estimate $1.002^{50}$.
      Solution
      $f(\epsilon) = (1+\epsilon)^n$, $f(0) = 1$, $f'(0) = n$: $f \approx 1 + n\epsilon$. So $1.002^{50} \approx 1.1$. (True: $e^{50\ln 1.002} = e^{0.0999} \approx 1.105$ — good, and the second-order term $\binom{50}{2}\epsilon^2 \approx 0.0049$ explains most of the gap.)

    Differentials

    Differentials give the tangent-line estimate a notation of its own: $dy = f'(x)\,dx$ says "a small input change $dx$ produces output change about $f'(x)\,dx$". Error propagation in measurements runs on this.

    Definition For $y = f(x)$: the differential is $dy = f'(x)\,dx$, where $dx$ is an independent small change. Then $\Delta y \approx dy$, with $\Delta y = f(x + dx) - f(x)$ the true change. Relative error: $\frac{dy}{y}$.
    Worked example A cube's side is measured as 10 cm with error up to $\pm 0.05$ cm. Volume $V = s^3$: $dV = 3s^2\,ds = 3(100)(\pm0.05) = \pm15$ cm³ on $V = 1000$ — a 1.5% volume error from a 0.5% length error. (Relative errors triple with the cube: $\frac{dV}{V} = 3\frac{ds}{s}$.)
    Drill
    1. EASY $y = x^2$, $x = 5$, $dx = 0.1$: compute $dy$ and the true $\Delta y$.
      Solution
      $dy = 10(0.1) = 1$; $\Delta y = 26.01 - 25 = 1.01$.
    2. MED A circle's radius is measured 1% too big. How wrong is the computed area, approximately?
      Solution
      $A = \pi r^2$: $\frac{dA}{A} = 2\frac{dr}{r} = 2\%$.
    3. HARD A pendulum's period is $T = 2\pi\sqrt{L/g}$. If $L$ is known to 0.2% and $g$ to 0.1%, bound the relative error in $T$.
      Solution
      $\ln T = \ln 2\pi + \tfrac12\ln L - \tfrac12\ln g$: $\frac{dT}{T} = \tfrac12\frac{dL}{L} - \tfrac12\frac{dg}{g}$. Worst case: $\tfrac12(0.2\%) + \tfrac12(0.1\%) = 0.15\%$.

    Mean Value Theorem

    Somewhere on any smooth trip, your instantaneous speed equals your average speed. That is the Mean Value Theorem — the bridge between derivative facts ($f' > 0$) and function facts ($f$ increasing), and the engine inside most proofs in this chapter.

    Theorem If $f$ is continuous on $[a,b]$ and differentiable on $(a,b)$, then there exists $c\in(a,b)$ with $$f'(c) = \frac{f(b) - f(a)}{b - a}.$$ Consequences: $f' = 0$ on an interval $\Rightarrow$ $f$ constant; $f' > 0 \Rightarrow$ strictly increasing; two functions with equal derivatives differ by a constant.
    Worked example $f(x) = x^3$ on $[0, 2]$: average slope $= \frac{8 - 0}{2} = 4$. MVT point: $f'(c) = 3c^2 = 4 \Rightarrow c = \frac{2}{\sqrt3} \approx 1.155$ — inside $(0,2)$ as promised.
    Think first Two toll cameras 60 km apart clock you passing them 30 minutes apart. Can they prove you exceeded 100 km/h?
    Reveal
    Average speed $= 120$ km/h; by MVT your instantaneous speed was exactly 120 at some moment — well over 100. Yes.
    Drill
    1. EASY Find the MVT point for $f(x) = x^2$ on $[1, 3]$.
      Solution
      Average slope $\frac{9-1}{2} = 4$; $2c = 4$, $c = 2$.
    2. MED Use MVT to prove $|\sin a - \sin b| \le |a - b|$ for all $a, b$.
      Solution
      $\sin a - \sin b = \cos(c)(a - b)$ for some $c$ between; $|\cos c| \le 1$. $\blacksquare$ (Sine is 1-Lipschitz — the concept behind Lipschitz constants in Ch 15.)
    3. HARD Show $f(x) = x^3 + 3x + 1$ has exactly one real root.
      Solution
      Existence: $f(-1) = -3 < 0 < 5 = f(1)$, IVT. Uniqueness: two roots would give (by Rolle, next topic) a point with $f' = 0$; but $f' = 3x^2 + 3 \ge 3 > 0$ always. Contradiction. $\blacksquare$

    Rolle's theorem

    The MVT's special case and stepping stone: start and end at the same height, and somewhere in between your instantaneous slope must be zero — every round trip has a turning point.

    Theorem If $f$ is continuous on $[a,b]$, differentiable on $(a,b)$, and $f(a) = f(b)$, then there exists $c \in (a,b)$ with $f'(c) = 0$. (Proof idea: the max or min of $f$ on $[a,b]$ either sits inside — where the derivative vanishes — or both extremes are at the endpoints, forcing $f$ constant.)
    Worked example $f(x) = x^2 - 4x + 3$ on $[1, 3]$: $f(1) = 0 = f(3)$. Rolle point: $f'(x) = 2x - 4 = 0$ at $c = 2$ — the vertex, dead center.
    Drill
    1. EASY Verify Rolle for $f(x) = \sin x$ on $[0, \pi]$.
      Solution
      $\sin 0 = \sin\pi = 0$; $f'(c) = \cos c = 0$ at $c = \tfrac\pi2$. ✓
    2. MED Why does Rolle fail for $f(x) = |x|$ on $[-1, 1]$ despite $f(-1) = f(1)$?
      Solution
      $f$ is not differentiable at 0, and indeed no point has slope 0 (slopes are $\pm1$). Hypotheses matter.
    3. HARD Show that between any two roots of $p(x) = x^4 - 4x + 1$ lies a root of $p'$; conclude $p$ has at most... how many real roots?
      Solution
      Rolle: between consecutive roots of $p$ sits a root of $p' = 4x^3 - 4$, which has exactly one real root ($x = 1$). So $p$ has at most 2 real roots. (It has exactly 2: $p(0) = 1 > 0$, $p(1) = -2 < 0$, $p(2) = 9 > 0$.)

    L'Hopital's rule

    For limits that collapse to $\frac00$ or $\frac\infty\infty$: compare the racers' speeds instead of positions — replace the ratio of functions by the ratio of their derivatives, and try again.

    Theorem If $\lim_{x\to a}\frac{f(x)}{g(x)}$ has form $\frac00$ or $\frac{\pm\infty}{\pm\infty}$, and $\lim_{x\to a}\frac{f'(x)}{g'(x)}$ exists (or is $\pm\infty$), then $$\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)}.$$ Other forms ($0\cdot\infty$, $\infty - \infty$, $1^\infty$, $0^0$, $\infty^0$) must be rewritten as quotients (or via ln) first.
    Worked example $\lim_{x\to0}\dfrac{e^x - 1 - x}{x^2}$ ($\tfrac00$): differentiate: $\dfrac{e^x - 1}{2x}$ (still $\tfrac00$): again: $\dfrac{e^x}{2} \to \dfrac12$. And a $1^\infty$: $\lim_{x\to\infty}\big(1 + \tfrac3x\big)^x = e^{\lim x\ln(1 + 3/x)} = e^{\lim \frac{\ln(1+3/x)}{1/x}} \xrightarrow{\text{L'H}} e^{\lim\frac{\frac{-3/x^2}{1+3/x}}{-1/x^2}} = e^3$.
    Pitfall Check the form first! $\lim_{x\to0}\frac{x}{\cos x}$ is $\frac{0}{1} = 0$ — L'Hôpital here would give $\frac{1}{-\sin x} \to$ nonsense. And don't quotient-rule: differentiate top and bottom separately.
    Drill
    1. EASY $\lim_{x\to0}\dfrac{\sin 3x}{x}$ via L'Hôpital.
      Solution
      $\frac{3\cos 3x}{1}\to 3$.
    2. MED $\lim_{x\to\infty}\dfrac{\ln x}{x^{0.1}} = ?$
      Solution
      $\frac{1/x}{0.1x^{-0.9}} = \frac{10}{x^{0.1}} \to 0$: any positive power of $x$ beats $\ln$.
    3. HARD $\lim_{x\to0^+} x^x = ?$
      Solution
      Form $0^0$: $\ln(x^x) = x\ln x = \frac{\ln x}{1/x} \xrightarrow{\text{L'H}} \frac{1/x}{-1/x^2} = -x \to 0$. So $x^x \to e^0 = 1$.

    Critical points

    Where can a function turn around? Only where its derivative is zero or fails to exist. These candidate locations are the critical points — the shortlist every optimization search begins with.

    Definition $c$ is a critical point of $f$ if $c$ is in the domain and $f'(c) = 0$ or $f'(c)$ does not exist. Fermat's theorem: if $f$ has a local extremum at an interior point $c$ and $f'(c)$ exists, then $f'(c) = 0$. The converse fails: $f(x) = x^3$ has $f'(0) = 0$ but no extremum.
    Worked example $f(x) = x^3 - 3x^2 - 9x + 4$: $f' = 3x^2 - 6x - 9 = 3(x-3)(x+1)$: critical points $x = -1, 3$. Also $g(x) = x^{2/3}$: $g' = \tfrac23 x^{-1/3}$ never zero but undefined at 0 — the cusp at 0 is a critical point (in fact the minimum).
    Drill
    1. EASY Critical points of $f(x) = x^2 - 6x$?
      Solution
      $f' = 2x - 6$: $x = 3$.
    2. MED Critical points of $f(x) = xe^{-x}$?
      Solution
      $f' = e^{-x}(1 - x) = 0$: $x = 1$ only ($e^{-x}$ never 0).
    3. HARD Find all critical points of $f(x) = |x^2 - 4|$.
      Solution
      Smooth pieces: $f' = \pm2x$, zero at $x = 0$. Corners where $x^2 = 4$: $x = \pm2$ (derivative jumps between $\mp 4$ and $\pm4$, so undefined). Critical points: $\{-2, 0, 2\}$ — minima at $\pm2$ (value 0), local max at 0 (value 4).

    Local extrema

    A local maximum is a hilltop: highest in its neighborhood, not necessarily on the map. Two tests classify critical points: watch the derivative's sign change (first-derivative test) or check the bend (second-derivative test).

    Definition $f$ has a local max at $c$ if $f(c) \ge f(x)$ for all $x$ near $c$ (local min: $\le$). First-derivative test: $f'$ flips $+ \to -$ at $c$: local max; $- \to +$: local min; no flip: neither. Second-derivative test: $f'(c) = 0$ and $f''(c) > 0$: local min; $f''(c) < 0$: local max; $f''(c) = 0$: inconclusive.
    Worked example Continue $f(x) = x^3 - 3x^2 - 9x + 4$, critical at $-1, 3$. $f'' = 6x - 6$: $f''(-1) = -12 < 0$: local max, $f(-1) = -1 - 3 + 9 + 4 = 9$. $f''(3) = 12 > 0$: local min, $f(3) = 27 - 27 - 27 + 4 = -23$.
    Drill
    1. EASY Classify the critical point of $f(x) = x^2 - 6x$.
      Solution
      $f'' = 2 > 0$: local (indeed global) min at $x = 3$, $f(3) = -9$.
    2. MED Classify the critical point of $f(x) = xe^{-x}$ at $x=1$.
      Solution
      $f'' = e^{-x}(x - 2)$: $f''(1) = -e^{-1} < 0$: local max, value $e^{-1} \approx 0.368$.
    3. HARD $f(x) = x^4$: show the second-derivative test fails at 0 but the first-derivative test succeeds.
      Solution
      $f' = 4x^3$, $f'' = 12x^2$: $f''(0) = 0$, inconclusive. But $f'$ flips $-\to+$ at 0: local min. (Same story with $x^3$: no flip, no extremum, and with $-x^4$: max. Degenerate criticals need the sign test — or higher derivatives.)

    Global extrema

    The global maximum is the highest point anywhere in the domain. On a closed interval, a continuous function must achieve one — and it can only hide at critical points or endpoints, so the search is a finite checklist.

    Theorem (Extreme Value Theorem.) A continuous function on a closed bounded interval $[a,b]$ attains a global max and min. Closed-interval method: evaluate $f$ at all critical points in $(a,b)$ and at $a$, $b$; the largest value is the global max, smallest the global min.
    Worked example $f(x) = x^3 - 3x$ on $[0, 2]$: $f' = 3x^2 - 3 = 0$ at $x = \pm1$; only $1 \in (0,2)$. Values: $f(0) = 0$, $f(1) = -2$, $f(2) = 2$. Global max 2 at $x=2$; global min $-2$ at $x=1$.
    Pitfall Open or unbounded domains void the guarantee: $f(x) = x$ on $(0,1)$ has neither max nor min; $f(x) = \frac1x$ on $(0,1]$ has a min but no max. Check the domain before promising extrema.
    Drill
    1. EASY Global extrema of $f(x) = x^2$ on $[-1, 2]$.
      Solution
      Candidates $x = -1, 0, 2$: values 1, 0, 4. Min 0 at 0; max 4 at 2.
    2. MED Global extrema of $f(x) = x + \frac4x$ on $[1, 4]$.
      Solution
      $f' = 1 - \frac4{x^2} = 0$ at $x = 2$. Values: $f(1) = 5$, $f(2) = 4$, $f(4) = 5$. Min 4 at 2; max 5 at both endpoints.
    3. HARD Find the global extrema of $f(x) = \sin x + \cos x$ on $[0, 2\pi]$.
      Solution
      $f' = \cos x - \sin x = 0$: $\tan x = 1$: $x = \tfrac\pi4, \tfrac{5\pi}4$. Values: $f(\tfrac\pi4) = \sqrt2$, $f(\tfrac{5\pi}4) = -\sqrt2$, $f(0) = f(2\pi) = 1$. Max $\sqrt2$, min $-\sqrt2$.

    Monotonicity

    The derivative's sign is the function's direction: positive means climbing, negative means falling. Splitting the domain at critical points into increasing/decreasing intervals gives you the function's whole storyline.

    Definition If $f' > 0$ on an interval, $f$ is strictly increasing there; $f' < 0$: strictly decreasing (both via MVT). Procedure: find critical points, test $f'$'s sign on each interval between them.
    Worked example $f(x) = x^3 - 3x^2 - 9x + 4$, $f' = 3(x-3)(x+1)$. Signs: $x < -1$: $(+)(-)(-) \Rightarrow +$, increasing; $-1 < x < 3$: $-$, decreasing; $x > 3$: $+$, increasing. Storyline: up to the peak at $-1$, down the valley to 3, up forever.
    Drill
    1. EASY Where is $f(x) = e^{-x^2}$ increasing?
      Solution
      $f' = -2xe^{-x^2}$: positive for $x < 0$. Increasing on $(-\infty, 0)$.
    2. MED Show $f(x) = x - \sin x$ is nondecreasing on all of $\mathbb{R}$; where is it momentarily flat?
      Solution
      $f' = 1 - \cos x \ge 0$ always; zero exactly at $x = 2k\pi$. Isolated flat points don't break monotonicity: $f$ is (weakly, in fact strictly) increasing.
    3. HARD Prove $e^x > 1 + x$ for all $x \ne 0$.
      Solution
      $g(x) = e^x - 1 - x$: $g' = e^x - 1$, negative for $x<0$, positive for $x>0$. So $g$ decreases to $g(0) = 0$ then increases: $g(x) > 0$ for $x \ne 0$. $\blacksquare$

    Concavity

    The second derivative reads the bend: concave up (holds water, $f'' > 0$) means the slope itself is rising; concave down means it's falling. Concavity tells you whether a function lies above or below its tangents — the geometric soul of convexity (Ch 15).

    Definition $f$ is concave up on an interval if $f'$ is increasing there (guaranteed when $f'' > 0$); concave down if $f'$ is decreasing ($f'' < 0$). Concave-up curves lie above their tangent lines and below their chords.
    Worked example $f(x) = x^4 - 6x^2$: $f'' = 12x^2 - 12 = 12(x-1)(x+1)$. Concave up on $(-\infty,-1)$ and $(1,\infty)$; concave down on $(-1, 1)$ — a W-shaped curve with a dome in the middle.
    Where this goes "Concave up everywhere" is convexity — the property that makes optimization provably easy (Ch 15) and powers Jensen's inequality (Ch 11).
    Drill
    1. EASY Concavity of $f(x) = e^x$? Of $\ln x$?
      Solution
      $e^x$: $f'' = e^x > 0$, concave up everywhere. $\ln x$: $f'' = -\frac1{x^2} < 0$, concave down everywhere.
    2. MED Where is $f(x) = \frac{1}{1+x^2}$ concave up?
      Solution
      $f' = \frac{-2x}{(1+x^2)^2}$, $f'' = \frac{-2(1+x^2)^2 + 2x\cdot2(1+x^2)\cdot2x}{(1+x^2)^4} = \frac{6x^2 - 2}{(1+x^2)^3}$. Concave up where $x^2 > \tfrac13$: $|x| > \tfrac{1}{\sqrt3}$.
    3. HARD Prove: if $f'' > 0$ on an interval, the graph lies above each tangent line.
      Solution
      Fix $a$; let $g(x) = f(x) - [f(a) + f'(a)(x-a)]$. Then $g(a) = 0$, $g'(x) = f'(x) - f'(a)$, and $g'' = f'' > 0$ makes $f'$ strictly increasing, so $g' < 0$ for $x<a$ and $g' > 0$ for $x>a$: $g$ has a strict minimum 0 at $a$: $g \ge 0$, equality only at $a$. $\blacksquare$

    Inflection points

    An inflection point is where the bend flips — concave up hands over to concave down. The tangent line crosses the curve there. In a growth curve it is the moment growth stops accelerating and starts decelerating.

    Definition $c$ is an inflection point if $f$ is continuous at $c$ and concavity changes across it. Necessary condition when $f''$ exists: $f''(c) = 0$ — but not sufficient ($x^4$ has $f''(0) = 0$ and no inflection). Verify the sign of $f''$ actually changes.
    Worked example Logistic curve $f(x) = \frac{1}{1+e^{-x}}$: $f'' = f(1-f)(1-2f)$ (using $f' = f(1-f)$). $f'' = 0$ when $f = \tfrac12$, i.e. $x = 0$; sign flips (up for $x<0$, down for $x>0$). Inflection at $(0, \tfrac12)$ — the point of fastest growth.
    Drill
    1. EASY Inflection points of $f(x) = x^3$?
      Solution
      $f'' = 6x$: changes sign at 0. Inflection at $(0,0)$.
    2. MED Find the inflection points of $f(x) = x^4 - 6x^2$.
      Solution
      From before, $f'' = 12(x^2 - 1)$ flips at $x = \pm1$: inflections at $(\pm1, -5)$.
    3. HARD Show $f(x) = xe^{-x}$ has exactly one inflection point and find it.
      Solution
      $f' = (1-x)e^{-x}$, $f'' = (x - 2)e^{-x}$: zero only at $x = 2$, sign flips $-\to+$. Inflection at $(2, 2e^{-2}) \approx (2, 0.271)$.

    Curve sketching

    Put the toolkit together: domain, intercepts, symmetry, asymptotes, increase/decrease, extrema, concavity, inflections — and the graph draws itself. Sketching is how you audit a function (or a loss curve) before trusting any single number about it.

    Definition Checklist: (1) domain and discontinuities; (2) intercepts; (3) symmetry (even/odd/periodic); (4) asymptotes (vertical, horizontal, slant); (5) $f'$: critical points, monotonic intervals, extrema; (6) $f''$: concavity, inflections; (7) plot key points, connect respecting all constraints.
    Worked example $f(x) = \dfrac{x}{x^2+1}$. Domain $\mathbb{R}$; odd; $f \to 0$ at $\pm\infty$ (horizontal asymptote $y = 0$); $f' = \frac{1 - x^2}{(x^2+1)^2}$: increasing on $(-1,1)$, max $f(1) = \tfrac12$, min $f(-1) = -\tfrac12$; $f'' = \frac{2x(x^2 - 3)}{(x^2+1)^3}$: inflections at $x = 0, \pm\sqrt3$. Sketch: an odd S-wave rising to $\tfrac12$ at 1 then decaying back to 0.
    Drill
    1. EASY Which features does $f(x) = e^{-x^2}$ have: symmetry, max, asymptotes?
      Solution
      Even; max 1 at 0; horizontal asymptote $y=0$ both ways. The bell curve.
    2. MED Sketch data for $f(x) = \frac{x^2}{x - 1}$: asymptotes and extrema.
      Solution
      Vertical $x = 1$. Division: $f = x + 1 + \frac{1}{x-1}$: slant asymptote $y = x+1$. $f' = 1 - \frac{1}{(x-1)^2} = 0$ at $x = 0, 2$: local max $f(0) = 0$, local min $f(2) = 4$.
    3. HARD For $f(x) = x^{2/3}(x - 5)$, find the cusp and classify the critical points.
      Solution
      $f = x^{5/3} - 5x^{2/3}$: $f' = \tfrac53 x^{2/3} - \tfrac{10}{3}x^{-1/3} = \tfrac{5}{3}x^{-1/3}(x - 2)$. Undefined at 0 (cusp; $f' \to +\infty$ from left, $-\infty$ from right: local max at 0, value 0). Zero at $x = 2$: sign $-\to+$: local min $f(2) = 2^{2/3}(-3) \approx -4.76$.

    Optimization

    Turn a "best possible" question into calculus: express the goal as a one-variable function, respect the constraints, and hunt its extrema through critical points. This is the ancestral form of everything Chapter 15 does at scale.

    Definition Recipe: (1) name variables, draw the picture; (2) write the objective; (3) use constraints to eliminate variables down to one; (4) determine the domain; (5) find critical points and compare with endpoints; (6) answer the actual question (including units).
    Worked example A farmer has 100 m of fence for a rectangular pen against a river (no fence on the river side). Maximize area. Sides: $x$ (perpendicular, two of them) and $y$: $2x + y = 100$, $A = xy = x(100 - 2x)$. $A' = 100 - 4x = 0$: $x = 25$, $y = 50$, $A = 1250$ m². Endpoints ($x = 0, 50$) give 0. ✓
    Think first Among all rectangles with perimeter 20, which has the largest area — and can you guess before differentiating?
    Reveal
    The square (5×5, area 25). $A = x(10 - x)$ peaks at $x = 5$. Symmetry usually wins.
    Drill
    1. EASY Find two nonnegative numbers summing to 10 with maximal product.
      Solution
      $P = x(10-x)$, $P' = 10 - 2x = 0$: $x = 5$: $5 \times 5 = 25$.
    2. MED An open-top box is made from a 12×12 sheet by cutting squares of side $x$ from the corners and folding. Maximize the volume.
      Solution
      $V = x(12 - 2x)^2$, $0 < x < 6$. $V' = (12-2x)^2 + x\cdot2(12-2x)(-2) = (12-2x)(12 - 6x) = 0$: $x = 2$ (interior). $V(2) = 2\cdot64 = 128$.
    3. HARD Find the point on the parabola $y = x^2$ closest to $(3, 0)$.
      Solution
      Minimize $D(x) = (x-3)^2 + x^4$. $D' = 2(x-3) + 4x^3 = 0 \Rightarrow 2x^3 + x - 3 = 0 \Rightarrow (x-1)(2x^2 + 2x + 3) = 0$. The quadratic has negative discriminant: $x = 1$ only. Point $(1, 1)$, distance $\sqrt{4 + 1} = \sqrt5$. ($D'' = 2 + 12x^2 > 0$: a true min.)

    Extrema hide in both places: $f(x)=x$ on $[0,1]$ peaks at an endpoint; $f(x)=-x^2$ on $[-1,1]$ at a critical point.

    Antiderivatives

    Run differentiation backwards: an antiderivative of $f$ is any function whose derivative is $f$. There are infinitely many, all vertical shifts of each other — hence the "+ C".

    Definition $F$ is an antiderivative of $f$ on an interval if $F' = f$ there. If $F$ is one antiderivative, the complete family is $F(x) + C$, $C \in \mathbb{R}$ (by the MVT corollary: equal derivatives differ by a constant).
    Worked example An object has velocity $v(t) = 6t^2 - 4$ and position $s(0) = 3$. Antidifferentiate: $s(t) = 2t^3 - 4t + C$; the initial condition pins $C$: $s(0) = C = 3$. So $s(t) = 2t^3 - 4t + 3$.
    Drill
    1. EASY Give an antiderivative of $f(x) = 3x^2 + \cos x$.
      Solution
      $x^3 + \sin x$ (+ C).
    2. MED Find $f$ given $f''(x) = 12x$, $f'(0) = 2$, $f(0) = 1$.
      Solution
      $f' = 6x^2 + 2$ (constant from $f'(0)$); $f = 2x^3 + 2x + 1$.
    3. HARD Why is "the" antiderivative of $\frac1x$ written $\ln|x| + C$ — and is even that the full truth?
      Solution
      For $x>0$, $(\ln x)' = \frac1x$; for $x<0$, $(\ln(-x))' = \frac{-1}{-x} = \frac1x$: together $\ln|x|$. Full truth: the domain is two disconnected intervals, so the constants may differ on each side — $\ln|x| + C_1$ on $x>0$ and $\ln|x| + C_2$ on $x<0$ is the most general antiderivative.

    Indefinite integrals

    The indefinite integral $\int f(x)\,dx$ is notation for the whole antiderivative family. Each derivative rule, read right-to-left, becomes an integration rule — a basic table you should know cold.

    Definition $$\int x^n dx = \frac{x^{n+1}}{n+1} + C \;(n \ne -1), \quad \int \frac{dx}{x} = \ln|x| + C, \quad \int e^x dx = e^x + C,$$ $$\int \sin x\,dx = -\cos x + C, \quad \int\cos x\,dx = \sin x + C, \quad \int \sec^2 x\,dx = \tan x + C, \quad \int\frac{dx}{1+x^2} = \arctan x + C.$$ Linearity: $\int(af + bg) = a\int f + b\int g$.
    Worked example $\int\Big(4x^3 - \dfrac2{x} + 5e^x\Big)dx = x^4 - 2\ln|x| + 5e^x + C$. Always check by differentiating: $(x^4)' = 4x^3$ ✓, $(-2\ln|x|)' = -\tfrac2x$ ✓, $(5e^x)' = 5e^x$ ✓.
    Pitfall There is no product rule for integrals: $\int fg \ne \int f\int g$. Products need substitution or parts. And never forget $+C$ — initial conditions live there.
    Drill
    1. EASY $\int (x^2 + 3)\,dx = ?$
      Solution
      $\frac{x^3}{3} + 3x + C$.
    2. MED $\int \dfrac{x^2 + 1}{x}\,dx = ?$
      Solution
      Split: $\int (x + \tfrac1x)dx = \frac{x^2}{2} + \ln|x| + C$.
    3. HARD $\int \tan^2 x\,dx = ?$
      Solution
      $\tan^2 = \sec^2 - 1$: $\int = \tan x - x + C$.

    Riemann sums

    To measure the area under a curve, tile it with thin rectangles and add them up. Finer tiles, better estimate. The definite integral is the limit of this process — area as an infinitely refined sum.

    Definition Partition $[a,b]$ into $n$ slices of width $\Delta x = \frac{b-a}{n}$; pick a sample point $x_i^*$ in each. The Riemann sum is $$S_n = \sum_{i=1}^n f(x_i^*)\,\Delta x.$$ Left/right/midpoint rules choose $x_i^*$ at the left edge, right edge, or center. If $S_n$ converges to the same value for every choice as $n\to\infty$, that value is $\int_a^b f(x)\,dx$.
    Worked example Estimate $\int_0^1 x^2 dx$ with $n = 4$ right endpoints: $\Delta x = \tfrac14$, heights at $\tfrac14, \tfrac12, \tfrac34, 1$: $S_4 = \tfrac14\big(\tfrac1{16} + \tfrac14 + \tfrac9{16} + 1\big) = \tfrac14\cdot\tfrac{30}{16} = \tfrac{15}{32} = 0.46875$. True value $\tfrac13$; right endpoints overshoot an increasing function. Midpoint with $n=4$ gives $0.328$ — much closer.
    Explore

    Increase n and watch left, midpoint, and right Riemann sums squeeze onto the true area under x².

    Drill
    1. EASY Left sum for $\int_0^2 x\,dx$ with $n = 2$.
      Solution
      $\Delta x = 1$; heights $f(0) = 0$, $f(1) = 1$: $S = 1$. (True: 2.)
    2. MED Show that for increasing $f$, left sums underestimate and right sums overestimate $\int_a^b f$.
      Solution
      On each slice, the left height is the min of $f$ there and the right height the max (monotonicity), so each rectangle under/over-covers the strip. Summing preserves the inequalities.
    3. HARD Compute $\lim_{n\to\infty}\sum_{i=1}^n \frac{i^2}{n^3}$ by recognizing a Riemann sum.
      Solution
      $\sum \frac{1}{n}\big(\frac in\big)^2$ is the right-endpoint sum for $\int_0^1 x^2 dx = \tfrac13$.

    Definite integrals

    The definite integral $\int_a^b f\,dx$ is a number: the signed area between the curve and the axis from $a$ to $b$ — area above counts positive, below negative. It accumulates anything: distance from velocity, probability from density, total loss from loss rate.

    Definition $\int_a^b f(x)\,dx = \lim_{n\to\infty} \sum_{i=1}^n f(x_i^*)\Delta x$ (exists for continuous $f$). Properties: linearity; additivity $\int_a^b = \int_a^c + \int_c^b$; $\int_a^a = 0$; $\int_b^a = -\int_a^b$; comparison: $f \le g \Rightarrow \int_a^b f \le \int_a^b g$ (for $a < b$).
    Worked example $\int_0^{2\pi}\sin x\,dx = 0$: the hump above $[0,\pi]$ (area 2) exactly cancels the dip below $[\pi, 2\pi]$ (area $-2$). Total unsigned area is $\int_0^{2\pi}|\sin x|\,dx = 4$.
    Pitfall "Area under the curve" is signed. If asked for geometric area, split at the zero crossings and integrate $|f|$.
    Drill
    1. EASY From geometry (no antiderivatives): $\int_0^3 (2x)\,dx = ?$
      Solution
      Triangle: $\tfrac12\cdot3\cdot6 = 9$.
    2. MED Given $\int_0^5 f = 12$ and $\int_3^5 f = 4$: find $\int_0^3 f$ and $\int_5^0 2f$.
      Solution
      $\int_0^3 = 12 - 4 = 8$; $\int_5^0 2f = -2\cdot12 = -24$.
    3. HARD Evaluate $\int_{-2}^2 \big(x^3\cos x + \sqrt{4 - x^2}\big)dx$ with symmetry.
      Solution
      $x^3\cos x$ is odd: integral 0. $\sqrt{4-x^2}$ is the upper semicircle of radius 2: area $\tfrac12\pi\cdot4 = 2\pi$. Total $2\pi$.

    Fundamental theorem of calculus

    The theorem that makes calculus a subject rather than two: accumulation and rate-of-change are inverse operations. Part 1: the running area under $f$ has derivative $f$. Part 2: to total up $f$, just evaluate any antiderivative at the endpoints.

    Theorem Let $f$ be continuous on $[a,b]$. FTC 1: $g(x) = \int_a^x f(t)\,dt$ is differentiable with $g'(x) = f(x)$. FTC 2: for any antiderivative $F$ of $f$: $$\int_a^b f(x)\,dx = F(b) - F(a).$$
    Worked example $\int_0^1 x^2 dx = \Big[\frac{x^3}{3}\Big]_0^1 = \frac13$ — the limit Archimedes needed exhaustion for, in one line. And an FTC-1 example: $\frac{d}{dx}\int_0^{x^2} e^{-t^2} dt = e^{-x^4}\cdot 2x$ (chain rule on the upper limit).
    Where this goes FTC is why probabilities come from integrating densities and densities from differentiating CDFs (Ch 11).
    Drill
    1. EASY $\int_1^e \frac{dx}{x} = ?$
      Solution
      $\ln e - \ln 1 = 1$.
    2. MED $\int_0^{\pi/2}\cos x\,dx$ and $\frac{d}{dx}\int_2^x \sqrt{1 + t^3}\,dt$.
      Solution
      $[\sin x]_0^{\pi/2} = 1$; and $\sqrt{1 + x^3}$ directly by FTC 1.
    3. HARD Find and classify the critical points of $g(x) = \int_0^x t(t - 3)\,dt$ without integrating.
      Solution
      $g'(x) = x(x-3)$: critical at 0 and 3. $g'' = 2x - 3$: $g''(0) = -3$: local max; $g''(3) = 3$: local min. FTC turns integral questions into derivative questions.
    $\frac{d}{dx}\int_x^5 \sin(t^2)\,dt = ?$
    Flip the limits: $\int_x^5 = -\int_5^x$, then FTC 1 gives $-\sin(x^2)$.

    Substitution integration

    Substitution is the chain rule in reverse: spot a nested function and its inner derivative loitering nearby, rename the inside as $u$, and the integral collapses. It is the single most used integration technique.

    Definition If $u = g(x)$ then $du = g'(x)dx$ and $$\int f(g(x))g'(x)\,dx = \int f(u)\,du.$$ For definite integrals, transform the limits too: $\int_a^b f(g(x))g'(x)dx = \int_{g(a)}^{g(b)} f(u)\,du$.
    Worked example $\int_0^2 x e^{x^2}dx$: let $u = x^2$, $du = 2x\,dx$, limits $0 \to 0$, $2 \to 4$: $$\int_0^4 e^u\,\frac{du}{2} = \frac12\big[e^u\big]_0^4 = \frac{e^4 - 1}{2} \approx 26.8.$$
    Pitfall Change the limits or change back to $x$ — never both, never neither. Writing $\frac12 e^u\big|_0^2$ (old limits, new variable) is the classic lost-point.
    Drill
    1. EASY $\int \cos(3x)\,dx = ?$
      Solution
      $u = 3x$: $\tfrac13\sin 3x + C$.
    2. MED $\int \frac{\ln x}{x}dx = ?$
      Solution
      $u = \ln x$, $du = \frac{dx}x$: $\int u\,du = \frac{(\ln x)^2}{2} + C$.
    3. HARD $\int_0^{\pi/2}\frac{\sin x}{1 + \cos^2 x}dx = ?$
      Solution
      $u = \cos x$, $du = -\sin x\,dx$; limits $1 \to 0$: $\int_1^0\frac{-du}{1+u^2} = \int_0^1\frac{du}{1+u^2} = \arctan 1 = \frac\pi4$.

    Integration by parts

    The product rule in reverse: trade the integral of $u\,dv$ for the (hopefully easier) integral of $v\,du$. It shines when one factor simplifies under differentiation (polynomials) while the other survives integration ($e^x$, $\sin$, $\cos$).

    Definition $$\int u\,dv = uv - \int v\,du.$$ Choosing $u$: LIATE priority (Log, Inverse trig, Algebraic, Trig, Exponential) — differentiate the earlier, integrate the later.
    Worked example $\int x e^x dx$: $u = x$, $dv = e^x dx$; $du = dx$, $v = e^x$: $xe^x - \int e^x dx = (x-1)e^x + C$. Sneakier: $\int \ln x\,dx$: $u = \ln x$, $dv = dx$: $x\ln x - \int x\cdot\frac{dx}{x} = x\ln x - x + C$.
    Drill
    1. EASY $\int x\cos x\,dx = ?$
      Solution
      $u = x$, $dv = \cos x\,dx$: $x\sin x + \cos x + C$.
    2. MED $\int x^2 e^x dx = ?$ (parts twice)
      Solution
      First: $x^2e^x - 2\int xe^x = x^2e^x - 2(x-1)e^x = (x^2 - 2x + 2)e^x + C$.
    3. HARD $\int e^x\sin x\,dx = ?$ (the boomerang)
      Solution
      Parts twice: $I = e^x\sin x - \int e^x\cos x = e^x\sin x - \big(e^x\cos x + I\big)$. Solve: $2I = e^x(\sin x - \cos x)$: $I = \frac{e^x(\sin x - \cos x)}{2} + C$.

    Partial fraction integration

    Rational functions integrate by demolition: split $\frac{p(x)}{q(x)}$ into simple pieces — constants over linear factors, which integrate to logarithms, plus arctangent pieces from irreducible quadratics.

    Definition After polynomial division (if $\deg p \ge \deg q$), factor $q$ and expand: each factor $(x - a)^k$ contributes $\frac{A_1}{x-a} + \cdots + \frac{A_k}{(x-a)^k}$; each irreducible $(x^2 + bx + c)^k$ contributes terms $\frac{B_j x + C_j}{(x^2+bx+c)^j}$. Solve for the constants; integrate termwise: $\int\frac{dx}{x - a} = \ln|x-a|$, $\int \frac{dx}{x^2 + 1} = \arctan x$.
    Worked example $\int\frac{x + 7}{x^2 - x - 6}dx$. Factor: $(x-3)(x+2)$. $\frac{x+7}{(x-3)(x+2)} = \frac{A}{x-3} + \frac{B}{x+2}$: $x + 7 = A(x+2) + B(x-3)$. At $x = 3$: $10 = 5A$, $A = 2$. At $x = -2$: $5 = -5B$, $B = -1$. Integral: $2\ln|x-3| - \ln|x+2| + C$.
    Drill
    1. EASY $\int \frac{dx}{x(x+1)} = ?$
      Solution
      $\frac1{x(x+1)} = \frac1x - \frac1{x+1}$: $\ln\big|\frac{x}{x+1}\big| + C$.
    2. MED $\int\frac{2x + 3}{(x-1)^2}dx = ?$
      Solution
      $\frac{2x+3}{(x-1)^2} = \frac{2}{x-1} + \frac{5}{(x-1)^2}$ (check: $2(x-1) + 5 = 2x + 3$ ✓): $2\ln|x-1| - \frac{5}{x-1} + C$.
    3. HARD $\int_0^1\frac{dx}{(x+1)(x^2+1)} = ?$
      Solution
      $\frac{1}{(x+1)(x^2+1)} = \frac{A}{x+1} + \frac{Bx + C}{x^2+1}$. $1 = A(x^2+1) + (Bx+C)(x+1)$. $x=-1$: $1 = 2A$, $A = \tfrac12$. Compare $x^2$: $0 = A + B$, $B = -\tfrac12$. Constant: $1 = A + C$, $C = \tfrac12$. Integral: $\tfrac12\ln|x+1| - \tfrac14\ln(x^2+1) + \tfrac12\arctan x\Big|_0^1 = \tfrac12\ln2 - \tfrac14\ln2 + \tfrac\pi8 = \tfrac14\ln 2 + \tfrac\pi8 \approx 0.566$.

    Improper integrals

    Integrals over infinite ranges, or across a blow-up point, are defined as limits of ordinary ones. Some infinite regions have finite area — the whole of probability theory lives on this fact (densities integrate to 1 over all of $\mathbb{R}$).

    Definition $\int_a^\infty f\,dx = \lim_{t\to\infty}\int_a^t f\,dx$ (convergent if the limit is finite). Unbounded integrand at $b$: $\int_a^b f = \lim_{t\to b^-}\int_a^t f$. Benchmark ($p$-integrals): $\int_1^\infty \frac{dx}{x^p}$ converges iff $p > 1$; $\int_0^1\frac{dx}{x^p}$ converges iff $p < 1$.
    Worked example $\int_1^\infty\frac{dx}{x^2} = \lim_{t\to\infty}\Big[-\frac1x\Big]_1^t = \lim_{t\to\infty}\Big(1 - \frac1t\Big) = 1$ — finite area under an infinite tail. But $\int_1^\infty \frac{dx}{x} = \lim \ln t = \infty$: the harmonic tail diverges. The boundary between them is exactly $p = 1$.
    Drill
    1. EASY $\int_0^\infty e^{-x}dx = ?$
      Solution
      $[-e^{-x}]_0^\infty = 0 - (-1) = 1$.
    2. MED Does $\int_0^1\frac{dx}{\sqrt x}$ converge? Evaluate if so.
      Solution
      $p = \tfrac12 < 1$: converges. $[2\sqrt x]_0^1 = 2$.
    3. HARD Evaluate $\int_{-\infty}^{\infty}\frac{dx}{1 + x^2}$ and explain why the answer is beautiful.
      Solution
      $[\arctan x]_{-\infty}^{\infty} = \frac\pi2 - (-\frac\pi2) = \pi$. The area under the Cauchy bell is exactly π — and dividing by π gives the Cauchy probability density (Ch 11), a distribution so heavy-tailed its mean doesn't exist.

    Sequences and limits

    A sequence is an infinite list $a_1, a_2, a_3, \dots$ — a function on the natural numbers. Its limit, if any, is the value the terms crowd onto. Iterative algorithms produce sequences; "does training converge?" is literally a sequence-limit question.

    Definition $\lim_{n\to\infty} a_n = L$ iff for every $\varepsilon > 0$ there is $N$ with $n > N \Rightarrow |a_n - L| < \varepsilon$. Key facts: monotone + bounded $\Rightarrow$ convergent (the completeness of $\mathbb{R}$); $|r| < 1 \Rightarrow r^n \to 0$; $\frac{n!}{n^n}\to0$; $n^{1/n}\to1$; $\big(1 + \frac xn\big)^n \to e^x$.
    Worked example $a_{n+1} = \sqrt{2 + a_n}$, $a_1 = \sqrt2$. Bounded above by 2 (induction: $a_n < 2 \Rightarrow a_{n+1} < \sqrt4 = 2$) and increasing, so it converges. The limit satisfies $L = \sqrt{2 + L}$: $L^2 - L - 2 = 0$, $L = 2$.
    Drill
    1. EASY $\lim_{n\to\infty}\frac{3n^2 + n}{n^2 + 5} = ?$
      Solution
      3 (leading terms).
    2. MED Does $a_n = (-1)^n\frac{n}{n+1}$ converge?
      Solution
      No: even terms $\to 1$, odd terms $\to -1$. (But $|a_n| \to 1$.)
    3. HARD Show $a_n = \frac{2^n}{n!} \to 0$.
      Solution
      For $n \ge 2$: $\frac{a_{n+1}}{a_n} = \frac{2}{n+1} \le \frac23$, so $a_n \le a_2 (\tfrac23)^{n-2} = 2(\tfrac23)^{n-2} \to 0$. Squeeze with $0$. $\blacksquare$ Factorials beat exponentials.

    Infinite series

    A series adds infinitely many terms. The meaning: track the running total (partial sums); if those converge, the series has that sum. Whether an infinite sum makes sense at all is the entire subtlety.

    Definition $\sum_{n=1}^\infty a_n = \lim_{N\to\infty} S_N$ where $S_N = \sum_{n=1}^N a_n$, if the limit exists. Divergence test: if $a_n \not\to 0$ the series diverges. Converse fails: the harmonic series $\sum\frac1n$ has $a_n \to 0$ yet diverges.
    Worked example Telescoping: $\sum_{n=1}^\infty \frac{1}{n(n+1)} = \sum\big(\frac1n - \frac1{n+1}\big)$. Partial sum: $S_N = 1 - \frac{1}{N+1} \to 1$. Sum: 1. And why the harmonic series diverges: group terms $\frac12, (\frac13 + \frac14) > \frac12, (\frac15 + \cdots + \frac18) > \frac12, \dots$ — infinitely many halves.
    Drill
    1. EASY Does $\sum_{n=1}^\infty \frac{n}{2n+1}$ converge?
      Solution
      Terms $\to \tfrac12 \ne 0$: diverges.
    2. MED Compute $\sum_{n=2}^\infty \frac{2}{n^2 - 1}$.
      Solution
      $\frac{2}{(n-1)(n+1)} = \frac1{n-1} - \frac1{n+1}$: partial sums telescope with two leftovers: $S_N = 1 + \frac12 - \frac1N - \frac1{N+1} \to \frac32$.
    3. HARD A ball drops from 1 m and each bounce returns to $\tfrac23$ of its previous height. Total vertical distance traveled?
      Solution
      Down 1, then each bounce contributes up+down $2(\tfrac23)^k$: total $= 1 + 2\sum_{k=1}^\infty(\tfrac23)^k = 1 + 2\cdot\frac{2/3}{1/3} = 1 + 4 = 5$ m.

    Convergence tests

    Most series can't be summed in closed form, but you can still decide whether they converge. Each test compares the tail of your series with something understood: an integral, a geometric series, another series.

    Definition For positive terms: comparison ($a_n \le b_n$, $\sum b_n$ converges $\Rightarrow \sum a_n$ converges); limit comparison ($a_n/b_n \to c \in (0,\infty)$: same fate); integral test ($\sum f(n)$ vs $\int f$, $f$ positive decreasing) — gives the $p$-series rule: $\sum \frac{1}{n^p}$ converges iff $p > 1$; ratio test ($|a_{n+1}/a_n| \to L$: converges if $L < 1$, diverges if $L > 1$, silent at 1); root test ($|a_n|^{1/n}\to L$, same verdicts). Alternating series test: terms alternate, decrease in magnitude to 0 $\Rightarrow$ converge. Absolute convergence ($\sum|a_n| < \infty$) implies convergence.
    Worked example $\sum \frac{n^2}{2^n}$: ratio $\frac{(n+1)^2}{2^{n+1}}\cdot\frac{2^n}{n^2} = \frac12\big(1 + \frac1n\big)^2 \to \frac12 < 1$: converges. $\sum\frac{1}{\sqrt n}$: $p = \tfrac12 \le 1$: diverges. $\sum\frac{(-1)^n}{n}$: alternating, terms shrink to 0: converges (to $-\ln 2$) — but not absolutely.
    Pitfall The ratio test says nothing at $L = 1$ — both $\sum\frac1n$ (diverges) and $\sum\frac1{n^2}$ (converges) have ratio limit 1. Reach for comparison or the integral test instead.
    Drill
    1. EASY Does $\sum\frac{1}{n^3}$ converge?
      Solution
      $p = 3 > 1$: yes.
    2. MED Test $\sum \frac{3^n}{n!}$.
      Solution
      Ratio: $\frac{3}{n+1} \to 0 < 1$: converges (its sum is $e^3 - 1$ if starting at $n=1$).
    3. HARD Test $\sum_{n=2}^\infty \frac{1}{n\ln n}$.
      Solution
      Integral test: $\int_2^\infty\frac{dx}{x\ln x} = [\ln\ln x]_2^\infty = \infty$: diverges — barely. (With $(\ln n)^2$ in the denominator it would converge.)

    Geometric series

    The one series family you can always sum exactly: each term is the last times a fixed ratio $r$. It converges precisely when $|r| < 1$, and its sum formula powers everything from repeating decimals to discounted rewards in RL.

    Definition $$\sum_{n=0}^\infty ar^n = \frac{a}{1 - r} \quad (|r| < 1); \qquad \sum_{n=0}^{N-1} ar^n = a\,\frac{1 - r^N}{1 - r}.$$ Diverges for $|r| \ge 1$.
    Worked example $0.\overline{7} = 0.7 + 0.07 + \cdots = \frac{0.7}{1 - 0.1} = \frac79$. RL flavor: reward 1 per step, discount $\gamma = 0.99$: total discounted return $\sum_{t=0}^\infty \gamma^t = \frac{1}{1 - 0.99} = 100$ — the "effective horizon" $\frac{1}{1-\gamma}$ of Ch 25.
    Where this goes Discounted returns (Ch 25) are geometric series; so are the eigen-decompositions of $(I - \gamma P)^{-1}$ behind value functions.
    Drill
    1. EASY $\sum_{n=0}^\infty \big(\tfrac13\big)^n = ?$
      Solution
      $\frac{1}{1 - 1/3} = \frac32$.
    2. MED $\sum_{n=2}^\infty \frac{5}{4^n} = ?$
      Solution
      First term $\frac{5}{16}$, ratio $\frac14$: $\frac{5/16}{3/4} = \frac{5}{12}$.
    3. HARD For which $x$ does $\sum_{n=0}^\infty (x - 2)^n$ converge, and to what?
      Solution
      Ratio $r = x - 2$: need $|x - 2| < 1$, i.e. $1 < x < 3$. Sum $= \frac{1}{1 - (x-2)} = \frac{1}{3 - x}$.

    Power series

    A power series is a polynomial that never ends: $\sum c_n (x - a)^n$. Each one converges on an interval centered at $a$ — inside it, the series behaves like the friendliest function imaginable: differentiate and integrate it term by term.

    Definition $\sum_{n=0}^\infty c_n(x-a)^n$ has a radius of convergence $R \in [0, \infty]$: absolute convergence for $|x - a| < R$, divergence for $|x-a| > R$ (endpoints case-by-case). Compute $R$ via ratio/root test. Within $(a-R, a+R)$: term-by-term differentiation and integration are valid and preserve $R$.
    Worked example $\sum_{n=1}^\infty \frac{x^n}{n}$: ratio $\big|\frac{x^{n+1}/(n+1)}{x^n/n}\big| = |x|\frac{n}{n+1} \to |x|$: $R = 1$. Endpoints: $x = 1$ harmonic — diverges; $x = -1$ alternating harmonic — converges. Interval: $[-1, 1)$. (Its sum is $-\ln(1-x)$.)
    Drill
    1. EASY Radius of convergence of $\sum n! \,x^n$?
      Solution
      Ratio $(n+1)|x| \to \infty$ unless $x = 0$: $R = 0$.
    2. MED Radius of $\sum \frac{x^n}{n!}$?
      Solution
      Ratio $\frac{|x|}{n+1}\to0 < 1$ always: $R = \infty$ (it's $e^x$).
    3. HARD Start from $\frac{1}{1-x} = \sum_{n\ge0} x^n$ ($|x|<1$) and derive a series for $\ln(1+x)$, then estimate $\ln 1.1$ to 4 decimals.
      Solution
      Replace $x \to -t$: $\frac1{1+t} = \sum (-1)^n t^n$. Integrate 0 to $x$: $\ln(1+x) = \sum_{n\ge0}(-1)^n\frac{x^{n+1}}{n+1} = x - \frac{x^2}2 + \frac{x^3}3 - \cdots$. At $x = 0.1$: $0.1 - 0.005 + 0.000333 - 0.000025 = 0.095308\ldots \approx 0.0953$. (True $\ln 1.1 = 0.0953102$.)

    Taylor series

    Build a polynomial that agrees with $f$ at a point to every order: match the value, the slope, the bend, and on forever. For nice functions the resulting series is the function — the ultimate local-to-global move, and the origin of every approximation in numerical computing.

    Definition The Taylor series of $f$ at $a$: $$f(x) \sim \sum_{n=0}^\infty \frac{f^{(n)}(a)}{n!}(x - a)^n.$$ The degree-$N$ truncation is the Taylor polynomial $T_N$; Lagrange remainder: $f(x) - T_N(x) = \frac{f^{(N+1)}(\xi)}{(N+1)!}(x-a)^{N+1}$ for some $\xi$ between $a$ and $x$ — small when derivatives are controlled and $x$ is near $a$.
    Worked example $f = \ln x$ at $a = 1$: $f' = x^{-1}, f'' = -x^{-2}, f''' = 2x^{-3}$, so $f^{(n)}(1) = (-1)^{n-1}(n-1)!$: $$\ln x = (x-1) - \frac{(x-1)^2}{2} + \frac{(x-1)^3}{3} - \cdots \quad (0 < x \le 2).$$ Estimate $\ln 1.2$ with 3 terms: $0.2 - 0.02 + 0.00267 = 0.18267$ (true $0.18232$).
    Explore

    Raise the degree and watch Taylor polynomials of sin x (at 0) hug the curve further and further out.

    Where this goes The second-order Taylor expansion of the loss (gradient + Hessian, Ch 9) justifies Newton's method (Ch 15/18) and explains why curvature governs learning rates.
    Drill
    1. EASY Taylor polynomial $T_2$ of $e^x$ at $a = 0$, and estimate $e^{0.2}$.
      Solution
      $1 + x + \frac{x^2}2$: $1 + 0.2 + 0.02 = 1.22$ (true 1.2214).
    2. MED Find the Taylor series of $\frac1x$ at $a = 2$.
      Solution
      $\frac1x = \frac{1}{2 + (x-2)} = \frac12\cdot\frac{1}{1 + \frac{x-2}{2}} = \sum_{n\ge0}\frac{(-1)^n}{2^{n+1}}(x-2)^n$, valid $|x - 2| < 2$.
    3. HARD Bound the error of approximating $\sin x$ by $x - \frac{x^3}{6}$ on $|x| \le 0.5$.
      Solution
      $T_3 = T_4$ for sine (the $x^4$ coefficient is 0), so use the degree-4 remainder: $|R_4| \le \frac{\max|f^{(5)}|}{5!}|x|^5 \le \frac{1}{120}(0.5)^5 = \frac{0.03125}{120} \approx 2.6\times10^{-4}$.

    Maclaurin series

    A Maclaurin series is just a Taylor series centered at 0 — but the ones below are worth carrying in your head. Half of applied math is recognizing these five patterns in the wild.

    Definition $$e^x = \sum_{n\ge0}\frac{x^n}{n!} \;(\text{all } x)\qquad \sin x = \sum_{n\ge0}\frac{(-1)^n x^{2n+1}}{(2n+1)!} \qquad \cos x = \sum_{n\ge0}\frac{(-1)^n x^{2n}}{(2n)!}$$ $$\frac{1}{1-x} = \sum_{n\ge0}x^n \;(|x|<1) \qquad \ln(1+x) = \sum_{n\ge1}\frac{(-1)^{n-1}x^n}{n} \;(-1<x\le1) \qquad (1+x)^\alpha = \sum_{n\ge0}\binom{\alpha}{n}x^n \;(|x|<1).$$
    Worked example Multiply series: $e^x\sin x = \big(1 + x + \tfrac{x^2}2 + \tfrac{x^3}6\big)\big(x - \tfrac{x^3}6\big) + O(x^5) = x + x^2 + \big(\tfrac12 - \tfrac16\big)x^3 + \big(\tfrac16 - \tfrac16\big)x^4 + O(x^5) = x + x^2 + \tfrac{x^3}{3} + O(x^5)$.
    Think first Substitute $x = i\theta$ into the series of $e^x$, and split real/imaginary. What do you get?
    Reveal
    $e^{i\theta} = \big(1 - \tfrac{\theta^2}{2!} + \tfrac{\theta^4}{4!} - \cdots\big) + i\big(\theta - \tfrac{\theta^3}{3!} + \cdots\big) = \cos\theta + i\sin\theta$ — Euler's formula (Ch 6), now proved.
    Drill
    1. EASY First three nonzero terms of the Maclaurin series of $e^{-x^2}$.
      Solution
      Substitute into $e^u$: $1 - x^2 + \frac{x^4}{2}$.
    2. MED Use series to compute $\lim_{x\to0}\frac{\sin x - x}{x^3}$.
      Solution
      $\sin x - x = -\frac{x^3}{6} + O(x^5)$: limit $-\frac16$. (Faster than triple L'Hôpital.)
    3. HARD Estimate $\int_0^1 e^{-x^2}dx$ to three decimals with the series.
      Solution
      $\int_0^1\sum\frac{(-1)^n x^{2n}}{n!}dx = \sum\frac{(-1)^n}{n!(2n+1)} = 1 - \tfrac13 + \tfrac1{10} - \tfrac1{42} + \tfrac1{216} - \tfrac1{1320}\cdots$ $= 1 - 0.3333 + 0.1 - 0.0238 + 0.00463 - 0.00076 \approx 0.7468$. Alternating: error below the first dropped term. Answer 0.747.

    Uniform convergence

    Pointwise convergence lets each $x$ converge at its own pace; uniform convergence forces one pace for all — the whole graph of $f_n$ enters an ε-tube around $f$ at once. It's the hypothesis that lets you safely swap limits with integrals, and its failure is a classic source of paradoxes.

    Definition $f_n \to f$ uniformly on $S$ iff $\sup_{x\in S}|f_n(x) - f(x)| \to 0$. Consequences: a uniform limit of continuous functions is continuous, and $\int_a^b f_n \to \int_a^b f$. Weierstrass M-test: if $|u_n(x)| \le M_n$ on $S$ and $\sum M_n < \infty$, then $\sum u_n$ converges uniformly on $S$. Power series converge uniformly on any closed interval strictly inside their radius.
    Worked example $f_n(x) = x^n$ on $[0, 1]$: pointwise limit $f(x) = 0$ for $x < 1$, $f(1) = 1$ — discontinuous! So convergence cannot be uniform (indeed $\sup_{[0,1)}|x^n - 0| = 1$ always). On $[0, 0.9]$ instead: $\sup = 0.9^n \to 0$ — uniform there.
    Pitfall Pointwise convergence does not preserve integrals: $f_n = n\,\mathbb{1}_{(0,1/n)}$ (a spike) $\to 0$ pointwise, yet $\int_0^1 f_n = 1 \not\to 0$. Uniformity (or dominated convergence, later) is what rules the spikes out.
    Drill
    1. EASY Does $f_n(x) = \frac{\sin nx}{n}$ converge uniformly on $\mathbb{R}$?
      Solution
      $\sup|f_n| \le \frac1n \to 0$: yes, uniformly to 0.
    2. MED Show $\sum_{n=1}^\infty \frac{\cos nx}{n^2}$ converges uniformly on $\mathbb{R}$.
      Solution
      M-test with $M_n = \frac1{n^2}$, $\sum M_n = \frac{\pi^2}6 < \infty$. ✓ (The sum is continuous everywhere.)
    3. HARD $f_n(x) = \frac{x}{1 + nx^2}$ on $\mathbb{R}$: find the pointwise limit and decide uniformity.
      Solution
      Pointwise limit 0. Maximize: $f_n'(x) = \frac{1 - nx^2}{(1+nx^2)^2} = 0$ at $x = \frac{1}{\sqrt n}$: $\sup f_n = \frac{1/\sqrt n}{2} = \frac{1}{2\sqrt n}\to0$: uniform. (Note $f_n'(0) = 1 \not\to 0 = f'(0)$... actually $f'(0)=0$; uniform convergence of functions does not give convergence of derivatives.)

      Solution

    2. HARD The logistic sigmoid is $\sigma(x) = \frac{1}{1+e^{-x}}$. (a) Show $\sigma' = \sigma(1-\sigma)$ and find where $\sigma'$ is maximal. (b) Compute $\int_0^t \sigma(x)\,dx$ in closed form. (c) Show the Maclaurin expansion $\sigma(x) = \tfrac12 + \tfrac x4 - \tfrac{x^3}{48} + O(x^5)$.

(b) $\int\sigma = \int\frac{e^x}{1+e^x}dx = \ln(1+e^x)$: $\int_0^t = \ln\frac{1+e^t}{2}$ (the softplus, shifted). (c) $\sigma(0) = \tfrac12$, $\sigma'(0) = \tfrac14$, $\sigma''(0) = \sigma'(1-2\sigma)\big|_0 = \tfrac14\cdot0 = 0$, $\sigma''' = \frac{d}{dx}[\sigma'(1-2\sigma)] = \sigma''(1-2\sigma) - 2\sigma'^2\big|_0 = -2\cdot\tfrac1{16} = -\tfrac18$: coefficient $\frac{-1/8}{6} = -\frac{1}{48}$. ✓
    3. HARD Gradient descent on $f(w) = \tfrac12(w - 5)^2$ from $w_0 = 0$ with learning rate $\eta$: $w_{k+1} = w_k - \eta f'(w_k)$. (a) Show $w_k = 5\big(1 - (1-\eta)^k\big)$. (b) For which $\eta$ does the sequence converge to 5? (c) With $\eta = 0.2$, how many steps until $|w_k - 5| < 0.01$?
      Solution
      (a) $f'(w) = w - 5$: $w_{k+1} - 5 = (1-\eta)(w_k - 5)$, a geometric sequence: $w_k - 5 = (1-\eta)^k(w_0 - 5) = -5(1-\eta)^k$. ✓ (b) Need $|1 - \eta| < 1$: $0 < \eta < 2$. ($\eta = 1$: one-step convergence; $\eta > 1$: oscillating convergence; $\eta \ge 2$: divergence.) (c) $5(0.8)^k < 0.01 \Rightarrow k > \frac{\ln 500}{\ln 1.25} = \frac{6.215}{0.2231} \approx 27.9$: $k = 28$ steps. This tiny analysis is the seed of every learning-rate rule in Ch 15.

    Task 1 — Numerical derivatives. Implement forward difference $\frac{f(x+h)-f(x)}{h}$ and central difference $\frac{f(x+h)-f(x-h)}{2h}$. For $f = \sin$ at $x = 1$, plot (or print) the error vs $h \in \{10^{-1}, \dots, 10^{-12}\}$ and observe: central is $O(h^2)$, and both blow up for tiny $h$ (floating-point cancellation — Ch 18).

    Reference solution
    import numpy as np

f, x, true = np.sin, 1.0, np.cos(1.0)
for h in 10.0 ** -np.arange(1, 13):
    fwd = (f(x + h) - f(x)) / h
    cen = (f(x + h) - f(x - h)) / (2 * h)
    print(f"h={h:.0e}  fwd err={abs(fwd-true):.2e}  cen err={abs(cen-true):.2e}")
# fwd error ~ h (best near h=1e-8); cen ~ h^2 (best near h=1e-5);
# below that, rounding error ~ eps/h dominates and errors grow.

    Task 2 — Riemann vs Simpson. Integrate $e^{-x^2}$ on $[0,1]$ with midpoint sums and Simpson's rule for $n = 2, 4, \dots, 256$; compare against the series value 0.746824. Verify midpoint error shrinks ~4× and Simpson ~16× per doubling.

    Reference solution
    import numpy as np

f = lambda x: np.exp(-x**2)
true = 0.7468241328124271

def midpoint(f, a, b, n):
    x = a + (np.arange(n) + 0.5) * (b - a) / n
    return f(x).sum() * (b - a) / n

def simpson(f, a, b, n):          # n even
    x = np.linspace(a, b, n + 1); y = f(x)
    h = (b - a) / n
    return h/3 * (y[0] + y[-1] + 4*y[1:-1:2].sum() + 2*y[2:-2:2].sum())

for n in [2, 4, 8, 16, 32, 64, 128, 256]:
    em = abs(midpoint(f, 0, 1, n) - true)
    es = abs(simpson(f, 0, 1, n) - true)
    print(f"n={n:4d}  mid={em:.2e}  simp={es:.2e}")
# mid: O(1/n^2)  -> /4 per doubling;  simp: O(1/n^4) -> /16 per doubling

    Task 3 — Taylor engine. Write taylor_sin(x, N) summing the Maclaurin series of sine through degree N (use the recurrence between consecutive terms, not factorials). Check against np.sin at x = 0.5, 2, 10 and find the N needed for 1e-12 accuracy at each — note how N grows with |x|.

    Reference solution
    import numpy as np

def taylor_sin(x, N):
    term, s = x, x
    n = 1                              # current degree
    while n + 2 <= N:
        term *= -x*x / ((n+1)*(n+2))   # t_{k+1} = -x^2/( (2k+2)(2k+3) ) t_k
        s += term
        n += 2
    return s

for x in [0.5, 2.0, 10.0]:
    for N in range(1, 120, 2):
        if abs(taylor_sin(x, N) - np.sin(x)) < 1e-12:
            print(f"x={x}: N={N}")
            break
# x=0.5: N~13,  x=2: N~21,  x=10: N~51 — terms must pass the hump |x|^n/n!
