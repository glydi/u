    Points

    A point is pure location: no size, no direction, no shape. Everything in geometry — lines, circles, vectors, the loss surfaces of chapter 15 — is built out of sets of points. In coordinate geometry we name a point by numbers: $(3, 2)$ means "3 right, 2 up from the origin".

    Definition A point is a location in space with zero dimension. In the Cartesian plane $\mathbb{R}^2$ a point is an ordered pair $(x, y)$; in space $\mathbb{R}^3$ it is a triple $(x,y,z)$. Two points are equal iff all their coordinates are equal.
    Worked example Which of $A=(2,-1)$, $B=(-1,2)$, $C=(2,-1)$ are the same point? Coordinates are ordered: $A$ and $B$ differ because $2 \ne -1$ in the first slot. $A = C$ since both coordinates match. Order matters: $(2,-1) \ne (-1,2)$.
    Where this goes A point $(x_1,\dots,x_n) \in \mathbb{R}^n$ is exactly a vector or a data sample; every dataset in Ch 19 is a cloud of points.
    Drill
    1. EASY Plot (mentally) $P=(-3,4)$. Which quadrant is it in?
      Solution
      $x<0$, $y>0$: quadrant II (upper left).
    2. MED Find all points on the $y$-axis at distance 5 from the origin.
      Solution
      Points on the $y$-axis have $x=0$, so distance is $|y|=5$: the points are $(0,5)$ and $(0,-5)$.
    3. HARD How many points $(x,y)$ with integer coordinates satisfy $x^2+y^2=25$?
      Solution
      Integer solutions of $x^2+y^2=25$: $(\pm5,0)$, $(0,\pm5)$, $(\pm3,\pm4)$, $(\pm4,\pm3)$. Count: $4 + 4\cdot2 + 4\cdot 2$... carefully: $(\pm5,0),(0,\pm5)$ gives 4; $(\pm3,\pm4)$ gives 4; $(\pm4,\pm3)$ gives 4. Total 12.

    Lines

    A line is the straightest possible path: infinitely thin, infinitely long, no bending. Two distinct points determine exactly one line — this is why "fit a line through the data" is such a strong statement: one wrong point moves the whole thing.

    Definition A line through distinct points $P$ and $Q$ is the set of all points $P + t(Q-P)$ for $t \in \mathbb{R}$. A segment restricts $t\in[0,1]$; a ray restricts $t \ge 0$. In the plane a non-vertical line is the graph of $y = mx+b$.
    Worked example Parametrize the line through $P=(1,2)$ and $Q=(4,8)$. Direction: $Q-P=(3,6)$. Line: $(x,y) = (1+3t,\; 2+6t)$. At $t=0$ we get $P$, at $t=1$ we get $Q$, at $t=\tfrac12$ the midpoint $(2.5, 5)$.
    Pitfall Vertical lines like $x=3$ are not graphs of any function $y=mx+b$ — their slope is undefined, not "infinity you can compute with".
    Drill
    1. EASY Give a parametrization of the line through $(0,0)$ and $(2,1)$.
      Solution
      $(x,y)=(2t, t)$, $t\in\mathbb{R}$. Equivalently $y = x/2$.
    2. MED Is the point $(7,14)$ on the line through $(1,2)$ and $(4,8)$?
      Solution
      Need $1+3t=7 \Rightarrow t=2$, then $y = 2+6\cdot2 = 14$. Yes.
    3. HARD Lines $\ell_1: (1+t, 2+2t)$ and $\ell_2: (4-s, 1+s)$. Do they intersect? Where?
      Solution
      Set $1+t = 4-s$ and $2+2t = 1+s$. From the first, $s = 3-t$. Substitute: $2+2t = 1+3-t = 4-t \Rightarrow 3t = 2 \Rightarrow t = 2/3$. Point: $(1+\tfrac23,\, 2+\tfrac43) = (\tfrac53, \tfrac{10}3)$. Check with $s = 3-\tfrac23=\tfrac73$: $(4-\tfrac73, 1+\tfrac73) = (\tfrac53,\tfrac{10}3)$. ✓

    Planes

    A plane is a flat sheet extending forever in two directions — the 2D analogue of a line. Three points not on a common line pin down exactly one plane. In machine learning, a plane (or hyperplane) is a decision boundary: everything on one side is class A, the other side class B.

    Definition A plane in $\mathbb{R}^3$ is the set of points $(x,y,z)$ satisfying $ax+by+cz=d$ with $(a,b,c)\ne(0,0,0)$. The vector $\mathbf{n}=(a,b,c)$ is normal (perpendicular) to the plane.
    Worked example Find the plane through $(1,0,0)$ with normal $\mathbf{n}=(2,3,-1)$. Equation: $2x+3y-z = d$. Plug in the point: $2\cdot1+0-0 = 2$, so $d=2$. Plane: $2x+3y-z=2$. Check that $(0,0,-2)$ is on it: $0+0+2=2$. ✓
    Where this goes A hyperplane $\mathbf{w}^\top\mathbf{x}=b$ is the decision boundary of logistic regression and SVMs (Ch 19).
    Drill
    1. EASY Is $(1,1,3)$ on the plane $2x+3y-z=2$?
      Solution
      $2+3-3 = 2$. Yes.
    2. MED Where does the plane $x+2y+2z=6$ cross each coordinate axis?
      Solution
      $x$-axis ($y=z=0$): $x=6 \to (6,0,0)$. $y$-axis: $2y=6 \to (0,3,0)$. $z$-axis: $2z=6 \to (0,0,3)$.
    3. HARD Distance from the point $(3,1,2)$ to the plane $2x+3y-z=2$. (Formula: $\frac{|ax_0+by_0+cz_0-d|}{\sqrt{a^2+b^2+c^2}}$.)
      Solution
      Numerator: $|2\cdot3 + 3\cdot1 - 2 - 2| = |6+3-2-2| = 5$. Denominator: $\sqrt{4+9+1}=\sqrt{14}$. Distance $= 5/\sqrt{14} \approx 1.336$.

    Angles

    An angle measures how much you turn when you pivot from one ray to another around their common endpoint. Degrees split a full turn into 360 parts. Angles are the currency of direction: everything in trigonometry (Ch 6) is a function of an angle.

    Definition An angle is formed by two rays sharing a vertex. Measures: full turn $=360^\circ$, straight angle $=180^\circ$, right angle $=90^\circ$. Angles are complementary if they sum to $90^\circ$, supplementary if they sum to $180^\circ$. Vertical angles (opposite angles at a crossing) are equal. When a line crosses two parallel lines, corresponding angles are equal and alternate interior angles are equal.
    Worked example Two lines cross, making one angle of $37^\circ$. The four angles at the crossing are: $37^\circ$ (given), its vertical angle $37^\circ$, and two supplementary angles of $180^\circ - 37^\circ = 143^\circ$ each. Check: $37+37+143+143 = 360$. ✓
    Think first A ladder leans against a wall making a $70^\circ$ angle with the ground. What angle does it make with the wall?
    Reveal
    Ground and wall are perpendicular, so the ladder's angles with ground and wall are complementary: $90^\circ - 70^\circ = 20^\circ$.
    Drill
    1. EASY Find the supplement of $64^\circ$.
      Solution
      $180^\circ - 64^\circ = 116^\circ$.
    2. MED Two parallel lines are cut by a transversal. One angle is $52^\circ$. List the measures of all eight angles.
      Solution
      At each intersection the four angles are $52^\circ, 128^\circ, 52^\circ, 128^\circ$ (vertical pairs equal, adjacent supplementary). Corresponding angles at the second intersection are equal to the first, so all eight are four $52^\circ$'s and four $128^\circ$'s.
    3. HARD An angle is $24^\circ$ more than twice its complement. Find it.
      Solution
      Let the angle be $x$; complement $90-x$. Then $x = 2(90-x)+24 = 204 - 2x \Rightarrow 3x = 204 \Rightarrow x = 68^\circ$. Check: complement $22^\circ$, and $2\cdot22+24 = 68$. ✓

    Triangles

    The triangle is the atom of geometry: any polygon can be cut into triangles, and any surface can be approximated by a mesh of them (that is literally how 3D graphics works). Its three angles always share exactly $180^\circ$ between them.

    Definition A triangle has three vertices and three sides. Angle sum: $\alpha+\beta+\gamma = 180^\circ$. Area $= \tfrac12 \times \text{base} \times \text{height}$. Triangle inequality: each side is shorter than the sum of the other two, $c < a+b$. Types: equilateral (all sides equal, all angles $60^\circ$), isosceles (two sides equal), scalene (all different); acute/right/obtuse by largest angle.
    Worked example A triangle has angles $x$, $2x$, $3x$. Then $6x = 180^\circ$, so $x=30^\circ$: angles $30^\circ, 60^\circ, 90^\circ$ — a right triangle. If its hypotenuse is 10, the side opposite $30^\circ$ is 5 (in a 30-60-90 triangle the sides are in ratio $1 : \sqrt3 : 2$), the third side $5\sqrt3 \approx 8.66$. Area $=\tfrac12\cdot 5\cdot 5\sqrt3 = \tfrac{25\sqrt3}{2}\approx 21.65$.
    Pitfall "Base × height" needs the perpendicular height, not the slanted side length. For sides 5, 5, 8 the height onto the base 8 is $\sqrt{5^2-4^2}=3$, so area is 12 — not $\tfrac12\cdot 8\cdot 5=20$.
    Drill
    1. EASY Two angles of a triangle are $48^\circ$ and $71^\circ$. Find the third.
      Solution
      $180 - 48 - 71 = 61^\circ$.
    2. MED Can 3, 4, 8 be side lengths of a triangle?
      Solution
      No: $3+4 = 7 < 8$ violates the triangle inequality.
    3. HARD An isosceles triangle has perimeter 36 and base 10. Find its area.
      Solution
      Equal sides: $(36-10)/2 = 13$ each. Height onto the base: $\sqrt{13^2 - 5^2} = \sqrt{169-25} = 12$. Area $= \tfrac12 \cdot 10 \cdot 12 = 60$.

    Triangle congruence

    Two triangles are congruent when one is an exact copy of the other — same side lengths, same angles — possibly moved, rotated or flipped. You don't need to check all six measurements: three well-chosen ones force the rest.

    Definition Triangles $ABC$ and $DEF$ are congruent ($\triangle ABC \cong \triangle DEF$) if corresponding sides and angles are equal. Sufficient criteria: SSS (three sides), SAS (two sides and the angle between them), ASA (two angles and the side between), AAS (two angles and a non-included side), and HL for right triangles (hypotenuse + leg). SSA is not a valid criterion in general, and AAA gives only similarity.
    Worked example $AB = DE = 7$, $\angle A = \angle D = 40^\circ$, $AC = DF = 5$. The equal angle sits between the two pairs of equal sides, so by SAS the triangles are congruent — and we get for free that $BC = EF$ and the remaining angles match.
    Pitfall SSA fails: with two sides and a non-included angle, two different triangles can exist (the "ambiguous case" — see the law of sines in Ch 6).
    Drill
    1. EASY Which criterion applies: $\angle A=\angle D$, $\angle B=\angle E$, $AB = DE$?
      Solution
      The side $AB$ lies between angles $A$ and $B$: ASA. Congruent.
    2. MED In an isosceles triangle $ABC$ with $AB=AC$, let $M$ be the midpoint of $BC$. Prove $\triangle ABM \cong \triangle ACM$.
      Solution
      $AB = AC$ (given), $BM = CM$ ($M$ midpoint), $AM = AM$ (shared). SSS gives congruence. Consequence: $\angle B = \angle C$ (base angles of an isosceles triangle are equal) and $AM \perp BC$.
    3. HARD Diagonals of a parallelogram $ABCD$ meet at $P$. Show $AP = PC$, i.e. the diagonals bisect each other.
      Solution
      Consider $\triangle APB$ and $\triangle CPD$. $AB = CD$ (opposite sides of a parallelogram), $\angle PAB = \angle PCD$ and $\angle PBA = \angle PDC$ (alternate interior angles, $AB \parallel CD$ cut by the diagonals). ASA gives $\triangle APB \cong \triangle CPD$, so $AP = CP$ and $BP = DP$.

    Triangle similarity

    Similar triangles have the same shape but possibly different size: equal angles, sides scaled by one common factor. Similarity is how we measure the unmeasurable — the height of a tree from its shadow, the distance to the Moon.

    Definition $\triangle ABC \sim \triangle DEF$ if corresponding angles are equal; then corresponding sides satisfy $\frac{DE}{AB} = \frac{EF}{BC} = \frac{DF}{AC} = k$ (the scale factor). Criteria: AA (two equal angles), SAS-similarity (two sides in proportion, included angle equal), SSS-similarity (all sides in proportion). Areas scale by $k^2$.
    Worked example A 1.8 m person casts a 1.2 m shadow; a tree casts a 6 m shadow at the same time. Sun rays are parallel, so the two right triangles are similar (AA: right angle + same sun angle). Scale: $\frac{6}{1.2} = 5$, so the tree is $1.8 \times 5 = 9$ m tall.
    Think first If a triangle's sides are all doubled, what happens to its area?
    Reveal
    It quadruples: area scales with $k^2 = 4$. Base doubles and height doubles.
    Drill
    1. EASY Triangles with sides $(3,4,5)$ and $(6,8,10)$ — similar?
      Solution
      Yes, SSS-similarity with $k = 2$: each ratio $6/3=8/4=10/5=2$.
    2. MED In $\triangle ABC$, a line through $D$ on $AB$ and $E$ on $AC$ is parallel to $BC$, with $AD = 4$, $DB = 6$, $DE = 5$. Find $BC$.
      Solution
      $\triangle ADE \sim \triangle ABC$ (AA, parallel line makes equal corresponding angles). Ratio $AD/AB = 4/10 = 2/5$, so $BC = DE \cdot \tfrac{5}{2} = 12.5$.
    3. HARD In a right triangle, the altitude from the right angle to the hypotenuse splits it into segments of length 4 and 9. Find the altitude.
      Solution
      The altitude $h$ creates two triangles each similar to the whole (AA), which gives the geometric-mean relation $h^2 = 4 \cdot 9 = 36$, so $h = 6$.

    Pythagorean theorem

    In a right triangle, the square built on the longest side has exactly as much area as the two smaller squares combined. This one identity generates the distance formula, vector norms, least squares, and the whole notion of "Euclidean" space.

    Definition (Theorem.) In a right triangle with legs $a, b$ and hypotenuse $c$: $$a^2 + b^2 = c^2.$$ Converse: if $a^2+b^2=c^2$ holds for a triangle's sides, the angle opposite $c$ is right.
    Theorem Proof by rearrangement: place four copies of the triangle inside a square of side $a+b$. The uncovered area is a tilted square of side $c$, so $(a+b)^2 - 4\cdot\tfrac{ab}{2} = c^2$, i.e. $a^2 + 2ab + b^2 - 2ab = c^2$, giving $a^2+b^2 = c^2$. $\blacksquare$
    Worked example Legs 5 and 12: $c = \sqrt{25+144} = \sqrt{169} = 13$. Now the other direction: hypotenuse 25, one leg 7: other leg $= \sqrt{625 - 49} = \sqrt{576} = 24$. Common integer triples worth recognizing: $(3,4,5), (5,12,13), (8,15,17), (7,24,25)$.
    Explore

    Drag the legs and watch the three squares rebalance: the two small areas always sum to the big one.

    Where this goes $\|\mathbf{x}\|^2 = x_1^2+\cdots+x_n^2$ is the Pythagorean theorem applied $n-1$ times; it becomes the L2 norm of Ch 8 and the squared-error loss of Ch 19.
    Drill
    1. EASY A right triangle has legs 6 and 8. Find the hypotenuse.
      Solution
      $\sqrt{36+64} = \sqrt{100} = 10$.
    2. MED Is a triangle with sides 9, 12, 15 right-angled? What about 8, 9, 12?
      Solution
      $9^2+12^2 = 81+144 = 225 = 15^2$: yes (it is $3\times(3,4,5)$). $8^2+9^2 = 64+81=145 \ne 144 = 12^2$: no; since $145 > 144$ the angle opposite 12 is acute.
    3. HARD A 10 m ladder leans against a wall, its foot 6 m out. The foot slides out to 8 m. How far did the top slide down?
      Solution
      Heights: $\sqrt{100-36} = 8$ m, then $\sqrt{100-64} = 6$ m. The top slides down $8-6 = 2$ m. (Note the foot moved 2 m as well — a coincidence of this triple, not a law.)
    4. HARD Find the length of the space diagonal of a box with edges 2, 3, 6.
      Solution
      Apply Pythagoras twice: floor diagonal $\sqrt{2^2+3^2} = \sqrt{13}$, then diagonal $=\sqrt{13 + 36} = \sqrt{49} = 7$.
    A triangle has sides 5, 6, 8. The angle opposite the side of length 8 is…
    $5^2+6^2 = 61 < 64 = 8^2$. When the hypotenuse-candidate's square exceeds the sum, the opposite angle is obtuse.

    Circles

    A circle is the set of points at one fixed distance (the radius) from a center — perfect symmetry in every direction. The ratio of any circle's circumference to its diameter is always the same number, $\pi \approx 3.14159$.

    Definition The circle with center $(h,k)$ and radius $r$ is $\{(x,y) : (x-h)^2 + (y-k)^2 = r^2\}$. Circumference $C = 2\pi r$; area $A = \pi r^2$. A chord joins two points on the circle; a diameter is a chord through the center ($d = 2r$); a tangent touches at one point and is perpendicular to the radius there.
    Worked example Find center and radius of $x^2 + y^2 - 6x + 4y - 12 = 0$. Complete the square: $(x^2-6x+9) + (y^2+4y+4) = 12 + 9 + 4$, so $(x-3)^2 + (y+2)^2 = 25$. Center $(3,-2)$, radius $5$.
    Think first A pizza of radius 20 cm vs two pizzas of radius 10 cm — which is more pizza?
    Reveal
    The big one: $\pi\cdot 20^2 = 400\pi$ vs $2 \cdot \pi \cdot 10^2 = 200\pi$. Area grows with $r^2$.
    Drill
    1. EASY Radius 7: circumference and area?
      Solution
      $C = 14\pi \approx 43.98$; $A = 49\pi \approx 153.94$.
    2. MED Write the equation of the circle with center $(-1, 4)$ passing through $(2, 0)$.
      Solution
      $r^2 = (2-(-1))^2 + (0-4)^2 = 9+16 = 25$. Equation: $(x+1)^2 + (y-4)^2 = 25$.
    3. HARD A chord of length 8 sits in a circle of radius 5. How far is the chord from the center?
      Solution
      Drop a perpendicular from the center to the chord: it bisects the chord (4 each side). Distance $= \sqrt{5^2 - 4^2} = 3$.

    Arc length

    An arc is a slice of the circle's rim. Its length is just the fraction of the full turn you sweep, times the full circumference. Sweep half the circle, get half of $2\pi r$.

    Definition For central angle $\theta$ (in degrees), arc length $s = \frac{\theta}{360^\circ}\, 2\pi r$. In radians (Ch 6) this collapses to the clean $s = r\theta$.
    Worked example A $120^\circ$ arc on a circle of radius 9: $s = \frac{120}{360}\cdot 2\pi\cdot 9 = \frac13 \cdot 18\pi = 6\pi \approx 18.85$.
    Where this goes $s = r\theta$ is the reason radians exist — Ch 6 builds sine and cosine on it, and it makes $\frac{d}{dx}\sin x = \cos x$ come out clean in Ch 7.
    Drill
    1. EASY Arc length of a quarter circle of radius 4.
      Solution
      $\frac{90}{360}\cdot 2\pi\cdot4 = 2\pi \approx 6.28$.
    2. MED An arc of length $5\pi$ sits on a circle of radius 6. What is its central angle in degrees?
      Solution
      $5\pi = \frac{\theta}{360}\cdot 12\pi \Rightarrow \theta = 360\cdot\frac{5}{12} = 150^\circ$.
    3. HARD The minute hand of a clock is 12 cm. How far does its tip travel between 3:00 and 3:35?
      Solution
      35 minutes $= \frac{35}{60}$ of a full turn. Distance $= \frac{35}{60}\cdot 2\pi\cdot 12 = 14\pi \approx 43.98$ cm.

    Sector area

    A sector is a pizza slice: two radii plus the arc between them. Same logic as arc length — take the fraction of the turn, but of the full area this time.

    Definition Sector with central angle $\theta$ (degrees): $A = \frac{\theta}{360^\circ}\pi r^2$. In radians: $A = \tfrac12 r^2\theta$.
    Worked example A $60^\circ$ slice of a radius-12 pizza: $A = \frac{60}{360}\pi\cdot144 = 24\pi \approx 75.4$. Sanity check: six such slices tile the pizza, $6 \cdot 24\pi = 144\pi = \pi r^2$. ✓
    Pitfall A segment (region between a chord and its arc) is not a sector: its area is sector minus triangle, $\tfrac12 r^2(\theta - \sin\theta)$ with $\theta$ in radians.
    Drill
    1. EASY Area of a $90^\circ$ sector of radius 6.
      Solution
      $\frac14 \pi \cdot 36 = 9\pi \approx 28.27$.
    2. MED A sector of radius 10 has area $15\pi$. Find its angle and arc length.
      Solution
      $15\pi = \frac{\theta}{360}\cdot 100\pi \Rightarrow \theta = 54^\circ$. Arc: $\frac{54}{360}\cdot 20\pi = 3\pi$.
    3. HARD Find the area of the circular segment cut off by a chord subtending $90^\circ$ in a circle of radius 4.
      Solution
      Sector: $\frac14\pi\cdot16 = 4\pi$. Triangle (two radii with right angle between): $\tfrac12\cdot4\cdot4 = 8$. Segment $= 4\pi - 8 \approx 4.57$.

    Coordinate geometry

    Descartes' great trick: put a grid over the plane so every point becomes a pair of numbers, every curve becomes an equation, and every geometry problem becomes algebra. This is the bridge on which all of machine learning stands — data lives in coordinates.

    Definition The Cartesian plane assigns each point a pair $(x,y)$: signed distances to two perpendicular axes meeting at the origin $(0,0)$. The axes split the plane into quadrants I ($+,+$), II ($-,+$), III ($-,-$), IV ($+,-$). A curve is the set of points whose coordinates satisfy an equation.
    Worked example Show algebraically that the triangle $A=(0,0)$, $B=(4,0)$, $C=(0,3)$ is right-angled and find its area. $AB$ lies along the $x$-axis, $AC$ along the $y$-axis — perpendicular, so the right angle is at $A$. Legs 4 and 3, area $\tfrac12\cdot4\cdot3 = 6$, hypotenuse $BC = \sqrt{(4-0)^2+(0-3)^2} = 5$.
    Drill
    1. EASY Which quadrant contains $(-2,-7)$?
      Solution
      Both negative: quadrant III.
    2. MED Find $k$ so that $(k, 2k)$ lies on the circle $x^2+y^2 = 45$.
      Solution
      $k^2 + 4k^2 = 5k^2 = 45 \Rightarrow k = \pm3$. Points $(3,6)$ and $(-3,-6)$.
    3. HARD The points $A=(1,1)$, $B=(5,1)$, $C=(7,4)$, $D=(3,4)$ form a quadrilateral. Show it is a parallelogram and find its area.
      Solution
      $\vec{AB} = (4,0)$ and $\vec{DC} = (7-3, 4-4) = (4,0)$: one pair of opposite sides is equal and parallel, so $ABCD$ is a parallelogram. Base $AB = 4$, height = vertical distance between the parallel sides $= 3$. Area $= 12$.

    Distance formula

    The distance between two points is the hypotenuse of the right triangle whose legs are the horizontal and vertical gaps. That's the Pythagorean theorem wearing coordinates.

    Definition $$d\big((x_1,y_1),(x_2,y_2)\big) = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}.$$ In $\mathbb{R}^n$: $d(\mathbf{p},\mathbf{q}) = \sqrt{\sum_{i=1}^n (q_i - p_i)^2} = \|\mathbf{q}-\mathbf{p}\|$.
    Worked example Distance from $(-1, 2)$ to $(3, -1)$: $\sqrt{(3-(-1))^2 + (-1-2)^2} = \sqrt{16 + 9} = 5$.
    Where this goes Nearest-neighbor classification (Ch 19) and k-means (Ch 19) are nothing but this formula applied millions of times in high dimension.
    Drill
    1. EASY Distance from $(0,0)$ to $(6,8)$.
      Solution
      $\sqrt{36+64} = 10$.
    2. MED Find all $y$ such that $(3, y)$ is at distance 5 from $(0, 1)$.
      Solution
      $9 + (y-1)^2 = 25 \Rightarrow (y-1)^2 = 16 \Rightarrow y = 5$ or $y = -3$.
    3. HARD Show that $A=(1,2)$, $B=(4,6)$, $C=(8,3)$ form an isosceles right triangle.
      Solution
      $AB = \sqrt{9+16} = 5$; $BC = \sqrt{16+9} = 5$; $AC = \sqrt{49+1} = \sqrt{50}$. $AB = BC$ (isosceles) and $AB^2 + BC^2 = 50 = AC^2$, so the angle at $B$ is right. ✓

    Midpoint formula

    The midpoint of a segment is the average of its endpoints, coordinate by coordinate. Averaging positions is something you will do constantly: centroids of clusters, centers of mass, interpolation between embeddings.

    Definition Midpoint of $(x_1,y_1)$ and $(x_2,y_2)$: $M = \left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$. More generally the point a fraction $t$ of the way is $(1-t)(x_1,y_1) + t(x_2,y_2)$.
    Worked example Midpoint of $(-2, 5)$ and $(6, -1)$: $\left(\frac{-2+6}{2}, \frac{5-1}{2}\right) = (2, 2)$. And the point one third of the way from the first to the second: $\tfrac23(-2,5) + \tfrac13(6,-1) = \left(\tfrac{-4+6}{3}, \tfrac{10-1}{3}\right) = \left(\tfrac23, 3\right)$.
    Drill
    1. EASY Midpoint of $(1,9)$ and $(7,3)$.
      Solution
      $(4, 6)$.
    2. MED $M=(3,-2)$ is the midpoint of $AB$ with $A = (7, 4)$. Find $B$.
      Solution
      $B = 2M - A = (6-7, -4-4) = (-1, -8)$.
    3. HARD The centroid of a triangle is the average of its three vertices. For $A=(0,0)$, $B=(6,0)$, $C=(0,9)$, verify the centroid lies on the median from $C$ to the midpoint of $AB$, two thirds of the way down.
      Solution
      Centroid $G = \left(\frac{0+6+0}{3}, \frac{0+0+9}{3}\right) = (2,3)$. Midpoint of $AB$: $M=(3,0)$. Point $\tfrac23$ of the way from $C=(0,9)$ to $M=(3,0)$: $\tfrac13(0,9)+\tfrac23(3,0) = (2, 3) = G$. ✓

    Line equations

    A line in the plane is captured by one linear equation. Different forms of that equation expose different facts: slope-intercept shows steepness and starting height, point-slope shows a known point, general form treats vertical lines fairly.

    Definition Slope through $(x_1,y_1),(x_2,y_2)$: $m = \frac{y_2-y_1}{x_2-x_1}$ (rise over run). Forms: slope-intercept $y = mx+b$; point-slope $y - y_1 = m(x-x_1)$; general $Ax+By+C=0$ (handles vertical lines, $B=0$). Parallel lines: equal slopes. Perpendicular: $m_1 m_2 = -1$ (neither vertical).
    Worked example Line through $(2,3)$ and $(6,11)$: $m = \frac{11-3}{6-2} = 2$. Point-slope: $y - 3 = 2(x-2)$, so $y = 2x - 1$. Perpendicular line through $(2,3)$: slope $-\tfrac12$, giving $y = -\tfrac12 x + 4$.
    Pitfall $m_1m_2=-1$ fails silently for vertical/horizontal pairs: $x = 2$ and $y = 5$ are perpendicular, but the vertical line has no slope to multiply.
    Drill
    1. EASY Slope and $y$-intercept of $3x + 2y = 12$?
      Solution
      $y = -\tfrac32 x + 6$: slope $-\tfrac32$, intercept $(0,6)$.
    2. MED Find the line through $(1, -2)$ parallel to $4x - 2y = 7$.
      Solution
      Given line: $y = 2x - \tfrac72$, slope 2. Answer: $y + 2 = 2(x-1)$, i.e. $y = 2x - 4$.
    3. HARD Find the foot of the perpendicular from $P=(4, 1)$ to the line $y = 2x + 1$, and the distance from $P$ to the line.
      Solution
      Perpendicular through $P$: slope $-\tfrac12$, $y = -\tfrac12(x-4)+1 = -\tfrac12 x + 3$. Intersect: $2x+1 = -\tfrac12 x + 3 \Rightarrow \tfrac52 x = 2 \Rightarrow x = \tfrac45$, $y = \tfrac{13}5$. Foot $(\tfrac45, \tfrac{13}5)$. Distance $= \sqrt{(4-\tfrac45)^2 + (1-\tfrac{13}5)^2} = \sqrt{(\tfrac{16}5)^2 + (-\tfrac85)^2} = \sqrt{\tfrac{256+64}{25}} = \frac{\sqrt{320}}{5} = \frac{8\sqrt5}{5} \approx 3.58$. (Check with the point-line formula: $|2\cdot4 - 1 + 1|/\sqrt{5} = 8/\sqrt5$. ✓)

    Parabolas

    A parabola is the set of points equidistant from a fixed point (focus) and a fixed line (directrix). It is also the graph of $y = ax^2$, the path of a thrown ball, and the shape of every satellite dish — parallel rays bounce off it straight into the focus.

    Definition Parabola with focus $F$ and directrix $\ell$: $\{P : d(P,F) = d(P,\ell)\}$. Standard form opening up with vertex at the origin: $x^2 = 4py$, focus $(0,p)$, directrix $y = -p$. As a function: $y = a(x-h)^2 + k$ with vertex $(h,k)$ and $a = \frac{1}{4p}$.
    Worked example Find focus and directrix of $y = \tfrac18 x^2$. Rewrite: $x^2 = 8y$, so $4p = 8$, $p = 2$. Focus $(0, 2)$, directrix $y = -2$. Check with the point $(4,2)$ on the parabola: distance to focus $= \sqrt{16+0} = 4$; distance to directrix $= 2-(-2) = 4$. ✓
    Drill
    1. EASY Vertex of $y = 2(x-3)^2 - 5$? Which way does it open?
      Solution
      Vertex $(3,-5)$; $a = 2 > 0$ so it opens upward.
    2. MED Find the parabola with focus $(0,1)$ and directrix $y = -1$.
      Solution
      $p = 1$, so $x^2 = 4y$, i.e. $y = x^2/4$.
    3. HARD A dish antenna is 2 m wide and 0.25 m deep. Where is the focus?
      Solution
      Model as $x^2 = 4py$ with rim point $(1, 0.25)$: $1 = 4p(0.25) = p$, so $p = 1$ m. The receiver sits 1 m above the vertex, on the axis.

    Ellipses

    An ellipse is a stretched circle: the set of points whose distances to two foci add to a constant. Pin a loop of string at two nails and pull a pencil taut — you draw an ellipse. Planets orbit in them.

    Definition Ellipse: $\{P : d(P,F_1) + d(P,F_2) = 2a\}$. Standard form centered at the origin, major axis on $x$: $$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1,\quad a \ge b,$$ with foci $(\pm c, 0)$, $c^2 = a^2 - b^2$. Eccentricity $e = c/a \in [0, 1)$: $e=0$ is a circle, $e \to 1$ is a cigar. Area $= \pi ab$.
    Worked example $\frac{x^2}{25} + \frac{y^2}{9} = 1$: $a=5$, $b=3$, $c = \sqrt{25-9} = 4$. Foci $(\pm4, 0)$, eccentricity $e = 4/5$. Verify the string property at the top point $(0,3)$: distances to the foci are each $\sqrt{16+9} = 5$, summing to $10 = 2a$. ✓
    Pitfall For ellipses $c^2 = a^2 - b^2$ (foci inside), for hyperbolas $c^2 = a^2 + b^2$ (foci outside). Mixing these up is the classic conic error.
    Drill
    1. EASY Semi-axes of $\frac{x^2}{16} + \frac{y^2}{49} = 1$? Which axis is major?
      Solution
      Semi-axes 4 (along $x$) and 7 (along $y$). Major axis is vertical since $49 > 16$; foci at $(0, \pm\sqrt{33})$.
    2. MED Find the ellipse with foci $(\pm3, 0)$ passing through $(0, 4)$.
      Solution
      $c = 3$, and $(0,4)$ gives $b = 4$; $a^2 = b^2 + c^2 = 25$. Ellipse: $\frac{x^2}{25}+\frac{y^2}{16}=1$.
    3. HARD Earth's orbit has $e \approx 0.0167$ and $a \approx 149.6$ million km. How much closer is Earth to the Sun at perihelion than at aphelion?
      Solution
      Perihelion $= a(1-e)$, aphelion $= a(1+e)$; difference $= 2ae = 2 \cdot 149.6 \cdot 0.0167 \approx 5.0$ million km.

    Hyperbolas

    Flip the ellipse's plus to a minus: a hyperbola is the set of points whose distances to two foci differ by a constant. It comes in two branches and hugs a pair of straight asymptotes far from the center — the graph of $y = 1/x$ is one, rotated 45°.

    Definition Hyperbola: $\{P : |d(P,F_1) - d(P,F_2)| = 2a\}$. Standard form: $$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1,$$ opening left-right, vertices $(\pm a, 0)$, foci $(\pm c, 0)$ with $c^2 = a^2 + b^2$, asymptotes $y = \pm\frac{b}{a}x$. Eccentricity $e = c/a > 1$.
    Worked example $\frac{x^2}{9} - \frac{y^2}{16} = 1$: $a = 3$, $b = 4$, $c = \sqrt{9+16} = 5$. Vertices $(\pm3,0)$, foci $(\pm5,0)$, asymptotes $y = \pm\tfrac43 x$. The point $(5, \tfrac{16}{3})$ is on it: $\tfrac{25}{9} - \tfrac{256/9}{16} = \tfrac{25}{9} - \tfrac{16}{9} = 1$. ✓
    Drill
    1. EASY Asymptotes of $\frac{x^2}{4} - \frac{y^2}{25} = 1$?
      Solution
      $y = \pm\frac52 x$.
    2. MED Find the hyperbola with vertices $(\pm2, 0)$ and foci $(\pm3, 0)$.
      Solution
      $a = 2$, $c = 3$, $b^2 = c^2 - a^2 = 5$: $\frac{x^2}{4} - \frac{y^2}{5} = 1$.
    3. HARD Two microphones 2 km apart (at $(\pm1, 0)$, km units) hear a bang; the west mic hears it $2$ s later. Sound travels 0.34 km/s. On what curve does the source lie?
      Solution
      Distance difference $= 0.34\cdot2 = 0.68$ km $= 2a$, so $a = 0.34$. $c = 1$, $b^2 = 1 - 0.1156 = 0.8844$. Source lies on the east branch of $\frac{x^2}{0.1156} - \frac{y^2}{0.8844} = 1$ (closer to the east mic). This is how LORAN navigation worked.

    Conic sections

    Slice an infinite double cone with a plane: tilt the plane a little and you get an ellipse, tilt it parallel to the cone's side for a parabola, steeper still for a hyperbola. One family, one master equation, distinguished by eccentricity.

    Definition A conic is the zero set of a quadratic $Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$. Its type is decided by the discriminant $\Delta = B^2 - 4AC$: ellipse if $\Delta < 0$ (circle if also $B = 0, A = C$), parabola if $\Delta = 0$, hyperbola if $\Delta > 0$. Unified focus–directrix view: $d(P, F) = e \cdot d(P, \ell)$ with $0<e<1$ ellipse, $e=1$ parabola, $e>1$ hyperbola.
    Worked example Classify $x^2 + 4xy + y^2 + 2x - 3 = 0$. Here $A = 1, B = 4, C = 1$: $\Delta = 16 - 4 = 12 > 0$ — a hyperbola (the $xy$ term means its axes are rotated).

    3D coordinates

    Add a third axis, $z$, sticking out of the page: every point in space is now a triple $(x, y, z)$. Nothing conceptually new happens — and that is the point. The same machinery keeps working in 3, 4, or 4096 dimensions, which is where neural network activations live.

    Definition $\mathbb{R}^3 = \{(x,y,z)\}$ with three mutually perpendicular axes (right-handed: curl fingers from $+x$ to $+y$, thumb points along $+z$). Coordinate planes: $xy$-plane ($z=0$), $xz$-plane ($y=0$), $yz$-plane ($x=0$). A sphere of radius $r$ centered at $(h,k,l)$: $(x-h)^2+(y-k)^2+(z-l)^2 = r^2$.
    Worked example The point $(2, -3, 5)$: 2 along $x$, 3 back along $y$, 5 up. Its projection onto the $xy$-plane (drop the height) is $(2,-3,0)$; its distance to that plane is $|z| = 5$; its mirror image through the $xy$-plane is $(2,-3,-5)$.
    Drill
    1. EASY What is the reflection of $(1,2,3)$ through the $yz$-plane?
      Solution
      Flip $x$: $(-1, 2, 3)$.
    2. MED Describe the set $x^2 + y^2 = 4$ in $\mathbb{R}^3$.
      Solution
      No constraint on $z$: an infinite cylinder of radius 2 around the $z$-axis (not a circle!).
    3. HARD Where does the sphere $(x-1)^2 + y^2 + (z-2)^2 = 9$ intersect the $xy$-plane?
      Solution
      Set $z=0$: $(x-1)^2 + y^2 + 4 = 9 \Rightarrow (x-1)^2 + y^2 = 5$ — a circle in the $xy$-plane, center $(1,0,0)$, radius $\sqrt5$.

    3D distance

    Pythagoras stacks: the distance in 3D is the square root of the sum of three squared gaps. Apply the 2D theorem on the floor, then once more up the wall.

    Definition $$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}.$$ Midpoint: average each of the three coordinates.
    Worked example From $(1, 2, 3)$ to $(4, 6, 15)$: $d = \sqrt{3^2 + 4^2 + 12^2} = \sqrt{9+16+144} = \sqrt{169} = 13$.
    Think first The unit cube has corners $(0,0,0)$ through $(1,1,1)$. How long is its longest diagonal — and what would it be for a unit cube in 100 dimensions?
    Reveal
    $\sqrt{1+1+1} = \sqrt3 \approx 1.73$. In $n$ dimensions: $\sqrt n$; for $n=100$ that's 10 — the corners of a high-dimensional cube are surprisingly far apart, one seed of the "curse of dimensionality".

    Vectors

    A vector is an arrow: it has length and direction but no fixed starting point. "3 km northeast" is a vector; "the bakery" is a point. Vectors are the single most important object in this book — data, gradients, model weights, and word embeddings are all vectors.

    Definition A vector in $\mathbb{R}^n$ is a tuple $\mathbf{v} = (v_1, \dots, v_n)$, drawn as an arrow from the origin to that point (or from anywhere: only displacement matters). Its magnitude (length, norm) is $\|\mathbf{v}\| = \sqrt{v_1^2 + \cdots + v_n^2}$. The zero vector $\mathbf{0}$ has length 0 and no direction. A unit vector has length 1: normalize by $\hat{\mathbf{v}} = \mathbf{v}/\|\mathbf{v}\|$.
    Worked example The displacement from $A = (1, 2)$ to $B = (4, -2)$ is $\mathbf{v} = B - A = (3, -4)$, with $\|\mathbf{v}\| = \sqrt{9+16} = 5$. Unit vector in the same direction: $\hat{\mathbf{v}} = (\tfrac35, -\tfrac45)$ — check: $\sqrt{\tfrac{9}{25}+\tfrac{16}{25}} = 1$. ✓
    Pitfall A vector is not a point, even though both are tuples. The vector $(3,-4)$ drawn starting at $(10, 10)$ ends at $(13, 6)$ — same vector, different arrows on the page.
    Where this goes Chapter 8 rebuilds everything here abstractly (vector spaces); Ch 21 represents every word and image as a vector.
    Drill
    1. EASY Magnitude of $\mathbf{v} = (2, -1, 2)$?
      Solution
      $\sqrt{4+1+4} = 3$.
    2. MED Find the unit vector pointing from $(5, 1)$ toward $(2, 5)$.
      Solution
      Displacement $(-3, 4)$, length 5: $\hat{\mathbf{u}} = (-\tfrac35, \tfrac45)$.
    3. HARD Find all vectors of length 10 that make equal angles with both coordinate axes in the plane.
      Solution
      Equal angles with both axes means $|v_1| = |v_2|$. With $v_1^2 + v_2^2 = 100$: $2v_1^2 = 100$, $|v_1| = \sqrt{50} = 5\sqrt2$. Four vectors: $(\pm5\sqrt2, \pm5\sqrt2)$.

    Vector addition

    To add vectors, walk one then the other: place the tail of the second at the head of the first. Coordinates make it trivial — add slot by slot. Forces, velocities, and gradient updates all combine this way.

    Definition $(u_1, \dots, u_n) + (v_1, \dots, v_n) = (u_1{+}v_1, \dots, u_n{+}v_n)$. Addition is commutative and associative; geometrically $\mathbf{u}+\mathbf{v}$ is the diagonal of the parallelogram with sides $\mathbf{u}, \mathbf{v}$. Triangle inequality: $\|\mathbf{u}+\mathbf{v}\| \le \|\mathbf{u}\| + \|\mathbf{v}\|$.
    Worked example A plane flies with velocity $(200, 0)$ km/h (due east); wind blows $(0, 50)$ km/h (due north). Ground velocity: $(200, 50)$, speed $\sqrt{200^2 + 50^2} = \sqrt{42500} \approx 206.2$ km/h, tilted north of east by the angle whose tangent is $50/200 = 0.25$ ($\approx 14^\circ$).
    Drill
    1. EASY $(1, -2, 3) + (4, 2, -3) = ?$
      Solution
      $(5, 0, 0)$.
    2. MED $\|\mathbf{u}\| = 3$ and $\|\mathbf{v}\| = 4$. What are the largest and smallest possible values of $\|\mathbf{u}+\mathbf{v}\|$?
      Solution
      Largest 7 (same direction), smallest 1 (opposite directions). Anything in $[1,7]$ is achievable by varying the angle.
    3. HARD Three forces act on a body: $(3, 1)$, $(-1, 2)$, and $\mathbf{F}$. The body is in equilibrium (net force zero). Find $\mathbf{F}$ and its magnitude.
      Solution
      $\mathbf{F} = -[(3,1)+(-1,2)] = -(2,3) = (-2,-3)$; $\|\mathbf{F}\| = \sqrt{13} \approx 3.61$.

    Vector subtraction

    $\mathbf{u} - \mathbf{v}$ is the arrow from the head of $\mathbf{v}$ to the head of $\mathbf{u}$: "what must I add to $\mathbf{v}$ to get $\mathbf{u}$?" Differences of vectors are how you measure relative position — and how word analogies like king − man + woman ≈ queen work.

    Definition $\mathbf{u} - \mathbf{v} = \mathbf{u} + (-\mathbf{v})$, computed slot by slot. The distance between points $P, Q$ is $\|\mathbf{q} - \mathbf{p}\|$ — the norm of the difference of their position vectors.
    Worked example $\mathbf{u} = (5, 2)$, $\mathbf{v} = (1, 4)$: $\mathbf{u} - \mathbf{v} = (4, -2)$. Check the definition: $\mathbf{v} + (4,-2) = (5, 2) = \mathbf{u}$. ✓ Geometrically, $(4,-2)$ is the arrow from the tip of $\mathbf{v}$ to the tip of $\mathbf{u}$ — the other diagonal of the parallelogram.
    Drill
    1. EASY $(7, 0, -1) - (2, 3, -5) = ?$
      Solution
      $(5, -3, 4)$.
    2. MED Points $P = (2,1)$, $Q = (6,4)$. Express the point $R$ such that $Q$ is the midpoint of $PR$, using vector arithmetic.
      Solution
      $\mathbf{r} = \mathbf{q} + (\mathbf{q} - \mathbf{p}) = 2\mathbf{q} - \mathbf{p} = (12-2, 8-1) = (10, 7)$.
    3. HARD In embedding land: king $=(2, 6)$, man $=(1, 2)$, woman $=(1.5, 2.5)$. Compute king − man + woman and interpret.
      Solution
      $(2-1+1.5,\; 6-2+2.5) = (2.5, 6.5)$. The difference king − man $=(1,4)$ captures "royalty minus gender-neutral person"; adding woman transfers that offset — the resulting point is where "queen" should live. Real word2vec embeddings show exactly this arithmetic in 300 dimensions.

    Scalar multiplication

    Multiplying a vector by a number stretches or shrinks it; a negative number also flips it. The vector's direction line never changes. Learning rates in gradient descent are exactly this: scale the gradient vector before stepping.

    Definition $c\,(v_1, \dots, v_n) = (cv_1, \dots, cv_n)$. Properties: $\|c\mathbf{v}\| = |c|\,\|\mathbf{v}\|$; $c > 0$ preserves direction, $c < 0$ reverses it. Vectors $\mathbf{u}, \mathbf{v}$ are parallel (collinear) iff $\mathbf{u} = c\mathbf{v}$ for some scalar $c \ne 0$.
    Worked example $\mathbf{v} = (3, -4)$, $\|\mathbf{v}\| = 5$. Then $-2\mathbf{v} = (-6, 8)$ with length $|-2|\cdot 5 = 10$, pointing exactly opposite. And to get a vector of length 2 in the direction of $\mathbf{v}$: $\tfrac{2}{5}\mathbf{v} = (1.2, -1.6)$.
    Drill
    1. EASY Compute $3(2, -1) - 2(1, 4)$.
      Solution
      $(6,-3) - (2,8) = (4, -11)$.
    2. MED Are $(4, -6, 2)$ and $(-6, 9, -3)$ parallel?
      Solution
      $(-6,9,-3) = -\tfrac32(4,-6,2)$. Yes — parallel, opposite directions.
    3. HARD Gradient descent: position $\mathbf{x} = (2, 3)$, gradient $\mathbf{g} = (8, -4)$, learning rate $\eta = 0.25$. Compute the new position $\mathbf{x} - \eta\mathbf{g}$ and how far the step moved.

    Dot product

    The dot product multiplies two vectors into a single number that measures agreement: positive when they point roughly the same way, zero when perpendicular, negative when opposed. It is the fundamental similarity measure — attention scores in transformers are dot products.

    Definition $$\mathbf{u}\cdot\mathbf{v} = \sum_{i=1}^n u_i v_i = \|\mathbf{u}\|\,\|\mathbf{v}\|\cos\theta,$$ where $\theta$ is the angle between them. Hence $\cos\theta = \frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$, and $\mathbf{u}\cdot\mathbf{u} = \|\mathbf{u}\|^2$. Perpendicular (orthogonal) $\iff \mathbf{u}\cdot\mathbf{v} = 0$.
    Worked example $\mathbf{u} = (1, 2, 2)$, $\mathbf{v} = (2, -2, 1)$. Dot: $2 - 4 + 2 = 0$ — orthogonal, even though nothing about the numbers looks special. Now $\mathbf{u} = (3, 4)$, $\mathbf{v} = (5, 0)$: $\mathbf{u}\cdot\mathbf{v} = 15$; $\cos\theta = \frac{15}{5\cdot5} = 0.6$, so $\theta = \arccos 0.6 \approx 53.13^\circ$.

    Cross product

    Only in 3D: the cross product of two vectors is a third vector perpendicular to both, whose length equals the area of the parallelogram they span. It encodes rotation and orientation — torque, angular momentum, and surface normals in graphics are cross products.

    Definition $$\mathbf{u}\times\mathbf{v} = (u_2v_3 - u_3v_2,\; u_3v_1 - u_1v_3,\; u_1v_2 - u_2v_1).$$ Properties: $\mathbf{u}\times\mathbf{v} \perp \mathbf{u}, \mathbf{v}$; $\|\mathbf{u}\times\mathbf{v}\| = \|\mathbf{u}\|\|\mathbf{v}\|\sin\theta$ = parallelogram area; direction by the right-hand rule; anticommutative: $\mathbf{v}\times\mathbf{u} = -\mathbf{u}\times\mathbf{v}$; $\mathbf{u}\times\mathbf{u} = \mathbf{0}$.
    Worked example $\mathbf{u} = (1, 0, 0)$, $\mathbf{v} = (0, 1, 0)$: $\mathbf{u}\times\mathbf{v} = (0\cdot0-0\cdot1,\; 0\cdot0-1\cdot0,\; 1\cdot1-0\cdot0) = (0,0,1)$ — $x$ cross $y$ is $z$, the right-hand rule in action. Bigger example: $\mathbf{u}=(2,1,0)$, $\mathbf{v}=(1,3,0)$: $\mathbf{u}\times\mathbf{v} = (1\cdot0-0\cdot3,\; 0\cdot1-2\cdot0,\; 2\cdot3-1\cdot1) = (0,0,5)$: parallelogram area 5, pointing up.
    Pitfall Order matters: swapping the arguments flips the sign. And there is no true cross product in 2D or 4D+ — for 2D use the scalar $u_1v_2 - u_2v_1$ (signed area).
    Drill
    1. EASY $(0,0,1)\times(1,0,0) = ?$
      Solution

      Solution

    3. HARD Find a unit normal to the plane through $P=(1,0,0)$, $Q=(0,2,0)$, $R=(0,0,3)$.
      Solution
      $\vec{PQ} = (-1,2,0)$, $\vec{PR} = (-1,0,3)$. Cross: $(2\cdot3-0\cdot0,\; 0\cdot(-1)-(-1)\cdot3,\; (-1)\cdot0-2\cdot(-1)) = (6, 3, 2)$. Length $\sqrt{36+9+4} = 7$. Unit normal: $\pm\tfrac17(6,3,2)$.

    Vector projection

    Projection answers: how much of $\mathbf{u}$ points along $\mathbf{v}$? Shine a light perpendicular to $\mathbf{v}$; the shadow of $\mathbf{u}$ on $\mathbf{v}$'s line is the projection. The leftover part is perpendicular — splitting a vector into "along" and "across" is one of the most reused moves in mathematics.

    Definition Scalar projection (shadow length, signed): $\text{comp}_{\mathbf{v}}\mathbf{u} = \frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{v}\|}$. Vector projection: $$\text{proj}_{\mathbf{v}}\mathbf{u} = \frac{\mathbf{u}\cdot\mathbf{v}}{\mathbf{v}\cdot\mathbf{v}}\,\mathbf{v}.$$ The rejection $\mathbf{u} - \text{proj}_{\mathbf{v}}\mathbf{u}$ is orthogonal to $\mathbf{v}$.
    Worked example Project $\mathbf{u} = (3, 4)$ onto $\mathbf{v} = (2, 0)$. $\mathbf{u}\cdot\mathbf{v} = 6$, $\mathbf{v}\cdot\mathbf{v} = 4$: $\text{proj}_{\mathbf{v}}\mathbf{u} = \tfrac64(2,0) = (3, 0)$ — just the horizontal part, as the picture demands. Rejection: $(3,4) - (3,0) = (0,4)$, orthogonal to $\mathbf{v}$. ✓ And $(3,0)+(0,4)$ rebuilds $\mathbf{u}$.

      $\mathbf{u}\cdot\mathbf{v} = 12+8 = 20$; $\|\mathbf{v}\|^2 = 25$. Projection: $\tfrac{20}{25}(3,4) = (2.4, 3.2)$. Rejection: $(4,2)-(2.4,3.2) = (1.6, -1.2)$; check $(1.6)(3) + (-1.2)(4) = 4.8-4.8=0$. ✓
    3. HARD A 100 N weight rests on a ramp inclined 30°. Split gravity into components along and perpendicular to the ramp.
      Solution
      Along-ramp component: $100\sin 30^\circ = 50$ N (pulls it downhill); perpendicular: $100\cos 30^\circ = 50\sqrt3 \approx 86.6$ N (pressed into the ramp). Check: $50^2 + (50\sqrt3)^2 = 2500 + 7500 = 100^2$. ✓

    Geometric transformations

    A transformation moves every point of the plane at once: slide it (translation), spin it (rotation), mirror it (reflection), stretch it (scaling). Rotations, reflections and scalings are linear — they can be written as matrices, which is the door into Chapter 8. Data augmentation in vision models is exactly these operations applied to images.

    Definition Translation by $\mathbf{t}$: $P \mapsto P + \mathbf{t}$. Scaling by $k$ about the origin: $(x,y) \mapsto (kx, ky)$. Reflection across the $x$-axis: $(x,y)\mapsto(x,-y)$; across $y=x$: $(x,y)\mapsto(y,x)$. Rotation by angle $\theta$ counterclockwise about the origin: $$(x, y) \mapsto (x\cos\theta - y\sin\theta,\; x\sin\theta + y\cos\theta).$$ Rigid motions (translations, rotations, reflections) preserve distances; scalings multiply them by $|k|$.
    Worked example Rotate $(1, 0)$ by $90^\circ$: $(\cos 90^\circ - 0, \sin 90^\circ + 0) = (0, 1)$. ✓ Rotate $(2, 1)$ by $90^\circ$: $(2\cdot 0 - 1\cdot 1,\; 2\cdot1 + 1\cdot 0) = (-1, 2)$. Note the general $90^\circ$ pattern $(x,y)\mapsto(-y,x)$, and that lengths are preserved: $\|(2,1)\| = \|(-1,2)\| = \sqrt5$.

    Task 1 — Vector toolkit. Write functions norm, angle_between, project (vector projection of u onto v), and verify on the worked examples: angle between (3,4) and (5,0) ≈ 53.13°, proj of (4,2) onto (3,4) = (2.4, 3.2).

    Reference solution
    import numpy as np

def norm(v):
    return float(np.sqrt(np.dot(v, v)))

def angle_between(u, v, degrees=True):
    c = np.dot(u, v) / (norm(u) * norm(v))
    c = np.clip(c, -1.0, 1.0)          # guard float error
    a = np.arccos(c)
    return float(np.degrees(a)) if degrees else float(a)

def project(u, v):
    v = np.asarray(v, float)
    return (np.dot(u, v) / np.dot(v, v)) * v

print(angle_between([3, 4], [5, 0]))    # 53.1301...
print(project([4, 2], [3, 4]))          # [2.4 3.2]
r = np.array([4, 2]) - project([4, 2], [3, 4])
print(np.dot(r, [3, 4]))                # ~0: rejection is orthogonal

    Task 2 — Rotation and rigidity. Build the 2D rotation as a function rotate(points, theta) applied to an N×2 array of points. Rotate a random point cloud by 73° and verify numerically that all pairwise distances are unchanged (max absolute change < 1e-9).

    Reference solution
    import numpy as np

def rotate(P, theta):
    c, s = np.cos(theta), np.sin(theta)
    R = np.array([[c, -s], [s, c]])
    return P @ R.T                       # rotate each row

def pairwise_dists(P):
    d = P[:, None, :] - P[None, :, :]
    return np.sqrt((d ** 2).sum(-1))

rng = np.random.default_rng(0)
P = rng.normal(size=(50, 2))
Q = rotate(P, np.radians(73))
print(np.abs(pairwise_dists(P) - pairwise_dists(Q)).max())  # ~1e-15

    Task 3 — Point in a triangle via cross products. Using 2D cross products (signed areas), write in_triangle(p, a, b, c) that returns True iff p lies inside triangle abc. Test with the centroid (inside) and a far point (outside).

    Reference solution
    import numpy as np

def cross2(o, a, b):
    """Signed area x2 of triangle o-a-b (positive = counterclockwise)."""
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def in_triangle(p, a, b, c):
    s1 = cross2(a, b, p)
    s2 = cross2(b, c, p)
    s3 = cross2(c, a, p)
    has_neg = (s1 < 0) or (s2 < 0) or (s3 < 0)
    has_pos = (s1 > 0) or (s2 > 0) or (s3 > 0)
    return not (has_neg and has_pos)   # all same sign (or zero: on edge)

a, b, c = (0, 0), (6, 0), (0, 8)
centroid = (2, 8/3)
print(in_triangle(centroid, a, b, c))  # True
print(in_triangle((10, 10), a, b, c))  # False
