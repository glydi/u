    What a differential equation is

    An ordinary equation asks "which number makes this true?" A differential equation asks "which function makes this true?" — it relates a function to its own derivatives. Nature rarely tells you a quantity directly; it tells you how the quantity changes: cooling, growth, motion, learning dynamics. Solving the equation reconstructs the trajectory from the law.

    Definition An ordinary differential equation (ODE) of order $n$ relates $t$, $y(t)$ and derivatives up to $y^{(n)}$: $F(t,y,y',\dots,y^{(n)})=0$. A solution is a function satisfying it on an interval. An initial value problem (IVP) adds conditions $y(t_0)=y_0,\dots$ pinning down one solution from the general family.
    Worked example Verify $y(t)=3e^{2t}-\tfrac12$ solves $y'=2y+1$ with $y(0)=\tfrac52$. Left side: $y'=6e^{2t}$. Right side: $2(3e^{2t}-\tfrac12)+1=6e^{2t}-1+1=6e^{2t}$ ✓. Initial condition: $y(0)=3-\tfrac12=\tfrac52$ ✓. The general solution is $y=Ce^{2t}-\tfrac12$: one constant per order.
    Where this goes Gradient flow $\dot\theta=-\nabla L(\theta)$ is the continuous-time limit of gradient descent (Ch 15); neural ODEs (this chapter) make the network itself an ODE.

    Slope fields

    A first-order ODE $y'=f(t,y)$ assigns a slope to every point of the plane. Draw a tiny dash with that slope at a grid of points and you can see every solution at once: solutions are the curves that flow with the dashes, like iron filings following a magnetic field.

    Definition The slope field of $y'=f(t,y)$ is the assignment of direction $\big(1,f(t,y)\big)$ to each point $(t,y)$. Solution curves are everywhere tangent to the field. Points where $f=0$ trace nullclines, where solutions run horizontally.
    Worked example $y'=y-t$. Along the line $y=t$ the slope is $0$ (nullcline). Above it, slopes are positive and grow; below, negative. Guess a particular solution of the form $y=at+b$: then $a=at+b-t$ for all $t$ forces $a=1$, $b=1$: $y=t+1$ is a straight-line solution, and the general solution $y=t+1+Ce^{t}$ peels away from it exponentially — visible in the field as curves hugging then leaving the line.

    Separable equations

    If the rate factors into (function of $y$)×(function of $t$), you can herd all the $y$'s to one side, all the $t$'s to the other, and integrate both sides separately. It is the workhorse first technique — and it already solves growth, decay, cooling and the logistic equation.

    Definition $y'=g(t)\,h(y)$ is separable. Where $h(y)\neq0$: $$\int\frac{dy}{h(y)}=\int g(t)\,dt+C.$$ Constant solutions come from roots of $h(y)=0$ and must be checked separately.
    Worked example $y'=ty^2$, $y(0)=1$. Separate: $\dfrac{dy}{y^2}=t\,dt$. Integrate: $-\dfrac1y=\dfrac{t^2}{2}+C$. At $(0,1)$: $-1=C$. So $y=\dfrac{1}{1-t^2/2}=\dfrac{2}{2-t^2}$. Note the solution blows up at $t=\sqrt2$ — finite-time blow-up from an innocent-looking equation.
    Pitfall Dividing by $h(y)$ silently discards equilibrium solutions. $y'=y^2$ has the family $y=\frac{-1}{t+C}$ and $y\equiv0$, which the division threw away.

    3. MED Newton's cooling: $T'=-k(T-20)$, $T(0)=90$, $T(10)=60$. Find $k$ and $T(20)$.

    4. HARD Solve $y'=\dfrac{y^2-1}{2}$ with $y(0)=0$ and give the interval of validity.
      Solution
      $\int\frac{2\,dy}{(y-1)(y+1)}=\int dt$. Partial fractions: $\frac{2}{(y-1)(y+1)}=\frac{1}{y-1}-\frac{1}{y+1}$, so $\ln\left|\frac{y-1}{y+1}\right|=t+C$. At $(0,0)$: $\ln1=C=0$. Valid for all $t$ ($y\to\mp1$ as $t\to\pm\infty$).

    First-order linear equations

    Linear means $y$ and $y'$ appear to the first power, never multiplied together: $y'+p(t)y=q(t)$. Think of a bank account with time-varying interest $-p$ and deposits $q$. These are the only first-order equations with a complete, formulaic solution theory — via the integrating factor.

    Definition The standard form is $y'+p(t)\,y=q(t)$. It is homogeneous if $q\equiv0$ (solution $y=Ce^{-\int p}$). The general solution is (particular solution) $+$ (general homogeneous solution) — superposition, the fingerprint of linearity.
    Worked example $y'+2y=e^{-t}$. Homogeneous: $y_h=Ce^{-2t}$. Particular: try $y_p=Ae^{-t}$: $-Ae^{-t}+2Ae^{-t}=Ae^{-t}=e^{-t}\Rightarrow A=1$. General: $y=e^{-t}+Ce^{-2t}$. With $y(0)=3$: $C=2$, so $y=e^{-t}+2e^{-2t}$.
    Drill
    1. EASY Solve $y'=3y$ with $y(0)=5$.
      Solution
      $y=5e^{3t}$.
    2. MED Put $ty'+2y=t^3$ ($t>0$) into standard form and identify $p,q$.
      Solution
      $y'+\frac{2}{t}y=t^2$: $p=\frac2t$, $q=t^2$.
    3. HARD Show that the difference of any two solutions of $y'+p(t)y=q(t)$ solves the homogeneous equation, and explain why this makes the "particular + homogeneous" structure inevitable.
      Solution
      If $y_1'+py_1=q$ and $y_2'+py_2=q$, subtract: $(y_1-y_2)'+p(y_1-y_2)=0$. So every solution differs from a fixed particular one by a homogeneous solution, and conversely adding a homogeneous solution preserves the equation: solution set $=y_p+\{\text{homogeneous solutions}\}$ — an affine subspace, exactly like $A\mathbf x=\mathbf b$ in Ch 8.

    Integrating factors

    Multiply $y'+py=q$ by the cunning factor $\mu=e^{\int p\,dt}$ and the left side collapses into the derivative of a single product, $(\mu y)'$. Then just integrate. It feels like a trick; it is really "undoing the product rule."

    Definition For $y'+p(t)y=q(t)$, the integrating factor is $\mu(t)=e^{\int p(t)\,dt}$. Then $(\mu y)'=\mu q$ and $$y=\frac{1}{\mu(t)}\left(\int\mu(t)\,q(t)\,dt+C\right).$$
    Worked example $y'+\dfrac{2}{t}y=t^2$ ($t>0$). $\mu=e^{\int 2/t\,dt}=e^{2\ln t}=t^2$. Then $(t^2y)'=t^4$, so $t^2y=\dfrac{t^5}{5}+C$ and $y=\dfrac{t^3}{5}+\dfrac{C}{t^2}$. Check with $C=0$: $y'=\frac{3t^2}{5}$, $\frac{2}{t}\cdot\frac{t^3}{5}=\frac{2t^2}{5}$, sum $=t^2$ ✓.
    Pitfall The equation must be in standard form first — coefficient of $y'$ equal to 1 — or $\mu$ comes out wrong. And $\int p\,dt$ needs no constant: any antiderivative works.
    Drill
    1. EASY Solve $y'+y=2$ with the integrating factor.
      Solution
      $\mu=e^t$: $(e^ty)'=2e^t\Rightarrow e^ty=2e^t+C\Rightarrow y=2+Ce^{-t}$.
    2. MED Solve $y'-2ty=t$, $y(0)=0$.
      Solution
      $\mu=e^{-t^2}$: $(e^{-t^2}y)'=te^{-t^2}\Rightarrow e^{-t^2}y=-\tfrac12e^{-t^2}+C$. $y(0)=0\Rightarrow C=\tfrac12$. $y=\tfrac12(e^{t^2}-1)$.
    3. HARD Solve $ty'+(t+1)y=e^{-t}$ for $t>0$.
      Solution
      Standard form: $y'+\frac{t+1}{t}y=\frac{e^{-t}}{t}$. $\mu=e^{\int(1+1/t)dt}=e^{t+\ln t}=te^{t}$. $(te^ty)'=te^t\cdot\frac{e^{-t}}{t}=1$, so $te^ty=t+C$, $y=e^{-t}\left(1+\frac{C}{t}\right)$.

    Exponential growth and decay

    The simplest law of change — "the rate is proportional to the amount" — produces the most consequential function in mathematics. Populations, radioactivity, compound interest, and unregularized gradient dynamics all obey $y'=ky$: growth for $k>0$, decay for $k<0$, with a fixed doubling time or half-life.

    Definition $y'=ky\iff y(t)=y_0e^{kt}$. Doubling time ($k>0$): $t_2=\dfrac{\ln2}{k}$. Half-life ($k<0$): $t_{1/2}=\dfrac{\ln2}{|k|}$.
    Worked example Carbon-14 has half-life $5730$ years, so $k=-\frac{\ln2}{5730}$. A bone retains $35\%$ of its original C-14. Age: $0.35=e^{kt}\Rightarrow t=\dfrac{\ln0.35}{k}=\dfrac{\ln(1/0.35)}{\ln2}\cdot5730=\dfrac{1.0498}{0.6931}\cdot5730\approx8680$ years.
    Think first Money grows at 5% per year, compounded continuously. Roughly how long to double — and where does the folk "rule of 72" come from?
    Reveal
    $t_2=\ln2/0.05\approx13.9$ years. Since $\ln2\approx0.693$, continuous compounding gives a "rule of 69.3": $t_2\approx69.3/(\text{percent rate})$. The traditional 72 adjusts upward for annual (discrete) compounding and easier mental division.

    1. EASY A culture triples every 4 hours. Find $k$.
      Solution
      $3=e^{4k}\Rightarrow k=\frac{\ln3}{4}\approx0.2747$ per hour.
    2. MED With $y'=ky$ and $y(2)=8$, $y(5)=64$, find $y(0)$.
      Solution
      $\frac{y(5)}{y(2)}=e^{3k}=8\Rightarrow k=\ln2$. $y(0)=y(2)e^{-2k}=8\cdot\frac14=2$.
    3. HARD Solve the decay-with-inflow model $y'=-ky+r$ ($k,r>0$ constant) and show every solution tends to $r/k$.
      Solution
      Integrating factor $e^{kt}$: $(e^{kt}y)'=re^{kt}\Rightarrow y=\frac{r}{k}+Ce^{-kt}$. As $t\to\infty$, $Ce^{-kt}\to0$: all solutions converge to the equilibrium $r/k$ — inflow balances decay. (This is also the mean of an Ornstein–Uhlenbeck process, Ch 12.)

    Logistic equation

    Exponential growth can't last: resources saturate. The logistic law multiplies the growth rate by "room remaining," $1-y/K$. Solutions form the S-curve: exponential take-off, inflection at half capacity, saturation at $K$. The same curve is the sigmoid of logistic regression (Ch 19) — probability saturating instead of population.

    Definition $$y'=ry\Big(1-\frac{y}{K}\Big),\qquad y(0)=y_0\ \Rightarrow\ y(t)=\frac{K}{1+\Big(\frac{K-y_0}{y_0}\Big)e^{-rt}}.$$ Equilibria: $y=0$ (unstable) and $y=K$ (stable). The inflection point is at $y=K/2$, where growth is fastest.
    Worked example $r=1$, $K=100$, $y_0=10$: $y(t)=\dfrac{100}{1+9e^{-t}}$. When does $y=50$? $1+9e^{-t}=2\Rightarrow e^{-t}=\frac19\Rightarrow t=\ln9\approx2.197$. Growth rate there: $y'=1\cdot50(1-\tfrac12)=25$ per unit time — the maximum, as promised at $K/2$.
    Explore

    Slide $r$, $K$ and $y_0$; the S-curve and its inflection line $y=K/2$ update. Start above $K$ to see decay toward capacity.

      Solution
      $y=0$ unstable (small populations grow), $y=50$ stable (perturbations decay back).
    2. MED Derive the logistic solution by separation and partial fractions.
      Solution
      $\int\frac{K\,dy}{y(K-y)}=\int r\,dt$. Since $\frac{K}{y(K-y)}=\frac1y+\frac{1}{K-y}$: $\ln\frac{y}{K-y}=rt+C$. Exponentiate and solve: $\frac{y}{K-y}=Ae^{rt}$ with $A=\frac{y_0}{K-y_0}$, giving $y=\frac{K}{1+\frac{K-y_0}{y_0}e^{-rt}}$.
    3. HARD Show that $u=1/y$ turns the logistic equation into a linear one, and re-derive the solution.
      Solution
      $u'=-y'/y^2=-\frac{r}{y}+\frac{r}{K}=-ru+\frac{r}{K}$: linear! Solution $u=\frac1K+Ce^{-rt}$; with $u_0=1/y_0$, $C=\frac1{y_0}-\frac1K$. Invert: $y=\Big(\frac1K+\big(\frac{1}{y_0}-\frac1K\big)e^{-rt}\Big)^{-1}$ — algebraically identical to the standard form. (This substitution trick is a Bernoulli equation with $n=2$.)

    Existence and uniqueness

    Before trusting a model — or a numerical solver — ask: does a solution exist, and is it the only one? The Picard–Lindelöf theorem says yes to both, locally, provided the right-hand side is continuous and doesn't change too violently in $y$ (Lipschitz). Uniqueness is what makes trajectories deterministic: through each point passes exactly one solution, so trajectories never cross.

    Theorem (Picard–Lindelöf) If $f(t,y)$ is continuous in a rectangle around $(t_0,y_0)$ and Lipschitz in $y$ there — $|f(t,y_1)-f(t,y_2)|\le L|y_1-y_2|$ — then the IVP $y'=f(t,y)$, $y(t_0)=y_0$ has exactly one solution on some interval around $t_0$. (Continuity of $\partial f/\partial y$ suffices for the Lipschitz condition.)
    Worked example $y'=3y^{2/3}$, $y(0)=0$: here $\partial f/\partial y=2y^{-1/3}$ blows up at $y=0$ — not Lipschitz — and indeed $y\equiv0$ and $y=t^3$ both solve it. But $y'=y^2$, $y(0)=1$ is Lipschitz near $y=1$ and has the unique solution $y=\frac{1}{1-t}$… which exists only for $t<1$: the theorem is local, and solutions can escape to infinity in finite time.
    Pitfall Existence-uniqueness is local. Global existence needs more (e.g. linear growth of $f$ in $y$). Blow-up in finite time — $y'=y^2$ — is the standard counterexample to naive extrapolation.
    Drill
    1. EASY Does $y'=\sin(ty)+t^2$, $y(0)=1$ have a unique local solution?
      Solution
      Yes: $f$ is smooth everywhere ($\partial f/\partial y=t\cos(ty)$ continuous), so Picard–Lindelöf applies.
    2. MED For $y'=\sqrt{|y|}$, $y(0)=0$, exhibit two distinct solutions.
      Solution
      $y\equiv0$; and $y=t^2/4$ for $t\ge0$ (with $y=0$ for $t<0$): $y'=t/2=\sqrt{t^2/4}$ ✓. Square-root right-hand sides at their zero are the classic uniqueness failure.
    3. HARD Show solutions of $y'=y^2$, $y(0)=y_0>0$ blow up at $t=1/y_0$, and explain why no Lipschitz bound on all of $\mathbb{R}$ exists for $f(y)=y^2$.
      Solution
      Separate: $-1/y=t+C$, $C=-1/y_0$: $y=\frac{y_0}{1-y_0t}\to\infty$ as $t\to1/y_0^-$. Globally, $|y_1^2-y_2^2|=|y_1+y_2||y_1-y_2|$ and $|y_1+y_2|$ is unbounded, so no single $L$ works on all of $\mathbb{R}$ — Lipschitz holds only on bounded sets, so the theorem gives only local solutions, honestly matching the blow-up.

    Second-order linear equations

    Newton's law $F=ma$ makes physics second-order: acceleration, the second derivative, responds to position and velocity. Constant-coefficient linear equations $ay''+by'+cy=0$ are completely solvable, and their solution space is a 2-dimensional vector space — pick two independent solutions and every solution is a combination.

    Definition $ay''+by'+cy=g(t)$ with $a\neq0$. Homogeneous ($g=0$): solutions form a 2-D vector space; a fundamental set $\{y_1,y_2\}$ is any linearly independent pair, and the general solution is $c_1y_1+c_2y_2$. Nonhomogeneous: general solution $=y_p+c_1y_1+c_2y_2$.
    Worked example $y''-y=0$: try $e^{rt}$: $r^2=1$, $r=\pm1$. General solution $y=c_1e^{t}+c_2e^{-t}$. IVP $y(0)=2$, $y'(0)=0$: $c_1+c_2=2$, $c_1-c_2=0$ so $c_1=c_2=1$: $y=e^t+e^{-t}=2\cosh t$.
    Drill

      Solution
      $y_1''=-4\cos2t=-4y_1$ ✓, same for $y_2$. General: $y=c_1\cos2t+c_2\sin2t$.
    2. MED Solve $y''+4y=8t$ with $y(0)=0,y'(0)=0$.
      Solution
      Particular: try $y_p=At$: $4At=8t$, $A=2$. General $y=2t+c_1\cos2t+c_2\sin2t$. $y(0)=c_1=0$; $y'=2+2c_2\cos2t$, $y'(0)=2+2c_2=0$, $c_2=-1$. $y=2t-\sin2t$.
    3. HARD The Wronskian is $W(t)=y_1y_2'-y_2y_1'$. Show for $y''+py'+qy=0$ that $W'=-pW$ (Abel's identity), and conclude $W$ is either always zero or never zero.

      $W'=y_1y_2''-y_2y_1''=y_1(-py_2'-qy_2)-y_2(-py_1'-qy_1)=-p(y_1y_2'-y_2y_1')=-pW$. So $W=W(t_0)e^{-\int p}$; the exponential never vanishes, so $W$ keeps the character of its initial value — independence of solutions is an all-or-nothing property.

    Characteristic equation

    Guess $y=e^{rt}$ and the differential equation collapses to a quadratic in $r$ — the characteristic equation. Its roots dictate everything: two real roots give two exponentials, complex roots give oscillation wrapped in an exponential envelope, a repeated root sprouts a factor of $t$.

    Definition For $ay''+by'+cy=0$, the characteristic equation is $ar^2+br+c=0$ with roots $r_{1,2}=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$.
    • Distinct real $r_1\neq r_2$: $y=c_1e^{r_1t}+c_2e^{r_2t}$.
    • Repeated $r$: $y=(c_1+c_2t)e^{rt}$.
    • Complex $r=\alpha\pm i\beta$: $y=e^{\alpha t}(c_1\cos\beta t+c_2\sin\beta t)$.
    Worked example $y''+2y'+5y=0$: $r^2+2r+5=0$, $r=\frac{-2\pm\sqrt{4-20}}{2}=-1\pm2i$. Solution $y=e^{-t}(c_1\cos2t+c_2\sin2t)$: oscillation at angular frequency 2 inside a decaying envelope $e^{-t}$ — a damped vibration. With $y(0)=1,y'(0)=1$: $c_1=1$; $y'=e^{-t}((-c_1+2c_2)\cos2t+(-c_2-2c_1)\sin2t)$ so $-1+2c_2=1$, $c_2=1$. $y=e^{-t}(\cos2t+\sin2t)$.
    Pitfall For the repeated root, the fundamental pair is $e^{rt}$ and $te^{rt}$ — forgetting the $t$ leaves you one dimension short of the solution space. The $t$ arises as the limit of $\frac{e^{r_2t}-e^{r_1t}}{r_2-r_1}$ as roots merge.
    Drill
    1. EASY Solve $y''-5y'+6y=0$.
      Solution
      $r^2-5r+6=(r-2)(r-3)$: $y=c_1e^{2t}+c_2e^{3t}$.
    2. MED Solve $y''+6y'+9y=0$, $y(0)=1$, $y'(0)=0$.
      Solution
      $(r+3)^2=0$: $y=(c_1+c_2t)e^{-3t}$. $c_1=1$; $y'=(c_2-3c_1-3c_2t)e^{-3t}$, $y'(0)=c_2-3=0$, $c_2=3$. $y=(1+3t)e^{-3t}$.
    3. HARD For $y''+by'+y=0$, describe how the solution type changes as $b$ increases from $0$ to $3$, naming the transition value.
      Solution
      Roots $r=\frac{-b\pm\sqrt{b^2-4}}{2}$. $b=0$: pure oscillation ($\pm i$). $0<b<2$: complex with negative real part — decaying oscillation (underdamped). $b=2$: repeated root $-1$ (critical damping). $b>2$: two negative real roots — monotone decay (overdamped). The transition at $b=2$ is where $b^2=4ac$.

    Harmonic oscillator

    A mass on a spring, a pendulum at small angle, a circuit with inductance and capacitance — all reduce to $y''+\omega^2y=0$, the harmonic oscillator, physics' favorite equation. Solutions circle forever in phase space, trading position for velocity like kinetic and potential energy.

    Definition $my''+ky=0$, i.e. $y''+\omega_0^2y=0$ with natural frequency $\omega_0=\sqrt{k/m}$. General solution $y=A\cos(\omega_0t)+B\sin(\omega_0t)=R\cos(\omega_0t-\varphi)$ with amplitude $R=\sqrt{A^2+B^2}$, phase $\varphi=\operatorname{atan2}(B,A)$. Energy $E=\frac12m\dot y^2+\frac12ky^2$ is conserved.
    Worked example $m=1$, $k=4$ ($\omega_0=2$), released from rest at $y=3$: $y(0)=3,\ y'(0)=0\Rightarrow A=3,B=0$: $y=3\cos2t$. Velocity $y'=-6\sin2t$ peaks at $6$ when $y=0$. Energy check: $\frac12(6)^2=18$ at the center; $\frac12\cdot4\cdot3^2=18$ at the extremes ✓ — the same energy sloshing between forms.
    Drill
    1. EASY What is the period of $y''+9y=0$?
      Solution
      $\omega_0=3$, period $T=2\pi/3$.
    2. MED Write $y=3\cos5t+4\sin5t$ in amplitude-phase form.
      Solution
      $R=\sqrt{9+16}=5$, $\varphi=\operatorname{atan2}(4,3)\approx0.9273$: $y=5\cos(5t-0.9273)$.
    3. HARD Differentiate the energy $E(t)=\frac12\dot y^2+\frac{\omega_0^2}{2}y^2$ along solutions and show it is constant; deduce trajectories in the $(y,\dot y)$ plane are ellipses.
      Solution
      $\dot E=\dot y\ddot y+\omega_0^2y\dot y=\dot y(\ddot y+\omega_0^2y)=0$ by the equation. So $\frac{\dot y^2}{2E}+\frac{y^2}{2E/\omega_0^2}=1$: an ellipse with semi-axes $\sqrt{2E}$ (velocity) and $\sqrt{2E}/\omega_0$ (position); each energy level is one closed orbit.

    Damping and resonance

    Add friction and the oscillator loses energy: underdamped (spirals down through ever-smaller swings), critically damped (fastest return, no overshoot — how door closers are tuned), overdamped (sluggish crawl). Drive it periodically and the response peaks when the driving frequency matches the natural one: resonance, the reason soldiers break step on bridges.

    Definition Damped: $y''+2\zeta\omega_0y'+\omega_0^2y=0$ with damping ratio $\zeta$. $\zeta<1$: underdamped, $y=e^{-\zeta\omega_0t}R\cos(\omega_dt-\varphi)$, $\omega_d=\omega_0\sqrt{1-\zeta^2}$. $\zeta=1$: critical. $\zeta>1$: overdamped. Driven: $y''+2\zeta\omega_0y'+\omega_0^2y=F\cos\omega t$ has steady-state amplitude $$R(\omega)=\frac{F}{\sqrt{(\omega_0^2-\omega^2)^2+(2\zeta\omega_0\omega)^2}},$$ maximized near $\omega\approx\omega_0$ for small $\zeta$ (peak $\approx F/(2\zeta\omega_0^2)$).
    Worked example $y''+y'+25y=0$: $\omega_0=5$, $2\zeta\omega_0=1$ so $\zeta=0.1$ — underdamped. $\omega_d=5\sqrt{1-0.01}\approx4.975$. The envelope decays like $e^{-0.5t}$. Driven at $\omega=5$ with $F=1$: $R=\frac{1}{\sqrt{0+(1\cdot5)^2}}=\frac15$ — versus static response $1/25$: resonance amplifies 5×, exactly $1/(2\zeta)$.

    Systems of ODEs

    Real systems have many interacting variables: predator and prey, positions and velocities, all the units of a recurrent network. Stack them into a vector $\mathbf x(t)$ and the law of motion becomes $\dot{\mathbf x}=f(\mathbf x)$ — one arrow field on state space. Any higher-order ODE converts to a first-order system, so systems are the universal format (and what every numerical solver actually consumes).

    Definition A first-order system: $\dot{\mathbf x}=f(t,\mathbf x)$, $\mathbf x\in\mathbb{R}^n$. Linear constant-coefficient case: $\dot{\mathbf x}=A\mathbf x$; if $A\mathbf v=\lambda\mathbf v$ then $\mathbf x(t)=e^{\lambda t}\mathbf v$ is a solution, and with a basis of eigenvectors the general solution is $\sum_ic_ie^{\lambda_it}\mathbf v_i$. Conversion: $y''=g(y,y')$ becomes $\dot x_1=x_2$, $\dot x_2=g(x_1,x_2)$.
    Worked example $\dot{\mathbf x}=A\mathbf x$, $A=\begin{pmatrix}0&1\\-2&-3\end{pmatrix}$ (this is $y''+3y'+2y=0$ in disguise). Eigenvalues: $\det(A-\lambda I)=\lambda^2+3\lambda+2=(\lambda+1)(\lambda+2)$: $\lambda=-1,-2$. Eigenvectors: $\lambda=-1$: $(1,-1)^\top$; $\lambda=-2$: $(1,-2)^\top$. General solution $$\mathbf x(t)=c_1e^{-t}\begin{pmatrix}1\\-1\end{pmatrix}+c_2e^{-2t}\begin{pmatrix}1\\-2\end{pmatrix},$$ every trajectory sliding into the origin along the slow ($\lambda=-1$) eigendirection.

    Matrix exponential

    For scalars, $\dot x=ax$ gives $x=e^{at}x_0$. For systems, exactly the same — once you define $e^{At}$ by the power series. The matrix exponential is the flow map of a linear system: it advances any initial state by time $t$, and eigendecomposition computes it by exponentiating eigenvalues.

    Definition $$e^{At}=\sum_{k=0}^{\infty}\frac{(At)^k}{k!}=I+At+\frac{A^2t^2}{2!}+\cdots$$ (always converges). Then $\mathbf x(t)=e^{At}\mathbf x_0$ solves $\dot{\mathbf x}=A\mathbf x$, $\mathbf x(0)=\mathbf x_0$. If $A=V\Lambda V^{-1}$, then $e^{At}=Ve^{\Lambda t}V^{-1}$ with $e^{\Lambda t}=\mathrm{diag}(e^{\lambda_it})$. Properties: $e^{A(t+s)}=e^{At}e^{As}$; $\frac{d}{dt}e^{At}=Ae^{At}$; $\det e^{At}=e^{\operatorname{tr}(A)t}$.
    Worked example $A=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ (rotation generator). Powers cycle: $A^2=-I$, $A^3=-A$, $A^4=I$. Series: $$e^{At}=I\Big(1-\frac{t^2}{2!}+\cdots\Big)+A\Big(t-\frac{t^3}{3!}+\cdots\Big)=\begin{pmatrix}\cos t&-\sin t\\ \sin t&\cos t\end{pmatrix}$$ — rotation by angle $t$: the linear system $\dot{\mathbf x}=A\mathbf x$ spins states in circles, matching the harmonic oscillator's phase-space orbits.
    Pitfall $e^{A+B}=e^Ae^B$ only when $AB=BA$. Noncommuting matrices break it — the root of operator-splitting errors in numerical methods.

    Phase portraits

    Forget time; draw state space and let trajectories paint the dynamics. For planar linear systems the whole zoo is classified by the eigenvalues of $A$: nodes (both same sign), saddles (opposite signs), spirals (complex with nonzero real part), centers (pure imaginary). One glance at a phase portrait tells you the fate of every initial condition.

    Definition The phase portrait of $\dot{\mathbf x}=f(\mathbf x)$ in $\mathbb{R}^2$ is the family of solution curves in the $(x_1,x_2)$ plane. For $\dot{\mathbf x}=A\mathbf x$ with eigenvalues $\lambda_{1,2}$: real, same sign — node (stable if negative); real, opposite — saddle; $\alpha\pm i\beta$, $\alpha<0$ — stable spiral; $\alpha>0$ — unstable spiral; $\alpha=0$ — center. Trace-determinant shortcut: the $\lambda$'s are roots of $\lambda^2-\operatorname{tr}(A)\lambda+\det A=0$.
    Worked example $A=\begin{pmatrix}-1&2\\-2&-1\end{pmatrix}$: $\operatorname{tr}=-2$, $\det=1+4=5$, discriminant $4-20<0$: complex $\lambda=-1\pm2i$. Stable spiral, rotating clockwise (at $(1,0)$, $\dot{\mathbf x}=(-1,-2)$ points down) and contracting by $e^{-t}$ per unit time.

    Equilibria and linearization

    Nonlinear systems are hard, but near a resting point they behave like their linearization: replace $f$ by its Jacobian at the equilibrium (Ch 9) and read stability off the eigenvalues. This local-linear lens is how we understand pendulums, epidemics, lasers — and the fixed points of recurrent networks and training dynamics.

    Definition $\mathbf x^\star$ is an equilibrium of $\dot{\mathbf x}=f(\mathbf x)$ if $f(\mathbf x^\star)=\mathbf0$. Hartman–Grobman: if the Jacobian $J=Df(\mathbf x^\star)$ has no eigenvalue with zero real part (hyperbolic case), the nonlinear flow near $\mathbf x^\star$ is topologically the same as $\dot{\mathbf u}=J\mathbf u$. All eigenvalues with negative real part ⇒ asymptotically stable; any positive real part ⇒ unstable.
    Worked example Pendulum: $\dot\theta=v$, $\dot v=-\sin\theta$. Equilibria: $(\theta,v)=(0,0)$ (hanging) and $(\pi,0)$ (inverted). Jacobian $J=\begin{pmatrix}0&1\\-\cos\theta&0\end{pmatrix}$. At $(0,0)$: $\begin{pmatrix}0&1\\-1&0\end{pmatrix}$, $\lambda=\pm i$ — a center (non-hyperbolic; energy conservation confirms closed orbits). At $(\pi,0)$: $\begin{pmatrix}0&1\\1&0\end{pmatrix}$, $\lambda=\pm1$ — a saddle: the inverted pendulum falls along the unstable eigendirection.
    Where this goes Lyapunov functions and stability theory (Ch 28); linearizing RNN dynamics around fixed points explains memory and vanishing gradients (Ch 21).

    Euler's method

    When no formula solves the ODE, walk it: at your current point, read the slope, step a little way along it, repeat. That is Euler's method — crude, intuitive, and the conceptual seed of every fancier solver. Its error shrinks only linearly with the step size, which is why we rarely use it raw. Gradient descent is exactly Euler's method applied to gradient flow.

    Definition For $y'=f(t,y)$, $y(t_0)=y_0$, with step $h$: $$y_{n+1}=y_n+h\,f(t_n,y_n),\qquad t_{n+1}=t_n+h.$$ Local (per-step) error $O(h^2)$; global error over a fixed interval $O(h)$ — a first-order method.
    Worked example $y'=y$, $y(0)=1$, $h=0.5$, two steps to $t=1$: $y_1=1+0.5(1)=1.5$; $y_2=1.5+0.5(1.5)=2.25$. True $e\approx2.71828$: error $0.468$. Halve to $h=0.25$ (four steps): $y_4=(1.25)^4=2.4414$, error $0.277$ — roughly halved, as first order predicts. In general Euler on $y'=y$ gives $(1+h)^{1/h}\to e$: compound interest rediscovered.

    Integrate $y'=\cos t\cdot y$ (exact: $e^{\sin t}$). Shrink $h$ and compare Euler (amber) and RK4 (blue) against the exact curve; the readout shows final errors.

    Pitfall Stability, not just accuracy: for $y'=-\lambda y$ ($\lambda>0$), Euler gives $y_{n+1}=(1-h\lambda)y_n$, which oscillates and diverges when $h>2/\lambda$ even though the true solution decays. Step size limits are stability limits.

    Runge-Kutta methods

    Euler trusts the slope at the start of the step; Runge–Kutta methods sample the slope at several trial points inside the step and blend them, cancelling error terms order by order. The classic RK4 uses four evaluations for fourth-order accuracy — halving $h$ cuts the error 16-fold — and has been the default workhorse for a century.

    Definition RK4 for $y'=f(t,y)$: $$k_1=f(t_n,y_n),\quad k_2=f\big(t_n+\tfrac h2,\,y_n+\tfrac h2k_1\big),\quad k_3=f\big(t_n+\tfrac h2,\,y_n+\tfrac h2k_2\big),\quad k_4=f(t_n+h,\,y_n+hk_3),$$ $$y_{n+1}=y_n+\frac h6\,(k_1+2k_2+2k_3+k_4).$$ Global error $O(h^4)$. (Midpoint/RK2, $y_{n+1}=y_n+hf(t_n+\frac h2,y_n+\frac h2k_1)$, is the order-2 sibling.)
    Worked example $y'=y$, $y(0)=1$, one RK4 step with $h=1$: $k_1=1$, $k_2=1+\tfrac12=1.5$, $k_3=1+0.75=1.75$, $k_4=1+1.75=2.75$. $y_1=1+\frac{1+3+3.5+2.75}{6}=1+\frac{10.25}{6}=2.7083$. True $e=2.71828$: error $0.010$ from a single step spanning the whole interval — versus Euler's $0.72$. The blend $\frac16(1,2,2,1)$ reproduces the Taylor series of $e^h$ through $h^4/24$.

    Stiff equations

    A stiff system mixes very fast and very slow time scales: the fast part dies out almost instantly, yet explicit solvers must keep taking microscopic steps to avoid instability long after the fast transient is irrelevant. The cure is implicit methods, which solve for the new point instead of extrapolating — unconditionally stable, at the price of solving an equation per step.

    Definition A linear system $\dot{\mathbf x}=A\mathbf x$ is stiff when the stiffness ratio $\max|\mathrm{Re}\,\lambda_i|/\min|\mathrm{Re}\,\lambda_i|$ is large. Backward (implicit) Euler: $$y_{n+1}=y_n+h\,f(t_{n+1},y_{n+1}),$$ requiring a (generally nonlinear) solve for $y_{n+1}$. For $y'=\lambda y$ it gives $y_{n+1}=\frac{y_n}{1-h\lambda}$, stable for every $h>0$ whenever $\mathrm{Re}\,\lambda<0$ (A-stability).
    Worked example $y'=-1000(y-\cos t)-\sin t$, $y(0)=1$: exact solution $y=\cos t$ (check: $y'=-\sin t$ and the bracket vanishes). The $-1000$ makes it stiff: forward Euler needs $h<2/1000=0.002$ to avoid explosion even though the solution is a lazy cosine. Backward Euler with $h=0.1$: $y_{n+1}=\frac{y_n+h(1000\cos t_{n+1}-\sin t_{n+1})}{1+1000h}$ — the huge coefficient now sits harmlessly in the denominator, and 63 steps cross $t=2\pi$ where forward Euler needed 3200.
    Pitfall Stiffness is a property of the solver-equation pair, not of solution roughness: the exact solution above is perfectly smooth. If shrinking the step is the only thing keeping an explicit solver alive, suspect stiffness and switch to an implicit method (or an exponential integrator).

    Partial differential equations

    When the unknown is a function of several variables — temperature over space and time, a probability density evolving over states — the law of change involves partial derivatives: a PDE. The big three linear archetypes are diffusion (heat equation), waves (wave equation), and equilibrium (Laplace's equation), and an enormous amount of science is variations on them.

    Definition A PDE relates an unknown $u(x_1,\dots,x_n)$ and its partial derivatives. Canonical second-order examples: heat $u_t=\alpha u_{xx}$ (parabolic), wave $u_{tt}=c^2u_{xx}$ (hyperbolic), Laplace $u_{xx}+u_{yy}=0$ (elliptic). A well-posed problem couples the PDE with initial and/or boundary conditions so a unique solution depends continuously on the data.
    Worked example Check that $u(x,t)=f(x-ct)+g(x+ct)$ solves the wave equation $u_{tt}=c^2u_{xx}$ for any twice-differentiable $f,g$: $u_{tt}=c^2f''(x-ct)+c^2g''(x+ct)$ and $u_{xx}=f''+g''$, so $u_{tt}=c^2u_{xx}$ ✓ — every 1-D wave is a right-mover plus a left-mover at speed $c$ (d'Alembert). Contrast the heat equation, whose solutions smooth out instead of translating.

    Heat equation

    Heat flows from hot to cold at a rate set by curvature: where the temperature profile is concave (a hot bump), it falls; where convex (a cold dip), it rises. Peaks melt, valleys fill, everything smooths toward the average. The same equation governs any diffusing quantity — ink, probability, noise in a diffusion model.

    Definition $$u_t=\alpha\,u_{xx}$$ on a rod $0\le x\le L$, with e.g. $u(0,t)=u(L,t)=0$ and $u(x,0)=\phi(x)$. Separated solutions: $u_n=e^{-\alpha(n\pi/L)^2t}\sin\frac{n\pi x}{L}$; the general solution is $u=\sum_nb_nu_n$ with $b_n$ the Fourier sine coefficients of $\phi$ (Ch 14). On all of $\mathbb{R}$, the heat kernel solves it: $u(x,t)=\frac{1}{\sqrt{4\pi\alpha t}}e^{-x^2/(4\alpha t)}$ — a Gaussian of variance $2\alpha t$ spreading in time.
    Worked example Rod of length $L=\pi$, $\alpha=1$, $u(x,0)=\sin x+\tfrac12\sin 3x$, ends held at 0. Each mode decays at rate $n^2$: $$u(x,t)=e^{-t}\sin x+\tfrac12e^{-9t}\sin3x.$$ At $t=0.5$: coefficients $0.607$ and $0.0056$ — the wiggly mode is already 100× more suppressed. High frequencies die as $e^{-n^2t}$: diffusion is a ruthless low-pass filter, which is why an old temperature profile looks like a single smooth arch.

    1. EASY For $u_t=u_{xx}$ with $u(x,0)=\sin 2x$ on $[0,\pi]$, zero ends, write the solution.
      Solution
      Single mode $n=2$: $u=e^{-4t}\sin2x$.
    2. MED A hot spot is described by the heat kernel with $\alpha=1$. How does its peak height and width scale with $t$?
      Solution
      Peak $=\frac{1}{\sqrt{4\pi t}}\propto t^{-1/2}$; standard deviation $=\sqrt{2t}\propto t^{1/2}$. Area (total heat) stays 1: it spreads, never disappears.
    3. HARD Show that $E(t)=\int_0^L u^2\,dx$ is nonincreasing for solutions with zero boundary values, and interpret.
      Solution
      $E'(t)=\int 2uu_t\,dx=2\alpha\int uu_{xx}\,dx=2\alpha\Big([uu_x]_0^L-\int u_x^2dx\Big)=-2\alpha\int_0^Lu_x^2\,dx\le0$ (boundary term vanishes). The "energy" decays until $u_x\equiv0$, i.e. $u\equiv0$: diffusion dissipates every gradient. This also proves uniqueness: the difference of two solutions has $E(0)=0$, hence stays 0.

    Neural ODEs

    A residual network computes $\mathbf h_{k+1}=\mathbf h_k+f(\mathbf h_k;\theta)$ — which is Euler's method with step 1. Take the limit of infinitely many, infinitely small layers and the network becomes an ODE: $\dot{\mathbf h}(t)=f(\mathbf h(t),t;\theta)$, with depth as continuous time. Inference is solving the ODE; training differentiates through the solver — or, more elegantly, solves a second ODE backwards for the gradients.

    Definition A neural ODE maps input $\mathbf h(0)=\mathbf x$ to output $\mathbf h(T)=\mathbf h(0)+\int_0^Tf(\mathbf h(t),t;\theta)\,dt$, with $f$ a neural network. Adjoint method: the gradient flows backward via $\mathbf a(t)=\partial L/\partial\mathbf h(t)$ satisfying $$\dot{\mathbf a}=-\Big(\frac{\partial f}{\partial\mathbf h}\Big)^{\!\top}\mathbf a,\qquad \nabla_\theta L=\int_T^0-\,\mathbf a(t)^\top\frac{\partial f}{\partial\theta}\,dt,$$ solved by any ODE solver in $O(1)$ memory — the continuous-time twin of backpropagation (Ch 9).
    Worked example Take the linear "network" $f(h)=ah$, scalar. Then $h(T)=e^{aT}h_0$. Loss $L=\frac12(h(T)-y)^2$. Adjoint: $\dot a_{\!dj}=-a\,a_{dj}$ backwards from $a_{dj}(T)=h(T)-y$, so $a_{dj}(t)=(h(T)-y)e^{a(T-t)}$. Parameter gradient: $\nabla_aL=\int_0^Ta_{dj}(t)\,h(t)\,dt=(h(T)-y)h_0\int_0^Te^{a(T-t)}e^{at}dt=(h(T)-y)\,h_0\,Te^{aT}$. Direct check: $\partial_a\frac12(e^{aT}h_0-y)^2=(e^{aT}h_0-y)\cdot Te^{aT}h_0$ — identical ✓.
    Think first A ResNet block computes $\mathbf h+f(\mathbf h)$. What ODE property explains why very deep ResNets train when plain deep nets don't?
    Reveal
    The block's Jacobian is $I+\partial f/\partial\mathbf h$: near the identity. Backprop multiplies these Jacobians; products of near-identity matrices neither vanish nor explode (they approximate the well-conditioned flow map $e^{\int J\,dt}$ of a smooth ODE), whereas products of arbitrary layer Jacobians decay or blow up exponentially in depth (Ch 21).
    Where this goes Continuous normalizing flows use $\frac{d}{dt}\ln p=-\nabla\cdot f$ (Ch 9's divergence!) to track densities; the probability-flow ODE of diffusion models (Ch 22) is a neural ODE. Ch 12's SDEs add noise to this picture.
    Drill
    1. EASY Show a ResNet update $\mathbf h_{k+1}=\mathbf h_k+hf(\mathbf h_k)$ is one Euler step of $\dot{\mathbf h}=f(\mathbf h)$.
      Solution
      Euler for $\dot{\mathbf h}=f$: $\mathbf h_{k+1}=\mathbf h_k+h\,f(\mathbf h_k)$ — identical, with layer index as time and step $h$ (ResNets take $h=1$).
    2. MED Why does the adjoint method use $O(1)$ memory while ordinary backprop through $k$ solver steps uses $O(k)$? What does it trade away?
      Solution
      Backprop must store every intermediate activation to multiply Jacobians later. The adjoint method instead re-generates states on the fly by integrating $\mathbf h$ backwards in time alongside $\mathbf a$, storing only the current values. Trade-off: extra compute (a second backward solve) and possible error if the backward pass of a non-reversible/unstable dynamics doesn't reproduce the forward states exactly.
    3. HARD For the linear neural ODE $\dot{\mathbf h}=A\mathbf h$, show the adjoint equation $\dot{\mathbf a}=-A^\top\mathbf a$ preserves the inner product $\mathbf a(t)^\top\mathbf h(t)$, and interpret.
      Solution
      $\frac{d}{dt}(\mathbf a^\top\mathbf h)=\dot{\mathbf a}^\top\mathbf h+\mathbf a^\top\dot{\mathbf h}=-\mathbf a^\top A\mathbf h+\mathbf a^\top A\mathbf h=0$. The pairing between gradients and state perturbations is conserved in time — the continuous version of the chain-rule bookkeeping $\delta_{i-1}^\top d\mathbf h_{i-1}=\delta_i^\top d\mathbf h_i$ that makes backprop exact (Ch 9).

    1. MED Mixing tank. A 100 L tank starts with 5 kg of salt dissolved. Brine at 0.2 kg/L flows in at 5 L/min; the well-mixed solution drains at 5 L/min. Model, solve, and find the salt content after 20 minutes and as $t\to\infty$.

    2. HARD Full portrait of a damped oscillator. For $\ddot y+2\dot y+5y=0$: (a) solve with $y(0)=1,\dot y(0)=0$; (b) convert to a system and classify the origin; (c) compute the times of the first three zero crossings; (d) show the trajectory's phase-space spiral shrinks by the factor $e^{-\pi}$ per half-turn... precisely, compute the ratio of successive extrema of $y(t)$.
      Solution
      (a) $r^2+2r+5=0$: $r=-1\pm2i$: $y=e^{-t}(c_1\cos2t+c_2\sin2t)$; $c_1=1$, $\dot y(0)=-c_1+2c_2=0\Rightarrow c_2=\frac12$: $y=e^{-t}(\cos2t+\tfrac12\sin2t)$. (b) $\dot{\mathbf x}=\begin{pmatrix}0&1\\-5&-2\end{pmatrix}\mathbf x$; eigenvalues $-1\pm2i$: stable spiral. (c) $y=0$ when $\tan2t=-2$: $2t=\pi-\arctan2+k\pi$, so $t_k=\frac{\pi-\arctan 2}{2}+\frac{k\pi}{2}\approx0.417,\,1.988,\,3.559$. (d) Extrema occur where $\dot y=0$, spaced by the half-period $\Delta t=\pi/2$ of the $\omega_d=2$ oscillation; successive extrema ratio $=-e^{-\Delta t}=-e^{-\pi/2}\approx-0.208$: each swing is 20.8% of the previous, opposite side.
    3. HARD Solver design. You must integrate the linear system $\dot{\mathbf x}=A\mathbf x$, $A=\begin{pmatrix}-1&0\\0&-500\end{pmatrix}$, from $\mathbf x(0)=(1,1)^\top$ to $t=10$ with a relative accuracy of about $10^{-3}$ on the slow component. (a) What step does forward Euler need for stability, and how many steps? (b) Show backward Euler with $h=0.02$ is stable and estimate its slow-mode accuracy. (c) Explain which solver you'd choose and why the fast mode's accuracy is irrelevant after $t\approx0.01$.
      Solution
      (a) Stability needs $h<2/500=0.004$: at least $2500$ steps, all wasted resolving a mode that is dead after $t\approx0.01$ ($e^{-5}\approx0.7\%$). (b) Backward Euler factors: slow $\frac{1}{1+0.02}$, fast $\frac{1}{1+10}$ — both in $(0,1)$: stable. Slow mode after $n=500$ steps: $(1.02)^{-500}=e^{-500\ln1.02}=e^{-9.901}$ vs exact $e^{-10}$: relative error $e^{0.099}-1\approx10.4\%$ — too big, so take $h=0.002$ ($5000$ steps): $(1.002)^{-5000}=e^{-5000\ln 1.002}=e^{-9.995}$, relative error $\approx0.5\%$ ✓, or better, use the trapezoidal rule/RK with larger $h$. (c) Choose an implicit (or exponential) method: stability decoupled from the fast scale lets accuracy alone set $h$; the fast component is $\approx0$ for essentially the whole interval, so representing it accurately buys nothing.

    Task 1 — Euler vs RK4 convergence Integrate $y'=\cos(t)\,y$, $y(0)=1$ (exact $y=e^{\sin t}$) to $t=6$ with both methods across step sizes; verify the empirical orders (slopes ≈ 1 and 4 on a log-log plot).
    Reference solution
    import numpy as np
f = lambda t, y: np.cos(t) * y
exact = lambda t: np.exp(np.sin(t))

def euler(h, T=6.0):
    n = int(round(T / h)); t, y = 0.0, 1.0
    for _ in range(n):
        y += h * f(t, y); t += h
    return y

def rk4(h, T=6.0):
    n = int(round(T / h)); t, y = 0.0, 1.0
    for _ in range(n):
        k1 = f(t, y); k2 = f(t + h/2, y + h/2*k1)
        k3 = f(t + h/2, y + h/2*k2); k4 = f(t + h, y + h*k3)
        y += h/6 * (k1 + 2*k2 + 2*k3 + k4); t += h
    return y

hs = np.array([0.2, 0.1, 0.05, 0.025, 0.0125])
eE = np.array([abs(euler(h) - exact(6)) for h in hs])
eR = np.array([abs(rk4(h)  - exact(6)) for h in hs])
pE = np.polyfit(np.log(hs), np.log(eE), 1)[0]
pR = np.polyfit(np.log(hs), np.log(eR), 1)[0]
print(f"Euler order ~ {pE:.2f}  RK4 order ~ {pR:.2f}")  # ~1 and ~4
    Task 2 — Phase portrait & stiffness demo Simulate the damped pendulum $\dot\theta=v$, $\dot v=-\sin\theta-0.3v$ from several initial conditions with RK4, then demonstrate forward-Euler instability on the stiff scalar $y'=-200(y-\sin t)+\cos t$.
    Reference solution
    import numpy as np

def rk4_sys(f, x0, h, n):
    xs = [np.asarray(x0, float)]
    t = 0.0
    for _ in range(n):
        x = xs[-1]
        k1 = f(t, x); k2 = f(t + h/2, x + h/2*k1)
        k3 = f(t + h/2, x + h/2*k2); k4 = f(t + h, x + h*k3)
        xs.append(x + h/6*(k1 + 2*k2 + 2*k3 + k4)); t += h
    return np.array(xs)

pend = lambda t, x: np.array([x[1], -np.sin(x[0]) - 0.3*x[1]])
for th0 in (0.5, 2.0, 3.0):
    traj = rk4_sys(pend, [th0, 0.0], 0.05, 400)
    print(f"theta0={th0}: final (theta, v) = {traj[-1].round(4)}")
    # all spiral into (0, 0)

# stiffness: y' = -200 (y - sin t) + cos t, exact solution y = sin t (with y0=0)
g = lambda t, y: -200*(y - np.sin(t)) + np.cos(t)
for h in (0.011, 0.009, 0.001):        # stability threshold h = 2/200 = 0.01
    y, t = 0.0, 0.0
    for _ in range(int(2/h)):
        y += h * g(t, y); t += h
    print(f"h={h}: y(2) = {y:.4f}  (exact {np.sin(2):.4f})")
    # h=0.011 explodes; h=0.009 survives; h=0.001 accurate
    Task 3 — Train a tiny neural ODE Fit $\dot h=\theta_1\tanh(\theta_2 h)$ so that $h(1)\approx2$ from $h(0)=1$: integrate with RK4 and differentiate the solver by finite differences (honest, simple), then gradient-descend the parameters.
    Reference solution
    import numpy as np

def flow(theta, h0=1.0, T=1.0, n=50):
    a, b = theta
    f = lambda h: a * np.tanh(b * h)
    h, dt = h0, T / n
    for _ in range(n):
        k1 = f(h); k2 = f(h + dt/2*k1)
        k3 = f(h + dt/2*k2); k4 = f(h + dt*k3)
        h += dt/6*(k1 + 2*k2 + 2*k3 + k4)
    return h

def loss(theta): return 0.5 * (flow(theta) - 2.0) ** 2

theta = np.array([0.5, 0.5])
for it in range(300):
    eps, g = 1e-6, np.zeros(2)
    for i in range(2):                       # finite-difference gradient
        e = np.zeros(2); e[i] = eps
        g[i] = (loss(theta + e) - loss(theta - e)) / (2 * eps)
    theta -= 0.5 * g
print("theta =", theta.round(4), " h(1) =", round(flow(theta), 5))
# h(1) converges to 2.0: the ODE's vector field has been *learned*
