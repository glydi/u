    Decision and Game Theory

    Choosing well alone, and against others.

    States

    Every decision problem begins with "what might the world be?" A state is one complete way things could stand — everything relevant to the outcome of your choice, whether or not you can see it. Listing the states carefully is half the work: a bad state space hides exactly the possibilities that matter.

    Definition A state space $\mathcal S$ is a set of mutually exclusive, jointly exhaustive descriptions of the world; exactly one state $s\in\mathcal S$ obtains. The decision maker holds a belief $p(s)$ over states (Ch 11), and outcomes are determined jointly by the state and the chosen action.
    Worked example Deciding whether to carry an umbrella: $\mathcal S=\{\text{rain},\ \text{no rain}\}$ with belief $p(\text{rain})=0.3$. That two-state model suffices for the umbrella — but not for "bike or bus?", where $\{\text{light rain},\text{downpour},\text{dry}\}$ change the answer differently: the right granularity of $\mathcal S$ depends on which distinctions change the best action.
    Pitfall States must be action-independent in the basic framework: "the state is that I'll be late" is contaminated by your own choice. If your action influences the world's evolution, you need the sequential machinery later in this chapter (and Ch 25's MDPs), or causal decision theory (Ch 27) — folding action effects into "states" produces incoherent expected values.
    Where this goes States become Markov states in Ch 25, belief states under partial observability in Ch 26/28, and latent world-model states in Ch 29.
    Drill
    1. EASY For a medical test decision, propose a minimal state space and check the two defining properties.
      Solution
      $\mathcal S=\{\text{disease present},\ \text{disease absent}\}$: mutually exclusive (not both), exhaustive (one must hold). Note the test result is not a state — it is an observation correlated with the state.
    2. MED A poker player models the state as "opponent's hole cards". How many states with two hidden cards from a 52-card deck after seeing her own two cards?
      Solution
      $\binom{50}{2}=\frac{50\cdot49}{2}=1225$ states — small enough to enumerate exactly, which is why poker solvers can maintain exact beliefs over hands.
    3. HARD Explain why coarsening a state space (merging states) can strictly reduce achievable expected utility, and give the condition under which it is harmless.
      Solution
      The best decision rule maps information about states to actions; merging $s_1,s_2$ forces a single action wherever they were distinguishable, so if the optimal actions differ ($a^*(s_1)\ne a^*(s_2)$) and the decision maker had information separating them, the merged problem's optimum is a strict average-of-constrained choice — weakly worse, strictly if the utilities differ. Harmless iff the merged states are decision-equivalent: the same action is optimal in both for every attainable belief (a "sufficient statistic" of the state for the decision — Ch 13's sufficiency, reappearing).

    Actions

    Actions are what you actually control: the menu of choices. In the classic formulation an action is a function from states to outcomes — choosing an action means choosing which column of the outcome table you live in, without knowing the row.

    Definition An action set $\mathcal A$ lists the feasible choices. With outcome function $o(a,s)$, each action $a\in\mathcal A$ induces a row-by-row gamble: the outcome profile $\{o(a,s)\}_{s\in\mathcal S}$. A decision rule (policy) more generally maps observations to actions.
    Worked example Umbrella problem, outcome table (comfort levels): carry/rain: dry-but-encumbered (7); carry/no rain: encumbered (8); leave/rain: soaked (1); leave/no rain: free (10). Choosing "carry" means accepting the profile $(7,8)$ over the states; "leave" the profile $(1,10)$. Nothing is yet said about which is better — that needs beliefs and utilities.
    Drill
    1. EASY Why is "win the lottery" not an action while "buy a lottery ticket" is?
      Solution
      Actions must be directly controllable: you can choose to buy a ticket; winning is an outcome determined by action plus state (the drawn numbers).
    2. MED An action $a$ dominates $b$ if $o(a,s)\succeq o(b,s)$ for all $s$, strictly for some. Show dominance in the table: add action "carry tiny umbrella" with outcomes (rain: 6, no rain: 9). Does it dominate either existing action?
      Solution
      Vs carry $(7,8)$: tiny gives $(6,9)$ — better in no-rain, worse in rain: no dominance. Vs leave $(1,10)$: $(6,9)$ — better in rain, worse in no-rain: no dominance. No action here dominates; the choice genuinely depends on beliefs. (Dominated actions, when they exist, can be deleted before any probability is assessed.)
    3. HARD Mixed actions: allow randomizing between "carry" ($7,8$) and "leave" ($1,10$) with probability $q$ on carry. With utility = comfort and $p(\text{rain})=0.3$, is any randomization strictly better than both pure actions?
      Solution
      Expected utility is linear in $q$: $EU(q)=q\,EU(\text{carry})+(1-q)EU(\text{leave})$. $EU(\text{carry})=0.3\cdot7+0.7\cdot8=7.7$; $EU(\text{leave})=0.3\cdot1+0.7\cdot10=7.3$. Any mixture lies between 7.3 and 7.7: never above the best pure action. In single-agent decision problems randomization can never strictly help (linearity); it becomes valuable only against a strategic opponent (mixed strategies, below) or for exploration over time (bandits).

    Preferences

    Before any numbers, there are rankings: you prefer this outcome to that one. Decision theory's foundation is that if your preferences over gambles satisfy a few consistency axioms — you can always compare, you don't cycle, and irrelevant alternatives don't distract you — then they behave as if you were maximizing some utility function. The numbers are earned from the rankings, not assumed.

    Definition A preference relation $\succeq$ over outcomes (or lotteries) is: complete ($x\succeq y$ or $y\succeq x$ for all pairs), transitive ($x\succeq y\succeq z\Rightarrow x\succeq z$). The von Neumann–Morgenstern axioms add continuity (if $x\succ y\succ z$, some mixture of $x,z$ is indifferent to $y$) and independence ($x\succeq y\iff\alpha x+(1-\alpha)w\succeq\alpha y+(1-\alpha)w$ for lotteries).
    Theorem (von Neumann–Morgenstern) Preferences over lotteries satisfy the four axioms iff there exists $u$ such that $L_1\succeq L_2\iff\mathbb E_{L_1}[u]\ge\mathbb E_{L_2}[u]$; $u$ is unique up to positive affine transformation $u\mapsto au+b$, $a>0$.
    Worked example Money pump: suppose an agent has cyclic preferences $A\succ B\succ C\succ A$ and will pay 1¢ to swap to anything preferred. Start it holding $C$: it pays to get $B$, pays to get $A$, pays to get $C$ — back where it started, 3¢ poorer, forever. Transitivity is not politeness; it is what makes an agent unexploitable by a bookie shuffling its own preferences.
    Where this goes Preference data over model outputs (Ch 23's reward modeling) is exactly this machinery: Bradley–Terry fits a utility from noisy pairwise $\succeq$ judgments — inheriting these axioms' assumptions, and their failures when human preferences are intransitive or context-dependent.

    1. EASY Give a real example where human preferences violate completeness.
      Solution
      Incomparable options: "career in city A" vs "different career in city B" — many people genuinely cannot rank them and are not indifferent either (small sweeteners to one side don't resolve the choice, which indifference would imply).
    2. MED The Allais paradox: most people prefer (a) certain \$1M over (b) 10% \$5M / 89% \$1M / 1% \$0, yet prefer (d) 10% \$5M / 90% \$0 over (c) 11% \$1M / 89% \$0. Show this violates independence.
      Solution
      Write choices as mixtures with a common 89% component. (a) = 11% [\$1M] + 89% [\$1M]; (b) = 11% [$\frac{10}{11}$ \$5M, $\frac{1}{11}$ \$0] + 89% [\$1M]. (c) and (d) are the same two 11%-sublotteries mixed with 89% [\$0] instead. Independence says the ranking of the 11%-sublotteries must not depend on the common component — but people flip: (a)≻(b) yet (d)≻(c). Certainty is overweighted; human preferences are not vNM-consistent.
    3. HARD Show that if $u$ represents $\succeq$, so does $v=au+b$ ($a>0$), and that a nonlinear monotone transform can fail for lotteries.
      Solution
      Affine: $\mathbb E[v]=a\mathbb E[u]+b$, an increasing function of $\mathbb E[u]$, so all lottery comparisons are preserved. Nonlinear: take $u$ values 0, 1, 2 for outcomes $z,y,x$ and $v=u^2$ (0,1,4). Lottery $L$ = 50/50 $x,z$ vs sure $y$: under $u$, $\mathbb E=1=1$ (indifferent); under $v$, $\mathbb E=2>1$ (strict preference). Monotone transforms preserve rankings of outcomes but not of expectations — cardinal structure matters for choice under risk, which is exactly what vNM utility adds beyond ordinal preference.

    Utility functions

    A utility function turns outcomes into numbers so that "prefer" becomes "bigger". Its shape encodes taste for risk: concave utility means each extra dollar matters less than the last, making a bird in the hand worth two in the bush. Utility is not money — conflating them is the oldest error in the subject.

    Definition A utility function $u:\mathcal O\to\mathbb R$ represents $\succeq$ when $x\succeq y\iff u(x)\ge u(y)$ (and over lotteries via expectations, per vNM). For wealth: $u$ concave $\Leftrightarrow$ risk-averse, linear $\Leftrightarrow$ risk-neutral, convex $\Leftrightarrow$ risk-seeking. Common families: $u(w)=\log w$; CRRA $u(w)=\frac{w^{1-\gamma}}{1-\gamma}$; CARA $u(w)=-e^{-\alpha w}$.
    Explore

    Slide risk aversion $\gamma$ and see the CRRA utility curve, a 50/50 gamble between \$50 and \$150, its expected utility (dot on the chord) and the certainty equivalent (where the curve crosses that level).

    Worked example $u(w)=\log w$, gamble: 50% \$50, 50% \$150. $\mathbb E[u]=\tfrac12\ln50+\tfrac12\ln150=\tfrac12(3.912+5.011)=4.4615$. Certainty equivalent: $e^{4.4615}\approx\$86.6$ — a log-utility agent trades this \$100-expected-value gamble for any sure amount above \$86.60. The \$13.40 gap is the risk premium.
    Pitfall Utility numbers have no absolute meaning — only differences-of-expectations comparisons within one agent. "My utility is 40, yours is 30" licenses nothing: interpersonal comparison and summation of vNM utilities requires extra assumptions the theorem does not provide (a live issue for social choice and for aggregating preferences across users in Ch 23-style reward modeling).

      Sure: $u=20$. Gamble: $\tfrac12\cdot10+\tfrac12\cdot30=20$. Exactly indifferent — the gamble's certainty equivalent is precisely \$400 (note its expected value is \$500; the \$100 premium is the price of risk at this curvature).

      Solution
      $\log$: $u'=1/w$, $u''=-1/w^2$: $A(w)=1/w$ — absolute risk aversion falls with wealth (richer ⇒ more risk-tolerant in absolute stakes). CARA: $u'=\alpha e^{-\alpha w}$, $u''=-\alpha^2e^{-\alpha w}$: $A(w)=\alpha$, constant — the same absolute caution at any wealth.

      Definition: $u(w-\pi)=\mathbb E[u(w+\varepsilon)]$.     Expected utility

    The master rule of decision under risk: score each action by the probability-weighted average utility of its outcomes, and take the argmax. Everything in this chapter and the next two — value functions, Bellman equations, minimax — is this rule wearing different clothes.

    Definition The expected utility of action $a$ under belief $p$: $$EU(a)=\sum_{s\in\mathcal S}p(s)\,u\big(o(a,s)\big),$$ and the rational choice is $a^*=\arg\max_{a\in\mathcal A}EU(a)$. With observations, beliefs are first updated by Bayes (Ch 11) and the rule applies to the posterior.
    Worked example Umbrella, utilities as before, $p(\text{rain})=0.3$: $EU(\text{carry})=0.3\cdot7+0.7\cdot8=7.7$; $EU(\text{leave})=0.3\cdot1+0.7\cdot10=7.3$. Carry. Break-even belief: $7p+8(1-p)=p+10(1-p)\Rightarrow 8-p=10-9p\Rightarrow8p=2\Rightarrow p^*=0.25$ — above 25% rain probability, carry; below, leave. The decision reduces to comparing your belief to a threshold, a structure that recurs everywhere.
    Think first Why weight by probabilities at all — why not judge an action by its worst case, or its best?
    Reveal
    Worst-case (maximin) ignores how unlikely the worst is: it refuses any gamble with a bad tail, however tiny, and is paralyzed in rich state spaces where every action has some awful state. Best-case is symmetric folly. The vNM theorem says: if your preferences over gambles are merely consistent (no money pumps, no certainty-mirage flips), you are already an expected-utility maximizer for some $u$ — the weighting is not an extra assumption but a consequence. Maximin remains sensible when probabilities themselves are unknowable (adversarial settings — see zero-sum games below).

      Expected gain $=0.1\cdot15=1.5<2$: don't. (This is a value-of-information calculation — formalized two sections ahead.)

      Solution
      No insurance: $EU=0.999\ln(400000)+0.001\ln(100000)=0.999\cdot12.899+0.001\cdot11.513=12.8976$. Insurance: sure wealth $399550$: $\ln(399550)=12.8981$.     3. HARD St. Petersburg: a coin is flipped until heads; payout $2^n$ for first heads on flip $n$. Expected value is infinite.       Solution
      $\mathbb E[\log_2 X]=\sum_{n\ge1}2^{-n}\cdot n=2$ (standard sum). Certainty equivalent $=2^2=\$4$: a log-utility agent pays at most ~\$4 for the infinite-expected-value game. (Bernoulli invented log utility for exactly this puzzle in 1738.)

    Expected value

    Expected value is expected utility with $u(w)=w$: the probability-weighted average payoff itself. It is the right criterion when stakes are small relative to your wealth, when the same gamble repeats many times (the law of large numbers makes the average the near-certain outcome), or when you are a fleet operator aggregating thousands of independent decisions.

    Definition $EV(a)=\sum_sp(s)\,x(a,s)$ for monetary/numeric payoffs $x$. By the LLN (Ch 11), the average payoff of $n$ i.i.d. plays converges to $EV$; by the CLT, fluctuations shrink as $\sigma/\sqrt n$.
    Worked example A \$1 lottery ticket wins \$500 with probability $10^{-3}$: $EV=0.001\cdot500-1=-\$0.50$. One ticket is a cheap thrill; a strategy of buying 10,000 tickets has $EV=-\$5000$ with standard deviation $\sqrt{10^4}\cdot\sigma_1\approx100\cdot15.8\approx\$1580$: the loss is now ~3σ certain. Repetition converts a fuzzy gamble into its expected value — for better or worse.
    Pitfall Expected value is blind to ruin. A strategy with positive EV per bet but a chance of losing everything (after which you cannot continue) has long-run growth determined by $\mathbb E[\log(\text{wealth ratio})]$, not $\mathbb E[\text{gain}]$ — the Kelly criterion's domain. Maximizing EV bet-by-bet with full stakes goes bankrupt with probability 1.

      Solution
      Daily total: mean $\$20{,}000$, std $\sqrt{10^4}\cdot40=\$4000$. Losing day: $\Pr[Z<-5]\approx2.9\times10^{-7}$ — essentially never. Risk aversion should be reserved for decisions correlated across the fleet (a policy change, a pricing move) that don't diversify away.

    Risk

    Two gambles with the same mean can feel utterly different — the difference is risk: the spread and shape of the outcome distribution. Variance is the first summary; tail measures like Value-at-Risk and CVaR capture what variance misses — the size of the bad tail specifically, which is what actually keeps decision makers awake.

    Definition For payoff $X$: variance $\sigma^2=\mathbb E[(X-\mu)^2]$; Value-at-Risk $\mathrm{VaR}_\alpha$ = the loss threshold exceeded with probability at most $1-\alpha$ (the $\alpha$-quantile of loss); Conditional VaR $\mathrm{CVaR}_\alpha=\mathbb E[\text{loss}\mid\text{loss}\ge\mathrm{VaR}_\alpha]$ — the mean of the worst $(1-\alpha)$ tail. A distribution $X$ is riskier than $Y$ with equal mean (second-order stochastic dominance) if every risk-averse EU maximizer prefers $Y$.
    Worked example Loss distribution: \$0 with 0.95, \$10k with 0.04, \$100k with 0.01. $\mathrm{VaR}_{0.95}$: the 95th percentile of loss $=\$10$k (5% of outcomes lose $\ge$\$10k). $\mathrm{CVaR}_{0.95}=\mathbb E[\text{loss}\mid\text{loss}\ge10\text{k}]=\frac{0.04\cdot10+0.01\cdot100}{0.05}$k$=\frac{1.4}{0.05}$k$=\$28$k. Variance-based analysis treats the two bad outcomes symmetrically with gains; CVaR reads only the tail that hurts.
    Pitfall VaR is not subadditive: merging two portfolios can increase reported VaR beyond the sum, and VaR says nothing about how bad the tail is beyond the threshold — a 5% chance of losing \$10k and a 5% chance of losing \$10M can have the same $\mathrm{VaR}_{0.95}$. CVaR fixes both (it is a coherent risk measure) and is furthermore optimizable by linear programming.

    Risk-sensitive decision making

    Sometimes the mean is not what you should optimize: a surgeon, a portfolio manager and a safety-critical agent all care about the distribution's shape. Risk-sensitive decision making bakes the caution into the objective — exponential utility, mean–variance trade-offs, or CVaR constraints — turning "be careful" into mathematics an optimizer can obey.

    Definition Common risk-sensitive objectives: exponential/entropic: maximize $-\frac1\alpha\log\mathbb E[e^{-\alpha X}]$ (risk-aversion $\alpha>0$; recovers $\mathbb E[X]$ as $\alpha\to0$); mean–variance: maximize $\mathbb E[X]-\lambda\mathrm{Var}(X)$; CVaR objective: maximize $\mathbb E[X]$ subject to $\mathrm{CVaR}_\alpha(\text{loss})\le c$, or maximize $\mathrm{CVaR}_\alpha(X)$ itself.
    Worked example Two policies: A yields $X\sim\mathcal N(10,\,4)$; B yields $\mathcal N(12,\,64)$. Entropic value at $\alpha=0.25$ (Gaussian identity: $-\frac1\alpha\log\mathbb E[e^{-\alpha X}]=\mu-\frac{\alpha\sigma^2}{2}$): A: $10-\frac{0.25\cdot4}{2}=9.5$; B: $12-\frac{0.25\cdot64}{2}=4.0$. A wins despite 2 less mean — the objective charges B its variance at rate $\alpha/2$. At $\alpha=0.05$: A $=9.9$, B $=10.4$: B wins. One knob spans the whole caution spectrum.
    Where this goes Risk-sensitive and distributional RL (Ch 25) optimize these objectives over trajectories; Ch 32's execution budgets and escalation policies are CVaR-thinking applied to agent actions.

    Value of information

    Information is worth exactly what it lets you do differently. Before paying for a test, a survey or a sensor, compute: expected utility deciding with the information (choosing optimally after each possible answer) minus expected utility of the best decision without it. If the answer couldn't change your action, its value is zero — no matter how much it reduces uncertainty.

    Definition The expected value of information from observing $Y$: $$\mathrm{EVOI}(Y)=\mathbb E_{y}\Big[\max_a\ \mathbb E[u(a,S)\mid Y=y]\Big]-\max_a\ \mathbb E[u(a,S)],$$ always $\ge0$. The expected value of perfect information (observing $S$ itself): $\mathrm{EVPI}=\mathbb E_s[\max_au(a,s)]-\max_a\mathbb E_s[u(a,s)]$, an upper bound on any test's value.
    Worked example Umbrella again ($p_{\text{rain}}=0.3$; carry: 7.7, leave: 7.3 — recall leave is optimal only below $p^*=0.25$). EVPI: with perfect foresight, rain→carry (7), no rain→leave (10): $\mathbb E=0.3\cdot7+0.7\cdot10=9.1$. Without: 7.7. $\mathrm{EVPI}=1.4$ utils — the most any forecast could be worth. A forecast that is 80% accurate in each state: $p(\text{say rain})=0.3\cdot0.8+0.7\cdot0.2=0.38$; posterior given "rain" $=\frac{0.24}{0.38}=0.632$→carry ($EU=0.632\cdot7+0.368\cdot8=7.368$); given "dry": $p_{\text{rain}}=\frac{0.06}{0.62}=0.097$→leave ($EU=0.097\cdot1+0.903\cdot10=9.13$). $\mathrm{EVOI}=0.38\cdot7.368+0.62\cdot9.13-7.7=2.80+5.66-7.7=0.76$ utils.
    Pitfall Information that arrives after the decision is locked, that you will ignore, or that only confirms the action you'd take anyway has zero decision value — a lesson organizations relearn expensively ("we commissioned a study" ≠ value). Conversely EVOI is computed against your current belief: adversarially chosen or biased information sources need the game-theoretic treatment, not this formula.
    Where this goes Exploration bonuses in bandits/RL (below, Ch 25) are EVOI in disguise; Ch 26's information-gathering actions and Ch 30's metareasoning ("is more thinking worth it?") reuse the same calculation.

    Bayesian decision theory

    The full pipeline: hold a prior, observe evidence, update by Bayes, then choose the action minimizing expected loss under the posterior. Different loss functions yield different "best answers" from the same posterior — the mean, the median, the mode — which is why estimation (Ch 13) is secretly decision theory.

    Definition With loss $L(a,s)$ and posterior $p(s\mid y)$, the Bayes-optimal act is $$a^*(y)=\arg\min_a\ \mathbb E[L(a,S)\mid y].$$ Standard results: squared loss → posterior mean; absolute loss → posterior median; 0–1 loss → posterior mode (MAP). The Bayes risk is the resulting expected loss over both data and states.
    Worked example Disease with prior 1%; test with sensitivity 95%, specificity 95% comes back positive. Posterior: $\frac{0.01\cdot0.95}{0.01\cdot0.95+0.99\cdot0.05}=\frac{0.0095}{0.0590}\approx0.161$. Loss table: treat/sick 1, treat/healthy 5, skip/sick 50, skip/healthy 0. Expected losses: treat $=0.161\cdot1+0.839\cdot5=4.36$; skip $=0.161\cdot50=8.05$. Treat — despite the disease being 5× more likely absent than present, because missing it costs 10× the false-treatment harm. The 16% posterior alone decides nothing; posterior × loss decides.

    Sequential decision making

    Real decisions come in chains: today's choice changes what you'll know and what you can do tomorrow. The central technique is to reason backward — value the future first, then choose the present in light of it. Decision trees make this concrete: chance nodes average, decision nodes maximize, and the recursion rolls values from the leaves to the root.

    Definition A finite-horizon sequential problem: at stages $t=1..T$, observe, choose $a_t$, receive reward, transition. Backward induction computes $$V_T(\cdot)=\max_a\ \mathbb E[u],\qquad V_t(x)=\max_{a}\ \mathbb E\big[r_t(x,a)+V_{t+1}(X')\ \big|\ x,a\big]$$ — the finite-horizon Bellman recursion (Ch 25 makes it stationary and infinite-horizon).
    Worked example Sell an asset within 2 days; each day an offer arrives: \$100 or \$200 with equal probability; refuse today and you must take tomorrow's offer. Day 2 value (must accept): $V_2=\mathbb E[\text{offer}]=150$. Day 1 policy: accept offer $x$ iff $x\ge V_2=150$: accept 200, refuse 100. Day-1 value: $\tfrac12\cdot200+\tfrac12\cdot150=175$. Note the naive "take the first decent offer" undervalues waiting; the option to refuse is worth \$25 over the myopic $\mathbb E=150$.
    Pitfall Solving forward — greedily optimizing each step's immediate payoff — fails whenever actions have option value or information value: greedy sells at \$100 half the time here (expected \$150). Equally wrong: evaluating a plan by its expected path while ignoring that you'll re-decide at each node with new information; rigid-plan evaluation understates value exactly when flexibility matters most.
    Where this goes This recursion is Ch 25's Bellman equation, Ch 26's game-tree/expectimax search, and Ch 28's dynamic programming for control — the single most reused idea in the AGI half of this book.
    Drill
    1. EASY Extend the asset example to 3 days (day 3: must accept). Compute $V_3,V_2,V_1$.
      Solution
      $V_3=150$. Day 2: accept iff offer $\ge150$: $V_2=\tfrac12\cdot200+\tfrac12\cdot150=175$. Day 1: accept iff $\ge175$: accept 200 only: $V_1=\tfrac12\cdot200+\tfrac12\cdot175=187.5$. More runway → choosier threshold → higher value.
    2. MED Why must backward induction process stages in reverse order — what exactly breaks if you compute $V_1$ before $V_2$?
      Solution
      $V_1$'s optimal action depends on the continuation value $V_2$ (accept iff offer $\ge V_2$); without $V_2$ you cannot price the option of refusing. Formally the recursion $V_t=\max_a\mathbb E[r+V_{t+1}]$ has a data dependency on $t+1$; computing in forward order uses undefined (or guessed) continuation values — which is precisely what value iteration fixes by iterating guesses to a fixed point (Ch 25).
    3. HARD Secretary-style: 3 candidates arrive in random order; you observe only relative ranks and must accept or irrevocably reject each. Maximize the probability of hiring the best. Find the optimal rule and its success probability by backward induction.
      Solution
      Rule form: reject the first $k$, then take the first candidate better than all seen. $k=0$ (accept first): $P=1/3$. $k=1$: skip #1; accept #2 iff better than #1, else forced to #3. Success: best is in position 2 and better than #1 (always true if best): $P(\text{best at }2)=1/3$ — accepted ✓. Best at 3: reach #3 iff #2 wasn't better than #1, i.e. #2 is not the best-so-far: given best at 3, the better of first two is first with prob 1/2 → then #2 rejected, #3 accepted ✓: contributes $\tfrac13\cdot\tfrac12=\tfrac16$. Total $=\tfrac13+\tfrac16=\tfrac12$. $k=2$: accept #3 always: $P=1/3$. Optimal: skip 1, then take the first record — succeeds with probability $\tfrac12$ (the $n=3$ case of the famous $1/e$ rule).

    Exploration

    When acting also teaches, some actions are worth taking because you don't know how good they are. Exploration is deliberately choosing informative over currently-best: trying the new restaurant, the untested ad, the unproven arm. Its value is exactly the value of information applied to your own future decisions.

    Definition In sequential problems with unknown payoff parameters, exploration is choosing actions to improve estimates of their values, sacrificing immediate expected reward for expected future reward. Canonical devices: random exploration ($\epsilon$-greedy), optimism (act as if uncertain arms were as good as plausibly possible — UCB), and posterior sampling (Thompson, below).
    Worked example Two slot machines: A has known payout rate 0.5; B is unknown, prior Beta(1,1) (uniform). Myopically A ties B ($\mathbb E=0.5$). But one pull of B is informative: if B turns out better (posterior mean rises), you exploit it for all remaining pulls; if worse, you return to A having lost little. With 100 pulls remaining, pulling B first is strictly optimal — the information about B compounds over 99 future decisions while A's known rate teaches nothing.
    Pitfall Under-exploration is invisible: a policy that settled early on a mediocre action shows steady reward and no error signal — the better option's superiority is exactly the data you never collected. This haunts A/B testing (stopping early), recommender systems (feedback loops narrow to what's already shown) and RLHF-tuned models (Ch 23) whose training suppressed diverse outputs.
    Drill
    1. EASY Why does exploration's value shrink as the remaining horizon shrinks?
      Solution
      Information pays through changed future decisions; with few decisions left there is little future to improve. On the last step, explore-value is zero: act greedily.
    2. MED After 10 pulls, arm estimates are $\hat\mu_A=0.6$ (from 8 pulls) and $\hat\mu_B=0.5$ (from 2 pulls). Why might pulling B be correct despite the lower estimate?
      Solution
      B's estimate carries far more uncertainty (2 samples): its plausible range easily contains values above 0.6, and resolving that uncertainty is cheap now and valuable for the whole future. The decision should compare A's known-ish 0.6 against B's upper plausible value or posterior draw — the logic UCB and Thompson formalize.
    3. HARD Construct a two-armed example where a myopic (one-step EVOI) explorer under-explores relative to the true multi-step optimum.
      Solution
      Arm A: known 0.5. Arm B: either 0.9 or 0.1 with prior 50/50, but B's payoffs are noisy enough that one pull barely moves the posterior (e.g. Bernoulli observations shift posterior odds by a factor 9 only after several consistent outcomes). One-step EVOI: a single pull's posterior change may not flip any immediate decision → myopic value ≈ 0 → never explore. Multi-step: a sequence of 5 pulls of B resolves it nearly fully; with 1000 pulls remaining, expected gain $\approx\tfrac12\cdot(0.9-0.5)\cdot995$ minus small exploration cost — enormous. Information can be a threshold good: worthless in one bite, decisive in five — myopic EVOI misses exactly those cases (this is why bandit algorithms reason about cumulative regret, not single-step lookahead).

    Exploitation

    Exploitation is cashing in: choosing the action your current knowledge says is best. It is the default that exploration must justify deviating from — and knowing when to stop exploring is as important as exploring at all. The tension between the two is the defining dilemma of learning while acting.

    Definition The greedy/exploiting action under estimates $\hat\mu$: $a^{\text{greedy}}=\arg\max_a\hat\mu_a$. The exploration–exploitation trade-off is scored by cumulative regret: $$R_T=T\mu^*-\mathbb E\Big[\sum_{t=1}^{T}\mu_{a_t}\Big],$$ the total expected shortfall versus always playing the best arm $\mu^*=\max_a\mu_a$.
    Worked example Arms with true rates $(0.5,\,0.4)$. Pure exploitation after 2 initial pulls each: with modest probability the worse arm looks better (e.g. B lucks into 2/2 while A hits 1/2) and greedy locks onto B forever: regret grows linearly, $0.1$ per step. Pure exploration (uniform random forever): regret $=T\cdot\frac{0.1}{2}=0.05T$ — also linear. Good algorithms interpolate: explore enough to identify A (cost $O(\log T)$), then exploit — sublinear regret.
    An algorithm's cumulative regret grows like $\sqrt T$. What does that imply about its average per-step regret?
    Average regret $=R_T/T=1/\sqrt T\to0$: sublinear cumulative regret means the fraction of time spent on suboptimal arms vanishes. Linear regret ($R_T\propto T$) is the signature of never learning — constant average shortfall forever.
    Drill
    1. EASY True rates $(0.7,0.5,0.3)$; an algorithm plays them $(800,150,50)$ times in $T=1000$. Compute its regret.
      Solution
      $R=1000\cdot0.7-(800\cdot0.7+150\cdot0.5+50\cdot0.3)=700-(560+75+15)=700-650=50$.
    2. MED Why does the "explore then commit" strategy (uniform for $m$ rounds per arm, then greedy forever) have a delicate $m$? Give both failure directions.
      Solution
      $m$ too small: the empirical best is wrong with non-negligible probability, and committing to a wrong arm costs $\Delta$ per step for the remaining $T-Km$ steps — expected regret linear in $T$. $m$ too large: exploration itself costs $\approx m\sum_a\Delta_a$, wasting rounds on known-worse arms. The optimum balances $m\Delta$ against $T\cdot\Pr[\text{wrong}]\cdot\Delta$ with $\Pr[\text{wrong}]\approx e^{-m\Delta^2/2}$: $m\propto\frac{\log T}{\Delta^2}$ — which requires knowing $\Delta$ and $T$; adaptive algorithms (UCB, Thompson) achieve it without knowing either.
    3. HARD Prove pure greedy (with each arm tried once initially) can incur linear regret with constant probability, for two Bernoulli arms $(\mu_1,\mu_2)=(0.9,\,0.1)$.
      Solution
      Initial pulls: with probability $(1-\mu_1)\mu_2=0.1\cdot0.1=0.01$, arm 1 yields 0 and arm 2 yields 1: estimates $(0,1)$. Greedy then plays arm 2; every success keeps $\hat\mu_2>0$... more carefully: $\hat\mu_2$ stays $\ge$ some positive value while $\hat\mu_1=0$ is never updated (arm 1 is never replayed since $\hat\mu_1=0$ can't exceed $\hat\mu_2>0$ as long as arm 2 registers any success, and even at $\hat\mu_2\to0.1$ it exceeds 0). So with probability $\ge0.01\cdot$(arm 2 not flatlining to exactly 0, which has probability bounded away from 0... at worst ties are broken toward arm 2) the algorithm plays arm 2 forever: regret $\ge c\cdot0.8T$ — linear with constant probability, hence linear expected regret. The flaw: a zero estimate from one unlucky sample is never revisited — no optimism, no randomness, no second chances.

    Multi-armed bandits

    The bandit is the fruit-fly of decision-making-under-ignorance: $K$ arms with unknown reward rates, one pull per round, maximize total reward. No states, no transitions — just the naked explore/exploit trade-off. Its theory produces the two workhorse ideas (optimism via UCB, posterior sampling via Thompson) that power everything from A/B testing to LLM router selection and Ch 26's tree search.

    Definition A stochastic $K$-armed bandit: unknown means $\mu_1..\mu_K$; each round pick $a_t$, observe reward drawn from arm $a_t$'s distribution. UCB1: play $a_t=\arg\max_a\ \hat\mu_a+\sqrt{\tfrac{2\ln t}{n_a}}$ ($n_a$ = pulls of $a$). Guarantee: regret $O\big(\sum_{a:\Delta_a>0}\tfrac{\ln T}{\Delta_a}\big)$ — logarithmic, and (Lai–Robbins) no algorithm beats $\Omega(\ln T)$ on all instances.
    Explore

    Three arms (true rates 0.35, 0.55, 0.45 — hidden from the algorithms). Press Run to simulate 500 pulls of ε-greedy vs UCB and watch cumulative regret; UCB's should bend logarithmic while ε-greedy's keeps a linear drift.

    Worked example UCB at $t=100$: arm A: $\hat\mu=0.60$, $n=80$; arm B: $\hat\mu=0.50$, $n=20$. Bonuses: A: $\sqrt{\frac{2\ln100}{80}}=\sqrt{\frac{9.21}{80}}=0.339$; B: $\sqrt{\frac{9.21}{20}}=0.679$. Indices: A $=0.939$, B $=1.179$ — play B despite the worse mean: 20 samples haven't earned trust, and the bonus prices exactly that. As $n_B$ grows the bonus shrinks like $1/\sqrt{n_B}$, and B must keep winning on merit to keep being played.
    Where this goes UCB applied to tree nodes is Ch 26's UCT/Monte Carlo Tree Search; bandit thinking runs through Ch 25's exploration strategies and Ch 30's test-time compute allocation.
    Drill
    1. EASY In UCB1, what happens to an arm's index if it is never played while others are?
      Solution
      Its $\hat\mu$ and $n_a$ freeze while $\ln t$ grows: the bonus $\sqrt{2\ln t/n_a}$ increases without bound, so every arm is eventually retried — starvation is impossible by construction.
    2. MED Derive the shape of the UCB bonus from Hoeffding's inequality (Ch 11).
      Solution
      Hoeffding: $\Pr[\mu_a>\hat\mu_a+\epsilon]\le e^{-2n_a\epsilon^2}$. Demand failure probability $\le t^{-4}$ (small enough to union-bound over time and arms): $e^{-2n_a\epsilon^2}=t^{-4}\Rightarrow\epsilon=\sqrt{\frac{2\ln t}{n_a}}$. The index $\hat\mu_a+\epsilon$ is thus a high-confidence upper bound on $\mu_a$: "optimism in the face of uncertainty" with the optimism calibrated to vanish exactly as fast as confidence accrues.
    3. HARD Sketch why optimism yields low regret: bound the number of pulls of a suboptimal arm $a$ (gap $\Delta_a$) under UCB.
      Solution
      Arm $a$ is pulled at time $t$ only if $\hat\mu_a+c_{t,n_a}\ge\hat\mu^*+c_{t,n^*}$. With confidence bounds holding (whp): $\hat\mu_a\le\mu_a+c_{t,n_a}$ and $\hat\mu^*+c_{t,n^*}\ge\mu^*$. Chaining: $\mu_a+2c_{t,n_a}\ge\mu^*$, i.e. $2\sqrt{2\ln t/n_a}\ge\Delta_a$, forcing $n_a\le\frac{8\ln t}{\Delta_a^2}$. So each bad arm is played $O(\ln T/\Delta_a^2)$ times, contributing regret $n_a\Delta_a=O(\ln T/\Delta_a)$; summing over arms gives the theorem (plus $O(1)$ terms from the rare confidence failures). The bonus is engineered so that being played shrinks your claim to optimism at exactly the rate that makes over-pulling impossible.

    Thompson sampling

    Thompson sampling explores by believing its own uncertainty: keep a posterior over each arm's rate, draw one sample from each posterior, and play the arm whose sample is highest. Arms are chosen with exactly the probability that they are the best — bold while uncertain, settling automatically as posteriors sharpen. Thirty lines of code, state-of-the-art regret.

    Definition Maintain posterior $p(\mu_a\mid\text{data})$ per arm. Each round: sample $\tilde\mu_a\sim p(\mu_a\mid\cdot)$ for all $a$; play $a_t=\arg\max_a\tilde\mu_a$; update the played arm's posterior. For Bernoulli arms with Beta priors: arm $a$ with $s$ successes, $f$ failures has posterior $\mathrm{Beta}(1+s,\,1+f)$ (conjugacy, Ch 13). Property: $\Pr[a_t=a]=\Pr[\mu_a=\max_b\mu_b\mid\text{data}]$ — probability matching.
    Worked example Arm A: 6 successes / 4 failures → Beta(7,5), mean 0.583. Arm B: 1 success / 1 failure → Beta(2,2), mean 0.5. A single round: draw $\tilde\mu_A\sim$Beta(7,5), $\tilde\mu_B\sim$Beta(2,2). Beta(2,2) is wide (std ≈ 0.22 vs Beta(7,5)'s 0.14): $\Pr[\tilde\mu_B>\tilde\mu_A]\approx0.36$ — B gets a real minority of play, in proportion to its genuine chance of being better. After 100 more observations each, the posteriors sharpen and the same rule exploits nearly deterministically.
    Pitfall Thompson's magic assumes the posterior is honest. Misspecified likelihoods (rewards that drift over time, correlated observations) make posteriors falsely confident and kill exploration prematurely; delayed feedback batches updates and over-samples stale beliefs. Fixes: discount old data / sliding windows for nonstationarity, and inject the delay structure into the model.

      Solution
      $\Pr[\tilde\mu_{\text{new}}>0.5]$ with $\tilde\mu_{\text{new}}\sim U[0,1]$: exactly 0.5 — a completely unknown arm gets half the play against a known-average one, which is just right: it's better with probability ½.
    2. MED Update: the Beta(2,2) arm from the worked example is played and fails. New posterior, new mean, and the qualitative effect on its future play rate?
      Solution
      Beta(2,3): mean $=2/5=0.4$, and the distribution narrows slightly. $\Pr[\tilde\mu_B>\tilde\mu_A]$ falls (mean gap widened to 0.183 and B's variance shrank) — roughly to ~0.25: play rate decays smoothly with evidence, never to zero while real doubt remains.
    3. HARD Compare Thompson and UCB on: (a) determinism/auditability, (b) behavior with many near-identical arms, (c) incorporating prior knowledge.
      Solution
      (a) UCB is deterministic given history (auditable, reproducible; but predictable/exploitable by adversaries); Thompson is randomized (harder to audit per-decision, robust to being gamed, and its randomness doubles as tie-breaking). (b) Many near-equal arms: UCB cycles through all of them since each unplayed arm's bonus dominates — cost linear in $K$; Thompson also spreads play but proportionally to posterior optimality, gracefully splitting among true near-ties instead of insisting on resolving unresolvable gaps. (c) Priors: Thompson consumes real prior information natively (informative Betas shift early play), while UCB has no principled prior slot — warm-starting requires hacking pseudo-counts. Empirically Thompson often wins in practice; both meet the $\ln T$ lower bound in theory.

    Abstention

    Sometimes the best answer is "I won't answer": route to a human, run another test, decline the bet. Abstention adds a special action whose payoff is a known, modest cost — worth taking exactly when your confidence is inside the band where both errors are more expensive. For classifiers and LLMs alike, knowing when not to act is a capability, not a cop-out.

    Definition Classification with rejection: predict $\hat y$ or abstain at cost $c\in(0,\tfrac12)$ (0–1 loss for errors — wait: errors cost 1). Chow's rule: with posterior confidence $q=\max_y p(y\mid x)$, $$\text{abstain}\iff q<1-c,$$ i.e. predict only when the error probability $1-q$ is below the abstention cost. Selective prediction reports the coverage–risk curve: error rate among answered cases vs fraction answered.
    Worked example $c=0.3$: answer iff $q\ge0.7$. On a case with posterior $(0.6,0.4)$: answering errs with probability 0.4 > 0.3 → abstain. Case $(0.8,0.2)$: error 0.2 < 0.3 → answer. If 20% of cases fall in the abstain band with average error 0.35 there, and answered cases err at 0.08: total expected loss $=0.8\cdot0.08+0.2\cdot0.3=0.064+0.06=0.124$ vs always-answer $=0.8\cdot0.08+0.2\cdot0.35=0.134$ — abstention buys 1 point of loss, and (often more valuable) an answered-set error of 8% instead of 13.4%.
    Where this goes LLM hallucination mitigation (Ch 23) is abstention with poorly calibrated $q$; Ch 32's human-approval escalation is abstention priced by the human's time; uncertainty-aware decisions (next) generalize the confidence machinery.
    Drill
    1. EASY Under Chow's rule with $c=0.1$, what confidence is required to answer? And with $c=0.45$?
      Solution
      $q\ge0.9$ (cheap abstention → answer rarely); $q\ge0.55$ (expensive abstention → answer nearly always).

      Solution
      Answering with the argmax class errs with probability $1-q$: expected loss $1-q$. Abstaining costs $c$. Answer iff $1-q\le c\iff q\ge1-c$. ∎ (With asymmetric error costs the threshold shifts per class — same one-line derivation with the loss table of the Bayesian-decision section.)
    3. HARD Why does abstention based on a miscalibrated confidence (e.g. an over-confident LLM) fail asymmetrically, and how does the coverage–risk curve reveal it?
      Solution
      Overconfidence puts wrong answers above the threshold: the abstain band catches too few errors, so answered-set risk stays high while coverage barely drops — the curve is flat where it should fall steeply. Perfectly calibrated confidence yields the steepest achievable curve (each increment of abstention removes the currently-riskiest cases); deviations from that ideal curve localize where in the confidence range calibration is broken (Ch 13's calibration + ECE, operationalized). Fixes: recalibrate (temperature scaling), or use auxiliary uncertainty signals (sampled self-consistency) as the gating quantity instead of raw softmax confidence.

    Uncertainty-aware decisions

    Not all uncertainty is the same substance. Aleatoric uncertainty is the dice — irreducible randomness in the world; epistemic uncertainty is your ignorance — reducible by data. The distinction is decision-relevant: epistemic uncertainty rewards information-gathering and caution about model error, aleatoric uncertainty rewards hedging and risk pricing. Acting well means responding to each with its own remedy.

    Definition Under a posterior over models $p(\theta\mid\mathcal D)$, predictive uncertainty decomposes (for outcome $Y$): $$\underbrace{\mathrm{Var}[Y]}_{\text{total}}=\underbrace{\mathbb E_\theta[\mathrm{Var}(Y\mid\theta)]}_{\text{aleatoric}}+\underbrace{\mathrm{Var}_\theta[\mathbb E(Y\mid\theta)]}_{\text{epistemic}}$$ (law of total variance, Ch 11). Decision consequences: epistemic variance shrinks with data (EVOI $>0$); robust/pessimistic choices hedge epistemic model error; aleatoric spread is priced by risk measures.
    Worked example Two coins each estimated at 50% heads: coin A observed 5000 times (aleatoric only: it is fair); coin B never observed, model average of "always heads" and "always tails" (purely epistemic). Same predictive $p=0.5$; utterly different decisions. Betting repeatedly on A is safe diversification (independent flips, CLT). Betting repeatedly on B is catastrophic: outcomes are perfectly correlated across bets (same unknown coin) — one flip of information first is worth almost the entire stake. Total variance per flip is identical; the decomposition drives the choice.
    Think first An LLM gives an answer with stated confidence 70%. What single follow-up experiment distinguishes whether the missing 30% is aleatoric or epistemic — and why does it matter for whether to consult a second model?
    Reveal
    Resample: ask the same question many times (and/or rephrase). If answers scatter across options — the model itself is unsure — the uncertainty behaves epistemically at the ensemble level: a second model or a retrieval step likely adds real information. If it answers identically every time yet is wrong 30% in calibration terms, the residual is (from this model's view) irreducible — a second identical-family model correlates and adds little; you need a different information source. Ensembles help exactly in proportion to error decorrelation — the epistemic share.

    1. EASY Classify: (a) measurement noise of a thermometer; (b) not knowing the thermometer's bias; (c) tomorrow's coin flip; (d) which of two demand models is right.
      Solution
      Aleatoric: (a), (c). Epistemic: (b), (d) — both reducible by calibration/data.
    2. MED Verify the decomposition numerically: $\theta\in\{0.2,0.8\}$ equally likely, $Y\sim\mathrm{Bern}(\theta)$.
      Solution

    3. HARD A robot's collision-probability estimate for a maneuver is 1% from a model ensemble whose members individually say (0.1%, 0.1%, 2.9%). Why is treating "1%" as aleatoric risk dangerous, and what decision rule respects the structure?
      Solution
      The spread is epistemic: one plausible model says 2.9% — the true risk may be ~3×, and crucially the error is systematic: if the pessimistic model is right, it is right on every future maneuver too (correlated failures, no CLT rescue). Averaging launders model disagreement into a false point estimate. Respecting the structure: act on a robust quantile of the ensemble (e.g. decide as if risk = worst plausible member, or CVaR over the model posterior), and treat the disagreement as an EVOI signal — gather data that discriminates the members before committing to repeated execution.

    Normal-form games

    Now the environment thinks back. A normal-form game strips strategic interaction to its skeleton: players, each with a strategy menu, and a payoff for every combination of choices, all decided simultaneously. The payoff matrix is to game theory what the state space is to decision theory — get it right and the analysis is half done.

    Definition A normal-form game: players $i=1..n$, strategy sets $S_i$, payoff functions $u_i:S_1\times\cdots\times S_n\to\mathbb R$. Two-player games are written as a bimatrix: cell $(a,b)$ holds $(u_1(a,b),u_2(a,b))$. Each player knows the whole structure; choices are simultaneous.
    Worked example Prisoner's Dilemma (years in prison as negative payoff; C = stay silent, D = betray): $$\begin{array}{c|cc} & C & D\\\hline C & (-1,-1) & (-10,0)\\ D & (0,-10) & (-6,-6)\end{array}$$ Each cell: (row's payoff, column's payoff). Whatever the column player does, the row player fares better defecting ($0>-1$ against C; $-6>-10$ against D) — and symmetrically. Both defect, landing at $(-6,-6)$ though $(-1,-1)$ was available: individually flawless reasoning, collectively poor outcome. That gap is the subject of the rest of this chapter.

    1. EASY Write the payoff matrix for Matching Pennies: both pick heads or tails; row wins \$1 if they match, column wins \$1 if they differ.

    Dominant strategies

    A dominant strategy is best no matter what opponents do — the rare luxury of not needing to predict anyone. When every player has one, the game solves itself (as in the Prisoner's Dilemma); more often, deleting dominated strategies iteratively prunes the game, sometimes all the way to a unique prediction.

    Definition Strategy $s_i$ strictly dominates $s_i'$ if $u_i(s_i,s_{-i})>u_i(s_i',s_{-i})$ for every opponent profile $s_{-i}$ (weakly: $\ge$ everywhere, $>$ somewhere). Iterated elimination of strictly dominated strategies (IESDS): repeatedly delete dominated strategies from any player; the surviving set is order-independent and contains all Nash equilibria.
    Worked example Row has strategies U, M, D vs column's L, R with row payoffs: U: (3,0); M: (2,2); D: (0,3) and suppose column payoffs make column play either. Is M dominated? By U: no ($2>0$ at R... compare per column: L: U=3>M=2; R: U=0mixture: play U and D each with ½: payoffs (1.5, 1.5)... that loses to M at both. Try mixing U,D with weights $(q,1-q)$: L: $3q$, R: $3(1-q)$. Need both $>2$: $q>\tfrac23$ and $q<\tfrac13$ — impossible: M is not dominated here. Change M to (1.4,1.4): mixture at $q=\tfrac12$ gives (1.5,1.5) > (1.4,1.4): M is strictly dominated by a mixed strategy though no pure strategy dominates it — mixtures matter even for elimination.

    Nash equilibrium

    A Nash equilibrium is a profile of strategies where nobody gains by deviating alone: every player's choice is a best response to everyone else's. It is the self-consistency condition of strategic prediction — any proposed "solution" failing it refutes itself, since some player would break it. Existence is guaranteed (with mixtures); uniqueness and goodness are not.

    Definition A profile $(s_1^*,\dots,s_n^*)$ is a Nash equilibrium if for every player $i$ and every alternative $s_i$: $$u_i(s_i^*,s_{-i}^*)\ \ge\ u_i(s_i,s_{-i}^*).$$ Theorem (Nash 1950): every finite game has at least one equilibrium in mixed strategies.
    Worked example Battle of the Sexes: two friends prefer being together; row prefers opera, column prefers football: (O,O)=(2,1), (F,F)=(1,2), miscoordination (0,0). Check (O,O): row deviating to F gets 0<2 ✓; column deviating gets 0<1 ✓ — equilibrium. Symmetrically (F,F). Two pure equilibria (plus one mixed) — Nash narrows to self-consistent outcomes but does not select among them; conventions, communication or focal points do.
    Pitfall Nash ≠ optimal: the Prisoner's Dilemma's unique equilibrium (D,D) is Pareto-dominated by (C,C). Equilibrium is a stability concept — no unilateral incentive to move — not a welfare concept; groups can be stably stuck in bad places. Also: real humans (and trained agents) often don't play Nash, especially in one-shot games; treat it as a boundary condition, not a forecast.
    A game has no pure-strategy Nash equilibrium. What does Nash's theorem guarantee?
    Nash's theorem: every finite game has an equilibrium once randomized strategies are allowed. Matching Pennies is the canonical example — no pure equilibrium, unique mixed one at 50/50 for both.

    Mixed strategies

    When any predictable choice can be punished, unpredictability becomes the strategy: randomize. A mixed strategy assigns probabilities to your pure options, and in equilibrium the probabilities are set by a strange, backwards logic — each player randomizes exactly so as to make the opponent indifferent among the actions they mix over.

    Definition A mixed strategy for player $i$ is a distribution $\sigma_i$ over $S_i$; payoffs extend by expectation. Indifference principle: in equilibrium, every pure strategy in the support of $\sigma_i$ earns the same expected payoff against $\sigma_{-i}$ (else $i$ would shift mass to the better one), and no strategy outside the support earns more.
    Explore

    Matching Pennies from the row player's view: slide column's $\Pr(H)$ and see row's expected payoff for H, T and the best response; equilibrium is where the lines cross (0.5) and row becomes indifferent.

    Worked example Battle of the Sexes mixed equilibrium. Let column play O with probability $q$. Row indifferent: $u(O)=2q$, $u(F)=1(1-q)$: $2q=1-q\Rightarrow q=\tfrac13$. Symmetrically row plays O with $p$ making column indifferent: $1\cdot p=2(1-p)\Rightarrow p=\tfrac23$. Equilibrium: row (⅔ O), column (⅓ O). Expected payoff each: $2\cdot\tfrac23\cdot\tfrac13+1\cdot\tfrac13\cdot\tfrac23+0=\tfrac23$ — worse than either pure equilibrium (1 and 2): the price of failing to coordinate, paid in miscoordination probability $\tfrac23\cdot\tfrac23+\tfrac13\cdot\tfrac13=\tfrac59$.

      Solution
      Expected payoff is linear in $\sigma_1$: $u_1(\sigma_1,\sigma_2)=\sum_sp_su_1(s,\sigma_2)$. The "paradox": given the opponent's equilibrium mix, the randomizer is indeed indifferent — randomization isn't for this payoff but for stability: any deterministic choice would change the opponent's best response and unravel the profile. The mix is held in place by the opponent's exploitation threat, not by direct gain.

    Zero-sum games and minimax

    In strictly competitive games — my gain is exactly your loss — the right paranoia is provably optimal: choose the strategy whose worst case is best, expecting an opponent who sees you coming. Von Neumann's theorem says the maximin and minimax values coincide (with mixing), so "security level" thinking loses nothing, and equilibrium = optimal play for both.

    Definition A two-player zero-sum game: $u_2=-u_1$; write the row player's payoff matrix $A$. Maximin: $\underline v=\max_{\sigma_1}\min_{\sigma_2}\sigma_1^\top A\sigma_2$; minimax: $\bar v=\min_{\sigma_2}\max_{\sigma_1}\sigma_1^\top A\sigma_2$. Minimax theorem (von Neumann 1928): $\underline v=\bar v=v$, the game's value; optimal mixed strategies exist and form exactly the Nash equilibria. Computable by linear programming (Ch 15's duality: the two players' LPs are duals).
    Worked example $A=\begin{pmatrix}3&-1\\-2&4\end{pmatrix}$ (row maximizes). No saddle point (row minima: $-1,-2$; max $=-1$; column maxima: $3,4$; min $=3$; $-1\ne3$). Row mixes $(p,1-p)$ to equalize column responses: vs col-1: $3p-2(1-p)=5p-2$; vs col-2: $-p+4(1-p)=4-5p$. Equal: $5p-2=4-5p\Rightarrow p=0.6$, value $v=5(0.6)-2=1$. Column mixes $(q,1-q)$: $3q-(1-q)=4q-1$ and $-2q+4(1-q)=4-6q$: $4q-1=4-6q\Rightarrow q=0.5$, value $=1$ ✓. Row guarantees $\ge1$; column guarantees row $\le1$: the value is exactly 1.
    Where this goes Minimax is Ch 26's game-tree search criterion (chess engines are approximate minimax machines), the "min" player in GAN training (Ch 22), and the worst-case stance of robust/adversarial ML (Ch 35).

Interchangeability is the special zero-sum gift: "optimal play" is well-defined without coordination — the reason chess engines needn't model their specific opponent.

    Repeated games

    Play the same game tomorrow and today's defection has a price: your reputation. Repetition turns one-shot logic upside down — cooperation in the Prisoner's Dilemma can become equilibrium behavior, sustained by the credible threat of future punishment, provided the future matters enough (high continuation probability / low discounting).

    Definition A repeated game plays stage game $G$ for $T$ rounds (or infinitely, with discount factor $\delta\in(0,1)$: payoff $\sum_t\delta^tu_i(t)$, or continuation probability $\delta$ per round). Strategies condition on history. Folk theorem (informal): for $\delta$ close enough to 1, every feasible payoff profile giving each player more than their minmax value is sustainable as an equilibrium — repetition makes an enormous set of outcomes self-enforcing, cooperation included.
    Worked example PD with payoffs (C,C)=3 each, (D,C)=5 to defector / 0 to victim, (D,D)=1, discount $\delta$. Grim trigger: cooperate until anyone defects, then defect forever. Deviation payoff: $5+\delta\cdot\frac{1}{1-\delta}$ vs cooperation $\frac{3}{1-\delta}$. Cooperation sustained iff $\frac{3}{1-\delta}\ge5+\frac{\delta}{1-\delta}$: $3\ge5(1-\delta)+\delta\Rightarrow3\ge5-4\delta\Rightarrow\delta\ge\tfrac12$. If each round follows with $\ge$50% probability, the one-time gain of 2 never beats the perpetual loss of 2 per round.
    Pitfall Finitely repeated with a known last round: backward induction unravels cooperation entirely (defect at $T$ since no future; then $T-1$ is effectively last; induction to round 1). Real cooperation survives because horizons are uncertain, reputations extend beyond the pair, and players aren't common-knowledge rational — the theory's cleanest negative result is also its best-documented empirical failure. Noise matters too: with occasional misperceived moves, grim trigger detonates permanently over accidents; forgiving strategies (tit-for-tat with occasional forgiveness, win-stay-lose-shift) dominate noisy tournaments.

All work by pushing the interaction back toward the one-shot game, where competitive pricing is dominant — a rare case where destroying repeated-game structure is the pro-social design (Ch 33's collusion risks).

    Mechanism design

    Mechanism design is game theory played backwards: you want a social outcome — honest bids, efficient allocation, truthful reports — and you get to write the rules. Design payoffs so that each participant's selfish best move is the behavior you wanted. The crown jewels: truthful auctions (second-price/VCG) and the revelation principle, which says you can always look for mechanisms where honesty is optimal.

    Definition A mechanism specifies a message space per agent and an outcome rule (allocation + payments) mapping messages to results. It is incentive-compatible (strategyproof, in dominant strategies) if truthful reporting is optimal for every agent regardless of others. Revelation principle: any equilibrium outcome of any mechanism can be replicated by a truthful direct mechanism. VCG: allocate to maximize reported total value; charge each agent the externality they impose on others — truthfulness is a dominant strategy.
    Worked example One item, bidders value it (privately) at 10, 8, 5. Second-price auction: everyone bids truthfully (dominance, proved in the dominant-strategies drill); bidder 1 wins, pays 8 — the externality: without bidder 1, the item would have gone to bidder 2 who valued it at 8. Check VCG framing: others' welfare without me: 8; with me winning: 0; my payment $=8-0=8$ ✓. The winner's own bid sets whether they win, never what they pay — severing that link is what kills the incentive to shade.
    Where this goes Mechanism design governs multi-agent AI directly: eliciting honest confidence from model ensembles (proper scoring rules are mechanisms), allocating shared compute among agents, auction-based task delegation (Ch 33), and designing evaluation schemes agents can't game (Ch 32, Ch 35).
    Drill
    1. EASY In a first-price auction (winner pays own bid), why is truthful bidding not optimal?
      Solution
      Bidding your value guarantees zero surplus even when you win; shading below value trades a small win-probability loss for positive surplus on wins — the optimal bid is strictly below value (e.g. with uniform rivals, bid $\frac{n-1}{n}v$).     2. MED A logarithmic scoring rule pays a forecaster $\log p(y)$ where $p$ is their reported distribution and $y$ the realized outcome. Show truthful reporting maximizes expected payment.

KL $\ge0$ with equality iff $p=q$: any dishonest report costs exactly the KL divergence. The log score is a mechanism making honesty dominant for beliefs — the elicitation analogue of the second-price auction (and the reason log-loss-trained models are incentivized toward calibrated probabilities).

    Task 1 — ε-greedy vs UCB vs Thompson Simulate a 3-armed Bernoulli bandit (rates 0.35, 0.55, 0.45) for 5,000 steps × 200 runs; plot/print mean cumulative regret of the three algorithms.
    Reference solution
    import numpy as np
rng = np.random.default_rng(0)
mu = np.array([0.35, 0.55, 0.45]); K = 3; T = 5000; RUNS = 200
best = mu.max()

def run(algo):
    regret = np.zeros(T)
    for _ in range(RUNS):
        s = np.zeros(K); f = np.zeros(K)   # successes, failures
        for t in range(T):
            n = s + f
            if algo == 'eps':
                a = rng.integers(K) if rng.random() < 0.1 else np.argmax(s/np.maximum(n,1))
            elif algo == 'ucb':
                a = t if t < K else np.argmax(s/n + np.sqrt(2*np.log(t+1)/n))
            else:  # thompson
                a = np.argmax(rng.beta(s+1, f+1))
            r = rng.random() < mu[a]
            s[a] += r; f[a] += 1-r
            regret[t] += best - mu[a]
    return regret.cumsum() / RUNS

for algo in ['eps', 'ucb', 'thompson']:
    reg = run(algo)
    print(f"{algo:9s} regret @1000: {reg[999]:7.1f}  @5000: {reg[-1]:7.1f}")
# expected: eps grows ~linearly (~0.1*mean-gap*T); ucb & thompson ~log T,
# with thompson typically lowest.
    Task 2 — EVOI on a decision tree Implement generic EVOI: given prior, likelihoods, actions and a utility table, compute prior-optimal EU, posterior decisions per observation, EVOI and EVPI. Verify the umbrella numbers from this chapter.
    Reference solution
    import numpy as np

def evoi(prior, like, U):
    # prior: (S,), like: p(y|s) shape (S,Y), U: utility (A,S)
    prior = np.asarray(prior, float)
    EU_prior = (U * prior).sum(1)                 # (A,)
    base = EU_prior.max()
    py = like.T @ prior                           # (Y,)
    post = (like * prior[:, None]).T / py[:, None]  # (Y,S)
    EU_post = post @ U.T                          # (Y,A)
    with_info = (py * EU_post.max(1)).sum()
    evpi = (prior * U.max(0)).sum() - base
    return base, with_info - base, evpi

# umbrella: states [rain, dry], actions [carry, leave]
prior = [0.3, 0.7]
U = np.array([[7, 8],     # carry: rain, dry
              [1, 10]])   # leave
like = np.array([[0.8, 0.2],   # p(forecast | rain)   -> [says-rain, says-dry]
                 [0.2, 0.8]])  # p(forecast | dry)
base, ev, evpi = evoi(prior, like, U)
print(f"base EU {base:.3f}  EVOI {ev:.3f}  EVPI {evpi:.3f}")
# base 7.700, EVOI 0.760, EVPI 1.400  (matches the chapter)
    Task 3 — 2×2 Nash solver Write a solver returning all pure equilibria and the mixed equilibrium (when it exists) of a 2×2 bimatrix game; verify on Matching Pennies, Prisoner's Dilemma and Battle of the Sexes.
    Reference solution
    import numpy as np

def nash_2x2(A, B):
    # A: row payoffs (2x2), B: column payoffs (2x2)
    A, B = np.asarray(A, float), np.asarray(B, float)
    pure = []
    for i in range(2):
        for j in range(2):
            if A[i, j] >= A[1-i, j] and B[i, j] >= B[i, 1-j]:
                pure.append((i, j))
    mixed = None
    # column mixes q on col0 to make row indifferent; row mixes p on row0 for column
    denq = (A[0,0]-A[0,1]-A[1,0]+A[1,1])
    denp = (B[0,0]-B[1,0]-B[0,1]+B[1,1])
    if denq != 0 and denp != 0:
        q = (A[1,1]-A[0,1]) / denq
        p = (B[1,1]-B[1,0]) / denp
        if 0 < q < 1 and 0 < p < 1:
            mixed = (p, q)
    return pure, mixed

MP_A = [[ 1,-1],[-1, 1]]; MP_B = [[-1, 1],[ 1,-1]]
PD_A = [[-1,-10],[0,-6]]; PD_B = [[-1,0],[-10,-6]]
BS_A = [[2,0],[0,1]];     BS_B = [[1,0],[0,2]]

print(nash_2x2(MP_A, MP_B))  # ([], (0.5, 0.5))
print(nash_2x2(PD_A, PD_B))  # ([(1, 1)], None)   -> (D,D)
print(nash_2x2(BS_A, BS_B))  # ([(0,0),(1,1)], (2/3, 1/3))
