    Why learning from finite data can work at all.

    Empirical risk minimization

    Learning theory's central object is a gap: you minimized the average loss on a sample, but you will be judged on the distribution. When is the sample average a faithful stand-in for the expectation — not just for one fixed rule, but for the rule you CHOSE because it looked good? This chapter is the mathematics of that "because."

    Definition Distribution $\mathcal D$ over $\mathcal X\times\mathcal Y$; loss $\ell$ (default: 0-1). True risk $R(h) = \mathbb E_{\mathcal D}[\ell(h(x), y)]$; empirical risk $\hat R_S(h) = \frac1n\sum_i \ell(h(x_i), y_i)$ on sample $S \sim \mathcal D^n$. ERM: $\hat h = \arg\min_{h\in\mathcal H}\hat R_S(h)$. Key decomposition: $$R(\hat h) - \min_{h\in\mathcal H}R(h) \le 2\sup_{h\in\mathcal H}|R(h) - \hat R_S(h)|$$ — control the worst-case gap over the class and ERM is guaranteed near-optimal in the class.
    Worked example Why the factor 2: let $h^* = \arg\min_{\mathcal H} R$. Then $R(\hat h) \le \hat R_S(\hat h) + \sup|\cdot| \le \hat R_S(h^*) + \sup|\cdot| \le R(h^*) + 2\sup|\cdot|$ — first inequality bounds $\hat h$'s optimism, second uses that ERM preferred $\hat h$ to $h^*$ on the sample, third bounds $h^*$'s sample luck. The gap must be controlled UNIFORMLY because $\hat h$ is data-dependent: you don't know in advance which hypothesis you'll need the guarantee for.
    Where this goes Everything below is machinery for bounding $\sup_{h\in\mathcal H}|R - \hat R|$: counting (finite classes), shattering (VC), averaging over random signs (Rademacher), or sidestepping the sup entirely (stability, PAC-Bayes).
    Drill
    1. EASY For one FIXED classifier $h$ with true error 0.3 and $n = 100$: what distribution does $n\hat R_S(h)$ follow, and what is the standard deviation of $\hat R_S(h)$?
      Solution
      Binomial(100, 0.3); $\mathrm{sd}(\hat R) = \sqrt{0.3\times0.7/100} \approx 0.046$.
    2. MED Why does LLN applied to $\hat h$ directly fail — where exactly does the argument "$\hat R_S(\hat h) \to R(\hat h)$ by LLN" break?
      Solution
      LLN needs the summands $\ell(h(x_i), y_i)$ to be i.i.d. for a FIXED $h$. But $\hat h$ was chosen after seeing the sample, so the losses $\ell(\hat h(x_i), y_i)$ are not independent draws — $\hat h$ was engineered to make them small. The randomness of $\hat h$ and of the sample are entangled; uniform convergence restores the argument by covering all $h$ simultaneously, fixed before the sample in aggregate.
    3. HARD Construct a class $\mathcal H$ and distribution where $\hat R_S(\hat h) = 0$ always but $R(\hat h) = \frac12$ always (for any $n$).
      Solution
      $\mathcal X = [0,1]$ uniform, labels $y$ = fair coin independent of $x$; $\mathcal H$ = all finite-support indicator tweaks: $h_T(x) = y_i$ if $x = x_i \in T$ else $0$ — more simply $\mathcal H$ = ALL functions $\mathcal X \to \{0,1\}$. ERM memorizes the sample: $\hat R = 0$; on a fresh point ($\ne$ any $x_i$ almost surely), the prediction (say 0) is independent of the coin label: $R = \frac12$. Uniform convergence fails: $\sup_h|R - \hat R| = \frac12$ for every $n$ — an unrestricted class learns nothing. (This is the no-free-lunch seed.)

    Hypothesis classes

    The hypothesis class is the learner's prior commitment: the set of functions it is willing to output. Too small and the truth isn't in it (approximation error); too rich and the data can't pin down a good member (estimation error). Learning theory measures classes not by how many parameters they have but by how many BEHAVIORS they can exhibit on finite samples.

    Definition $\mathcal H \subseteq \{h: \mathcal X \to \mathcal Y\}$. Examples: threshold functions on $\mathbb R$ ($h_t(x) = \mathbf 1[x \ge t]$); intervals; linear separators in $\mathbb R^d$ ($2^d$-ish richness: VC dim $d{+}1$); depth-$k$ decision trees; all neural nets of a fixed architecture; all measurable functions (the no-learning extreme). Measures of size: cardinality $|\mathcal H|$; growth function; VC dimension; Rademacher complexity; covering numbers — each feeding a family of bounds.
    Worked example Thresholds on $\mathbb R$ have infinitely many members ($t\in\mathbb R$), yet on any 5 sample points they realize at most 6 distinct labelings ($t$ below all, between each adjacent pair, above all). Behavioral count 6 ≪ $2^5 = 32$: the class is "small where it matters" — this behavioral counting, not cardinality, is what generalization bounds consume.
    Think first Two classes: (a) $\{h_\theta(x) = \mathbf 1[\sin(\theta x) > 0] : \theta \in\mathbb R\}$ — ONE parameter; (b) all decision stumps on $d$ features — $O(nd)$ behaviors. Which is richer in the learning-theory sense?
    Reveal
    (a), catastrophically: the sine family shatters arbitrarily large point sets (choose points $2^{-i}$; frequencies exist realizing every sign pattern) — infinite VC dimension from one parameter. Parameter count is not capacity; behavioral diversity is. (b) is safely learnable despite having "more parameters" naively.
    Drill
    1. EASY How many distinct labelings can threshold classifiers $\mathbf 1[x \ge t]$ produce on $n$ distinct points of $\mathbb R$?
      Solution
      $n + 1$: the threshold falls in one of $n+1$ gaps (sorted points), each giving a distinct labeling.
    2. MED Intervals $h_{[a,b]}(x) = \mathbf 1[a \le x \le b]$: count labelings on $n$ distinct points and compare growth to $2^n$.
      Solution
      A labeling is any consecutive run of 1s (or all 0s): $\binom{n}{2} + n + 1 = \binom{n+1}{2} + 1$ labelings ($O(n^2)$ vs $2^n$: polynomial — the class is VC-small; indeed VC dim = 2).
    3. HARD Show the class of CONVEX-set indicators in the plane realizes all $2^n$ labelings of $n$ points in "general position" on a circle — and what that implies.
      Solution
      Points on a circle: for any subset $T$, its convex hull contains no non-member point (circle points are extreme points), so the indicator of hull($T$) labels exactly $T$ positive. All $2^n$ subsets realized for every $n$: infinite VC dimension ⟹ no distribution-free generalization guarantee for ERM over convex sets — despite "convex" sounding tame. Geometric innocence ≠ statistical innocence.

    PAC learning (merged: Probably approximately correct learning)

    PAC learning makes "learnable" a theorem-grade word. You can't demand a perfect hypothesis (the sample is finite: "approximately") nor certainty (the sample may be unlucky: "probably"). A class is PAC-learnable if, for ANY accuracy ε and confidence δ you name, some algorithm gets within ε with probability 1−δ, using a number of samples polynomial in 1/ε and 1/δ — whatever the distribution.

    Definition $\mathcal H$ is PAC-learnable if there is an algorithm $A$ and function $n_{\mathcal H}(\varepsilon, \delta)$ such that for every distribution $\mathcal D$ and every $\varepsilon, \delta \in (0,1)$: given $n \ge n_{\mathcal H}(\varepsilon,\delta)$ i.i.d. samples, with probability $\ge 1 - \delta$, $A$ outputs $h$ with $R(h) \le \min_{h'\in\mathcal H}R(h') + \varepsilon$ (agnostic PAC; the realizable version assumes some $h^*\in\mathcal H$ has $R = 0$ and demands $R(h)\le\varepsilon$). Fundamental theorem: $\mathcal H$ is PAC-learnable ⟺ VC$(\mathcal H) < \infty$, with $n = \Theta\!\big(\frac{d + \log(1/\delta)}{\varepsilon^2}\big)$ (agnostic) or $\Theta\!\big(\frac{d\log(1/\varepsilon) + \log(1/\delta)}{\varepsilon}\big)$ (realizable), $d = $ VC dim.
    Worked example Learning an unknown threshold $t^*$ on $[0,1]$ (realizable). Algorithm: output any threshold consistent with the sample. A consistent threshold errs only on the gap between $t^*$ and the nearest sample points; the gap has probability mass $> \varepsilon$ only if no sample landed in an $\varepsilon$-mass region adjacent to $t^*$ — probability $\le (1-\varepsilon)^n \le e^{-\varepsilon n}$ per side. Setting $2e^{-\varepsilon n} \le \delta$: $n \ge \frac{1}{\varepsilon}\ln\frac{2}{\delta}$. For ε = 0.01, δ = 0.05: $n \ge 100\ln 40 \approx 369$ samples — concrete, distribution-free, and linear in $1/\varepsilon$ as the realizable rate promises.
    Pitfall PAC's quantifier order matters: ONE sample size must work for EVERY distribution. It does not say your particular problem needs that many samples (real distributions are kinder than the worst case), and it says nothing about computational cost — some classes are PAC-learnable information-theoretically but NP-hard to fit (e.g. agnostic halfspaces).
    Drill
    1. EASY Unpack "probably approximately correct" — which parameter governs each word?
      Solution
      "Probably": confidence $1-\delta$ (over the random sample). "Approximately correct": accuracy ε (excess risk of the output). Two failure modes, two dials.
    2. MED In the agnostic bound $n \sim \frac{d + \log(1/\delta)}{\varepsilon^2}$: what does halving ε cost? Halving δ? Explain the asymmetry.
      Solution
      Halving ε: 4× samples ($1/\varepsilon^2$ — you're fighting the CLT's $1/\sqrt n$ noise floor). Halving δ: additive $\frac{\log 2}{\varepsilon^2}$ — nearly free, because confidence improves EXPONENTIALLY in $n$ (concentration). Accuracy is expensive; confidence is cheap.
    3. HARD Why is the realizable rate $1/\varepsilon$ but the agnostic rate $1/\varepsilon^2$?
      Solution
      Realizable: you only need to rule out hypotheses with error $> \varepsilon$, and each survives a sample of consistent points with probability $\le(1-\varepsilon)^n \approx e^{-\varepsilon n}$: exponential kill rate linear in ε. Agnostic: you must ESTIMATE risks to precision ε to compare hypotheses near the optimum, and estimating a mean to ±ε from bounded samples takes $\Theta(1/\varepsilon^2)$ by CLT/Hoeffding — no shortcut exists (matching lower bounds). Deciding "is it zero?" is easier than "which is smaller?".
    PAC-learnability of a class is equivalent to…
    The fundamental theorem of statistical learning: PAC-learnable ⟺ VC dim < ∞. Finiteness is sufficient but not necessary (thresholds are infinite yet learnable), and PAC makes no assumption that the truth lies in the class (that's just the realizable special case).

    Uniform convergence

    Uniform convergence upgrades the law of large numbers from one hypothesis to all of them at once: with enough data, EVERY member of the class has empirical risk close to its true risk, simultaneously. Once that holds, the training-set leaderboard is trustworthy — the empirical winner is nearly the true winner — and ERM is vindicated in one line.

    Definition $\mathcal H$ has the uniform convergence property if for all $\varepsilon, \delta$ there is $n(\varepsilon,\delta)$ with $$P_{S\sim\mathcal D^n}\Big(\sup_{h\in\mathcal H}\big|R(h) - \hat R_S(h)\big| \le \varepsilon\Big) \ge 1 - \delta$$ for every $\mathcal D$. Uniform convergence ⟹ agnostic PAC-learnability of $\mathcal H$ by ERM (via the factor-2 decomposition); for 0-1 loss the converse holds too — for boolean classes, learnability, uniform convergence, and finite VC dimension are one property.
    Worked example Class of two hypotheses, both with true risk 0.5 (useless coins), $n = 100$. Individually each has $|\hat R - R| \le 0.1$ with prob ≈ 0.95. Jointly (union bound): ≥ 0.90. Now $10^6$ hypotheses: the union bound needs each to hold with prob $1 - 5\times10^{-8}$, i.e. deviations up to $\sqrt{\frac{\ln(2\times10^6/0.05)}{2\times100}} \approx 0.30$: with only 100 samples, a million-coin class WILL contain coins looking 20–30 points better than they are. The sup is the honest object; its size grows with class richness.

    Watch the empirical risks of many random useless classifiers scatter around 0.5: the LUCKIEST one looks skilled. Grow n and watch the illusion die at rate $\sqrt{\log|\mathcal H|/n}$.

    Drill
    1. EASY State in one sentence why uniform convergence makes ERM safe.
      Solution
      If every hypothesis's sample score is within ε of its true score, then the sample's winner is within 2ε of the class's true best — you cannot be fooled by more than 2ε.
    2. MED Uniform convergence bounds are two-sided ($\sup$ of $|R - \hat R|$). Which side protects against overfitting, and what does the other side buy?
      Solution
      $R \le \hat R + \varepsilon$ (upper) is the anti-overfitting direction: good sample scores imply good true scores. $\hat R \le R + \varepsilon$ ensures the true best hypothesis also LOOKS good on the sample — without it, ERM might discard $h^*$ because it got unlucky. Both directions are used in the factor-2 argument.
    3. HARD For unbounded losses (squared error with heavy-tailed noise), uniform convergence can fail even for small classes. Why, and what assumptions restore it?
      Solution
      Concentration (Hoeffding) needs bounded (or light-tailed) summands: one enormous loss value can swing $\hat R$ arbitrarily, so no finite $n$ guarantees closeness — a single hypothesis can fail LLN rates, let alone the sup. Restorations: bound the loss (clip predictions/targets), assume sub-Gaussian/sub-exponential noise (Bernstein bounds), or truncate + control tails separately. Every deep-learning bound quietly assumes bounded loss for this reason.

    Finite class bounds

    The simplest generalization theorem: if your class has $|\mathcal H|$ members, union-bound Hoeffding over all of them. The price of choosing from $K$ hypotheses is only $\sqrt{\log K}$ — logarithmic, which is why selecting among even millions of models on a decent validation set is safe, and why "log of the number of things you tried" is the master heuristic of trustworthy ML.

    Theorem (finite class) For 0-1 loss (or any loss in $[0,1]$), with probability $\ge 1 - \delta$ over $S\sim\mathcal D^n$: $$\sup_{h\in\mathcal H}\big|R(h) - \hat R_S(h)\big| \le \sqrt{\frac{\ln(2|\mathcal H|) + \ln(1/\delta)}{2n}}.$$ Proof: Hoeffding per hypothesis ($P(|R - \hat R| > \varepsilon) \le 2e^{-2n\varepsilon^2}$), union bound over $|\mathcal H|$, solve for ε. Realizable version: $R(\hat h) \le \frac{\ln|\mathcal H| + \ln(1/\delta)}{n}$ for consistent $\hat h$ — rate $1/n$.
    Worked example You grid-search $|\mathcal H| = 1000$ configurations on a validation set of $n = 5000$, δ = 0.05. Bound: $\sqrt{\frac{\ln 2000 + \ln 20}{10000}} = \sqrt{\frac{7.60 + 3.00}{10000}} = \sqrt{0.00106} \approx 0.033$. Every config's validation score is within ±3.3 points of truth simultaneously — the winner's score is honest to ~6.6 points worst case (in practice much better). Try $10^6$ configs instead: $\ln$ grows from 7.6 to 14.5 — the bound only worsens to ≈3.7 points. Selection is cheap; samples are dear.
    Where this goes $\ln|\mathcal H|$ is a description length in disguise — Ch 16's MDL: hypotheses you can name in $b$ bits form a class of size $2^b$, giving gap $\sim\sqrt{b/n}$. PAC-Bayes (below) generalizes this from counting to priors.
    Drill
    1. EASY With $n = 200$, δ = 0.05, $|\mathcal H| = 10$: compute the bound.
      Solution
      $\sqrt{\frac{\ln 20 + \ln 20}{400}} = \sqrt{\frac{5.99}{400}} \approx 0.122$.
    2. MED How many samples for gap ≤ 0.05 with δ = 0.01 over $|\mathcal H| = 10^6$?
      Solution
      $n \ge \frac{\ln(2\times10^6) + \ln 100}{2(0.05)^2} = \frac{14.51 + 4.61}{0.005} \approx 3824$. A few thousand validation points police a million models.
    3. HARD Derive the realizable $1/n$ rate: if some $h^*\in\mathcal H$ has $R(h^*) = 0$ and ERM returns a sample-consistent $\hat h$, then $P(R(\hat h) > \varepsilon) \le |\mathcal H|e^{-\varepsilon n}$.
      Solution
      Fix any "bad" $h$ with $R(h) > \varepsilon$: it survives (labels all $n$ points correctly) with probability $(1 - R(h))^n < (1-\varepsilon)^n \le e^{-\varepsilon n}$. Union over at most $|\mathcal H|$ bad hypotheses: some bad one survives with prob $\le |\mathcal H|e^{-\varepsilon n}$; otherwise every consistent hypothesis — including $\hat h$ — has $R \le \varepsilon$. Set RHS $= \delta$: $n \ge \frac{\ln|\mathcal H| + \ln(1/\delta)}{\varepsilon}$. The absence of estimation noise (zero errors, not few) upgrades $1/\varepsilon^2$ to $1/\varepsilon$. ∎

    VC dimension

    Infinite classes need a finite measure of richness. The VC dimension asks: what is the largest set of points your class can label in ALL possible ways ("shatter")? A class that shatters $d$ points but no $d+1$ has VC dimension $d$ — and that single integer controls learnability, sample complexity, and generalization for the whole class, however infinite.

    Definition $\mathcal H$ shatters $\{x_1..x_m\}$ if for every labeling $b \in \{0,1\}^m$ some $h\in\mathcal H$ realizes it. $\mathrm{VC}(\mathcal H) = $ the largest $m$ such that SOME $m$-point set is shattered ($\infty$ if unbounded). Canon: thresholds on ℝ: 1; intervals: 2; halfspaces in $\mathbb R^d$: $d + 1$; axis-aligned rectangles in the plane: 4; convex polygons with $k$ vertices: $2k+1$; $\sin(\theta x)$ signs: ∞. Proving VC $= d$ requires BOTH: exhibit one shattered $d$-set, and prove NO $(d{+}1)$-set is shatterable.
    Worked example Intervals have VC dim 2. Shatter $\{1, 2\}$: ∅ via $[5,6]$; $\{1\}$ via $[0.5, 1.5]$; $\{2\}$ via $[1.5, 2.5]$; both via $[0, 3]$. ✓ No 3 points $x_1 < x_2 < x_3$ can be shattered: the labeling $(1, 0, 1)$ needs an interval containing $x_1, x_3$ but not the point between them — impossible for an interval. VC = 2. ∎

    Pitfall VC dimension is about SOME set being shattered, not all sets: three collinear points are never shattered by halfplanes, yet halfplane VC dim in the plane is 3 (use a triangle). And parameters ≠ VC: the one-parameter sine class has VC ∞, while neural nets have VC roughly $O(\text{weights}\times\log(\text{weights}))$ (piecewise-linear case) — finite but astronomically large, which is why VC bounds are vacuous for deep nets (double descent, below).

    1. EASY What is the VC dimension of the class of constant classifiers {always-0, always-1}?
      Solution
      1: one point gets both labelings; two points can't get labeling (0,1).
    2. MED Show axis-aligned rectangles in the plane shatter some 4-point set but no 5-point set.
      Solution
      Shatter a diamond (N, S, E, W points): any subset is cut out by a rectangle clipping the unwanted extremes (each point is the unique extreme in its direction). No 5 points: take the 5th point $p$; among the 5, pick the topmost, bottommost, leftmost, rightmost — at most 4 distinct points; some point $q$ is extreme in NO direction. The labeling "the four extremes in, $q$ out" fails: a rectangle containing all four extremes contains their bounding box, which contains $q$. VC = 4. ∎
    3. HARD Halfspaces through the origin in $\mathbb R^d$ ($h_w(x) = \mathrm{sign}(w^\top x)$): show VC dimension is exactly $d$.
      Solution
      Shatter the standard basis $e_1..e_d$: for labeling $b\in\{\pm1\}^d$ take $w = \sum b_ie_i$: $\mathrm{sign}(w^\top e_i) = b_i$ ✓. No $d+1$ points: any $x_1..x_{d+1}$ in $\mathbb R^d$ are linearly dependent: $\sum_i a_ix_i = 0$ with some $a_i \ne 0$. Try the labeling $b_i = \mathrm{sign}(a_i)$ (arbitrary for $a_i = 0$): if some $w$ realized it, then $a_iw^\top x_i \ge 0$ for all $i$ with strict inequality for $a_i \neq 0$ — but $\sum_i a_i w^\top x_i = w^\top(\sum a_ix_i) = 0$, contradiction. VC = d. ∎ (With bias: $d+1$, by lifting.)

    Growth functions

    The growth function counts behaviors: over all possible $m$-point samples, the maximum number of distinct labelings the class realizes. It is the honest effective size of an infinite class on finite data — the number that replaces $|\mathcal H|$ in bounds. The drama: either it is $2^m$ forever (shattering never stops) or it bends to a polynomial, and VC dimension marks the bend.

    Definition $\Pi_{\mathcal H}(m) = \max_{x_1..x_m}\big|\{(h(x_1), \dots, h(x_m)) : h\in\mathcal H\}\big|$. Facts: $\Pi_{\mathcal H}(m) \le 2^m$ always; $\Pi_{\mathcal H}(m) = 2^m$ iff some $m$-set is shattered, so $\mathrm{VC}(\mathcal H) = \max\{m : \Pi_{\mathcal H}(m) = 2^m\}$. The VC bound replaces cardinality by growth: with prob $\ge 1-\delta$, $\sup_h|R - \hat R| \le \sqrt{\frac{8\ln(4\Pi_{\mathcal H}(2n)/\delta)}{n}}$ (via symmetrization: compare the sample to a ghost sample, reducing the sup over $\mathcal H$ to a max over its finitely many behaviors on $2n$ points).
    Worked example Thresholds: $\Pi(m) = m + 1$ (computed earlier). VC = 1 since $\Pi(1) = 2 = 2^1$ but $\Pi(2) = 3 < 4$. Plug into the VC bound with $n = 1000$, δ = 0.05: $\sqrt{\frac{8\ln(4\times2001/20)}{1000}} = \sqrt{\frac{8\ln 400.2}{1000}} = \sqrt{\frac{8\times5.99}{1000}} \approx 0.22$ — loose constants (bounds of this family are conservative by ~an order), but FINITE for an infinite class: the point of the whole construction.
    Drill
    1. EASY Compute $\Pi_{\mathcal H}(3)$ for intervals on ℝ.
      Solution
      Runs of consecutive 1s among 3 sorted points, plus empty: $\binom42 + 1 = 7$ (of 8 — only (1,0,1) missing).
    2. MED Why does the symmetrization trick let a bound about infinitely many hypotheses use $\Pi_{\mathcal H}(2n)$ — where does the "2n" come from?
      Solution
      The deviation $R(h) - \hat R_S(h)$ is compared instead to the gap between the real sample and an independent "ghost" sample $S'$ of the same size: if the sup deviation is large vs the truth, it is (with prob ≥ ½) large between the two samples too. But on the combined $2n$ points, only $\Pi_{\mathcal H}(2n)$ behaviors exist — the infinite class collapses to finitely many equivalence classes, and a union bound over those finishes it. Truth (an expectation) never appears again: only data.
    3. HARD Show that if $\Pi_{\mathcal H}(m)$ is polynomial, the generalization gap → 0 as $n\to\infty$, but if $\Pi_{\mathcal H}(m) = 2^m$ for all $m$, the VC bound is vacuous at every $n$.
      Solution
      Polynomial $\Pi(2n) \le (2n)^d$: bound $\sim\sqrt{\frac{8(d\ln 2n + \ln(4/\delta))}{n}} = O(\sqrt{d\ln n / n}) \to 0$. Full shattering: $\ln\Pi(2n) = 2n\ln 2$, bound $\sim\sqrt{16\ln 2 + \cdots} > 1$ — exceeding the maximum possible gap for 0-1 loss: no information. The dichotomy (Sauer, next) says these are the ONLY two regimes: learnability is an all-or-nothing phase distinction.

    Sauer's lemma

    Sauer's lemma is the hinge of the whole theory: once shattering stops — at VC dimension $d$ — the growth function doesn't merely dip below $2^m$; it crashes to a degree-$d$ polynomial. There is no middle ground between "exponentially rich forever" and "polynomially tame": one integer forces the collapse.

    Theorem (Sauer–Shelah) If $\mathrm{VC}(\mathcal H) = d$, then $$\Pi_{\mathcal H}(m) \le \sum_{i=0}^{d}\binom{m}{i} \le \Big(\frac{em}{d}\Big)^{d} \text{ for } m \ge d.$$ Proof idea (induction on $m + d$): fix a point $x$; split the realized behavior set into behaviors on the remaining points, counting twice those that appear with BOTH labels of $x$ — that doubled subclass shatters-with-$x$, so it has VC ≤ $d - 1$ on the rest; apply induction to both parts and Pascal's identity $\binom{m}{i} = \binom{m-1}{i} + \binom{m-1}{i-1}$.
    Worked example Halfspaces in the plane (VC = 3), $m = 100$ points: Sauer: $\Pi(100) \le \binom{100}{0}+\binom{100}{1}+\binom{100}{2}+\binom{100}{3} = 1 + 100 + 4950 + 161700 = 166{,}751$ — versus $2^{100} \approx 1.3\times10^{30}$: a $10^{24}$-fold collapse. The class LOOKS like it has $\sim1.7\times10^5$ members on any 100 points; that effective count is what the bound pays for.

This is the precise cash value of "capacity": each unit of VC dimension costs $\sim1/\varepsilon^2$ samples.

    Generalization bounds

    A generalization bound is a certificate: with probability $1-\delta$ over the sample, the true risk of your (data-chosen) hypothesis is at most its empirical risk plus an explicit complexity penalty. The genre has one grammar — risk ≤ fit + capacity/√n — realized by many capacity measures, each with its regime of usefulness.

    Definition Template: w.p. $\ge 1-\delta$, for all $h\in\mathcal H$: $R(h) \le \hat R_S(h) + \mathrm{cap}(\mathcal H, n, \delta)$. Instances: finite class: $\mathrm{cap} = \sqrt{\frac{\ln|\mathcal H| + \ln(1/\delta)}{2n}}$; VC: $\sqrt{\frac{8(d\ln\frac{2en}{d} + \ln\frac4\delta)}{n}}$; Rademacher: $2\mathfrak R_n(\mathcal H) + \sqrt{\frac{\ln(1/\delta)}{2n}}$; margin bounds for classifiers with real scores: risk ≤ margin-violations + $\tilde O\!\big(\frac{\text{norm capacity}}{\gamma\sqrt n}\big)$ — capacity measured by weight norms, not counts, explaining why SVMs and (partially) deep nets generalize despite huge parameter spaces.
    Worked example A depth-limited decision tree class with $|\mathcal H| \approx 10^{12}$ effective trees, trained to $\hat R = 0.08$ on $n = 50{,}000$, δ = 0.01: gap $\le \sqrt{\frac{\ln(10^{12}) + \ln 100}{2\times50000}} = \sqrt{\frac{27.6 + 4.6}{100000}} = \sqrt{3.22\times10^{-4}} \approx 0.018$. Certificate: true error ≤ 9.8%, no test set involved. This is the (rare) regime where bounds are non-vacuous: moderate capacity, big n.
    Pitfall For modern deep networks the classical certificates compute to risk ≤ 0.08 + 4000 — true but useless (vacuous). This is not a paradox: the bounds hold; they are just loose, because the trained network is not a worst-case member of its astronomically rich class. Non-vacuous deep bounds exist (PAC-Bayes with compression) but remain far from explaining practice. Bounds are best read as EXPLANATIONS of what drives generalization (capacity per sample, margins, stability, description length), not as numbers to ship.

    Rademacher complexity

    Rademacher complexity measures capacity by a wonderfully direct test: hand the class random coin-flip labels and ask how well it can correlate with them. A class that can chase pure noise on your sample is a class whose good training scores mean little. Unlike VC dimension it is distribution-dependent — it measures richness where your data actually lives — and it yields the tightest general-purpose bounds.

    Definition With i.i.d. Rademacher signs $\sigma_i \in \{\pm1\}$ (fair coins), the empirical Rademacher complexity on sample $S = (x_1..x_n)$ is $$\hat{\mathfrak R}_S(\mathcal H) = \mathbb E_\sigma\Big[\sup_{h\in\mathcal H}\frac1n\sum_{i=1}^n \sigma_i\,h(x_i)\Big],$$ and $\mathfrak R_n = \mathbb E_S[\hat{\mathfrak R}_S]$. Bound: w.p. $\ge 1-\delta$, for all $h$: $R(h) \le \hat R_S(h) + 2\mathfrak R_n(\ell\circ\mathcal H) + \sqrt{\frac{\ln(1/\delta)}{2n}}$. Toolkit: $\mathfrak R_n \le \sqrt{\frac{2\ln\Pi_{\mathcal H}(n)}{n}}$ (Massart, recovering VC bounds); linear class $\{x\mapsto w^\top x: \|w\|_2\le B\}$ on $\|x\|\le X$: $\hat{\mathfrak R}_S \le \frac{BX}{\sqrt n}$; contraction: an $L$-Lipschitz loss multiplies it by at most $L$.
    Worked example Two extreme classes on $n$ points. (a) A single fixed classifier: $\mathbb E_\sigma[\frac1n\sum\sigma_ih(x_i)] = 0$ — no sup, no noise-chasing, complexity 0 (plus $O(1/\sqrt n)$ if you take absolute values). (b) All functions: choose $h(x_i) = \sigma_i$: correlation 1 always — $\hat{\mathfrak R} = 1$… with $\{0,1\}$-valued $h$ and signs, sup is $\frac{\#\{+1\}}{n} \approx \frac12$ — maximal: the bound's gap term is order 1, vacuous. Real classes live between; e.g. bounded-norm linear with $B = X = 1$, $n = 10^4$: $\mathfrak R \le 0.01$ — a 2-point certificate.
    Think first Why is "ability to fit random labels" the right measure? Connect to the famous experiment where deep nets fit randomly-labeled ImageNet perfectly.
    Reveal
    The generalization gap is literally the class's ability to make sample averages differ from expectations; symmetrization shows this equals its ability to correlate with random signs. Zhang et al. (2017) showed standard deep nets reach zero training error on RANDOMIZED labels: their empirical Rademacher complexity on those samples is ~maximal, so any bound of this uniform type is vacuous for the full class — the modern generalization puzzle in one experiment. Resolution attempts: the ALGORITHM (SGD + implicit bias) explores only a low-complexity subset — see stability, PAC-Bayes, benign overfitting below.

      Solution
      $\sup$ over the two constants of $\pm\frac1n\sum\sigma_i = \frac{|\sum\sigma_i|}{n}$; $\mathbb E|\sum\sigma_i| \approx \sqrt{2n/\pi}$: $\hat{\mathfrak R} \approx \sqrt{\frac{2}{\pi n}}$ — the $1/\sqrt n$ floor that even trivial classes pay.

      Solution

      Solution
      Monotonicity: sup over a superset is ≥. Moral: ensembles/averaging add NO statistical capacity — voting many models is free in generalization terms (why bagging and boosting's margins story work), even though the ensemble has more parameters than any member.

    Structural risk minimization

    ERM needs the class fixed in advance — but choosing the class IS the hard decision. Structural risk minimization nests classes of growing capacity, $\mathcal H_1 \subset \mathcal H_2 \subset \cdots$, and picks the depth whose fit-plus-certificate is smallest: minimize the BOUND, not the training error. It is model selection with theory in the loop, and the ancestor of every "penalized fit" criterion.

    Definition Given a nested structure and per-class bounds, SRM selects $$\hat h = \arg\min_{k,\ h\in\mathcal H_k}\ \hat R_S(h) + \mathrm{cap}(\mathcal H_k, n, \delta_k),$$ with confidence split $\delta_k$ (e.g. $\delta_k = \delta 2^{-k}$, a union bound over levels). Guarantee: SRM's risk is within the best trade-off available in the structure, up to constants — it adapts to unknown problem complexity. Instances of the pattern: cost-complexity tree pruning, AIC/BIC, MDL's two-part codes (Ch 16), and — loosely — choosing architecture size by validation.
    Worked example Polynomial degrees as the structure; $n = 200$, per-level capacity charge (illustrative) $\sqrt{\frac{(k+1)\ln n + \ln(2^k/\delta)}{n}\cdot 8}\ldots$ use simplified $\mathrm{cap}_k = \sqrt{\frac{5(k+1) + 0.7k}{200}}$. Fits: deg 1: $\hat R = 0.30$, cap 0.17 → 0.47; deg 3: $\hat R = 0.12$, cap 0.23 → 0.35; deg 6: $\hat R = 0.10$, cap 0.29 → 0.39; deg 9: $\hat R = 0.02$, cap 0.34 → 0.36. SRM picks degree 3: it declines both the underfit line AND the interpolating degree-9 — the certificate arithmetic re-derives the validation-curve U shape without a validation set.
    Where this goes Ch 16's MDL is SRM with code lengths as capacity; regularization (next) is SRM's smooth twin — a continuous dial instead of discrete nesting.
    Drill
    1. EASY Why must $\delta$ be split across levels of the structure?
      Solution
      SRM examines infinitely many classes; the certificates must hold simultaneously. Allocating $\delta_k = \delta2^{-k}$ keeps the total failure probability $\le \sum\delta_k = \delta$ while charging deeper (less-preferred) classes a slightly larger $\ln(1/\delta_k) = \ln(1/\delta) + k\ln2$ — a built-in prior favoring simplicity.
    2. MED Contrast SRM with validation-based selection: one advantage and one disadvantage each.

      Solution
      SRM's objective at the true level: $\hat R(h^*) + \mathrm{cap}_{k^*} \to R(h^*) + 0$ since $\mathrm{cap}_k(n) \to 0$ for each FIXED k. SRM's chosen value is ≤ this, and by the per-level certificates its true risk is ≤ chosen value + (its level's cap, already included). Hence $\limsup R(\hat h) \le R(h^*)$: the penalty schedule vanishes level-wise while the union bound holds uniformly, so SRM automatically pays only the complexity of the level it needed — adaptivity. The price versus knowing $k^*$: the $k\ln2$ confidence surcharges and slower effective rates at small n.

    Regularization theory

    Regularization is SRM gone smooth: instead of a ladder of classes, one continuous penalty $\lambda\Omega(h)$ carving level sets of complexity through a big class. The theory says why this works: the penalty bounds the effective capacity of the sublevel set the optimizer can reach, so bounds apply with $\Omega(\hat h)$ in place of class size — you pay for the complexity you USE.

    Definition Penalized ERM: $\hat h_\lambda = \arg\min_{h}\ \hat R_S(h) + \lambda\Omega(h)$. Equivalences: (Lagrangian duality, Ch 15) for convex problems, penalization with $\lambda$ ⟺ constrained ERM over $\{\Omega(h)\le c(\lambda)\}$ — a class whose capacity (e.g. Rademacher $\le \frac{cX}{\sqrt n}$ for $\Omega = \|w\|_2$… with $c$ the norm budget) enters bounds directly. Three faces of one object: penalty = constraint (SRM level) = prior (MAP, Ch 19). Ill-posedness view (Tikhonov): inverse problems with unstable inverses are stabilized by the penalty; λ trades data fidelity for stability of the solution map.
    Worked example Ridge on $n = 100$, features scaled to $\|x\|\le1$. Choosing λ to keep $\|\hat w\|_2 \le 5$: margin-free linear-class bound gives gap $\lesssim \frac{2\cdot5\cdot1}{\sqrt{100}} + \sqrt{\frac{\ln(1/\delta)}{2n}} \approx 1.0 + 0.12$ — vacuous. Same setup, $n = 10^4$: $0.10 + 0.012$ — meaningful. The bound's message survives its looseness: capacity-per-sample $\frac{B X}{\sqrt n}$ is the controlling ratio, and λ is how you set $B$ without knowing it in advance.
    Pitfall Regularization theory's guarantees are for the PENALIZED optimum. Deep learning's twist: even with $\lambda = 0$, gradient methods impose implicit regularization — e.g. gradient descent on separable logistic regression converges in direction to the max-margin (min-norm) separator, and on least squares to the min-norm interpolant. The algorithm is part of the regularizer; theory that ignores the optimizer misses where modern capacity control actually comes from.

    Algorithmic stability

    Stability attacks generalization from the algorithm's side, ignoring the class entirely: if swapping ONE training example barely changes the learned predictor, the algorithm cannot have memorized that example — and a leave-one-out argument converts "insensitive to each point" directly into "training error ≈ true error." No sups, no shattering; capacity of the search, not of the class.

    Definition Algorithm $A$ has uniform stability $\beta$ if for all samples $S$, all replacements $S^{(i)}$ (swap example $i$), and all $z = (x,y)$: $|\ell(A(S), z) - \ell(A(S^{(i)}), z)| \le \beta$. Theorem (Bousquet–Elisseeff): then $\mathbb E[R(A(S)) - \hat R_S(A(S))] \le \beta$, and w.h.p. $R \le \hat R + \beta + (n\beta + 1)\sqrt{\frac{\ln(1/\delta)}{2n}}$-type bounds. Flagship: λ-strongly-convex regularized ERM with $L$-Lipschitz loss has $\beta \le \frac{2L^2}{\lambda n}$ — gap $O(\frac{1}{\lambda n})$. SGD: with step sizes $\eta_t$, few epochs, and smooth losses, stability $\beta = O(\frac{\sum\eta_t}{n})$-ish (Hardt–Recht–Singer): train fast, generalize.
    Worked example Ridge-regularized logistic regression ($L = 1$ after feature scaling), $\lambda = 0.01$, $n = 10^5$: $\beta \le \frac{2}{0.01\times10^5} = 2\times10^{-3}$ — expected gap ≤ 0.2%, from three numbers, with no reference to dimension (could be $10^9$ features) or VC anything. The certificate is about the PROCEDURE: strong convexity means one example can only tug the optimum $O(1/\lambda n)$ far.
    Think first 1-nearest-neighbor: stable or not? What about its true generalization?
    Reveal
    Not uniformly stable: swapping one training point flips predictions in its whole Voronoi cell, and a test point there changes loss by 1 — β = 1, the bound is vacuous. Yet 1-NN generalizes fine asymptotically (Cover–Hart, Ch 19). Lesson: uniform stability is sufficient, never necessary; average-case stability notions (hypothesis stability) partially rescue k-NN. Each proof technique is a lens, not the phenomenon.

      Solution
      $\mathbb E[R(A(S))] = \mathbb E_{S, z}[\ell(A(S), z)]$ with fresh $z$; by exchangeability this equals $\mathbb E_{S^{(i)}}[\ell(A(S^{(i)}), z_i)]$ — train with $z_i$ replaced, test on $z_i$.       Solution
      DP is a distributional stability: ε-DP means one example shifts output probabilities by factor $e^\varepsilon$ — so any downstream statistic (including "did the model fit $z_i$ well?") is nearly independent of $z_i$'s presence: expected gap $= O(\varepsilon)$ by the same swap argument, uniformly over post-processing. Because DP composes across queries, it controls even ADAPTIVE analysis (choosing the next question from previous answers) — the leaderboard-overfitting problem of Ch 19 — where classical bounds break. Stability is the common root of privacy, generalization, and reproducibility.

    PAC-Bayes bounds

    PAC-Bayes bounds are the Bayesian's generalization certificates: fix a prior over hypotheses before seeing data; learn any posterior distribution after; then the (Gibbs) risk of sampling from the posterior exceeds its empirical risk by at most a KL-divergence tax — how far you moved from the prior, per sample. Description length returns as the universal currency of capacity, now with real-valued weights.

    Theorem (McAllester-style) Fix prior $P$ over $\mathcal H$ (before data). W.p. $\ge 1-\delta$ over $S$, for ALL posteriors $Q$: $$\mathbb E_{h\sim Q}[R(h)] \le \mathbb E_{h\sim Q}[\hat R_S(h)] + \sqrt{\frac{\mathrm{KL}(Q\| P) + \ln\frac{2\sqrt n}{\delta}}{2n}}.$$ Finite-class recovery: $P$ uniform, $Q$ a point mass: KL $= \ln|\mathcal H|$ — the finite-class bound is the special case. The bound holds simultaneously for every $Q$: you may CHOOSE the posterior by minimizing the bound itself.
    Worked example Prior: Gaussian $\mathcal N(0, \sigma^2I)$ over weights; posterior: $\mathcal N(\hat w, \sigma^2I)$ around trained weights: $\mathrm{KL} = \frac{\|\hat w\|^2}{2\sigma^2}$ — the L2 regularizer appears as the exact price of information moved from prior to posterior. Numbers: $\|\hat w\|^2/2\sigma^2 = 250$, $n = 10^5$, δ = 0.01: gap $\le \sqrt{\frac{250 + \ln(2\times316/0.01)}{2\times10^5}} = \sqrt{\frac{250 + 11.06}{200000}} \approx 0.036$. Noise-robust nets (flat minima: adding weight noise doesn't hurt $\hat R$) admit broad low-KL posteriors — this route produced the first NON-VACUOUS bounds for real ImageNet-scale-ish networks (Dziugaite–Roy), and links flatness to generalization.
    Pitfall The prior must be chosen data-independently — tuning $\sigma$ after seeing results silently invalidates the certificate (fix: union-bound over a prior grid, paying $\ln K$). And the guarantee is for the STOCHASTIC (Gibbs) classifier averaged over Q; derandomizing to a single $\hat w$ costs extra (margin or majority-vote arguments).

      Solution
      KL $= \ln 2^{20} = 20\ln2 \approx 13.9$ nats — exactly the 20 bits needed to NAME the chosen hypothesis: the bound charges description length.
    2. MED Why does a BROAD posterior (high entropy around good hypotheses) beat a point mass in the bound, and what property of the loss landscape does that reward?
      Solution
      KL(Q‖P) shrinks as Q spreads toward P (less information transmitted), while $\mathbb E_Q[\hat R]$ stays small only if a whole REGION fits well — i.e., a flat minimum. The bound thus quantitatively prefers flat minima over sharp ones of equal training loss: sharpness-generalization, certified. (Compare Ch 15's SAM.)
    3. HARD Derive the finite-class Occam bound from PAC-Bayes with a NON-uniform prior $P(h) = 2^{-|c(h)|}$ over hypotheses with binary descriptions $c(h)$ (prefix-free).
      Solution
      Point-mass Q on $\hat h$: KL $= \ln\frac{1}{P(\hat h)} = |c(\hat h)|\ln2$. MDL, Bayes, and PAC all cash out in the same bits.

    Double descent

    The classical U-curve says test error worsens once capacity exceeds "enough." Modern practice found the plot twist: keep growing capacity PAST the point of interpolating the data, and test error comes back DOWN — often below the classical sweet spot. The peak sits exactly at the interpolation threshold, where the model has just barely enough parameters to fit everything and must contort to do it.

    Definition Model-wise double descent: test risk vs capacity rises to a peak near #parameters ≈ #samples (interpolation threshold), then descends again in the overparameterized regime. Mechanism (linear/random-feature models, provable): at the threshold, the design matrix is square-ish and nearly singular — the min-norm interpolant needs huge weights along tiny singular directions (variance explosion, Ch 18's conditioning!); with many more parameters than samples, many interpolants exist and the MIN-NORM one is small and smooth. Also epoch-wise and sample-wise variants (more data can briefly HURT near the threshold).
    Worked example Least squares with random features, $n = 40$ samples: at $p = 10$ features, bias-limited (classical underfit → good); at $p = 40$: the $40\times40$ system is near-singular — test error spikes 10–100×; at $p = 400$: min-norm solution spreads the fit over many directions with small coefficients — test error drops below the $p = 10$ value. Ridge with well-chosen λ flattens the peak entirely: the divergence is a variance phenomenon of the UNREGULARIZED interpolant, and even tiny λ caps $\frac{\sigma_i}{\sigma_i^2 + \lambda}$.

    Sweep model capacity through the interpolation threshold on a random-features regression and watch the test-error peak form and then descend; add ridge to tame it.

    Pitfall Double descent does not repeal bias-variance — it reveals that "capacity" on the x-axis was the wrong coordinate. Plotted against the right complexity measure (norm of the fitted function, effective degrees of freedom), the U-curve returns. The classical theory was incomplete, not wrong: it lacked the physics of WHICH interpolant the algorithm selects.

      Solution
      At the interpolation threshold $p \approx n$: the feature matrix is square and typically ill-conditioned ($\sigma_{\min}\to0$), so the unique interpolant has exploding norm — pure variance.
    2. MED Why does the OVERparameterized regime escape the explosion — what does the min-norm interpolant do with its extra dimensions?
      Solution
      With $p \gg n$, interpolants form an affine subspace of dimension $p - n$; gradient descent from zero (equivalently the pseudoinverse) selects the minimum-norm one, which distributes the required fit across many well-conditioned directions — small coefficients, smooth function. More parameters = more room to interpolate GENTLY. The algorithm's implicit bias (min norm) is the hidden regularizer.
    3. HARD For min-norm least squares with isotropic random features, the variance term scales like $\frac{\sigma^2 p}{n(p - n)}$-ish for $p > n$ (and $\frac{\sigma^2 p}{n - p}$-ish… rather $\frac{\sigma^2 p}{n(n-p)}$ below).       Solution
      As $p \to n^{\pm}$: denominators $(p - n)$ or $(n - p)$ → 0: variance → ∞ — the peak. As $p\to\infty$: $\frac{p}{n(p-n)} \to \frac1n$: variance falls back to the well-behaved $O(\sigma^2/n)$ — descent, though bias (from the null-space's unfitted truth components) sets the floor. Ridge replaces small singular values $\sigma_i$ in $\frac{\sigma_i}{\sigma_i^2}$ by $\frac{\sigma_i}{\sigma_i^2 + \lambda} \le \frac1{2\sqrt\lambda}$: the peak is clipped at height $O(1/\lambda)$ — regularization removes double descent, confirming its variance origin.

    At p ≈ n the interpolant is unique and must use enormous weights along near-null directions: variance explodes (conditioning!). Ridge or more data past the threshold fixes it. (Clean labels shrink but don't always remove the peak — model misspecification acts like noise.)

    Benign overfitting

    Interpolating noisy data — training error zero, noise memorized — should be fatal by classical lights. Benign overfitting is the proven phenomenon where it isn't: in high dimensions, an interpolating predictor can hide the memorized noise in directions that barely matter for prediction, while the signal-carrying directions stay clean. The model overfits and generalizes, because the overfitting is quarantined.

    Definition A predictor benignly overfits if $\hat R_S = 0$ (interpolation, noise included) yet $R \to$ near-optimal. For min-norm linear interpolation (Bartlett et al. 2020), benignity is characterized by the covariance spectrum $\lambda_1 \ge \lambda_2 \ge\cdots$: it requires (roughly) a few strong directions carrying the signal PLUS a long, flat tail of many weak directions whose total energy is spread so thin that noise absorbed there adds vanishing prediction error — quantified via effective ranks ($r_k = \frac{\sum_{i>k}\lambda_i}{\lambda_{k+1}}$ large). Neither too few tail dimensions (nowhere to hide noise) nor a too-concentrated tail (noise lands on meaningful directions).
    Worked example Caricature: signal lives on feature 1 ($\lambda_1 = 1$); noise-absorbing tail: $10^6$ features each with $\lambda_i = 10^{-6}$. The min-norm interpolant fits the signal along feature 1 and spreads each training point's noise across the million weak features — each getting a coefficient $\sim10^{-3}$-scale whose PREDICTION contribution is $\sim\lambda_i\times$coef², summing to $O(n/10^6)$… tiny. A fresh point's weak features are near-orthogonal to the training set's: the memorized noise never gets read back out. Same spectrum with a 10-feature tail: the noise has nowhere to hide and corrupts predictions — malignant.
    Think first 1-NN interpolates noisy labels too (each training point predicts its own noisy label in its cell). Is IT benign?
    Reveal
    Partly: 1-NN's asymptotic risk is $\le 2R^*$ — bounded inflation, not consistency: the memorized noise IS read back near each training point, but each cell shrinks as $n$ grows, so the damage is local and bounded. Interpolating kernel smoothers with spiky kernels (Nadaraya–Watson with tiny bandwidth at the data points) can be fully consistent: spikes memorize noise on a measure-zero set while the smooth part predicts. The unifying picture: benignity = memorization confined to components with vanishing test-time influence.

    1. EASY Why does classical uniform convergence FAIL to explain benign overfitting, definitionally?
      Solution

The explanation must be algorithm-specific (which interpolant), not class-uniform.
    2. MED In the spectrum characterization, what goes wrong if the tail is (a) too short, (b) too spiky (one moderately large tail eigenvalue)?
      Solution
      (a) Few tail dimensions: noise must load onto the few available directions with non-negligible coefficients — variance shows up in predictions: malignant. (b) A spiky tail direction has real predictive weight ($\lambda$ not tiny): noise absorbed there is read back at test time — again harmful. Benignity needs MANY, UNIFORMLY tiny directions: an approximate isotropy of the junk.
    3. HARD Connect benign overfitting to double descent and to deep networks: what shared mechanism, and what remains conjectural?
      Solution
      Shared: in overparameterized regimes the training procedure (min-norm/max-margin implicit bias of GD) selects interpolants that place the unavoidable fit-to-noise into high-dimensional, low-energy components; double descent's second descent IS entry into the benign regime. For deep nets: empirically consistent (nets fit label noise yet generalize; noise seems stored in rarely-activated directions/neurons), and NTK-linearized analyses inherit the linear theory; but a full proof for genuinely feature-learning networks — where the "spectrum" itself is learned — remains open. The frontier question of Ch 21's theory topics.

    No-free-lunch theorem

    Averaged over ALL possible worlds, every learning algorithm is exactly as good as random guessing: for any learner, the problems where it beats chance are precisely balanced by problems where it loses. Learning works only because our world is not an average world — data has structure, and an algorithm's inductive bias is a bet on which structure. There is no universal learner; there are only well-placed bets.

    Theorem (no free lunch, learning version) Let $\mathcal X$ be finite, and average over all target functions $f: \mathcal X \to \{0,1\}$ (uniformly). For ANY learner $A$ and any training set of $n$ points, the expected 0-1 risk of $A$'s hypothesis on unseen points is exactly $\frac12$. Equivalently (Shalev-Shwartz–Ben-David form): for any learner and any $n \le |\mathcal X|/2$, there EXISTS a distribution on which some hypothesis achieves risk 0, yet the learner's expected risk is $\ge \frac14$. Corollary: distribution-free learning of the class of ALL functions is impossible; VC(all functions) = ∞ is the same fact in capacity language.
    Worked example $\mathcal X = \{1,..,6\}$, you observe $f$ on $\{1,2,3\}$. The uniform average over all $2^6$ targets: the $2^3$ completions of the unseen half are equally likely regardless of what you saw — any prediction rule for points 4–6 is right on exactly half the completions. Your learner's cleverness on the observed half buys literally nothing about the unobserved half — UNLESS you shrink the world: assume $f$ is (say) monotone, and observations start constraining the rest. The assumption, not the algorithm, is what learns.
    Pitfall NFL does not say "all algorithms perform equally in practice" — practice is one world, not the uniform average, and real data (natural images, language, physics) is spectacularly non-uniform: compressible, smooth, compositional. NFL says you cannot justify an algorithm WITHOUT naming the structure it exploits. "It works on benchmarks" is an empirical claim about our world's structure; NFL just forbids pretending it's a theorem-for-free.
    Where this goes Inductive bias becomes architecture in Ch 21 (convolutions bet on locality/translation; transformers on relational structure); Ch 36's universal-intelligence discussions (AIXI's Occam prior over computable worlds) are the attempt to make the mildest possible bet — simplicity — and NFL is why even that is a bet.
    Drill
    1. EASY Reconcile: NFL says no learner beats chance on average, yet gradient boosting reliably wins tabular benchmarks.
      Solution
      The average is over ALL functions, almost all of which are incompressible noise never seen in practice. Benchmarks are drawn from OUR world's structured distribution, where boosting's biases (axis-aligned interactions, smoothness in stages) are good bets. NFL constrains claims, not practice.
    2. MED Prove the toy NFL: averaging uniformly over all targets $f$, any deterministic prediction at an unseen point errs with probability exactly ½.
      Solution
      Condition on everything observed: under the uniform prior over targets, $f$(unseen point) is an independent fair coin (the $2^{|\text{unseen}|}$ completions are equiprobable, half with each value at that point). Any prediction — however computed from the observations — matches a fair coin with probability ½. Summing over unseen points: expected off-sample error ½. ∎
    3. HARD "Cross-validation escapes NFL by CHOOSING among algorithms empirically." Does it?
      Solution
      No — meta-algorithms are algorithms: CV-selection is itself a learner, and NFL applies to it too (on the uniform average over worlds, CV's picks do no better than anti-CV's, since validation folds are as unpredictive of unseen points as training folds — the coin argument applies to every measurement of the sample). CV works in practice because worlds where sample performance predicts out-of-sample performance — i.e., i.i.d.-ish structured worlds — are the worlds we inhabit. Even "trust validation" is an inductive bias: a bet on stationarity. There is no view from nowhere; there are only good bets, and this chapter's bounds are the mathematics of when the standard bets pay.

    Problems
    1. MED Certify a model zoo. You will pick, by validation score, one of 200 models; the validation set has $n = 8000$ examples; δ = 0.05, 0-1 loss. (a) Give the uniform-convergence guarantee for the selection. (b) The winner scores 7.5% validation error: state the risk certificate. (c) A colleague proposes instead evaluating 2 million prompt-tuned variants; how does the certificate change, and what's the qualitative lesson? (d) Why does the TRAINING set of the winning model play no role in this particular certificate?
      Solution
      (a) Finite-class bound over the 200 models on validation data: gap $\le \sqrt{\frac{\ln(2\times200) + \ln(1/0.05)}{2\times8000}} = \sqrt{\frac{5.99 + 3.00}{16000}} = \sqrt{5.62\times10^{-4}} \approx 0.0237$. (b) $R \le 0.075 + 0.024 = 9.9\%$ w.p. ≥ 0.95. (c) $\ln(4\times10^6) \approx 15.2$: gap $\le \sqrt{\frac{15.2 + 3.0}{16000}} \approx 0.0337$ — 2 million candidates cost only ~1 extra point: selection pressure grows logarithmically, so honest evaluation scales to enormous searches — provided the candidates were fixed before touching the validation set (adaptive rounds compound and need fresh data or reusable-holdout/DP techniques). (d) The certificate treats each candidate as a FIXED hypothesis w.r.t. the validation sample: however wildly each was trained (on separate training data), validation scores are unbiased estimates of their risks. Training complexity is somebody else's problem; the validation set only pays for the CHOICE among 200.
    2. HARD VC end to end. Consider axis-aligned rectangles in the plane as a concept class (realizable setting: the truth is a rectangle; points inside are positive). (a) State its VC dimension (with one-line justifications both directions, citing the earlier drill). (b) Give the PAC sample complexity for ε = 0.05, δ = 0.05 using $n = O\!\big(\frac{d\ln(1/\varepsilon) + \ln(1/\delta)}{\varepsilon}\big)$ with constant 4 for concreteness: $n = \frac{4}{\varepsilon}\big(d\ln\frac{12}{\varepsilon} + \ln\frac{2}{\delta}\big)$. (c) Exhibit the classical CLOSURE algorithm (tightest rectangle around the positives) and prove its one-sided error property. (d) Give the direct argument (no VC machinery) that the closure algorithm needs only $n \ge \frac{4}{\varepsilon}\ln\frac{4}{\delta}$ samples, and compare.
      Solution
      (a) VC = 4: the diamond N/S/E/W set is shattered; any 5th point is trapped in the bounding box of the four extremes (drill above). (b) $n = \frac{4}{0.05}(4\ln240 + \ln40) = 80(4\times5.48 + 3.69) = 80\times25.6 \approx 2048$. (c) Closure: output the minimal rectangle containing all positive samples. It never mislabels a negative as positive incorrectly… precisely: the output rectangle ⊆ true rectangle (every positive sample is in the true one, and the minimal box around them is contained in any rectangle containing them). Hence all its errors are FALSE NEGATIVES on the four "margin strips" of the true rectangle not yet witnessed by a positive sample. (d) Carve the true rectangle's probability mass into 4 strips (one per side), each of mass ε/4, hugging each edge inward. If the sample contains a positive point in every strip, the closure box misses at most the union of partial strips: error < ε … more carefully each strip's uncovered part has mass ≤ ε/4, total ≤ ε. A given strip receives no sample point with probability $(1 - \varepsilon/4)^n \le e^{-n\varepsilon/4}$; union over 4 strips: failure ≤ $4e^{-n\varepsilon/4} \le \delta$ gives $n \ge \frac4\varepsilon\ln\frac4\delta = 80\times4.38 \approx 351$. The tailored argument beats the generic VC recipe by ~6× — general theorems are safety nets, not sharp tools; but only the VC framework tells you EVERY consistent algorithm works and the class itself is learnable.
    3. HARD Three certificates for one predictor. A logistic-regression-style model with L2 regularization λ = 0.02, 1-Lipschitz loss in [0,1], is trained on n = 50,000 samples to empirical (surrogate) risk 0.21; features satisfy ‖x‖ ≤ 1 and the trained weights ‖ŵ‖ = 3; δ = 0.01. Certify the true (surrogate) risk three independent ways: (a) Rademacher/norm bound with $\hat{\mathfrak R} \le \frac{\|\hat w\|X}{\sqrt n}$ (use the norm bound + contraction, plus the $\sqrt{\ln(1/\delta)/2n}$ term). (b) Uniform stability of strongly-convex regularized ERM, expected-gap version β = 2L²/(λn) (report the expected-risk certificate). (c) PAC-Bayes with Gaussian prior/posterior, σ chosen so KL = ‖ŵ‖²/(2σ²) with σ = 1 (use the McAllester form). Compare tightness and assumptions.
      Solution
      (a) Gap $\le 2\cdot\frac{3\times1}{\sqrt{50000}} + \sqrt{\frac{\ln(1/0.01)}{2\times50000}} = 2\times0.0134 + \sqrt{4.61\times10^{-5}} = 0.0268 + 0.0068 = 0.034$: $R \le 0.244$. (Contraction with L = 1 leaves the factor as is.) (b) β = $\frac{2\times1}{0.02\times50000} = 0.002$: EXPECTED gap ≤ 0.002 — $\mathbb E[R] \le 0.212$: strikingly tight, but it certifies the expectation over samples, not this run (high-probability versions add $\tilde O(\sqrt{1/n})$ terms ≈ 0.01–0.02 with modern bounds). (c) KL $= \frac{9}{2} = 4.5$; gap $\le \sqrt{\frac{4.5 + \ln(2\sqrt{50000}/0.01)}{2\times50000}} = \sqrt{\frac{4.5 + \ln(44721)}{100000}} = \sqrt{\frac{4.5 + 10.71}{100000}} = \sqrt{1.52\times10^{-4}} = 0.0123$: Gibbs risk $\le \mathbb E_Q\hat R + 0.012$ — tightest, but certifies the noise-perturbed classifier and needs $\mathbb E_Q[\hat R]$ evaluated under weight noise (if the minimum is flat, ≈ 0.21; a sharp minimum inflates it). Comparison: stability leverages the strongest assumption (strong convexity of the training OBJECTIVE) and wins on expectation; PAC-Bayes converts flatness into tightness and handles non-convexity; the norm/Rademacher bound assumes least (just norms) and pays for it. Same predictor, three lenses — capacity of the class, of the algorithm, of the description: the chapter in one problem.

    Three experiments: watch uniform convergence beat lucky classifiers, measure a VC dimension empirically, and produce your own double-descent curve.

    Task 1 — The lucky-coin leaderboard. Simulate K useless binary classifiers (true error 0.5) evaluated on n samples; show the best-looking one's apparent skill matches the theory $\approx \sqrt{\ln K/(2n)}$, and that a fresh test set exposes it.

    Reference solution
    import numpy as np
rng = np.random.default_rng(0)

def best_apparent_skill(K, n, trials=200):
    # each classifier's correctness on each sample: fair coin
    skills = []
    for _ in range(trials):
        acc = rng.binomial(n, 0.5, size=K) / n
        skills.append(acc.max() - 0.5)
    return np.mean(skills)

for K in (10, 1000, 100000):
    for n in (100, 1000):
        emp = best_apparent_skill(K, n)
        theory = np.sqrt(np.log(K) / (2 * n))
        print(f"K={K:6d} n={n:5d}: best apparent skill {emp:.3f}  ~ sqrt(lnK/2n) {theory:.3f}")

# fresh-set exposure: the 'winner' scores ~0.5 on new data
K, n = 100000, 100
scores = rng.binomial(n, 0.5, size=K) / n
w = scores.argmax()
fresh = rng.binomial(1000, 0.5) / 1000
print(f"winner looked {scores[w]:.2f} on n=100; scores {fresh:.3f} on fresh n=1000")

    Task 2 — Empirical shattering. For 1-D interval classifiers, test shattering computationally: for m = 2, 3, 4 random point sets, enumerate all labelings and check realizability; confirm VC = 2. Repeat for 2-D halfplanes on m = 3, 4 points (VC = 3).

    Reference solution
    import numpy as np
from itertools import product, combinations
rng = np.random.default_rng(1)

def interval_realizes(xs, labels):
    pos = [x for x, l in zip(xs, labels) if l]
    if not pos: return True
    a, b = min(pos), max(pos)
    return all(l == (a <= x <= b) for x, l in zip(xs, labels))

def shatters_intervals(xs):
    return all(interval_realizes(xs, lab) for lab in product([0, 1], repeat=len(xs)))

for m in (2, 3):
    xs = sorted(rng.uniform(0, 1, m))
    print(f"intervals shatter some {m} points: {shatters_intervals(xs)}")
# m=2: True; m=3: False (labeling 1,0,1 fails)  => VC = 2

def halfplane_realizes(P, labels):
    # exists w,b with sign(Pw+b) matching labels? try LP-ish: perceptron on augmented data
    X = np.hstack([P, np.ones((len(P), 1))])
    y = np.array(labels) * 2 - 1
    w = np.zeros(3)
    for _ in range(20000):
        errs = [i for i in range(len(P)) if y[i] * (X[i] @ w) <= 0]
        if not errs: return True
        i = errs[0]; w += y[i] * X[i]
    return False

def shatters_halfplanes(P):
    return all(halfplane_realizes(P, lab) for lab in product([0, 1], repeat=len(P)))

tri = np.array([[0, 0], [1, 0], [0.5, 1]])          # triangle: shattered
quad = np.array([[0, 0], [1, 0], [1, 1], [0, 1]])   # square: XOR labeling fails
print("halfplanes shatter triangle:", shatters_halfplanes(tri))    # True
print("halfplanes shatter square  :", shatters_halfplanes(quad))   # False => VC = 3

    Task 3 — Double descent, homemade. Random-feature (random ReLU features) least squares on a fixed dataset: sweep the number of features through n, using the pseudoinverse (min-norm) solution; plot train/test error and watch the peak at p ≈ n; show ridge removing it.

    Reference solution
    import numpy as np
rng = np.random.default_rng(2)

n, ntest, d = 60, 500, 12
Xtr = rng.standard_normal((n, d)); Xte = rng.standard_normal((ntest, d))
beta = rng.standard_normal(d)
ytr = Xtr @ beta + 0.5 * rng.standard_normal(n)
yte = Xte @ beta + 0.5 * rng.standard_normal(ntest)

def random_features(X, W): return np.maximum(X @ W, 0.0)   # ReLU features

Wfull = rng.standard_normal((d, 400)) / np.sqrt(d)
print(f"{'p':>5} {'train':>8} {'test(λ=0)':>10} {'test(λ=1e-3)':>12}")
for p in (5, 15, 30, 45, 55, 58, 60, 62, 70, 100, 200, 400):
    W = Wfull[:, :p]
    Ftr, Fte = random_features(Xtr, W), random_features(Xte, W)
    w0 = np.linalg.pinv(Ftr, rcond=1e-10) @ ytr              # min-norm interpolant
    wr = np.linalg.solve(Ftr.T @ Ftr + 1e-3 * np.eye(p), Ftr.T @ ytr)
    tr = np.mean((Ftr @ w0 - ytr) ** 2)
    te0 = np.mean((Fte @ w0 - yte) ** 2)
    ter = np.mean((Fte @ wr - yte) ** 2)
    print(f"{p:5d} {tr:8.3f} {te0:10.2f} {ter:12.3f}")
# test(λ=0) spikes near p = n = 60, then descends; ridge column stays flat
