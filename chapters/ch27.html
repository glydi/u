    Causality

    Telling what causes what, and what would have happened.

    20 topicsneeds: chapters 11, 13, 17feeds: chapters 29, 30, 35

    Correlation and causation

    Statistics sees that two things move together; it cannot, by itself, see why. Ice-cream sales and drownings rise together — because of summer, not each other. A correlation between $X$ and $Y$ has exactly three non-chance explanations: $X$ causes $Y$, $Y$ causes $X$, or something causes both. Untangling which requires assumptions or actions beyond the joint distribution — that gap is what this chapter fills.

    Definition $X$ and $Y$ are associated (correlated, dependent) if $P(Y \mid X = x)$ varies with $x$. $X$ causes $Y$ if intervening on $X$ changes the distribution of $Y$: $P(Y \mid do(X = x))$ varies with $x$. Reichenbach's common-cause principle: any dependence between $X$ and $Y$ arises from $X \to Y$, $Y \to X$, a common cause $Z$, or conditioning on a common effect (selection).
    Worked example Among hospital patients, coffee drinking correlates with heart disease, $r = 0.3$. Smokers both drink more coffee and get more heart disease. Stratify: among smokers, coffee–disease correlation is 0.02; among non-smokers, 0.01. The entire association was carried by smoking (a common cause). Nothing in the numbers $\{r\}$ announced this — you needed the extra variable and a hypothesis about its role.
    Pitfall "Correlation isn't causation" is often wielded as a conversation-ender, but the converse trap is real too: absence of correlation is not absence of causation. A drug that helps the sick and is prescribed only to the sick can show zero (or negative) marginal correlation with recovery. Causation can hide inside cancellation.

    1. EASY Shoe size correlates with reading ability in children. Give the confounder and the DAG.
      Solution
      Age: Age → ShoeSize, Age → Reading. Within a single age group the correlation vanishes.
    2. MED Countries' chocolate consumption correlates with Nobel prizes per capita ($r \approx 0.79$, famously). List the three candidate causal structures and the most plausible.
      Solution
      (1) Chocolate → Nobel (eating chocolate boosts science); (2) Nobel → chocolate (laureates trigger national celebration eating); (3) common cause: national wealth/R&D funding drives both chocolate affordability and research output.     3. HARD Construct a concrete joint distribution where $X$ causally affects $Y$ yet $\mathrm{Cov}(X, Y) = 0$.
      Solution
      Let $X \sim$ Uniform$\{-1, 0, 1\}$ and $Y = X^2$ (a genuine causal mechanism: set $X$, and $Y$ changes). $\mathbb E[X] = 0$; $\mathbb E[XY] = \mathbb E[X^3] = \frac{-1 + 0 + 1}{3} = 0$; so $\mathrm{Cov} = 0$. Intervening: $P(Y{=}1 \mid do(X{=}1)) = 1$ vs $P(Y{=}1\mid do(X{=}0)) = 0$ — strong causation, zero correlation. (Linear measures miss nonlinear mechanisms; mutual information would catch this one, but cancellation examples exist for it too via mixtures.)

    Simpson's paradox

    A trend can hold in every subgroup and reverse in the whole. A drug can look worse than placebo overall, yet better for men and better for women. Nothing is wrong with the arithmetic — the aggregation reweights the groups. The paradox dissolves only causally: whether you should read the pooled or the stratified numbers depends on the causal role of the grouping variable, not on the data.

    Definition Simpson's reversal: $P(y \mid x) < P(y \mid x')$ overall, while $P(y \mid x, z) > P(y \mid x', z)$ for every stratum $z$. Arithmetically possible because pooled rates are weighted averages with different weights per treatment group: $\frac{a_1 + a_2}{n_1 + n_2}$ is not a fixed-weight average of $\frac{a_1}{n_1}, \frac{a_2}{n_2}$.
    Worked example Kidney-stone treatments (real study). Treatment A (surgery): small stones 81/87 = 93%, large 192/263 = 73%; overall 273/350 = 78%. Treatment B (percutaneous): small 234/270 = 87%, large 55/80 = 69%; overall 289/350 = 83%. A wins both strata (93>87, 73>69); B wins overall (83>78). Why: doctors gave A mostly to hard (large-stone) cases. Stone size is a confounder (size → treatment choice, size → outcome), so the stratified comparison is the causally correct one: choose A.

      Solution
      Stratum 1: A 1/1 (100%) vs B 3/4 (75%). Stratum 2: A 2/5 (40%) vs B 1/3 (33%)... check pooled: A 3/6 = 50%, B 4/7 ≈ 57%. A wins both strata (100>75, 40>33), B wins pooled (57>50). ✓ The trick: A's trials concentrate in the hard stratum.
    3. HARD Show that Simpson's reversal is impossible in a randomized experiment (treatment independent of the stratum), for the difference-of-proportions metric.
      Solution
      With randomization, the stratum distribution is identical in both arms: $P(z \mid A) = P(z \mid B) = P(z)$. Pooled success under A: $\sum_z P(z)\,P(y\mid A, z)$; under B: $\sum_z P(z)\,P(y\mid B, z)$. If $P(y\mid A,z) > P(y\mid B,z)$ for every $z$, then the pooled values — same-weight averages — inherit the inequality strictly. Reversal requires different weights across arms, i.e. treatment–stratum dependence, i.e. confounding (or selection). Randomization forbids exactly that. ∎

    Causal graphs

    Draw the causal story: one node per variable, one arrow per direct influence. The picture is a bookkeeping device with teeth — from the diagram alone you can read off which correlations must appear, which adjustments are valid, and which questions the data can never answer. It is the interface between subject-matter knowledge and statistical machinery.

    Definition A causal graph is a directed graph over variables where an edge $X \to Y$ asserts that $X$ is a direct cause of $Y$ (relative to the variable set): changing $X$ while holding all other nodes fixed can change $Y$. Absence of an edge is the strong claim — no direct effect. Paths of arrows carry indirect influence; the three primitive junctions are the chain $A \to B \to C$, the fork $A \leftarrow B \to C$, and the collider $A \to B \leftarrow C$.
    Worked example Slippery pavement story: Season → Sprinkler, Season → Rain, Sprinkler → Wet, Rain → Wet, Wet → Slippery. Five nodes, five arrows. Read claims off the picture: Sprinkler and Rain are dependent (common cause Season) but become independent given Season; Sprinkler and Slippery are dependent, but independent given Wet (the chain is blocked); and — the strange one — Sprinkler and Rain become dependent given Wet: if the ground is wet and it didn't rain, the sprinkler probably ran. Each claim is testable; together they fingerprint the structure.
    Where this goes The three junctions power d-separation (two topics on); the graph plus structural equations is an SCM; and "does the model have the right graph?" returns as causal representation learning at chapter's end and as world-model fidelity in Ch 29.
    Drill
    1. EASY Classify the middle node: (a) Fire → Smoke → Alarm; (b) Genes → Height, Genes → Weight... i.e. Height ← Genes → Weight; (c) Talent → Admission ← Wealth.
      Solution
      (a) chain — Smoke is a mediator; (b) fork — Genes is a common cause (confounder for Height–Weight); (c) collider — Admission is a common effect.
    2. MED In the sprinkler graph, list all directed paths from Season to Slippery.
      Solution
      Season → Sprinkler → Wet → Slippery, and Season → Rain → Wet → Slippery. Two routes; the total effect of season on slipperiness flows through both, so blocking one (turn the sprinkler system off) reduces but does not remove the seasonal effect.
    3. HARD Why must a causal graph (in the standard formalism) be acyclic, and how do we model real feedback loops (thermostats, predator–prey)?
      Solution
      An arrow means "this equation's output feeds that one's input"; a directed cycle would make the system of structural equations self-referential with no guaranteed unique solution, and it would break the recursive factorization $P(\mathbf v) = \prod_i P(v_i \mid \text{pa}(v_i))$. Feedback is modeled by unrolling in time: Thermostat$_t$ → Heater$_t$ → Temp$_{t+1}$ → Thermostat$_{t+1}$ → … — a DAG over time-indexed copies (exactly a dynamic Bayesian network / the structure of Ch 28's state-space models). The cycle was never simultaneous; it was time, compressed.

    DAGs for causality

    The graphs of the previous topic, made mathematically precise: a directed acyclic graph whose factorization mirrors the causal recursion. The DAG does double duty — as a probabilistic object it encodes conditional independencies (a Bayesian network); as a causal object it additionally supports interventions. The same picture, two licenses; causal conclusions require the stronger one.

    Definition A DAG $G$ over $V = \{X_1,\dots,X_n\}$ is Markov-compatible with $P$ if $P(\mathbf x) = \prod_i P(x_i \mid \text{pa}_i)$. The causal Markov condition asserts this holds with pa = the direct causes; each variable is independent of its non-descendants given its parents. Faithfulness (the converse assumption): every independence in $P$ is implied by the graph structure — no accidental cancellations.
    Worked example Chain $X \to Y \to Z$ with binary variables: $P(x, y, z) = P(x)P(y\mid x)P(z\mid y)$. Take $P(x{=}1) = 0.5$, $P(y{=}1\mid x) = (0.9 \text{ if } x{=}1, 0.1 \text{ else})$, $P(z{=}1\mid y) = (0.8 \text{ if } y{=}1, 0.2 \text{ else})$. Then $P(z{=}1 \mid x{=}1) = 0.9(0.8) + 0.1(0.2) = 0.74 \ne P(z{=}1\mid x{=}0) = 0.26$: dependent. But given $y = 1$: $P(z{=}1 \mid x, y{=}1) = 0.8$ for either $x$ — independent. The factorization predicted both facts before any numbers were plugged in.
    Pitfall Markov-equivalence: $X \to Y \to Z$, $X \leftarrow Y \leftarrow Z$ and $X \leftarrow Y \to Z$ all imply exactly the same independencies ($X \perp Z \mid Y$ and nothing else). Observational data alone cannot distinguish them; only the collider $X \to Y \leftarrow Z$ (which implies $X \perp Z$ but not given $Y$) stands out. Fitting a Bayesian network that predicts well says little about which arrows are causal.

      Solution
      $P(s, k, r, w, l) = P(s)\,P(k \mid s)\,P(r \mid s)\,P(w \mid k, r)\,P(l \mid w)$.
    2. MED How many parameters does the sprinkler factorization need (all binary), versus the unrestricted joint?
      Solution
      Unrestricted: $2^5 - 1 = 31$. Factored: $P(s)$: 1; $P(k\mid s)$: 2; $P(r\mid s)$: 2; $P(w\mid k,r)$: 4; $P(l\mid w)$: 2 → 11 parameters. The savings are the independence assumptions; they grow exponential-to-linear as graphs get sparser.
    3. HARD Prove that for the collider $X \to Y \leftarrow Z$ (with $X \perp Z$ marginally), conditioning on $Y$ generically creates dependence ("explaining away"), using the Bernoulli OR-model $Y = X \lor Z$, $X, Z \sim$ Bern(0.5) independent.
      Solution
      Given $Y = 1$: $P(X{=}1\mid Y{=}1) = \frac{P(X{=}1)P(Y{=}1\mid X{=}1)}{P(Y{=}1)} = \frac{0.5\cdot1}{0.75} = \frac23$. Now also condition on $Z = 1$: $P(X{=}1 \mid Y{=}1, Z{=}1) = P(X{=}1) = \frac12$ (since $Z{=}1$ alone explains $Y{=}1$, $X$ reverts to its prior). $\frac23 \ne \frac12$: learning $Z$ changed belief in $X$ under conditioning on their common effect — dependence created. This is why conditioning on colliders (e.g. selecting on hospital admission, dataset inclusion) manufactures spurious correlations. ∎

    d-separation

    The reading rule for DAGs: a purely graphical test that decides, for any two variable sets and any conditioning set, whether the graph forces them independent. Information flows along paths; chains and forks are pipes that conditioning blocks, colliders are valves that conditioning opens. Master this one rule and every independence claim in the chapter becomes mechanical.

    Definition A path between $X$ and $Y$ is blocked by conditioning set $Z$ iff it contains (i) a chain $\cdot \to m \to \cdot$ or fork $\cdot \leftarrow m \to \cdot$ with $m \in Z$, or (ii) a collider $\cdot \to m \leftarrow \cdot$ with $m \notin Z$ and no descendant of $m$ in $Z$. $X$ and $Y$ are d-separated by $Z$ iff every path between them is blocked; then $X \perp Y \mid Z$ in every distribution Markov-compatible with the graph.
    Worked example Graph: $A \to B \to C$, $B \leftarrow D \to E$, and $C \to F \leftarrow E$. Is $A \perp E$? Paths from A to E: $A\to B \leftarrow D \to E$ (collider at B, unconditioned: blocked) and $A \to B \to C \to F \leftarrow E$ (collider at F: blocked). All blocked → $A \perp E$. ✓ Now condition on $F$: the second path's collider opens; the rest of that path ($A\to B\to C\to F \leftarrow E$) has no other blocker → unblocked → $A \not\perp E \mid F$. Conditioning created dependence between two marginally independent variables.

    1. EASY In $X \to M \to Y$: is $X \perp Y$? Is $X \perp Y \mid M$?
      Solution
      Not marginally (the chain is open); yes given $M$ (chain node conditioned → blocked).
    2. MED In $X \to C \leftarrow Y$, with $C \to D$: is $X \perp Y \mid D$?

      No. $D$ is a descendant of the collider $C$; conditioning on it partially opens the collider (rule (ii): blocked only if neither $m$ nor its descendants are in $Z$). Intuition: $D$ carries information about $C$, and knowing the common effect couples the causes.
    3. HARD M-bias: graph $X \leftarrow U_1 \to M \leftarrow U_2 \to Y$ with $U_1, U_2$ unobserved, plus the causal edge $X \to Y$. Show that adjusting for the observed pre-treatment variable $M$ introduces bias into estimating $X \to Y$.
      Solution
      Without conditioning: the path $X \leftarrow U_1 \to M \leftarrow U_2 \to Y$ is blocked at the collider $M$; the only open $X$–$Y$ connection is the causal edge, so the crude association is unbiased (here). Conditioning on $M$ opens the collider, unblocking the path $X \leftarrow U_1 \to M \leftarrow U_2 \to Y$ — a spurious channel that contaminates the estimate. Moral: "adjust for every pre-treatment covariate you have" is wrong; adjustment validity is a property of the graph (backdoor criterion, soon), not of measurement timing. ∎
    Conditioning on a collider node does what to the path through it?
    Colliders block by default and open when conditioned on (or when a descendant is) — the reverse of chains and forks. This asymmetry is the entire subtlety of d-separation.

    Structural causal models

    Under every causal DAG lives a machine: each variable is computed from its parents and some private noise by a fixed mechanism. An SCM is that machine written down. It generates the observational distribution, but it contains strictly more — because you can reach in, replace a mechanism, and ask what the machine does then. One object, three regimes: seeing, doing, imagining.

    Definition An SCM $\mathcal M = (U, V, F, P(U))$: exogenous noises $U$ with distribution $P(U)$, endogenous variables $V$, and assignments $F = \{f_i\}$ with $$X_i := f_i(\text{pa}_i, U_i).$$ The induced graph draws pa$_i \to X_i$. $\mathcal M$ entails: (1) the observational distribution (run the machine); (2) interventional distributions (replace assignments — next topics); (3) counterfactuals (infer $U$ from evidence, then rerun modified). These form Pearl's three-rung ladder: association, intervention, counterfactual.
    Worked example $\mathcal M$: $Z := U_Z$ with $U_Z \sim$ Bern(0.5) (rain); $X := Z \lor U_X$, $U_X \sim$ Bern(0.3) (sprinkler timer) — wet sidewalk... let $X$ = sprinkler on, $W := \max(Z, X)$ (wet). Run it: $P(W{=}1) = 1 - P(Z{=}0)P(X{=}0\mid Z{=}0) = 1 - 0.5\cdot0.7 = 0.65$. The same machine will shortly answer $P(W \mid do(X{=}0))$ and "would the sidewalk be dry had the sprinkler been off, given that it was on and it didn't rain?" — questions the joint distribution alone cannot pose.
    Where this goes The three-rung ladder is the organizing skeleton for counterfactual reasoning in Ch 30, for world models that support "what if I act differently" rollouts in Ch 29, and for the debate about what next-token predictors can and cannot infer (rung 1 data, rung 2 questions).
    Drill
    1. EASY What are the four components of an SCM, and which one makes it more than a Bayesian network?
      Solution
      Exogenous $U$ and $P(U)$, endogenous $V$, and assignments $F$. The assignments — deterministic mechanisms, not conditional probabilities — are the extra content: they specify what changes under intervention, which a BN's factorization leaves open.
    2. MED Two SCMs: (a) $X := U$, $Y := X \oplus U_Y$ (noisy copy); (b) $Y := U$, $X := Y \oplus U_X$ — with noise rates tuned so both give the same joint over $(X, Y)$. How would you tell them apart?
      Solution
      Intervene. Under (a), $do(Y{=}1)$ leaves $X$'s distribution unchanged (X doesn't listen to Y); under (b), $do(X{=}1)$ leaves $Y$ unchanged. Observationally identical, interventionally opposite — the definition of why causal direction is extra structure. (With assumptions like additive non-Gaussian noise, asymmetries in the joint can also reveal direction — see causal discovery.)
    3. HARD "Independence of mechanisms": state the principle and explain what it buys for transfer/robustness of learned models.
      Solution
      Principle: the mechanisms $f_i$ (and noise distributions) are autonomous — modular, mutually unrelated pieces that nature can change one at a time; $P(\text{cause})$ carries no information about $P(\text{effect}\mid\text{cause})$. Payoff: under distribution shift, typically only a few mechanisms change (a new spam-writing strategy changes $P(\text{text}\mid\text{spam})$, not $P(\text{spam})$... or vice versa). A model factored along causal lines can be repaired by relearning one module from little data, while a model of the anticausal factorization ($P(\text{cause}\mid\text{effect})$) shifts everywhere at once. This is the causal argument for why prediction direction matters in semi-supervised and transfer learning (Schölkopf et al.), and a design principle for world models.

    Structural equations

    The individual assignment $X_i := f_i(\text{pa}_i, U_i)$ deserves its own spotlight: the ":=" is not algebra's "=". It is an asymmetric recipe — the right side produces the left — and you may not move terms across it. Linear structural equations are the classic special case where effects are sums of weighted causes, and path-tracing rules compute total effects by multiplying edge weights.

    Definition A linear SCM (linear SEM): $X_i := \sum_{j \in \text{pa}_i} \beta_{ij} X_j + U_i$, noises independent. Wright's path rule: the total causal effect of $X$ on $Y$ = sum over all directed paths $X \to \cdots \to Y$ of the product of edge coefficients along each path. The covariance additionally includes contributions from paths through common causes.
    Worked example $Z := U_Z$; $X := 2Z + U_X$; $M := 3X + U_M$; $Y := 4M + 1\cdot Z + U_Y$ (all noises independent, unit variance... variances irrelevant to effects). Total effect of $X$ on $Y$: only directed path is $X \to M \to Y$: $3 \times 4 = 12$. So $do(X{:=}x)$ shifts $\mathbb E[Y]$ by $12$ per unit. The regression coefficient of $Y$ on $X$ alone would not be 12: the backdoor path $X \leftarrow Z \to Y$ adds a bias term through their covariance — regression sees paths of all kinds; causation counts only the directed ones.
    Pitfall Because ":=" is directional, "solving" a structural equation for a cause — rewriting $Y := \beta X + U$ as $X = (Y - U)/\beta$ — produces an algebraically valid but causally meaningless equation: it does not describe what setting $Y$ would do to $X$ (which is: nothing). Structural equations are programs, not constraints.
    Drill
    1. EASY In $X := 2Z + U_X$, $Y := 3X + Z + U_Y$: total effect of $Z$ on $Y$?
      Solution
      Paths: $Z \to Y$ (weight 1) and $Z \to X \to Y$ ($2 \times 3 = 6$): total $= 7$.
    2. MED Same model: compute $\mathrm{Cov}(X, Y)$ with all noises unit-variance, $Z$ unit-variance exogenous, and compare with the causal effect 3.
      Solution
      $\mathrm{Var}(Z) = 1$; $X = 2Z + U_X$; $Y = 3X + Z + U_Y = 6Z + 3U_X + Z + U_Y = 7Z + 3U_X + U_Y$. $\mathrm{Cov}(X, Y) = \mathrm{Cov}(2Z + U_X,\ 7Z + 3U_X + U_Y) = 14 + 3 = 17$. $\mathrm{Var}(X) = 4 + 1 = 5$. Regression slope $= 17/5 = 3.4 \ne 3$: the extra 0.4 is confounding through $Z$ ($X\leftarrow Z \to Y$). Adjusting for $Z$ (multiple regression of $Y$ on $X, Z$) recovers exactly 3.
    3. HARD Derive: in a linear SCM, the multiple-regression coefficient of $Y$ on $X$ controlling for a valid backdoor set $Z$ equals the total causal effect.
      Solution
      Write $Y = \tau X + \boldsymbol\gamma^\top \mathbf Z + \varepsilon$ where $\tau$ = sum of directed-path products (collapse mediators into the reduced form) and $\varepsilon$ collects noises along those paths, independent of $X$ given $\mathbf Z$ when $\mathbf Z$ blocks all backdoor paths (any residual correlation between $X$ and $\varepsilon$ would constitute an unblocked non-directed path). OLS on $(X, \mathbf Z)$ identifies the coefficient of $X$ as $\tau$ precisely when $\mathrm{Cov}(X, \varepsilon \mid \mathbf Z) = 0$ — the exogeneity condition that backdoor blocking guarantees. Hence adjusted regression = causal effect in linear systems; every classical "control for" is a special case of the backdoor criterion. ∎

    Interventions

    To intervene is to reach into the machine and set a variable, severing it from its usual causes: the gardener turns the sprinkler on regardless of season. Graphically, delete the arrows into the intervened node; algebraically, replace its equation with a constant. The distribution that results, written with Pearl's $do(\cdot)$, is a different object from conditioning — and the difference is the entire subject.

    Definition The intervention $do(X = x)$ transforms SCM $\mathcal M$ into $\mathcal M_x$: replace the assignment for $X$ by $X := x$ (graph surgery: remove all edges into $X$). Then $P(Y \mid do(X = x)) \equiv P_{\mathcal M_x}(Y)$. Truncated factorization: for Markovian models, $$P(\mathbf v \mid do(X = x)) = \prod_{i : V_i \ne X} P(v_i \mid \text{pa}_i)\ \Big|_{X = x}.$$ Conditioning filters the population; intervening changes the mechanism.
    Worked example Sprinkler SCM: Season (dry season w.p. 0.6 makes sprinkler more likely), $P(K{=}1\mid \text{dry}) = 0.8$, $P(K{=}1\mid\text{wet season}) = 0.1$. Observing the sprinkler on: $P(\text{dry} \mid K{=}1) = \frac{0.6\cdot0.8}{0.6\cdot0.8 + 0.4\cdot0.1} = \frac{0.48}{0.52} \approx 0.92$ — the sprinkler is evidence about the season. Intervening, $do(K{=}1)$: the surgery removes Season → Sprinkler, so $P(\text{dry} \mid do(K{=}1)) = 0.6$ — flipping the switch teaches you nothing about the weather and does not change it. Downstream (Wet), both regimes see effects; upstream, only observation does.
    Think first The barometer falls before storms. Compare $P(\text{storm} \mid \text{barometer low})$ and $P(\text{storm} \mid do(\text{barometer low}))$ — and say which one an agent optimizing "avoid storms" must use when deciding whether to smash the barometer.
    Reveal
    $P(\text{storm}\mid\text{low})$ is high (the reading is caused by pressure, which causes storms); $P(\text{storm}\mid do(\text{low}))$ = the base rate — forcing the needle down severs it from pressure and does nothing to the sky. An agent choosing actions must evaluate them with $do$: smashing or rigging the barometer changes observations, not weather. Agents that optimize predicted observations rather than intervened outcomes are wireheading-prone — the RL reward-hacking discussion of Ch 25, in causal dress.
    Drill
    1. EASY Apply graph surgery for $do(W{=}1)$ (wet) in the sprinkler DAG: which edges are removed, and is Slippery affected?
      Solution
      Remove Sprinkler → Wet and Rain → Wet. Slippery is downstream (Wet → Slippery survives): $P(L \mid do(W{=}1)) = P(L \mid W{=}1)$ here... it is affected, computed from $P(l\mid w{=}1)$. Sprinkler, Rain, Season keep their marginal distributions.
    2. MED Using the truncated factorization on the chain $X \to Y \to Z$: compute $P(z \mid do(y))$ and show it equals $P(z \mid y)$, but $P(x \mid do(y)) = P(x) \ne P(x\mid y)$ in general.
      Solution
      $P(x, z \mid do(y)) = P(x)\,P(z\mid y)$ (drop the factor $P(y\mid x)$, fix $y$). Marginalize: $P(z\mid do(y)) = P(z\mid y)$ ✓ (no confounding of $Y \to Z$ here), and $P(x \mid do(y)) = P(x)$, while conditioning gives $P(x\mid y) \propto P(x)P(y\mid x)$, which varies with $y$. Effects flow downstream of a $do$; inference flows both ways for an observation.
    3. HARD Soft interventions: instead of fixing $X$, we change its mechanism to a new $\tilde f_X$ (e.g. a subsidy shifts prices without fixing them). Formalize, and explain why RCT "assignment with noncompliance" is a soft intervention on treatment.
      Solution
      A soft (mechanism/parametric) intervention replaces $f_X(\text{pa}_X, U_X)$ by $\tilde f_X(\widetilde{\text{pa}}_X, \tilde U_X)$, keeping or altering parents; graph surgery replaces $X$'s incoming edges by the new parent set rather than deleting them. All identification machinery generalizes with $do$ replaced by the regime index. In an RCT with noncompliance, the experimenter sets the assignment $R$ (hard intervention on $R$), but treatment taken $X := f_X(R, \text{preferences } U)$ still listens to the patient: the trial soft-intervenes on $X$ via a new exogenous parent $R$. That's precisely the instrumental-variable structure (later topic): randomization gives you a clean handle, not the variable itself.

    Confounding

    A confounder is a common cause of treatment and outcome: it makes the treated and untreated groups different before the treatment does anything, so the raw comparison mixes the effect you want with the difference you started with. Confounding is the reason $P(y\mid x) \ne P(y\mid do(x))$, the reason we randomize, and the reason "we controlled for everything" needs a graph to mean anything.

    Definition $X$ and $Y$ are confounded if $P(y \mid do(x)) \ne P(y \mid x)$ — equivalently (given a causal DAG), there is an unblocked backdoor path from $X$ to $Y$: a path beginning with an arrow into $X$. A variable set $Z$ deconfounds the pair if adjusting for it makes the interventional and adjusted-observational quantities coincide (backdoor criterion, two topics on).
    Worked example Exercise ($X$) and heart disease ($Y$), confounded by age ($A$): older people exercise less and have more disease. Numbers: $P(A{=}\text{old}) = 0.5$; exercise rates 0.2 (old), 0.8 (young); disease rates: old — 0.3 (exercisers) vs 0.4 (not); young — 0.1 vs 0.2. True effect (within every age group): exercise cuts risk by 0.1. Crude comparison: $P(Y\mid X{=}1) = \frac{0.5\cdot0.2\cdot0.3 + 0.5\cdot0.8\cdot0.1}{0.5\cdot0.2 + 0.5\cdot0.8} = \frac{0.03 + 0.04}{0.5} = 0.14$; $P(Y\mid X{=}0) = \frac{0.5\cdot0.8\cdot0.4 + 0.5\cdot0.2\cdot0.2}{0.5} = \frac{0.16+0.02}{0.5} = 0.36$. Crude difference $-0.22$: exercise looks more than twice as protective as it is, because exercisers skew young. Adjusted: $\sum_a P(a)[P(y\mid x{=}1,a) - P(y\mid x{=}0,a)] = 0.5(-0.1) + 0.5(-0.1) = -0.1$ ✓.

      Solution

    3. HARD Unmeasured confounding can't be adjusted away — but it can be bounded. A study finds risk ratio RR = 2.5 for $X$ on $Y$. State the E-value idea and compute it: how strong would an unmeasured confounder have to be to explain the association away?
      Solution
      The E-value is the minimum strength of association (on the risk-ratio scale) that an unmeasured confounder would need with both treatment and outcome, given the measured covariates, to fully explain the observed RR: $E = \text{RR} + \sqrt{\text{RR}(\text{RR}-1)}$. Here $E = 2.5 + \sqrt{2.5 \times 1.5} = 2.5 + \sqrt{3.75} \approx 2.5 + 1.94 = 4.44$. Sensitivity analysis converts "no unmeasured confounding" from an article of faith into a quantified vulnerability.

    Causal identification

    Identification asks: can this causal quantity be computed, even in principle, from the distributions we can observe — given the assumed graph? It separates "we need better estimators" from "no amount of data can answer this." The workflow of causal inference is: draw the graph, check identifiability, derive the estimand, then — and only then — worry about statistics.

    Definition A query $Q$ (e.g. $P(y \mid do(x))$) is identifiable from observational data under graph $G$ if every SCM compatible with $G$ that induces the observed $P(\mathbf v)$ yields the same value of $Q$. Then $Q$ equals some functional of $P(\mathbf v)$ — the estimand. Complete algorithms exist (the ID algorithm; do-calculus is complete): identifiability is decidable from the graph alone.
    Worked example Three graphs, one query $P(y\mid do(x))$. (a) $X \to Y$ with no other structure: identifiable, estimand $P(y\mid x)$. (b) $X \to Y$ plus observed $Z$ with $X \leftarrow Z \to Y$: identifiable via adjustment, $\sum_z P(z)P(y\mid x, z)$. (c) $X \to Y$ plus a hidden common cause $U$: not identifiable — two different SCMs (strong effect + weak confounding vs zero effect + strong confounding) produce identical observational data but different $P(y\mid do(x))$. Same query, three verdicts, decided by the picture.
    Pitfall Identifiability is relative to the graph: it certifies "if the DAG is right, the data suffice," never that the DAG is right. The graph encodes untestable assumptions (especially absent edges and absent hidden confounders). Robust practice: report the graph, test its testable implications (the implied independencies), and run sensitivity analysis for the rest.

Identification is subtler than "no hidden confounders anywhere"; it is about whether the confounding can be routed around.

    Backdoor criterion

    The workhorse of identification: find a set of observed variables that blocks every backdoor path from treatment to outcome without touching the causal paths, adjust for it, done. The criterion turns the folklore of "controlling for covariates" into a checkable graphical condition — and, just as importantly, tells you what not to control for.

    Definition $Z$ satisfies the backdoor criterion relative to $(X, Y)$ iff (i) no node in $Z$ is a descendant of $X$, and (ii) $Z$ blocks (d-separates) every path from $X$ to $Y$ that starts with an arrow into $X$. Then the effect is identified by the adjustment formula $$P(y \mid do(x)) = \sum_z P(z)\; P(y \mid x, z).$$
    Worked example Kidney stones, at last with full rigor: Size → Treatment, Size → Recovery, Treatment → Recovery. Backdoor path: Treatment ← Size → Recovery; $Z = \{\text{Size}\}$ blocks it and contains no descendant of Treatment ✓. Adjustment: $P(\text{rec} \mid do(A)) = P(\text{small})P(\text{rec}\mid A, \text{small}) + P(\text{large})P(\text{rec}\mid A, \text{large})$. With $P(\text{small}) = 357/700 = 0.51$: $do(A)$: $0.51(0.93) + 0.49(0.73) = 0.832$; $do(B)$: $0.51(0.87) + 0.49(0.69) = 0.782$. A wins causally, 83.2% vs 78.2% — the stratified verdict, now derived rather than intuited.
    Pitfall Condition (i) is not decoration: adjusting for a descendant of $X$ — a mediator or a collider downstream — blocks causal flow or opens selection paths. And the criterion is sufficient, not necessary: some effects are identifiable with no valid backdoor set at all (front door, IV). "No valid adjustment set" ≠ "unidentifiable."

      Solution
      Observational: $P(z, x, y) = P(z)P(x\mid z)P(y\mid x, z)$. Under $do(X{=}x)$, drop $P(x\mid z)$: $P(z, y \mid do(x)) = P(z)\,P(y\mid x, z)$. Marginalize over $z$: $P(y\mid do(x)) = \sum_z P(z)P(y\mid x, z)$. ∎ Note what changed versus conditioning: $P(y\mid x) = \sum_z P(z\mid x)P(y\mid x,z)$ weights strata by $P(z\mid x)$ — the treated population's mix — while the do-expression weights by $P(z)$ — the whole population's. Confounding is that difference in weights, which is also why Simpson's reversal evaporates after adjustment.

    Frontdoor criterion

    Sometimes every backdoor is unblockable — the confounder is unmeasured — yet identification survives through the front: if the treatment works entirely through an observed mediator that the confounder doesn't touch, you can estimate the two clean hops ($X\to M$, $M \to Y$) and chain them. It is the most surprising formula in elementary causal inference: measuring the mechanism substitutes for measuring the confounder.

    Definition $M$ satisfies the front-door criterion for $(X, Y)$ iff (i) $M$ intercepts all directed paths from $X$ to $Y$; (ii) there is no unblocked backdoor path from $X$ to $M$; (iii) all backdoor paths from $M$ to $Y$ are blocked by $X$. Then $$P(y \mid do(x)) = \sum_m P(m \mid x) \sum_{x'} P(x')\, P(y \mid m, x').$$
    Worked example Smoking ($X$) → Tar ($M$) → Cancer ($Y$), hidden Genotype $U$ with $X \leftarrow U \to Y$ (Fisher's old objection: maybe a gene causes both craving and cancer). Toy numbers: $P(m{=}1\mid x{=}1) = 0.95$, $P(m{=}1\mid x{=}0) = 0.05$; $P(x{=}1) = 0.5$; $P(y{=}1\mid m, x')$: $(m{=}1, x'{=}1)$: 0.30, $(1,0)$: 0.20, $(0,1)$: 0.15, $(0,0)$: 0.05. Inner sums: for $m{=}1$: $0.5(0.30) + 0.5(0.20) = 0.25$; for $m{=}0$: $0.5(0.15)+0.5(0.05) = 0.10$. Then $P(y\mid do(x{=}1)) = 0.95(0.25) + 0.05(0.10) = 0.2425$; $P(y\mid do(x{=}0)) = 0.05(0.25) + 0.95(0.10) = 0.1075$. Causal risk difference ≈ 0.135 — computed through an unmeasured genetic confounder, using only observed quantities.
    Pitfall Condition (i) — the mediator captures all of the effect — is a strong scientific claim (any direct $X \to Y$ path bypassing $M$ breaks the formula), and condition (ii) requires the hidden confounder to spare the mediator. Front-door is a scalpel, not a default: its power comes from mechanism knowledge you must actually have.

    2. MED Why does the second hop average over $x'$ (the formula's $\sum_{x'} P(x')P(y\mid m, x')$) instead of just using $P(y \mid m)$?
      Solution
      $M \to Y$ is confounded: the path $M \leftarrow X \leftarrow U \to Y$ is open if you ignore $X$. Conditioning on $X$ blocks it (condition (iii)), so the effect of $M$ on $Y$ needs its own backdoor adjustment with adjustment set $\{X\}$ — which is exactly what the inner sum is. Front-door = two nested backdoor adjustments chained through the mediator.
    3. HARD Derive the front-door formula for the smoking graph by combining the two identified hops.
      Solution
      Hop 1: no backdoor from $X$ to $M$ (the path via $U$ requires an edge $U \to M$, absent; the path $X \leftarrow U \to Y \leftarrow M$ has a collider at $Y$): so $P(m\mid do(x)) = P(m\mid x)$. Hop 2: backdoor from $M$ to $Y$ is $M \leftarrow X \leftarrow U \to Y$; $\{X\}$ blocks it and is no descendant of $M$: $P(y\mid do(m)) = \sum_{x'}P(x')P(y\mid m, x')$. Composition: intervening on $X$ influences $Y$ only through $M$ (condition (i)), and once $M$'s value is set, $Y$'s response doesn't depend on how $M$ was produced (no $X\to Y$ direct, $U\not\to M$): $P(y \mid do(x)) = \sum_m P(m \mid do(x))\,P(y\mid do(m))$. Substitute the two identified hops to get the formula. (Fully rigorous versions run the three rules of do-calculus; this is the intuition they formalize.) ∎

    Adjustment sets

    Usually many different covariate sets satisfy the backdoor criterion — and they are not equal. Some are invalid despite looking responsible (colliders, mediators), some are valid but wasteful, and among the valid ones, the choice changes the variance of your estimate even though all converge to the same truth. Choosing adjustment sets is a graph problem with statistical consequences.

    Definition $Z$ is a valid adjustment set for $(X, Y)$ if $P(y\mid do(x)) = \sum_z P(z)P(y\mid x,z)$. Graphical characterization (generalized adjustment criterion): $Z$ contains no descendant of any node on a proper causal path from $X$ to $Y$, and $Z$ blocks all non-causal paths from $X$ to $Y$. The O-set heuristic for precision: prefer covariates that predict $Y$ (outcome parents), avoid pure predictors of $X$ (instruments), which inflate variance.
    Worked example Graph: $X \to Y$; confounder $C$ with $X \leftarrow C \to Y$; instrument $I \to X$; outcome-cause $W \to Y$ (independent of the rest). Valid sets include $\{C\}$, $\{C, W\}$, $\{C, I\}$, $\{C, W, I\}$. All unbiased. Precision ranking (linear-Gaussian intuition): adding $W$ shrinks residual outcome variance → tighter estimate; adding $I$ removes treatment variation without touching confounding → wider estimate. Best practical choice: $\{C, W\}$; worst valid: $\{C, I\}$. Same truth, different error bars.
    Think first A dataset has 300 covariates. Why is "throw them all into the regression" not a conservative default, even for prediction-savvy practitioners?
    Reveal
    Three failure modes: (1) some covariates are mediators or downstream of treatment — adjusting blocks the effect; (2) some are colliders (or M-bias nodes) — adjusting opens spurious paths; (3) instruments amplify bias: if any unmeasured confounding remains, conditioning on strong treatment-predictors is known to magnify the residual bias (Z-bias), and always inflates variance. Adjustment is causal surgery; doing it 300 times blindly is 300 chances to cut the wrong vessel.
    Drill
    1. EASY In the worked example's graph, why is $\{I\}$ alone invalid?
      Solution
      The backdoor path $X \leftarrow C \to Y$ remains unblocked ($I$ doesn't lie on it). Validity requires blocking every backdoor path.
    2. MED Two valid sets give estimates $-0.10 \pm 0.02$ and $-0.10 \pm 0.06$. What does the agreement tell you, and the widths?
      Solution
      Agreement of estimates across different valid adjustment sets is a (weak) consistency check of the assumed graph — divergence would flag a misspecified DAG or unmeasured confounding, since all valid sets must identify the same quantity. The widths reflect the precision ordering: the tighter set likely contains outcome predictors, the looser one treatment predictors. Report the tight one, but the comparison itself was the valuable diagnostic.
    3. HARD Propensity scores: define $e(z) = P(X{=}1\mid Z{=}z)$ for a valid backdoor set $Z$ and prove that adjusting for the scalar $e(Z)$ suffices.
      Solution
      Claim: $X \perp Z \mid e(Z)$. Proof: $P(X{=}1 \mid Z, e(Z)) = e(Z)$, a function of $e(Z)$ alone, so conditioning further on $Z$ adds nothing about $X$: within a stratum of the score, treatment is as-if random w.r.t. $Z$. Then potential outcomes (or the do-distribution): given $Z$ suffices for ignorability, and $X \perp Z \mid e(Z)$ implies ignorability given $e(Z)$ (Rosenbaum & Rubin): $\sum_z$-adjustment collapses to a one-dimensional adjustment $\int P(e)P(y\mid x, e)\,de$. The 300-covariate curse becomes a scalar matching/weighting problem — at the price that $e$ must itself be estimated, and misestimating it re-imports bias (hence doubly-robust estimators, which stay consistent if either the score or the outcome model is right). ∎

    Do-calculus

    Three rewrite rules that transform expressions containing $do(\cdot)$ — inserting or deleting observations and interventions — each licensed by a d-separation check in a surgically modified graph. Backdoor and front-door are two short derivations in this system; the deep theorem is completeness: if a causal effect is identifiable at all, some sequence of these three rules derives it.

    Definition Notation: $G_{\overline X}$ = graph with edges into $X$ deleted; $G_{\underline X}$ = edges out of $X$ deleted. For disjoint $X, Y, Z, W$:
    Rule 1 (insert/delete observation): $P(y\mid do(x), z, w) = P(y \mid do(x), w)$ if $Y \perp Z \mid X, W$ in $G_{\overline X}$.
    Rule 2 (exchange action/observation): $P(y \mid do(x), do(z), w) = P(y \mid do(x), z, w)$ if $Y \perp Z \mid X, W$ in $G_{\overline X \underline Z}$.
    Rule 3 (insert/delete action): $P(y\mid do(x), do(z), w) = P(y\mid do(x), w)$ if $Y \perp Z \mid X, W$ in $G_{\overline X, \overline{Z(W)}}$, where $Z(W)$ = nodes of $Z$ not ancestors of $W$ in $G_{\overline X}$.
    Worked example Deriving backdoor for the triangle $Z \to X$, $Z \to Y$, $X \to Y$: $$P(y\mid do(x)) = \sum_z P(z \mid do(x))\,P(y \mid do(x), z).$$ First factor: Rule 3 — is $Z \perp X$ in $G_{\overline{X}}$? Deleting edges into $X$ leaves $Z \to Y \leftarrow X$: collider blocks, yes → $P(z\mid do(x)) = P(z)$. Second factor: Rule 2 — is $Y \perp X \mid Z$ in $G_{\underline X}$? Deleting $X$'s outgoing edge leaves paths $X \leftarrow Z \to Y$ only, blocked by $Z$: yes → $P(y\mid do(x), z) = P(y \mid x, z)$. Result: $\sum_z P(z)P(y\mid x,z)$ — the adjustment formula, now a two-line proof.
    Where this goes Do-calculus + graphs is the identification engine behind transportability (external validity), missing-data corrections, and surrogate-experiment combining; algorithmically it is the ID algorithm, which either outputs an estimand or a certificate of non-identifiability.

    1. EASY Which rule directly justifies "in an RCT, $P(y\mid do(x)) = P(y\mid x)$" when $X$ has no incoming edges?
      Solution
      Rule 2 (with empty $X$-set, exchanging $do(x)$ for observing $x$): need $Y \perp X$ in $G_{\underline X}$; cutting $X$'s outgoing edges leaves no $X$–$Y$ path at all when $X$ has no parents. Doing = seeing.
    2. MED Use Rule 3 to show $P(x \mid do(y)) = P(x)$ in the chain $X \to Y$.
      Solution
      Check $X \perp Y$ in $G_{\overline Y}$: deleting edges into $Y$ removes $X \to Y$, disconnecting them → independent → the action on $Y$ can be deleted: $P(x\mid do(y)) = P(x)$. Interventions don't propagate upstream, now as a derived theorem rather than an intuition.
    3. HARD Sketch the front-door derivation as a do-calculus program (name the rule used at each step) for $X \to M \to Y$ with hidden $X \leftarrow U \to Y$.
      Solution
      1. $P(y\mid do(x)) = \sum_m P(m\mid do(x))\,P(y\mid do(x), m)$ (probability axioms). 2. $P(m\mid do(x)) = P(m\mid x)$: Rule 2, since $M \perp X$ in $G_{\underline X}$ (paths from $X$: only via $U \to Y \leftarrow M$, collider). 3. $P(y \mid do(x), m) = P(y\mid do(x), do(m))$: Rule 2 in $G_{\overline X\underline M}$ ($Y \perp M$ there: cutting $M$'s out-edge removes $M\to Y$; remaining path $M \leftarrow X \leftarrow U \to Y$ is cut at $X$'s deleted in-edges... in $G_{\overline X}$, $X$ has no in-edges, path blocked). 4. $P(y\mid do(x), do(m)) = P(y \mid do(m))$: Rule 3 ($Y \perp X$ in $G_{\overline{X}\overline M}$: with both intervened, no path remains from $X$ to $Y$... the path $X \leftarrow U \to Y$ is cut by $\overline X$). 5. Identify $P(y\mid do(m))$ by backdoor with set $\{X\}$ (as derived above). Chain the pieces to get the front-door formula. Each step is a d-separation check a program can perform — identification as symbolic computation. ∎

    Randomized experiments

    Randomization is identification by force: assign treatment with a coin, and every backdoor path is severed at birth, measured and unmeasured confounders alike. That is why the RCT is the gold standard — not that it is unbiased in any one trial, but that its bias is zero by design and its uncertainty is quantifiable from the randomization itself. Everything else in this chapter is what to do when you can't have one.

    Definition An RCT assigns $X \sim$ (known randomization distribution), independent of all pre-treatment variables: graphically, $X$'s only parent is the coin. Then $P(y\mid do(x)) = P(y\mid x)$ in the experiment, and the average treatment effect $\text{ATE} = \mathbb E[Y\mid X{=}1] - \mathbb E[Y\mid X{=}0]$ is estimated unbiasedly by the difference of group means, with exact inference available via the randomization distribution (Fisher's exact/permutation tests).
    Worked example 200 patients, 100 per arm by coin flip. Recovery: 62/100 treated, 48/100 control. $\widehat{\text{ATE}} = 0.14$. Standard error $\approx \sqrt{\frac{0.62\cdot0.38}{100} + \frac{0.48\cdot0.52}{100}} = \sqrt{0.002356 + 0.002496} = \sqrt{0.004852} \approx 0.0697$. 95% CI: $0.14 \pm 1.96(0.0697) = (0.003, 0.277)$ — significant, barely. Note what we never asked: what the confounders were. Randomization answered for all of them at once, including the ones nobody has discovered yet.
    Pitfall Randomization guarantees exchangeability at assignment; everything after can still break it: noncompliance (analyze by intention-to-treat, or use assignment as an instrument), attrition correlated with outcomes (dropouts reopen selection paths), spillover between units (SUTVA violations), and generalization — the RCT identifies the effect in the trial population, and transporting it elsewhere is a fresh causal problem with its own graph.
    Drill
    1. EASY Why can't Simpson's paradox reverse an RCT's verdict (connect to the earlier capstone-style proof)?
      Solution
      Randomization equalizes the stratum distribution across arms, so the pooled comparison is a same-weights average of stratum comparisons — if treatment wins in every stratum, it wins pooled. Reversal needs unequal weights, i.e. assignment–covariate dependence, which the coin forbids (up to sampling noise).
    2. MED A/B test with 5% of users randomly given a new ranking algorithm. Engagement rises 2%. A colleague objects: "power users are overrepresented in the morning, when you launched." Valid objection?
      Solution
      Only if the randomization was broken. If assignment is per-user random and concurrent (both arms live simultaneously over the same period), time-of-day and power-user composition are balanced across arms in expectation — the objection dissolves. If instead "A this week, B last week" (a before/after switch), it is not an RCT at all: time confounds everything, and the objection is fatal. The design detail, not the sample size, decides.
    3. HARD Fisher's exact reasoning: with 6 subjects, 3 randomized to treatment, outcomes (treated: 1, 1, 1; control: 0, 0, 1), test the sharp null "treatment affects nobody" by enumerating the randomization distribution of the treated-minus-control mean.
      Solution
      Under the sharp null, each subject's outcome is fixed regardless of assignment: outcomes are (1,1,1,0,0,1) — four 1s... count: treated (1,1,1), control (0,0,1): values are three 1s and one 1 among controls → the fixed outcome vector has four 1s and two 0s. Observed statistic: $\bar Y_T - \bar Y_C = 1 - 1/3 = 2/3$. Enumerate all $\binom63 = 20$ assignments: the treated group's sum can be 1, 2, or 3 (it must include at least one of the four 1s: min sum = 4 ones... choose 3 of {1,1,1,1,0,0}: sums 1 (choose one 1, two 0s: $\binom41\binom22 = 4$ ways), 2 ($\binom42\binom21 = 12$), 3 ($\binom43 = 4$)). Statistic for sum $s$: $\frac{s}{3} - \frac{4-s}{3} = \frac{2s-4}{3}$: values $-2/3, 0, 2/3$ with probabilities $4/20, 12/20, 4/20$. P(statistic ≥ observed $2/3$) $= 4/20 = 0.2$. Not significant: with 6 subjects, even a perfect-looking split arises by chance 20% of the time. The test used no model, no Gaussian, nothing but the physical act of randomization — inference from design alone. ∎

    Instrumental variables

    When treatment is confounded and you can't block the backdoor, look for a lever that moves the treatment but touches the outcome through nothing else: an instrument. Randomized encouragement, distance to the nearest hospital, a lottery number. The instrument's clean wiggle in $X$ carries a clean wiggle into $Y$, and their ratio recovers the causal effect — even with unmeasured confounding.

    Definition $Z$ is an instrument for $X \to Y$ iff (i) relevance: $Z$ affects $X$; (ii) exclusion: $Z$ affects $Y$ only through $X$ (no direct edge, no other path); (iii) exogeneity: $Z$ shares no common cause with $Y$. Linear case (Wald estimator): $$\hat\tau_{IV} = \frac{\mathrm{Cov}(Z, Y)}{\mathrm{Cov}(Z, X)}.$$ Binary heterogeneous case: IV identifies the LATE — the average effect among compliers (those whose $X$ is moved by $Z$), under monotonicity (no defiers).
    Worked example Does military service ($X$) affect earnings ($Y$)? Confounded hopelessly (who enlists differs in everything). Instrument: Vietnam draft lottery number ($Z$, randomly assigned; low numbers → more likely drafted; plausibly affects earnings only via service). Suppose being draft-eligible raises service probability by $\mathbb E[X\mid Z{=}1] - \mathbb E[X\mid Z{=}0] = 0.16$ and changes earnings by $-\$400$. Wald: $\hat\tau = -400 / 0.16 = -\$2500$ — the earnings effect of service for men whose service was determined by the lottery (compliers). Angrist's actual study: this design, roughly this arithmetic.

Slide the instrument's strength — watch IV stay centered but grow wild as the instrument weakens.

    Pitfall Weak instruments: when $\mathrm{Cov}(Z,X)$ is small, the ratio divides by nearly zero — the estimator's variance explodes and small exclusion violations get amplified by $1/\text{strength}$. Rule-of-thumb: first-stage F-statistic > 10; below that, IV can be worse than the bias it was hired to fix. Exclusion itself is untestable from data — it is an argument, not a statistic.
    Drill
    1. EASY Check the three IV conditions for "distance to college" instrumenting education's effect on wages, and name the shakiest.
      Solution
      Relevance: plausibly yes (nearby college → more schooling). Exclusion: shaky — distance correlates with urbanicity, which affects wages directly. Exogeneity: shaky for the same reason (family choices of where to live). IV credibility lives and dies on such arguments.
    2. MED Derive the Wald estimator from the linear SCM $X := \alpha Z + \delta U + e_X$, $Y := \tau X + \beta U + e_Y$, $Z \perp (U, e_X, e_Y)$.
      Solution
      $\mathrm{Cov}(Z, X) = \alpha \mathrm{Var}(Z)$; $\mathrm{Cov}(Z, Y) = \tau\,\mathrm{Cov}(Z, X) + \beta\,\mathrm{Cov}(Z, U) + \mathrm{Cov}(Z, e_Y) = \tau\alpha\mathrm{Var}(Z)$. Ratio $= \tau$. The confounder $U$ dropped out because $Z$ is independent of it — the instrument's variation is confounding-free by assumption (iii), and reaches $Y$ only via $X$ by (ii). ∎
    3. HARD Define compliers/always-takers/never-takers/defiers for binary $Z, X$, and prove the LATE theorem: $\frac{\mathbb E[Y\mid Z{=}1] - \mathbb E[Y\mid Z{=}0]}{\mathbb E[X\mid Z{=}1] - \mathbb E[X\mid Z{=}0]} = \mathbb E[Y(1) - Y(0) \mid \text{complier}]$ under monotonicity.
      Solution
      Types by potential treatment $(X(z{=}0), X(z{=}1))$: never-takers (0,0), compliers (0,1), defiers (1,0), always-takers (1,1); monotonicity bans defiers. Numerator: $\mathbb E[Y\mid Z{=}1] - \mathbb E[Y\mid Z{=}0]$; by exogeneity, type composition is identical across $Z$ arms, and within never/always-takers, treatment (hence outcome, by exclusion) doesn't depend on $Z$ — their contributions cancel. Only compliers change treatment with $Z$, contributing $P(\text{complier})\cdot\mathbb E[Y(1)-Y(0)\mid\text{complier}]$. Denominator: $\mathbb E[X\mid Z{=}1]-\mathbb E[X\mid Z{=}0] = P(\text{complier})$ (again, others cancel). Ratio = complier average effect. ∎ Moral: IV answers a local question — those never moved by any encouragement are simply invisible to it.

    Counterfactuals

    The third rung: not "what happens if we do $X$" in general, but "what would have happened in this very case had $X$ been different, given everything that actually occurred." Counterfactuals require the full SCM — you infer the case's hidden particulars from what happened, then rerun history with one mechanism changed. They underwrite attribution, blame, regret, and personalized decisions.

    Definition The counterfactual $Y_{X = x}(u)$ is $Y$'s value in the modified model $\mathcal M_x$ at noise setting $u$. To evaluate $P(Y_{X=x} \mid E)$ given evidence $E$: (1) abduction — update $P(U \mid E)$; (2) action — surgery $do(X = x)$; (3) prediction — compute $Y$'s distribution in the modified model under $P(U\mid E)$. Counterfactuals can differ across SCMs that agree on all observational and interventional distributions.
    Worked example $Y := X \oplus U$ (treatment flips a coin-determined default), $U \sim$ Bern(0.5), $X \sim$ Bern(0.5) independent. Patient took the drug and recovered: $X = 1, Y = 1$. Abduction: $1 = 1 \oplus U \Rightarrow U = 0$. Action: set $X = 0$. Prediction: $Y = 0 \oplus 0 = 0$. Counterfactual verdict: without the drug, this patient would not have recovered — probability 1, for this evidence, in this model. Note an interventional query could never say this: $P(Y{=}1\mid do(X{=}0)) = 0.5$ is about the population; the counterfactual used the patient's own outcome to pin down their $U$.
    Pitfall Rung-3 humility: two SCMs with identical rung-1 and rung-2 behavior can disagree on counterfactuals (e.g. $Y := X \oplus U$ vs $Y := $ independent fresh randomness per regime). Since no experiment distinguishes them, counterfactual claims lean on mechanism assumptions that data cannot fully test. State them; don't launder them.
    Where this goes Counterfactual reasoning is Ch 30's rung of deliberation ("had I moved the queen instead…"), the core of algorithmic-fairness definitions (counterfactual fairness), and the logic of regret in online learning and of hindsight relabeling in RL.
    Drill
    1. EASY Name the three steps for computing a counterfactual and what each consumes.
      Solution
      Abduction (evidence → posterior over noises $U$), action (surgery on the queried variable), prediction (run the modified model on the posterior noises). Consumes: full SCM + case evidence.
    2. MED In the worked example, compute the counterfactual for a patient who took the drug and did not recover.
      Solution
      $X = 1, Y = 0$: abduction gives $0 = 1 \oplus U \Rightarrow U = 1$. Action $X = 0$; prediction $Y = 0 \oplus 1 = 1$. This patient would have recovered without the drug — the drug harmed them, deterministically, in this model. Same drug, same population, opposite individual verdicts: counterfactuals personalize where interventions average.
    3. HARD Probability of necessity: define $PN = P(Y_{X=0} = 0 \mid X = 1, Y = 1)$ and compute it for: $P(Y{=}1\mid do(X{=}1)) = 0.7$, $P(Y{=}1 \mid do(X{=}0)) = 0.2$, under monotonicity ($X$ never prevents recovery: $Y_{X=1} \ge Y_{X=0}$ for every unit).
      Solution
      PN asks: among actual treated recoverers, what fraction owed recovery to treatment? Under monotonicity and exogeneity, Pearl's identity: $PN = \frac{P(y\mid do(x{=}1)) - P(y\mid do(x{=}0))}{P(y \mid do(x{=}1))}$... with treatment exogenous, $= \frac{0.7 - 0.2}{0.7} = \frac57 \approx 0.714$. About 71% of treated recoveries were caused by treatment; 29% would have happened anyway (their $Y_{X=0}$ was already 1). This is the quantity courts need ("but-for causation") and epidemiology's attributable fraction — computable only by climbing to rung 3, bounded (not point-identified) when monotonicity fails. ∎

    Potential outcomes

    The statisticians' formulation of the same subject: every unit carries a value $Y(1)$ — its outcome if treated — and $Y(0)$ — if not. Treatment reveals one and forever hides the other; causal inference is a missing-data problem where exactly half the table is missing by definition. The frameworks are two notations for one mathematics: $Y(x) \equiv Y_{X=x}$, potential outcome = SCM counterfactual.

    Definition Unit-level effect: $Y_i(1) - Y_i(0)$ — never observed for any unit (the fundamental problem of causal inference). $\text{ATE} = \mathbb E[Y(1) - Y(0)]$. Identification assumptions: ignorability $(Y(0), Y(1)) \perp X \mid Z$ (equivalent to $Z$ being a valid backdoor set), positivity $0 < P(X{=}1\mid Z) < 1$, and SUTVA (no interference between units; one version of treatment). Then $\text{ATE} = \mathbb E_Z\big[\mathbb E[Y\mid X{=}1, Z] - \mathbb E[Y \mid X{=}0, Z]\big]$.
    Worked example Four units with (in truth — a god's-eye table): $Y(0) = (5, 3, 7, 1)$, $Y(1) = (7, 4, 7, 3)$. Unit effects: $(2, 1, 0, 2)$; true ATE $= 1.25$. Reality assigns $X = (1, 0, 1, 0)$: we observe $Y = (7, 3, 7, 1)$. Naive difference of means: $\frac{7+7}{2} - \frac{3+1}{2} = 7 - 2 = 5 \ne 1.25$ — units 1 and 3 (high baselines) happened to be treated: selection. Had assignment been random, the estimator would be unbiased over the randomization distribution — this small example shows bias is about the assignment mechanism, visible only when you write both columns.
    Think first SUTVA bans interference between units. Give two modern settings where it fails badly, and what breaks.
    Reveal
    (1) Vaccines/epidemics: treating me protects you (herd immunity) — control units are partially treated through the network, shrinking measured contrasts below true effects. (2) Marketplace/platform A/B tests: giving some sellers a promotion steals demand from control sellers — effects are overstated (cannibalization). When units share an environment, "the effect of treating everyone" ≠ "per-unit effect × everyone," and the estimand itself must be redefined (cluster randomization, exposure mappings, equilibrium effects).
    Drill
    1. EASY Why is the unit-level effect fundamentally unobservable?
      Solution
      Observing $Y_i(1)$ requires treating unit $i$; observing $Y_i(0)$ requires not treating the same unit at the same time — mutually exclusive. Only one potential outcome is ever realized; the other is a counterfactual.
    2. MED Show that under random assignment, difference-in-means is unbiased for the ATE.
      Solution
      Randomization makes $X \perp (Y(0), Y(1))$, so $\mathbb E[Y \mid X{=}1] = \mathbb E[Y(1)\mid X{=}1] = \mathbb E[Y(1)]$, similarly for 0. Difference of the observed group means estimates $\mathbb E[Y(1)] - \mathbb E[Y(0)] = $ ATE. The missing half of the table is missing at random, so each observed column mean stands in for its full-population column mean.
    3. HARD Translate: express ignorability graphically, and positivity's failure graphically/practically, and say what happens to the adjustment estimator when positivity fails in a stratum.
      Solution
      Ignorability given $Z$ ⇔ $Z$ blocks all backdoor paths (and includes no descendants of $X$) — potential outcomes are determined by the unit's noises and mechanisms upstream of $Y$ except the $X$-assignment channel; conditioning on a backdoor-blocking $Z$ renders assignment independent of them. Positivity fails when some stratum $z^*$ deterministically receives (or is denied) treatment — graphically, an arrow $Z \to X$ so strong it is a function on that stratum. Then $P(y\mid x, z^*)$ for the never-assigned arm is undefined (no data at any sample size): the adjustment formula's term is $0/0$. Estimators respond by extrapolating from a model (invisible, dangerous), by trimming such strata (changes the estimand to the overlap population), or by exploding weights (IPW dividing by $\hat e \approx 0$). Identification needs both a blocked graph and genuine overlap — one is topology, the other is support. ∎

    Causal discovery

    Run the chapter in reverse: instead of assuming the graph and computing effects, infer the graph from data. Independence patterns carve away inconsistent structures (constraint-based methods); score functions rank DAGs (score-based); and asymmetries in functional form — noise shapes, mechanism independence — can even orient edges that independencies leave ambiguous. What's recoverable is a hard-won partial answer: usually an equivalence class, not one graph.

    Definition Under causal Markov + faithfulness (+ causal sufficiency: no hidden confounders), constraint-based algorithms (PC) recover the graph up to its Markov equivalence class (CPDAG): the skeleton plus all v-structures (colliders), other edges left undirected. With hidden confounders allowed: FCI, outputting a PAG. Functional-form methods: LiNGAM (linear non-Gaussian: fully identifies direction), additive-noise models ($Y = f(X) + N$, $N \perp X$ holds in the causal direction only, generically).
    Worked example Three variables; data reveal exactly one independence: $A \perp B$ (unconditionally), and $A \not\perp B \mid C$. PC reasoning: skeleton — $A$–$C$ and $B$–$C$ edges (each pair dependent except $A,B$); orientation — $A \perp B$ but dependent given $C$ is the collider signature: $A \to C \leftarrow B$. Fully oriented, no experiment needed. Contrast: had we found $A \perp B \mid C$ instead, the class would be $\{A\to C\to B,\ A\leftarrow C\leftarrow B,\ A \leftarrow C \to B\}$ — skeleton oriented only by convention; observation alone cannot choose.
    Pitfall Everything rests on faithfulness (no exactly-cancelling paths — reasonable generically, violated by design in equilibrium/control systems: a thermostat cancels the very correlations that would reveal it), on the correctness of finite-sample independence tests (errors cascade through PC's stages), and on causal sufficiency (a hidden confounder mimics an edge). Discovery outputs are hypotheses to be probed with interventions, not conclusions.
    Drill
    1. EASY Why can't observational data distinguish $X \to Y$ from $X \leftarrow Y$ for two Gaussian variables with linear relation?
      Solution
      Both models can produce any bivariate Gaussian (choose coefficient and noise variances accordingly); the two-variable joint has no independence constraints to differ on, and the Gaussian's symmetry kills functional-form asymmetries. Markov-equivalent, functionally symmetric: a coin flip.
    2. MED Explain the LiNGAM asymmetry: why does non-Gaussian noise break the tie?
      Solution
      If truly $Y = \beta X + N$ with $N \perp X$ and non-Gaussian ingredients, then regressing the wrong way, $X = \gamma Y + \tilde N$, leaves a residual $\tilde N$ that is a linear mixture of $X$'s and $N$'s variation — and by the Darmois–Skitovich theorem, such a mixture can be independent of the regressor only in the Gaussian case. So test both directions: the direction with independent residuals is causal. Gaussianity is the singular symmetric point; any skew or kurtosis is directional signal — ICA's insight repurposed.
    3. HARD How many interventions are needed, worst case, to fully orient a Markov equivalence class over $n$ variables — and why do randomized single-node interventions help so much?
      Solution
      An intervention on node $S$ orients every edge incident to... a single-node intervention on $X_i$ cuts its in-edges: comparing the interventional to observational distributions orients all edges at $X_i$ (edges into vs out of it distinguish by whether the neighbor's dependence survives), and Meek's rules propagate orientations further. In the worst case (e.g. a complete graph, whose equivalence class contains all orderings), $\lceil \log_2 n \rceil$ well-chosen multi-node interventions suffice (split-and-orient by halves), while single-node strategies need up to $n - 1$; general graphs need $O(\log n)$-ish targeted experiments guided by the current CPDAG. The practical headline: a handful of experiments, placed where the equivalence class is ambiguous, converts observational near-knowledge into full structure — experiment design as information maximization over graphs. ∎

    Causal representation learning

    Deep learning's variables are pixels and tokens; causality's variables are objects, forces, intentions. Causal representation learning aims to close that gap: learn, from raw high-dimensional data, latent variables that are the causal ones — modular mechanisms that recombine under intervention and shift. It is where this chapter and Chs 21/29 shake hands, and it is largely open.

    Definition Goal: from observations $x = g(z)$ generated by unknown latents $z$ with SCM structure among them, recover (up to tolerable ambiguity) the latents and their causal graph. Known obstruction: unsupervised disentanglement is non-identifiable from i.i.d. data alone (Locatello et al. 2019 — infinitely many entangled solutions fit equally well); identifiability returns with extra structure: multiple environments/interventions, temporal dynamics, sparse mechanism shifts, or weak supervision (paired data, labels).
    Worked example Invariant risk: predict $Y$ from features across environments $e \in \{$hospitals$\}$. Spurious feature $S$ (scanner brand) correlates with $Y$ differently per hospital; causal feature $C$ (tumor morphology) has a stable mechanism $P(Y\mid C)$ everywhere. A predictor using $C$ has the same risk-optimal behavior in every environment; one using $S$ needs different coefficients per environment. Training across just a few environments and demanding one simultaneously-optimal predictor (IRM's principle) rejects $S$ — the causal feature is the invariant one. Multi-environment data operationalizes "mechanism stability" as a learnable objective.
    Where this goes World models with intervention-respecting latents (Ch 29), the compositional-generalization agenda of Ch 36, and the interpretability question of whether a network's internal features are causally manipulable units (Ch 35: activation patching is intervention on representations).
    Drill
    1. EASY Why do i.i.d. pixels underdetermine causal latents?
      Solution
      Any invertible remixing $\tilde z = h(z)$ composed with $\tilde g = g \circ h^{-1}$ produces identical observations; the i.i.d. likelihood cannot prefer disentangled coordinates. Only non-i.i.d. structure — interventions, time, environments — makes causal coordinates distinguishable from their mixtures.
    2. MED The "sparse mechanism shift" hypothesis: state it and how it turns distribution shift from an enemy into a supervisor.
      Solution
      Hypothesis: natural distribution changes (new lighting, a new user cohort, an intervention) alter few causal mechanisms at once, while entangled representations see every such change as global. Supervision signal: prefer representations in which observed shifts are explainable by changing a small number of latent modules. Each environment pair becomes a labeled example of "what varies together" — shift as free annotation of the causal factorization.
    3. HARD Does a next-token predictor trained on rung-1 data acquire rung-2 knowledge? Give one argument each way, and the experimental handle that would decide for a specific model.
      Solution
      Against: the ladder theorem — observational distributions underdetermine interventional ones; a pure density estimator over text has, in principle, no basis for do-questions its corpus doesn't pin down. For: the corpus is not raw observation of the world — it contains descriptions of interventions and their outcomes (experiments, how-tos, code that runs), so the text distribution embeds rung-2 structure of the described world; a model can also be tuned on interactive/agentic data, which is genuinely interventional. The decisive handle is behavioral-causal testing: construct held-out intervention families (novel combinations of mechanisms it has seen separately), compare its predictions with real intervention outcomes, and — internally — use activation patching to test whether the model carries manipulable variables mediating those predictions. The answer is empirical and per-capability, not philosophical: some do-knowledge is in the text, and how much a given model has extracted must be measured, not asserted. ∎

rng = np.random.default_rng(2)
n = 100_000
A = rng.normal(size=n); B = rng.normal(size=n)
Cv = A + B + 0.7*rng.normal(size=n)
D = 1.2*Cv + rng.normal(size=n)
data = {'A': A, 'B': B, 'C': Cv, 'D': D}
names = list(data)

def pcorr(x, y, zs):
    """partial correlation of x,y given list of conditioning arrays"""
    if zs:
        Zm = np.column_stack(zs + [np.ones(n)])
        x = x - Zm @ np.linalg.lstsq(Zm, x, rcond=None)[0]
        y = y - Zm @ np.linalg.lstsq(Zm, y, rcond=None)[0]
    return np.corrcoef(x, y)[0, 1]

def indep(i, j, cond):
    r = pcorr(data[i], data[j], [data[k] for k in cond])
    return abs(r) < 0.01                     # generous threshold at this n

# 1. skeleton: start complete, remove edge if indep given any subset
edges = set(frozenset(p) for p in combinations(names, 2))
seps = {}
for i, j in combinations(names, 2):
    others = [k for k in names if k not in (i, j)]
    for size in range(0, 3):
        found = False
        for cond in combinations(others, size):
            if indep(i, j, list(cond)):
                edges.discard(frozenset((i, j)))
                seps[frozenset((i, j))] = set(cond)
                found = True; break
        if found: break
print('skeleton:', sorted(tuple(sorted(e)) for e in edges))
# expect: A-C, B-C, C-D

# 2. orient v-structures: i - k - j with i,j nonadjacent and k not in sep set
directed = set()
for i, j in combinations(names, 2):
    if frozenset((i, j)) in edges: continue
    for k in names:
        if k in (i, j): continue
        if frozenset((i, k)) in edges and frozenset((j, k)) in edges:
            if k not in seps.get(frozenset((i, j)), set()):
                directed.add((i, k)); directed.add((j, k))
print('v-structure arrows:', sorted(directed))
# expect: ('A','C') and ('B','C')  — i.e. A -> C <- B; C-D stays undirected
# (C -> D vs D -> C is not determined by independencies alone)
