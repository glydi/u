    Relations

    A relation is any collection of pairings between two sets — "is a friend of", "divides", "$x < y$". Formally it is just a subset of a Cartesian product: the set of exactly those pairs for which the relationship holds. Functions will turn out to be relations with one extra discipline.

    Definition A relation $R$ from $A$ to $B$ is a subset $R \subseteq A\times B$; we write $a\,R\,b$ for $(a,b) \in R$. A relation on $A$ is a subset of $A\times A$. Properties on $A$: reflexive ($a\,R\,a$ for all $a$), symmetric ($a\,R\,b \Rightarrow b\,R\,a$), transitive ($a\,R\,b, b\,R\,c \Rightarrow a\,R\,c$).
    Worked example On $A = \{1,2,3\}$, the relation "$<$" is $\{(1,2),(1,3),(2,3)\}$: not reflexive ($1 \not< 1$), not symmetric, transitive ✓. The relation "divides" on $\{1,2,3,4,6\}$ contains $(2,4), (2,6), (3,6), (1, k)$ for all $k$, and every $(k,k)$: reflexive and transitive but not symmetric.
    Drill
    1. EASY Is "$\le$" on $\mathbb{R}$ reflexive? Symmetric? Transitive?
      Solution
      Reflexive ✓ ($x \le x$), transitive ✓, not symmetric ($2 \le 3$ but $3 \not\le 2$).
    2. MED List all pairs in the relation "same parity" on $\{1,2,3,4\}$.
      Solution
      $(1,1),(1,3),(3,1),(3,3)$ and $(2,2),(2,4),(4,2),(4,4)$ — 8 pairs; reflexive, symmetric, transitive.
    3. HARD Give a relation that is symmetric and transitive but not reflexive, and explain why "symmetric + transitive ⟹ reflexive" fails.
      Solution
      The empty relation on $\{1\}$: symmetric and transitive vacuously, but $(1,1) \notin R$. The fake proof "$a\,R\,b \Rightarrow b\,R\,a \Rightarrow a\,R\,a$" silently assumes some $b$ related to $a$ exists.

    Equivalence relations

    An equivalence relation is a rigorous "sameness": reflexive, symmetric, transitive. Its power is that it carves the whole set into disjoint clusters — equivalence classes — where everything in a cluster counts as one object. Fractions ($\tfrac12 \sim \tfrac24$), clock arithmetic, and "same remainder mod $n$" are all this pattern.

    Definition $\sim$ is an equivalence relation if it is reflexive, symmetric and transitive. The class of $a$ is $[a] = \{x : x \sim a\}$. The classes partition the set: they are disjoint and cover everything; conversely every partition defines an equivalence relation.
    Worked example Congruence mod 3 on $\mathbb{Z}$: $a \sim b$ iff $3 \mid (a - b)$. Classes: $[0] = \{\dots,-3,0,3,6,\dots\}$, $[1] = \{\dots,-2,1,4,\dots\}$, $[2] = \{\dots,-1,2,5,\dots\}$. Three classes, disjoint, union $= \mathbb{Z}$ ✓.
    Where this goes "Same label" partitions datasets into classes (Ch 19); "same value under the model" is how embeddings cluster inputs (Ch 21).
    Drill
    1. EASY Is "has the same birthday as" an equivalence relation on people?
      Solution
      Yes — reflexive, symmetric, transitive; the classes are the 366 birthday groups.
    2. MED Show "$|x| = |y|$" is an equivalence on $\mathbb{R}$ and describe the classes.
      Solution
      All three properties follow from $=$ being an equivalence on the values $|x|$. Classes: $\{a, -a\}$ for $a > 0$, and $\{0\}$.
    3. HARD Is "$x - y \in \mathbb{Q}$" an equivalence relation on $\mathbb{R}$?
      Solution
      Yes: $x - x = 0 \in \mathbb{Q}$; $x - y \in \mathbb{Q} \Rightarrow y - x = -(x-y) \in \mathbb{Q}$; sum of rationals is rational for transitivity. Classes are "rational translates": $[\sqrt2] = \{\sqrt2 + q : q \in \mathbb{Q}\}$ — uncountably many classes, each countable.

    Ordered pairs

    An ordered pair $(a, b)$ remembers which item came first — unlike the set $\{a, b\}$. Pairs are the atoms of coordinates, graphs, and datasets: every plotted point, every (input, output) example a model trains on, is an ordered pair.

    Definition $(a, b) = (c, d) \iff a = c$ and $b = d$. (Kuratowski's set-theoretic encoding: $(a,b) := \{\{a\},\{a,b\}\}$ makes pairs out of pure sets.) Tuples generalize: $(a_1, \dots, a_n)$.
    Worked example $(2, 5) \ne (5, 2)$, though $\{2,5\} = \{5,2\}$. Solve $(x + 1,\ 2y) = (4,\ 10)$: equate coordinates: $x = 3$, $y = 5$.
    Drill
    1. EASY For which $x, y$ is $(x, y) = (y, x)$?
      Solution
      Exactly when $x = y$.
    2. MED Solve $(2a - b,\ a + b) = (1,\ 5)$.
      Solution
      $2a - b = 1$, $a + b = 5$. Add: $3a = 6$, $a = 2$, $b = 3$.
    3. HARD Using Kuratowski's definition, show $(a,b) = (c,d) \Rightarrow a = c$ when $a \ne b$.
      Solution
      $\{\{a\},\{a,b\}\} = \{\{c\},\{c,d\}\}$. The singleton $\{a\}$ must equal $\{c\}$ or $\{c,d\}$. If $\{a\} = \{c,d\}$ then $c = d = a$, making both sides $\{\{a\}\}$, forcing $\{a,b\} = \{a\}$, i.e. $a = b$ — excluded. So $\{a\} = \{c\}$, giving $a = c$.

    Function definition

    A function is a relation with a contract: every input gets exactly one output. No input left behind, no input with two answers. That determinism is the whole point — feed the same input twice, get the same output twice. A neural network, however huge, is one function.

    Definition $f : A \to B$ assigns to each $a \in A$ exactly one $f(a) \in B$. As a relation: $f \subseteq A\times B$ such that for every $a\in A$ there is exactly one $b$ with $(a,b) \in f$. $A$ is the domain, $B$ the codomain.
    Worked example On $A = \{1,2,3\}$, $B = \{x,y\}$: $\{(1,x),(2,x),(3,y)\}$ is a function (each input once). $\{(1,x),(1,y),(2,x),(3,x)\}$ is not (1 has two outputs). $\{(1,x),(3,y)\}$ is not (2 is unserved).
    Pitfall "$y^2 = x$" does not define $y$ as a function of $x$: input $x = 4$ has two candidate outputs $\pm2$. Choosing $y = \sqrt x$ (the non-negative root) repairs it — a function requires the choice.
    Drill
    1. EASY Is "each person ↦ their age in years" a function? Is "each person ↦ their sibling"?
      Solution
      Yes — one age each. No — some have none, some several.
    2. MED Does $\{(1,2),(2,2),(3,2)\}$ define a function from $\{1,2,3\}$?
      Solution
      Yes — a constant function. Different inputs may share an output; one input may not have two.
    3. HARD How many functions are there from an $m$-element set to an $n$-element set?
      Solution
      Each of the $m$ inputs independently picks one of $n$ outputs: $n^m$ (product rule from Ch 3).

    Function notation

    $f(x)$ names the output of machine $f$ on input $x$ — the parentheses mean "apply", not "multiply". The declaration $f: \mathbb{R}\to\mathbb{R},\ f(x) = x^2 + 1$ gives the machine's name, its input/output types, and its rule: a full function signature, as in code.

    Definition "$f : A \to B$" declares domain and codomain; "$x \mapsto$ expression" or "$f(x) = $ expression" gives the rule. $f$ is the function; $f(x)$ is a value. Anonymous form: the map $x \mapsto 3x + 1$.
    Worked example If $g(t) = t^2 - 3t$, then $g(5) = 25 - 15 = 10$, $g(-1) = 1 + 3 = 4$, and $g(x + 1) = (x+1)^2 - 3(x+1) = x^2 - x - 2$ — substitute the whole expression wherever $t$ appeared.
    Pitfall $f(a + b) \ne f(a) + f(b)$ in general (true only for linear maps): with $f(x) = x^2$, $f(1+1) = 4$ but $f(1) + f(1) = 2$.
    Drill
    1. EASY $f(x) = 2x - 7$: find $f(0)$, $f(4)$.
      Solution
      $-7$ and $1$.
    2. MED $h(x) = x^2 + 1$: simplify $h(2a) - 2h(a)$.
      Solution
      $4a^2 + 1 - 2a^2 - 2 = 2a^2 - 1$.
    3. HARD $f(x) = \dfrac{1}{1 - x}$: compute $f(f(f(x)))$.
      Solution
      $f(f(x)) = \dfrac{1}{1 - \frac{1}{1-x}} = \dfrac{1-x}{-x} = \dfrac{x-1}{x}$. Then $f\!\left(\tfrac{x-1}{x}\right) = \dfrac{1}{1 - \frac{x-1}{x}} = \dfrac{1}{1/x} = x$. Composing three times returns $x$ — $f$ has order 3.

    Domain

    The domain is the set of inputs the function accepts. When a formula is given without one, the convention is the natural domain: every real input for which the expression computes — no division by zero, no even roots of negatives, no logs of non-positives.

    Definition The domain of $f: A \to B$ is $A$. Natural-domain rules: denominators $\ne 0$; radicands of even roots $\ge 0$; log arguments $> 0$; and combinations intersect the constraints.
    Worked example $f(x) = \dfrac{\sqrt{x + 2}}{x - 3}$: need $x + 2 \ge 0$ (so $x \ge -2$) and $x \ne 3$. Domain: $[-2, 3)\cup(3, \infty)$.
    Drill
    1. EASY Find the domain of $f(x) = \dfrac{1}{x + 5}$.
      Solution
      All reals except $-5$.
    2. MED Find the domain of $g(x) = \ln(2x - 6)$.
      Solution
      $2x - 6 > 0$: $(3, \infty)$.
    3. HARD Find the domain of $h(x) = \sqrt{\dfrac{x-1}{x+2}}$.
      Solution
      Need the fraction $\ge 0$ and $x \ne -2$. Sign chart: both factors positive when $x \ge 1$; both negative when $x < -2$. Domain: $(-\infty, -2)\cup[1, \infty)$.

    Range

    The range is the set of outputs actually hit — possibly smaller than the codomain, the set of outputs merely allowed. Finding a range means asking: for which $y$ does $f(x) = y$ have a solution? It is the "solve for $x$" question turned inside out.

    Definition $\operatorname{range}(f) = \{f(a) : a \in A\} \subseteq B$ (also called the image). $f$ is surjective exactly when range $=$ codomain.
    Worked example $f(x) = x^2 - 4x + 7 = (x-2)^2 + 3$: since $(x-2)^2 \ge 0$ takes every value $\ge 0$, the range is $[3, \infty)$. Completing the square exposed the minimum.
    Drill
    1. EASY Range of $f(x) = |x| + 2$?
      Solution
      $[2, \infty)$.
    2. MED Range of $g(x) = \dfrac{1}{x^2 + 1}$?
      Solution
      $x^2 + 1 \in [1, \infty)$, so $g \in (0, 1]$ — maximum 1 at $x=0$, approaching 0 but never reaching it.
    3. HARD Range of $f(x) = \dfrac{2x + 1}{x - 1}$?
      Solution
      Set $y = \tfrac{2x+1}{x-1}$, solve for $x$: $y(x - 1) = 2x + 1 \Rightarrow x(y - 2) = y + 1 \Rightarrow x = \tfrac{y+1}{y-2}$ — solvable for every $y \ne 2$. Range: $\mathbb{R}\setminus\{2\}$ (2 is the horizontal asymptote).

    Independent variables

    The independent variable is the input — the quantity you choose freely, plotted on the horizontal axis. In an experiment it is what you control (dose, learning rate); the function then dictates everything downstream.

    Definition In $y = f(x)$, $x$ is the independent variable: it ranges over the domain, unconstrained by the function. Multivariable functions have several: $z = f(x, y)$.
    Worked example Training cost $C(h) = 12 + 3.5h$ for $h$ GPU-hours: $h$ is independent — you decide how long to train; $C$ merely responds. On a plot, $h$ runs along the $x$-axis.
    Drill
    1. EASY In "reaction time as a function of caffeine dose", which is independent?
      Solution
      Caffeine dose.
    2. MED In $A(r) = \pi r^2$, what is the independent variable and its natural domain in context?
      Solution
      The radius $r$, with $r \ge 0$ (or $r > 0$ for an actual circle) — context restricts beyond algebra.
    3. HARD Loss depends on learning rate and batch size: $L = f(\eta, B)$. When you plot $L$ vs $\eta$ at fixed $B = 32$, what happened to the variables?
      Solution
      $\eta$ stays independent; $B$ was frozen into a constant (a parameter). Slicing a multivariable function at a fixed value of one input yields a one-variable function per slice.

    Dependent variables

    The dependent variable is the output — its value depends on the input through the rule. It is what you measure rather than set, and it lives on the vertical axis. One dependent value per input: that is the function contract restated.

    Definition In $y = f(x)$, $y$ is the dependent variable: determined once $x$ is chosen. Changing notation ($y$, $f(x)$, output, response, label) never changes the role.
    Worked example For $y = 3x + 2$: choose $x = 4$ (free) and $y = 14$ is forced. You cannot independently demand $x = 4$ and $y = 10$ — the second is not yours to choose.
    Drill
    1. EASY In $d = 60t$ (distance at 60 km/h), which variable is dependent?
      Solution
      $d$ — it responds to the chosen time $t$.
    2. MED Can two different inputs give the same dependent value? Can one input give two?
      Solution
      Yes (e.g. $x^2$ at $\pm2$); no — that would break the function contract.
    3. HARD In supervised learning, data comes as pairs $(x_i, y_i)$. In what sense is $y$ "dependent" if the data is noisy?
      Solution
      The model assumes $y_i = f(x_i) + \varepsilon_i$: a deterministic dependence plus noise. The learned function predicts the deterministic part; "dependent" refers to the target's modeled dependence on the input, not exact determinism. (Ch 11 makes $\varepsilon$ precise; Ch 19 fits $f$.)

    Function evaluation

    Evaluation runs the machine: substitute the input everywhere the variable appears, then compute with the order of operations. The input can itself be an expression, another function's output, or the variable plus a nudge — the substitution rule never changes: replace every occurrence, wrapped in parentheses.

    Definition To evaluate $f$ at $a$: textually substitute $(a)$ for the variable in $f$'s rule, then simplify. The difference quotient $\dfrac{f(x+h) - f(x)}{h}$ is the evaluation pattern to master now.
    Worked example $f(x) = x^2 - 3x$: compute $\dfrac{f(x+h) - f(x)}{h}$. $f(x+h) = x^2 + 2xh + h^2 - 3x - 3h$. Subtract $f(x)$: $2xh + h^2 - 3h$. Divide by $h$: $2x + h - 3$. (As $h \to 0$ this becomes the derivative $2x - 3$ — Ch 7.)
    Pitfall $f(x + h) \neq f(x) + h$ and $\neq f(x) + f(h)$. Substitute, don't distribute the function symbol.
    Drill
    1. EASY $f(x) = 5 - 2x^2$: find $f(-3)$.
      Solution
      $5 - 2(9) = -13$.
    2. MED $g(x) = \dfrac{x}{x+1}$: find $g\!\left(\dfrac{1}{t}\right)$ simplified.
      Solution
      $\dfrac{1/t}{1/t + 1} = \dfrac{1}{1 + t}$ (multiply top and bottom by $t$; requires $t \ne 0, -1$).
    3. HARD $f(x) = \dfrac1x$: simplify the difference quotient $\dfrac{f(x+h)-f(x)}{h}$.
      Solution
      $\dfrac{\frac{1}{x+h} - \frac1x}{h} = \dfrac{\frac{x - (x+h)}{x(x+h)}}{h} = \dfrac{-h}{h\,x(x+h)} = \dfrac{-1}{x(x+h)}$.

    Function graphs

    The graph of $f$ is the set of all points $(x, f(x))$ — the function drawn as a curve. It converts algebra into geometry: solving $f(x) = 0$ becomes finding axis crossings; solving $f(x) = g(x)$ becomes finding intersections; the function's whole personality is visible at a glance.

    Definition $\operatorname{graph}(f) = \{(x, f(x)) : x \in \operatorname{dom} f\} \subseteq \mathbb{R}^2$. A point $(a,b)$ lies on the graph iff $f(a) = b$.
    Worked example Does $(2, 5)$ lie on the graph of $f(x) = x^2 + 1$? $f(2) = 5$ ✓ yes. Does $(3, 8)$? $f(3) = 10 \ne 8$ — no. Membership is one evaluation.
    Drill
    1. EASY Where does the graph of $f(x) = 2x - 6$ cross the $x$-axis?
      Solution
      Where $f(x) = 0$: $x = 3$, the point $(3, 0)$.
    2. MED From a graph, how do you read off $f(2)$ and solve $f(x) = 1$?
      Solution
      $f(2)$: go to $x = 2$, read the height. $f(x) = 1$: draw the horizontal line $y = 1$, read the $x$-coordinates of every intersection.
    3. HARD The graphs of $f(x) = x^2$ and $g(x) = x + 2$ intersect where?
      Solution
      $x^2 = x + 2 \Rightarrow x^2 - x - 2 = (x-2)(x+1) = 0$: points $(2, 4)$ and $(-1, 1)$.

    Vertical line test

    A curve is the graph of a function exactly when no vertical line hits it twice — because two hits on the line $x = a$ would mean input $a$ has two outputs. The test is the function contract made visible.

    Definition A set $S \subseteq \mathbb{R}^2$ is a function's graph iff for every $a$, the vertical line $x = a$ meets $S$ in at most one point.
    Worked example The unit circle $x^2 + y^2 = 1$ fails: the line $x = 0$ hits $(0, 1)$ and $(0, -1)$. Splitting into upper half $y = \sqrt{1 - x^2}$ and lower half $y = -\sqrt{1-x^2}$ yields two genuine functions.
    Drill
    1. EASY Is a horizontal straight line a function's graph? A vertical one?
      Solution
      Horizontal: yes (constant function). Vertical: no — one input, infinitely many outputs.
    2. MED Does $x = y^2$ define $y$ as a function of $x$? Does it define $x$ as a function of $y$?
      Solution
      No ($x = 4$ gives $y = \pm2$); yes — each $y$ gives exactly one $x = y^2$. Which variable is "input" decides.
    3. HARD A curve passes the vertical line test. Must every horizontal line hit it at most once too?
      Solution
      No — that is the horizontal line test, testing injectivity, a separate property. $y = x^2$ passes vertical, fails horizontal at $y = 4$ (hit by $x = \pm2$).

    One-to-one functions & injective functions (merged: two names, one property)

    A function is one-to-one (injective) when distinct inputs always produce distinct outputs — no collisions. Injective functions forget nothing: the output uniquely identifies the input, which is exactly what makes them invertible on their range. Graphically: every horizontal line hits at most once.

    Definition $f$ is injective iff $f(a) = f(b) \Rightarrow a = b$ (equivalently $a \ne b \Rightarrow f(a) \ne f(b)$). Horizontal line test: each $y$-value is reached at most once. Strictly monotonic functions are injective.
    Worked example $f(x) = 3x - 5$ is injective: $3a - 5 = 3b - 5 \Rightarrow a = b$. $g(x) = x^2$ on $\mathbb{R}$ is not: $g(2) = g(-2) = 4$. Restricted to $[0, \infty)$, $g$ becomes injective — domains matter.
    Where this goes Injectivity = invertibility on the image: the foundation of inverse functions below, of normalizing flows (Ch 22), and of "no information lost" arguments in Ch 16.
    Drill
    1. EASY Is $f(x) = x^3$ injective on $\mathbb{R}$?
      Solution
      Yes: $a^3 = b^3 \Rightarrow a = b$ (cube roots are unique for reals); strictly increasing.
    2. MED Is $f(x) = \dfrac{x}{x^2 + 1}$ injective on $\mathbb{R}$?
      Solution
      No: $f(2) = \tfrac25$ and $f(1/2) = \tfrac{1/2}{5/4} = \tfrac25$. (In general $f(x) = f(1/x)$.)
    3. HARD Prove: if $g \circ f$ is injective then $f$ is injective. Must $g$ be?
      Solution
      If $f(a) = f(b)$ then $g(f(a)) = g(f(b))$, and injectivity of $g\circ f$ forces $a = b$. $g$ need not be: $f(x) = e^x$ into $g(x) = x^2$ has $g\circ f = e^{2x}$ injective while $g$ is not — $g$ only needs to be injective on the range of $f$.

    Many-to-one functions

    Many-to-one is the opposite failure-of-forgetting: several inputs collapse to the same output. Perfectly legal — most functions are like this — but irreversible: from the output alone you cannot recover the input. Hash functions, classifiers, and $x^2$ all deliberately live here.

    Definition $f$ is many-to-one if some output has multiple preimages: $\exists a \ne b$ with $f(a) = f(b)$. The preimage of $y$ is $f^{-1}(\{y\}) = \{x : f(x) = y\}$ — a set, possibly large.
    Worked example $f(x) = x^2$: preimage of 9 is $\{-3, 3\}$; of 0 is $\{0\}$; of $-4$ is $\emptyset$. A classifier mapping images to "cat"/"dog" sends millions of images to two labels — many-to-one by design, and that is why you cannot reconstruct the image from the label.
    Drill
    1. EASY Is $f(x) = |x|$ many-to-one?
      Solution
      Yes: $f(3) = f(-3)$.
    2. MED Find the preimage of 5 under $f(x) = x^2 + 1$.
      Solution
      $x^2 = 4$: $\{-2, 2\}$.
    3. HARD $f: \{1,\dots,10\} \to \{1,2,3\}$. Show some output has at least 4 preimages.
      Solution
      Pigeonhole: 10 inputs into 3 outputs, some output receives $\lceil 10/3\rceil = 4$. Many-to-one-ness is forced whenever the domain outnumbers the codomain.

    Surjective functions

    A function is surjective (onto) when it covers its whole codomain: every allowed output actually happens. Surjectivity depends on the declared codomain — the same rule can be onto one codomain and not another — which is why the codomain declaration matters.

    Definition $f: A \to B$ is surjective iff for every $b \in B$ there is some $a \in A$ with $f(a) = b$; equivalently $\operatorname{range}(f) = B$.
    Worked example $f(x) = x^2$ as $\mathbb{R}\to\mathbb{R}$: not surjective ($-1$ unreached). As $\mathbb{R}\to[0,\infty)$: surjective — every $y \ge 0$ is $f(\sqrt y)$. Same rule, different verdicts.
    Drill
    1. EASY Is $f(x) = x + 1$ surjective as $\mathbb{Z}\to\mathbb{Z}$?
      Solution
      Yes: any $b$ is hit by $a = b - 1$.
    2. MED Is $f(x) = e^x$ surjective as $\mathbb{R}\to\mathbb{R}$? As $\mathbb{R}\to(0,\infty)$?
      Solution
      No — outputs are strictly positive. Yes — every $y > 0$ equals $e^{\ln y}$.
    3. HARD $f: \mathbb{N}\to\mathbb{N}$, $f(n) = \lceil n/2 \rceil$. Injective? Surjective?
      Solution
      Not injective: $f(1) = f(2) = 1$. Surjective: any $m$ is $f(2m)$. A function can be onto while collapsing — compression with full coverage.

    Bijective functions

    Bijective = injective + surjective: every output hit exactly once. A bijection is a perfect pairing between two sets — a lossless relabeling — and it is exactly the condition for a full two-sided inverse to exist. Bijections are also how set sizes are compared, finite or infinite (Ch 3's countability).

    Definition $f: A \to B$ is bijective iff every $b \in B$ has exactly one preimage. Then $f^{-1}: B \to A$ exists with $f^{-1}(f(a)) = a$ and $f(f^{-1}(b)) = b$. Finite sets admit a bijection iff they have equal cardinality.
    Worked example $f(x) = 2x + 3$ on $\mathbb{R}$: injective (slope $\ne 0$), surjective (solve $y = 2x+3$: $x = \tfrac{y-3}{2}$ always works) — bijective, with inverse $f^{-1}(y) = \tfrac{y-3}{2}$.
    Think first Can a finite set have a bijection with a proper subset of itself? An infinite set?
    Reveal
    Finite: no — a proper subset has strictly fewer elements. Infinite: yes — $n \mapsto 2n$ bijects $\mathbb{N}$ with the even numbers. This is Dedekind's definition of infinite.
    Drill
    1. EASY Is $f(x) = x^3$ a bijection $\mathbb{R}\to\mathbb{R}$?
      Solution
      Yes: strictly increasing (injective) and every real has a cube root (surjective).
    2. MED How many bijections are there from a 5-element set to itself?
      Solution
      $5! = 120$ — bijections of a set to itself are exactly permutations.
    3. HARD Show $f(x) = \dfrac{x}{1 + |x|}$ is a bijection $\mathbb{R}\to(-1, 1)$.
      Solution
      Outputs lie in $(-1,1)$ since $|x| < 1 + |x|$. Injective: $f$ is strictly increasing (for $x\ge0$, $\tfrac{x}{1+x}$ increases; odd symmetry handles $x<0$). Surjective: given $y \in (0,1)$ solve $y = \tfrac{x}{1+x}$: $x = \tfrac{y}{1-y} > 0$; $y=0 \mapsto x=0$; negative $y$ by symmetry. Whole infinite line, squeezed bijectively into a bounded interval.

    Linear functions

    A linear function changes at a constant rate: equal steps in $x$ produce equal steps in $y$, so the graph is a straight line. Two numbers pin it down completely — the rate (slope) and one anchor point. It is the simplest nontrivial model, and the local approximation of every smooth function.

    Definition $f(x) = mx + b$: slope $m$, $y$-intercept $b$. (Strictly, algebraists call this affine; "linear" in the vector-space sense of Ch 8 requires $b = 0$, so that $f(x+y) = f(x) + f(y)$.)
    Worked example $f(x) = 2x + 1$: inputs $0, 1, 2, 3$ give outputs $1, 3, 5, 7$ — each unit step in $x$ adds exactly 2. Constant differences are the fingerprint of linearity in a data table.
    Explore

    Slide $m$ and $b$; watch the line pivot (slope) and glide (intercept), with the rise/run triangle drawn.

    Drill
    1. EASY For $f(x) = -3x + 7$: slope and $y$-intercept?
      Solution
      $m = -3$, intercept $(0, 7)$.
    2. MED A table gives $f(1) = 5$, $f(4) = 17$. Assuming linearity, find $f(x)$.
      Solution
      $m = \tfrac{17-5}{4-1} = 4$; $f(x) = 5 + 4(x - 1) = 4x + 1$.
    3. HARD Show a linear function with $m \ne 0$ is a bijection $\mathbb{R}\to\mathbb{R}$.
      Solution
      Injective: $ma + b = mc + b \Rightarrow m(a - c) = 0 \Rightarrow a = c$ since $m \ne 0$. Surjective: $y = mx + b$ solves to $x = \tfrac{y - b}{m}$ for every $y$. Hence bijective, inverse $f^{-1}(y) = \tfrac{y-b}{m}$.

    Slope

    Slope is rise over run: how much $y$ changes per unit of $x$. It is the same for any two points on a line — that constancy is straightness. Positive slopes climb, negative slopes fall, zero is flat, and undefined (vertical) means "not a function of $x$ at all."

    Definition Through $(x_1, y_1)$ and $(x_2, y_2)$ with $x_1 \ne x_2$: $\;m = \dfrac{y_2 - y_1}{x_2 - x_1} = \dfrac{\Delta y}{\Delta x}$.
    Worked example Through $(-1, 4)$ and $(3, -2)$: $m = \dfrac{-2 - 4}{3 - (-1)} = \dfrac{-6}{4} = -\dfrac32$. Every 2 steps right, drop 3.
    Where this goes The derivative (Ch 7) is slope localized to a point; the gradient (Ch 9) is slope in many directions; gradient descent (Ch 15) walks against it.
    Drill
    1. EASY Slope through $(0,0)$ and $(4, 6)$?
      Solution
      $\tfrac64 = \tfrac32$.
    2. MED A line has slope $\tfrac25$ and passes through $(10, 3)$. What is $y$ at $x = 25$?
      Solution
      $\Delta x = 15$, so $\Delta y = \tfrac25 \cdot 15 = 6$: $y = 9$.
    3. HARD Points $(2, 5)$, $(4, 9)$, $(7, k)$ are collinear. Find $k$.
      Solution
      Slope from first two: $\tfrac{9-5}{4-2} = 2$. Collinearity: $\tfrac{k - 9}{7 - 4} = 2 \Rightarrow k = 15$.

    Slope-intercept form

    $y = mx + b$ is the line solved for $y$: slope and starting height displayed on the surface. It is the form for graphing (start at $b$, step by $m$) and for reading a line's behavior at a glance.

    Definition $y = mx + b$: slope $m$, and $b = $ the $y$-coordinate where the line crosses $x = 0$. Any non-vertical line has exactly one such form.
    Worked example Put $3x + 2y = 12$ in slope-intercept form: $2y = -3x + 12 \Rightarrow y = -\tfrac32 x + 6$. Slope $-\tfrac32$, intercept $(0,6)$ — invisible in the original, obvious now.
    Drill
    1. EASY Graph data: slope 2, $y$-intercept $-3$. Write the equation.
      Solution
      $y = 2x - 3$.
    2. MED Rewrite $x - 4y + 8 = 0$ in slope-intercept form.
      Solution
      $4y = x + 8 \Rightarrow y = \tfrac14 x + 2$.
    3. HARD For which $b$ does $y = 2x + b$ pass at distance exactly $\sqrt5$ from the origin?
      Solution
      Distance from $(0,0)$ to $2x - y + b = 0$ is $\tfrac{|b|}{\sqrt{2^2 + 1}} = \tfrac{|b|}{\sqrt5} = \sqrt5 \Rightarrow |b| = 5$: $b = \pm5$.

    Point-slope form

    Know one point and the slope? Then the line is $y - y_1 = m(x - x_1)$ — a direct transcription of the slope formula. It is the fastest route from data to equation, and the form in which tangent lines (Ch 7) are always born.

    Definition The line through $(x_1, y_1)$ with slope $m$: $\;y - y_1 = m(x - x_1)$.
    Worked example Line through $(2, -1)$ and $(5, 8)$: $m = \tfrac{8 - (-1)}{5 - 2} = 3$. Point-slope with $(2,-1)$: $y + 1 = 3(x - 2)$, i.e. $y = 3x - 7$. Using $(5, 8)$ instead: $y - 8 = 3(x - 5)$ — same line, different dress.
    Drill
    1. EASY Write the line through $(1, 4)$ with slope $-2$.
      Solution
      $y - 4 = -2(x - 1)$, i.e. $y = -2x + 6$.
    2. MED Find where the line through $(3, 2)$ with slope $\tfrac12$ crosses the $x$-axis.
      Solution
      $0 - 2 = \tfrac12(x - 3) \Rightarrow x = -1$: the point $(-1, 0)$.
    3. HARD A curve has tangent line at $(4, 5)$ with slope $\tfrac34$. Use it to estimate the curve's value at $x = 4.2$.
      Solution
      Tangent: $y = 5 + \tfrac34(x - 4)$. At $4.2$: $y = 5 + 0.15 = 5.15$. This is linear approximation (Ch 7) — point-slope as a prediction machine.

    Standard form

    Standard form $Ax + By = C$ treats $x$ and $y$ symmetrically and can express every line, vertical ones included — the one thing $y = mx + b$ cannot do. It is also the natural shape for systems of equations and for reading off intercepts by zeroing a variable.

    Definition $Ax + By = C$ with $A, B$ not both 0. Slope $= -\tfrac{A}{B}$ (if $B \ne 0$); $x$-intercept $\tfrac{C}{A}$, $y$-intercept $\tfrac{C}{B}$. Vertical line: $B = 0$ (e.g. $x = 3$).
    Worked example $4x + 3y = 24$: set $y = 0$: $x$-intercept $(6, 0)$; set $x = 0$: $y$-intercept $(0, 8)$. Two intercepts, one ruler — the fastest graph in the west. Slope: $-\tfrac43$.
    Drill
    1. EASY Write $y = \tfrac23 x - 4$ in standard form with integer coefficients.
      Solution
      $3y = 2x - 12 \Rightarrow 2x - 3y = 12$.
    2. MED Which lines can standard form express that slope-intercept cannot?
      Solution
      Vertical lines $x = c$ ($A = 1, B = 0$): infinite slope breaks $y = mx + b$.
    3. HARD A budget: CPU hours cost \$2, GPU hours \$5, total \$100. Write the constraint, its intercepts, and interpret the slope.
      Solution
      $2c + 5g = 100$. Intercepts: $(50, 0)$ (all CPU) and $(0, 20)$ (all GPU). Slope $\tfrac{dg}{dc} = -\tfrac25$: each extra CPU hour costs $\tfrac25$ of a GPU hour — the exchange rate along the budget line (the first "feasible set boundary" of Ch 15).

    Intercepts

    Intercepts are where a graph touches the axes: $y$-intercept at $x = 0$ (the "starting value"), $x$-intercepts where $f(x) = 0$ (the roots). They are the first features to compute when sketching anything, and often the most meaningful numbers in a model — initial cost, break-even point.

    Definition $y$-intercept: the point $(0, f(0))$ — at most one for a function. $x$-intercepts: all points $(r, 0)$ with $f(r) = 0$ — possibly many or none.
    Worked example $f(x) = x^2 - x - 6$: $y$-intercept $f(0) = -6$. Roots: $(x-3)(x+2) = 0$ at $x = 3, -2$. Three axis touchings: $(0,-6), (3,0), (-2,0)$ — the skeleton of the parabola's sketch.
    Drill
    1. EASY Intercepts of $y = 3x - 9$?
      Solution
      $y$: $(0, -9)$; $x$: $(3, 0)$.
    2. MED Intercepts of $f(x) = \dfrac{x - 2}{x + 1}$?
      Solution
      $y$: $f(0) = -2$, point $(0,-2)$. $x$: numerator zero, $x = 2$ (and $x=2$ is in the domain): $(2, 0)$.
    3. HARD Can a function have two $y$-intercepts? Can it have zero $x$-intercepts but negative values?
      Solution
      No — two $y$-intercepts means input 0 has two outputs, violating the function contract. Yes to the second: $f(x) = -1 - x^2$ is always negative and never zero — no $x$-intercepts, all values below the axis.

    Parallel lines

    Parallel lines have the same slope and never meet: same direction, different offset. In systems language they are the "no solution" case; in modeling they are quantities changing at identical rates from different baselines.

    Definition Non-vertical lines are parallel iff their slopes are equal (and intercepts differ; equal intercepts too means they coincide). All vertical lines are mutually parallel.
    Worked example Line through $(1, 2)$ parallel to $y = 3x - 5$: same slope 3, point-slope: $y - 2 = 3(x - 1)$, i.e. $y = 3x - 1$.
    Drill
    1. EASY Are $y = 2x + 1$ and $4x - 2y = 6$ parallel?
      Solution
      Second: $y = 2x - 3$. Same slope 2, different intercepts: parallel ✓.
    2. MED Find $k$ so that $kx + 3y = 1$ is parallel to $y = 4x + 7$.
      Solution
      Slope of first: $-\tfrac{k}{3} = 4 \Rightarrow k = -12$.
    3. HARD Show the distance between parallel lines $y = mx + b_1$ and $y = mx + b_2$ is $\dfrac{|b_1 - b_2|}{\sqrt{1 + m^2}}$.
      Solution
      Take the point $(0, b_1)$ on line 1. Distance to $mx - y + b_2 = 0$ is $\dfrac{|m\cdot0 - b_1 + b_2|}{\sqrt{m^2 + 1}} = \dfrac{|b_2 - b_1|}{\sqrt{1 + m^2}}$. The vertical gap $|b_1 - b_2|$ shrinks by the tilt factor.

    Perpendicular lines

    Perpendicular lines meet at a right angle; their slopes multiply to $-1$. The rule comes from rotating a direction 90°: run becomes rise and rise becomes negative run, so slope $m$ becomes $-\tfrac1m$ — the negative reciprocal.

    Definition Non-vertical lines with slopes $m_1, m_2$ are perpendicular iff $m_1 m_2 = -1$. A vertical line is perpendicular to every horizontal line.
    Worked example Line through $(4, 1)$ perpendicular to $y = -\tfrac23x + 5$: new slope $= \tfrac32$ (negative reciprocal of $-\tfrac23$). Equation: $y - 1 = \tfrac32(x - 4)$, i.e. $y = \tfrac32 x - 5$.
    Where this goes Perpendicularity generalizes to orthogonality of vectors via the dot product (Ch 5, Ch 8) — the geometric heart of projections and least squares.
    Drill
    1. EASY Slope perpendicular to $m = 5$?
      Solution
      $-\tfrac15$.
    2. MED Are the lines $3x + 4y = 8$ and $8x - 6y = 1$ perpendicular?
      Solution
      Slopes $-\tfrac34$ and $\tfrac{8}{6} = \tfrac43$. Product $= -1$ ✓ perpendicular.
    3. HARD Find the foot of the perpendicular from $(3, 7)$ to $y = 2x - 1$.
      Solution
      Perpendicular through $(3,7)$: slope $-\tfrac12$: $y = 7 - \tfrac12(x - 3)$. Intersect: $2x - 1 = 7 - \tfrac12 x + \tfrac32 \Rightarrow \tfrac52 x = \tfrac{19}{2} \Rightarrow x = \tfrac{19}{5}$, $y = 2\cdot\tfrac{19}{5} - 1 = \tfrac{33}{5}$. Foot: $\left(\tfrac{19}{5}, \tfrac{33}{5}\right)$ — the nearest point on the line, a baby projection.

    Quadratic functions

    A quadratic function $f(x) = ax^2 + bx + c$ bends: its rate of change itself changes at a constant rate. The graph is a parabola — the shape of thrown balls, satellite dishes, and every smooth function near its minimum, which is why quadratics rule optimization.

    Definition $f(x) = ax^2 + bx + c$, $a \ne 0$. Opens up if $a > 0$, down if $a < 0$. Vertex at $x = -\tfrac{b}{2a}$; axis of symmetry $x = -\tfrac{b}{2a}$; range $[f(-\tfrac{b}{2a}), \infty)$ for $a > 0$.
    Worked example $f(x) = 2x^2 - 8x + 5$: vertex at $x = \tfrac{8}{4} = 2$, $f(2) = 8 - 16 + 5 = -3$. Opens up, so minimum value $-3$; range $[-3, \infty)$; symmetric about $x = 2$: $f(1) = f(3) = -1$ ✓.
    Where this goes Near a minimum, every smooth loss looks quadratic (Taylor, Ch 7/9); Newton's method (Ch 15) exploits exactly this.
    Drill
    1. EASY Vertex of $f(x) = x^2 - 6x + 11$?
      Solution
      $x = 3$, $f(3) = 9 - 18 + 11 = 2$: vertex $(3, 2)$.
    2. MED Maximum of $f(x) = -3x^2 + 12x - 7$?
      Solution
      $x = \tfrac{-12}{-6} = 2$, $f(2) = -12 + 24 - 7 = 5$. Opens down: maximum 5.
    3. HARD A farmer has 60 m of fence for a rectangular pen against a wall (no fence on the wall side). Maximize the area.
      Solution
      Sides $x, x$ (perpendicular) and $60 - 2x$ (parallel). Area $A(x) = x(60 - 2x) = -2x^2 + 60x$: vertex $x = 15$, $A = 15 \cdot 30 = 450$ m². Dimensions $15 \times 30$.

    Vertex form

    Vertex form $a(x - h)^2 + k$ names the parabola by its most important point: the vertex $(h, k)$, with $a$ setting width and direction. Converting to it is completing the square; reading from it is instant — the entire graph is "the standard parabola, shifted to $(h,k)$, stretched by $a$."

    Definition $f(x) = a(x - h)^2 + k$ has vertex $(h, k)$, axis $x = h$, extreme value $k$ (min if $a>0$, max if $a<0$). Expand to recover standard form; complete the square to get here.
    Worked example $f(x) = x^2 + 10x + 18 = (x^2 + 10x + 25) - 25 + 18 = (x + 5)^2 - 7$. Vertex $(-5, -7)$, minimum $-7$, axis $x = -5$.
    Pitfall The sign flip: $(x + 5)^2$ means $h = -5$, not $+5$. Vertex form is $(x - h)^2$; match signs carefully.
    Drill
    1. EASY Vertex of $f(x) = 3(x - 2)^2 + 1$?
      Solution
      $(2, 1)$, opening up, min value 1.
    2. MED Convert $f(x) = 2x^2 + 4x - 1$ to vertex form.
      Solution
      $2(x^2 + 2x) - 1 = 2\big((x+1)^2 - 1\big) - 1 = 2(x+1)^2 - 3$. Vertex $(-1, -3)$.
    3. HARD Find the quadratic with vertex $(3, -2)$ passing through $(5, 6)$.
      Solution
      $f(x) = a(x-3)^2 - 2$; at $x = 5$: $4a - 2 = 6 \Rightarrow a = 2$. $f(x) = 2(x-3)^2 - 2 = 2x^2 - 12x + 16$.

    Parabolas

    A parabola is the graph of a quadratic — and also, geometrically, the set of points equidistant from a focus point and a directrix line. That reflective definition is why satellite dishes and headlights are parabolic: rays parallel to the axis all bounce through the focus.

    Definition $y = \tfrac{1}{4p}x^2$ is the parabola with vertex at the origin, focus $(0, p)$ and directrix $y = -p$: each point is equidistant from focus and directrix. General quadratics are translations/stretches of this.
    Worked example $y = \tfrac18 x^2$: $\tfrac{1}{4p} = \tfrac18 \Rightarrow p = 2$: focus $(0, 2)$, directrix $y = -2$. Check point $(4, 2)$: distance to focus $= \sqrt{16 + 0} = 4$; distance to directrix $= 2 - (-2) = 4$ ✓.
    Drill
    1. EASY Which way do $y = -2x^2$ and $x = y^2$ open?
      Solution
      Down; rightward (the second is not a function of $x$).
    2. MED Find the focus of $y = x^2$.
      Solution
      $\tfrac{1}{4p} = 1 \Rightarrow p = \tfrac14$: focus $\left(0, \tfrac14\right)$, directrix $y = -\tfrac14$.
    3. HARD A dish antenna is 2 m wide and 0.25 m deep. Where is the focus?
      Solution
      Rim point $(1, 0.25)$ on $y = \tfrac{1}{4p}x^2$: $0.25 = \tfrac{1}{4p} \Rightarrow p = 1$. Focus 1 m above the vertex — receivers hang exactly there.

    Polynomial functions

    Polynomials are sums of power terms — the functions you can compute with only + and ×. Degree controls their large-scale destiny: the leading term takes over as $|x|$ grows, while the lower terms sculpt the wiggles in the middle. Smooth, flexible, and dense among continuous functions: the original universal approximators.

    Definition $p(x) = a_nx^n + \cdots + a_1 x + a_0$, $a_n \ne 0$: degree $n$, leading coefficient $a_n$. End behavior: $p(x) \sim a_n x^n$ as $x \to \pm\infty$. A degree-$n$ polynomial has at most $n$ real roots and at most $n - 1$ turning points.
    Worked example $p(x) = -2x^3 + 5x^2 + 4$: degree 3, leading term $-2x^3$. As $x\to\infty$, $p \to -\infty$; as $x \to -\infty$, $p \to +\infty$ (odd degree, negative leader: falls right, rises left).
    Drill
    1. EASY End behavior of $p(x) = x^4 - 100x^3$?
      Solution
      Even degree, positive leader: $p \to +\infty$ on both ends (the $-100x^3$ loses eventually — at $x = 100$ they tie).
    2. MED Can a degree-4 polynomial have exactly 3 real roots?
      Solution
      Yes — one root doubled: e.g. $x^2(x-1)(x-2)$ has roots $0$ (multiplicity 2), $1$, $2$: three distinct.
    3. HARD A cubic satisfies $p(0)=1, p(1)=2, p(-1)=6, p(2)=3$. Find it.
      Solution
      $p = ax^3+bx^2+cx+d$; $d = 1$. $a+b+c = 1$; $-a+b-c = 5$; $8a+4b+2c = 2$. Add first two: $2b = 6, b = 3$. Then $a + c = -2$ and $8a + 2c = -10 \Rightarrow 4a + c = -5$. Subtract: $3a = -3, a = -1$, $c = -1$. $p(x) = -x^3 + 3x^2 - x + 1$. Check $p(2) = -8 + 12 - 2 + 1 = 3$ ✓.

    Polynomial roots

    Roots are where a polynomial vanishes — and by the factor theorem, each root $r$ contributes a factor $(x - r)$. Multiplicity governs the geometry at the crossing: odd multiplicity cuts through the axis, even multiplicity bounces off it.

    Definition $r$ is a root of multiplicity $m$ if $(x - r)^m \mid p(x)$ but $(x-r)^{m+1} \nmid p(x)$. Counting multiplicity, a degree-$n$ polynomial has exactly $n$ complex roots (FTA, Ch 2). Odd $m$: sign change (graph crosses); even $m$: touch without crossing.
    Worked example $p(x) = x(x - 2)^2(x + 1)^3$: roots 0 (cross), 2 (bounce, multiplicity 2), $-1$ (cross with a flattened "inflection" shape, multiplicity 3). Degree $1 + 2 + 3 = 6$ ✓.
    Drill
    1. EASY Roots and multiplicities of $p(x) = (x-1)^2(x+4)$?
      Solution
      $1$ with multiplicity 2 (bounce), $-4$ with multiplicity 1 (cross).
    2. MED Write a degree-3 polynomial with roots $-2, 0, 5$ passing through $(1, 24)$.
      Solution
      $p(x) = a\,x(x+2)(x-5)$; $p(1) = a(1)(3)(-4) = -12a = 24 \Rightarrow a = -2$: $p(x) = -2x(x+2)(x-5)$.
    3. HARD If $p$ has real coefficients, degree 5, and roots $2i$ and $3 - i$, how many real roots does it have?
      Solution
      Conjugates $-2i$ and $3+i$ are also roots: four non-real roots. Degree 5 leaves exactly one more — and it must be real (non-real roots pair up). One real root.

    Rational functions

    A rational function is a ratio of polynomials — algebra's fractions promoted to functions. Their drama happens where the denominator dies: poles shoot to infinity, and the large-$x$ contest between numerator and denominator degrees decides the horizon. They are the simplest functions with genuinely wild behavior.

    Definition $f(x) = \dfrac{P(x)}{Q(x)}$, defined where $Q(x)\ne0$. If $P, Q$ share a factor $(x - a)$, cancelling leaves a hole at $a$ (removable); a zero of $Q$ alone gives a vertical asymptote (pole).
    Worked example $f(x) = \dfrac{x^2 - 1}{x^2 - x - 2} = \dfrac{(x-1)(x+1)}{(x-2)(x+1)}$. At $x = -1$: common factor — a hole at $\left(-1, \tfrac{-1-1}{-1-2}\right) = (-1, \tfrac23)$. At $x = 2$: pole — vertical asymptote. Same-degree horizon: $y \to 1$.
    Explore

    Slide the pole and the numerator degree; watch vertical and horizontal/slant asymptotes reorganize the curve.

    Drill
    1. EASY Where is $f(x) = \dfrac{3}{x - 4}$ undefined, and what happens there?
      Solution
      $x = 4$: a pole — $f \to +\infty$ from the right, $-\infty$ from the left.
    2. MED Identify holes and poles of $f(x) = \dfrac{x^2 - 4}{x^2 - 2x}$.
      Solution
      $\dfrac{(x-2)(x+2)}{x(x-2)}$: hole at $x = 2$ (value $\tfrac{4}{2} = 2$), pole at $x = 0$.
    3. HARD Sketch features of $f(x) = \dfrac{2x^2 - 2}{x^2 - 4}$: intercepts, asymptotes, sign.
      Solution
      $f = \dfrac{2(x-1)(x+1)}{(x-2)(x+2)}$. Zeros $\pm1$; $y$-intercept $f(0) = \tfrac{-2}{-4} = \tfrac12$. Poles $\pm2$; horizontal asymptote $y = 2$ (degree tie, ratio of leaders). Sign alternates across $-2, -1, 1, 2$: positive on $(-\infty,-2)$, negative on $(-2,-1)$, positive on $(-1,1)$... check $f(0) = \tfrac12 > 0$ ✓, negative on $(1,2)$, positive after.

    Asymptotes

    An asymptote is a line a curve approaches ever more closely without (necessarily) touching — the curve's behavior at the edges of its world. Three species: vertical (blow-ups at finite $x$), horizontal (settling as $x \to \pm\infty$), and slant (growing like a line). Asymptotes are the skeleton you draw first.

    Definition Vertical: $x = a$ with $|f(x)| \to \infty$ as $x \to a$. Horizontal: $y = L$ with $f(x) \to L$ as $x\to\infty$ or $-\infty$. Slant: $f(x) - (mx + b) \to 0$. A graph can cross horizontal/slant asymptotes in the middle — the promise is only about the tails.
    Worked example $f(x) = \dfrac{3x + 1}{x - 2}$: vertical at $x = 2$; horizontal at $y = 3$ (leading ratio). Note $f(x) = 3 + \dfrac{7}{x-2}$: the "$+\tfrac{7}{x-2}$" is the shrinking correction — asymptotics made explicit by division.
    Drill
    1. EASY Asymptotes of $f(x) = \dfrac{1}{x} + 5$?
      Solution
      Vertical $x = 0$, horizontal $y = 5$.
    2. MED Can a function cross its horizontal asymptote? Give an example or refute.
      Solution
      Yes: $f(x) = \dfrac{x}{x^2+1}$ has asymptote $y = 0$ and crosses it at $x = 0$. Only the limit at infinity is promised.
    3. HARD How many horizontal asymptotes can one function have?
      Solution
      At most two — one for $x \to +\infty$, one for $x \to -\infty$. Example with two: $f(x) = \dfrac{x}{\sqrt{x^2+1}} \to \pm 1$ (this is tanh-like; sigmoids in Ch 21 have exactly this two-asymptote shape).

    Vertical asymptotes

    A vertical asymptote marks a finite input where the output explodes — division by an approaching zero. Locate them at zeros of the denominator that survive cancellation, then determine the sign of the blow-up on each side: the two sides can agree or disagree.

    Definition $x = a$ is a vertical asymptote of $f$ if $f(x) \to +\infty$ or $-\infty$ as $x \to a^-$ or $x \to a^+$. For rational $f = P/Q$ in lowest terms: exactly the roots of $Q$.
    Worked example $f(x) = \dfrac{x + 1}{(x - 3)^2}$ at $x = 3$: numerator near 4 (positive), denominator a small positive square from both sides — $f \to +\infty$ on both sides. Compare $\dfrac{1}{x-3}$: $+\infty$ from the right, $-\infty$ from the left. Even vs odd pole order.
    Drill
    1. EASY Vertical asymptotes of $f(x) = \dfrac{x}{x^2 - 9}$?
      Solution
      $x = 3$ and $x = -3$ (numerator nonzero at both).
    2. MED Does $f(x) = \dfrac{x^2 - 9}{x - 3}$ have a vertical asymptote at $x = 3$?
      Solution
      No — it cancels to $x + 3$ with a hole at $(3, 6)$. Zeros of the denominator must survive reduction to be poles.
    3. HARD Determine the one-sided behavior of $f(x) = \dfrac{x - 1}{x(x+2)}$ at each pole.
      Solution
      At $x = 0$: numerator $\approx -1$; denominator sign: $x \to 0^+$ gives $(+)(+) = +$ so $f \to -\infty$; $x \to 0^-$ gives $(-)(+) = -$ so $f \to +\infty$. At $x = -2$: numerator $\approx -3$; $x\to-2^+$: $(-)( +\text{small}) < 0$... carefully: $x \approx -2^+$: $x < 0$, $x + 2 > 0$ small: denominator negative-small, $f = \tfrac{-3}{0^-} \to +\infty$; $x \to -2^-$: $x+2 < 0$, denominator positive-small ($(-)(-)$), $f \to -\infty$.

    Horizontal asymptotes

    A horizontal asymptote is a ceiling or floor at infinity: the value the function settles toward as inputs grow without bound. For rational functions it is a two-line rule comparing degrees; more generally it captures saturation — sigmoids, capacities, terminal velocities.

    Definition For $f = \dfrac{a_mx^m + \cdots}{b_nx^n + \cdots}$: if $m < n$, asymptote $y = 0$; if $m = n$, $y = \tfrac{a_m}{b_n}$; if $m > n$, none (the function grows — possibly toward a slant asymptote).
    Worked example $\dfrac{5x^2 - x}{2x^2 + 7}$: degrees tie, asymptote $y = \tfrac52$. Intuition: divide top and bottom by $x^2$: $\dfrac{5 - 1/x}{2 + 7/x^2} \to \dfrac{5}{2}$. The small terms evaporate at infinity.
    Drill
    1. EASY Horizontal asymptote of $\dfrac{3x + 2}{x^2 + 1}$?
      Solution
      Degree 1 < 2: $y = 0$.
    2. MED Horizontal asymptote(s) of $f(x) = \dfrac{7 - 2x^3}{4x^3 + x}$?
      Solution
      Tie at degree 3: $y = -\tfrac{2}{4} = -\tfrac12$ (both directions).
    3. HARD The sigmoid $\sigma(x) = \dfrac{1}{1 + e^{-x}}$: find both horizontal asymptotes.
      Solution
      $x \to +\infty$: $e^{-x}\to0$, $\sigma \to 1$. $x\to-\infty$: $e^{-x}\to\infty$, $\sigma\to0$. Asymptotes $y=0$ and $y=1$ — why sigmoid outputs read as probabilities (Ch 19, 21).

    Slant asymptotes

    When the numerator's degree exceeds the denominator's by exactly one, the function grows like a line — its slant (oblique) asymptote, found by polynomial division: quotient = asymptote, remainder = the vanishing correction.

    Definition If $f(x) = \dfrac{P(x)}{Q(x)}$ with $\deg P = \deg Q + 1$, dividing gives $f(x) = (mx + b) + \dfrac{R(x)}{Q(x)}$ with $\deg R < \deg Q$, so $f(x) - (mx+b) \to 0$: slant asymptote $y = mx + b$.
    Worked example $f(x) = \dfrac{x^2 + x - 3}{x - 1}$: divide: $x^2 + x - 3 = (x-1)(x + 2) - 1$, so $f(x) = x + 2 - \dfrac{1}{x - 1}$. Slant asymptote $y = x + 2$; vertical at $x = 1$.
    Drill
    1. EASY Does $\dfrac{x^3}{x^2 + 1}$ have a slant asymptote?
      Solution
      Degrees 3 vs 2: yes. $\dfrac{x^3}{x^2+1} = x - \dfrac{x}{x^2+1}$: asymptote $y = x$.
    2. MED Find the slant asymptote of $\dfrac{2x^2 - 3x + 1}{x + 2}$.
      Solution
      Divide: $2x^2 - 3x + 1 = (x+2)(2x - 7) + 15$: asymptote $y = 2x - 7$.
    3. HARD Show the hyperbola branch $y = \sqrt{x^2 + 1}$ has slant asymptote $y = x$ (as $x \to \infty$).
      Solution
      $\sqrt{x^2+1} - x = \dfrac{(x^2 + 1) - x^2}{\sqrt{x^2+1} + x} = \dfrac{1}{\sqrt{x^2+1} + x} \to 0$. The conjugate trick from Ch 2, retired from denominators, now computes asymptotics.

    Exponential functions

    An exponential function has the variable in the exponent: $f(x) = a\,b^x$. Its signature property is multiplicative growth — equal steps in $x$ multiply the output by equal factors. Populations, compound interest, chain reactions, and (for a while) compute budgets all grow this way; nothing polynomial can keep up.

    Definition $f(x) = a\,b^x$ with $b > 0$, $b \ne 1$: growth if $b > 1$, decay if $0 < b < 1$. Key property: $f(x + 1) = b\,f(x)$. Domain $\mathbb{R}$, range $(0, \infty)$ for $a > 0$, horizontal asymptote $y = 0$. Natural form $f(x) = a\,e^{kx}$.
    Worked example $f(x) = 100 \cdot 2^{x/3}$ (doubles every 3 units): $f(0) = 100$, $f(3) = 200$, $f(9) = 800$, $f(30) = 100 \cdot 2^{10} = 102\,400$. Meanwhile $g(x) = 100 + 50x$ reaches only 1600 at $x = 30$. Exponentials always win eventually.
    Where this goes $e^{kx}$ solves the growth ODE (Ch 10); softmax exponentiates logits (Ch 21); exponential decay schedules learning rates (Ch 15).
    Drill
    1. EASY Is $f(x) = 5(0.8)^x$ growth or decay, and what is $f(2)$?
      Solution
      Decay ($b < 1$); $f(2) = 5(0.64) = 3.2$.
    2. MED A colony triples every 4 hours from 200 cells. Write $N(t)$ and find $N(10)$.
      Solution
      $N(t) = 200 \cdot 3^{t/4}$; $N(10) = 200\cdot 3^{2.5} = 200 \cdot 9\sqrt3 \approx 3118$.
    3. HARD Find the exponential $f(x) = a b^x$ through $(1, 6)$ and $(4, 48)$.
      Solution
      Divide: $\tfrac{48}{6} = b^3 = 8 \Rightarrow b = 2$; $a\cdot2 = 6 \Rightarrow a = 3$: $f(x) = 3\cdot2^x$.

    Logarithmic functions

    The logarithmic function is the exponential's inverse: $f(x) = \log_b x$ asks "which exponent produces $x$?" It grows without bound but agonizingly slowly — the mirror image of exponential explosion — and compresses huge ranges into small ones, which is why loss curves and axes get log-scaled.

    Definition $f(x) = \log_b x$ ($b > 0, b\ne1$): domain $(0, \infty)$, range $\mathbb{R}$, vertical asymptote $x = 0$, passes through $(1, 0)$ and $(b, 1)$. Increasing for $b > 1$. Graph: the reflection of $b^x$ across $y = x$.
    Worked example $f(x) = \log_2 x$: $f(1) = 0$, $f(1024) = 10$, $f(10^6) \approx 19.9$. A million-fold input range lands in a 20-unit output range — logarithmic compression at work (and the depth of a balanced binary search over $10^6$ items).
    Drill
    1. EASY Domain of $f(x) = \log_3(x - 2)$?
      Solution
      $x > 2$: $(2, \infty)$; vertical asymptote $x = 2$.
    2. MED Sketch data: $g(x) = -\ln x$. Increasing or decreasing? Asymptote? Range?
      Solution
      Decreasing (negation flips $\ln$'s rise); vertical asymptote $x = 0$ with $g \to +\infty$ as $x\to0^+$; range $\mathbb{R}$. ($-\ln p$ is the "surprise" of probability $p$ — Ch 16.)
    3. HARD Solve $\log_2 x > \log_4(x + 6)$.
      Solution
      $\log_4(x+6) = \tfrac{\log_2(x+6)}{2}$. So need $2\log_2 x > \log_2(x+6)$, i.e. $x^2 > x + 6$ (valid since $\log_2$ increasing; domain $x > 0$). $x^2 - x - 6 > 0 \Rightarrow (x-3)(x+2) > 0 \Rightarrow x > 3$ (respecting $x > 0$). Answer $(3, \infty)$.

    Absolute value functions

    $f(x) = |x|$ is a V: the identity for positive inputs, its mirror for negative ones, with a sharp corner at 0. It is the simplest function that is continuous everywhere but not smooth — the prototype for kinks, hinge losses, and the L1 penalties that make solutions sparse.

    Definition $|x| = \begin{cases}x & x \ge 0\\ -x & x < 0\end{cases}$. General V: $f(x) = a|x - h| + k$ has corner (vertex) at $(h, k)$, arms of slope $\pm a$.
    Worked example $f(x) = 2|x - 3| - 4$: vertex $(3, -4)$, arms of slope $\pm2$. Zeros: $2|x-3| = 4 \Rightarrow |x - 3| = 2 \Rightarrow x = 1, 5$. Range $[-4, \infty)$.
    Where this goes $|x|$'s corner is why L1 regularization zeroes out weights exactly (Ch 15, 19) while smooth L2 only shrinks them.
    Drill
    1. EASY Vertex and range of $f(x) = |x + 2| + 1$?
      Solution
      Vertex $(-2, 1)$; range $[1, \infty)$.
    2. MED Solve $|2x - 1| = x + 3$ graphically-mindedly.
      Solution
      Cases: $2x - 1 = x + 3 \Rightarrow x = 4$ (check RHS $\ge 0$ ✓, and $2x-1=7\ge0$ consistent); $-(2x-1) = x+3 \Rightarrow -3x = 2 \Rightarrow x = -\tfrac23$ (check: $|{-\tfrac73}| = \tfrac73$, RHS $= \tfrac73$ ✓). Both valid.
    3. HARD Express $f(x) = |x| + |x - 2|$ piecewise and find its minimum.
      Solution
      $x < 0$: $-x + 2 - x = 2 - 2x$; $0 \le x \le 2$: $x + 2 - x = 2$; $x > 2$: $2x - 2$. Flat bottom: minimum value 2 on the whole interval $[0, 2]$ — total distance to two points is minimized anywhere between them (the geometric median idea).

    Piecewise functions

    A piecewise function applies different formulas on different regions of the domain — a mathematical switch statement. Tax brackets, shipping tiers, ReLU: one function, several regimes, with all the interest concentrated at the seams where pieces meet.

    Definition $f(x) = \begin{cases} \text{rule}_1 & x \in D_1 \\ \text{rule}_2 & x \in D_2 \\ \cdots \end{cases}$ where the $D_i$ partition the domain (no overlaps, no gaps). Evaluate by first locating the input's region.
    Worked example $\mathrm{ReLU}(x) = \begin{cases}0 & x < 0\\ x & x \ge 0\end{cases}$ — the flagship activation (Ch 21). $\mathrm{ReLU}(-3) = 0$, $\mathrm{ReLU}(2) = 2$. The pieces agree at the seam ($0 = 0$), so it is continuous; the slopes disagree ($0$ vs $1$), so there is a corner.
    Drill
    1. EASY $f(x) = \begin{cases}x^2 & x \le 1\\ 2x - 1 & x > 1\end{cases}$: find $f(0), f(1), f(3)$.
      Solution
      $0$; $1$ (use the first piece: $x \le 1$); $5$.
    2. MED Is the $f$ above continuous at $x = 1$?
      Solution
      Left value $1^2 = 1$; right limit $2(1) - 1 = 1$. They agree — continuous (and even smooth? slopes: $2x = 2$ vs $2$ — yes, matching slopes too).
    3. HARD Income tax: 0% up to 10k, 20% on the part between 10k and 40k, 40% above. Write tax $T(y)$ and compute $T(50000)$.
      Solution
      $T(y) = 0$ for $y \le 10^4$; $0.2(y - 10^4)$ for $10^4 < y \le 4\times10^4$; $6000 + 0.4(y - 4\times10^4)$ above. $T(50000) = 6000 + 0.4(10000) = 10\,000$. Marginal rates are the pieces' slopes; the function is continuous, its slope is not.

    Step functions

    A step function is piecewise-constant: flat plateaus with sudden jumps. It is how discrete decisions look as functions — thresholds, classifications, postage rates. The jumps make it discontinuous, and (fatally for gradient descent) its slope is zero everywhere it exists.

    Definition A step function takes finitely (or countably) many values, constant on intervals. Prototype: the Heaviside step $H(x) = 0$ for $x < 0$, $H(x) = 1$ for $x \ge 0$. CDFs of discrete random variables (Ch 11) are steps.
    Worked example Parking: \$3 per started hour. Cost $c(t) = 3\lceil t \rceil$ for $t > 0$: $c(0.5) = 3$, $c(1) = 3$, $c(1.01) = 6$. One minute across the seam costs \$3 — the discontinuity is real money.
    Where this goes The perceptron's original activation was a step (Ch 21); replacing steps by smooth sigmoids is what made networks trainable by gradients.
    Drill
    1. EASY Evaluate $H(-2)$, $H(0)$, $H(7)$ for the Heaviside step.
      Solution
      $0, 1, 1$.
    2. MED Express the "sign" function via steps and give its values at $-5, 0, 5$.
      Solution
      $\operatorname{sgn}(x) = H(x) - H(-x)$ gives $-1, 0, 1$... check $x=0$: $H(0) - H(0) = 0$ ✓ (with the convention $H(0)=1$). Values: $-1, 0, 1$.
    3. HARD Why can't gradient descent learn a threshold classifier $f(x) = H(w x - b)$ directly?
      Solution
      $\tfrac{\partial f}{\partial w} = 0$ wherever it exists (plateaus) and is undefined at the jump: the gradient carries no information about how to improve. The fix — replace $H$ with the smooth sigmoid $\sigma$ — is logistic regression (Ch 19).

    Floor and ceiling functions

    Floor rounds down to the nearest integer, ceiling rounds up. They are the canonical step functions and the bridge between continuous quantities and discrete counts: how many full pages, batches, buses. Off-by-one bugs are usually a floor/ceiling confusion in disguise.

    Definition $\lfloor x\rfloor = $ greatest integer $\le x$; $\lceil x \rceil = $ least integer $\ge x$. For non-integer $x$: $\lceil x\rceil = \lfloor x\rfloor + 1$. Beware negatives: $\lfloor -2.3\rfloor = -3$, $\lceil -2.3 \rceil = -2$. Identity: $\lceil \tfrac{n}{m}\rceil = \lfloor\tfrac{n - 1}{m}\rfloor + 1$ for integers $n \ge 1, m \ge 1$.
    Worked example 1000 samples in batches of 64: full batches $\lfloor \tfrac{1000}{64}\rfloor = 15$; total batches including the ragged last one $\lceil\tfrac{1000}{64}\rceil = 16$ (the last has $1000 - 960 = 40$ samples).
    Drill
    1. EASY Evaluate $\lfloor 3.99\rfloor$, $\lceil 3.01\rceil$, $\lfloor -0.5\rfloor$.
      Solution
      $3$, $4$, $-1$.
    2. MED How many multiples of 7 are in $[100, 500]$? (Floor form.)
      Solution
      $\lfloor\tfrac{500}{7}\rfloor - \lfloor\tfrac{99}{7}\rfloor = 71 - 14 = 57$.
    3. HARD Prove $\lfloor x \rfloor + \lfloor x + \tfrac12\rfloor = \lfloor 2x \rfloor$ for all real $x$.
      Solution
      Write $x = n + f$, $n = \lfloor x\rfloor$, $0 \le f < 1$. Case $f < \tfrac12$: LHS $= n + n = 2n$; RHS $= \lfloor 2n + 2f\rfloor = 2n$ ✓. Case $f \ge \tfrac12$: LHS $= n + (n + 1) = 2n + 1$; RHS $= \lfloor 2n + 2f \rfloor = 2n + 1$ since $1 \le 2f < 2$ ✓. (Hermite's identity, $m=2$.)

    Function transformations

    Once you know one function's graph, you know a whole family: add constants to shift it, multiply to stretch it, negate to flip it. The grammar is small — outside the function acts on $y$ (intuitive), inside acts on $x$ (backwards) — and it composes, so any $a\,f(b(x - h)) + k$ is four elementary moves.

    Definition From $y = f(x)$: $f(x) + k$ shifts up $k$; $f(x - h)$ shifts right $h$; $a f(x)$ stretches vertically by $a$; $f(bx)$ compresses horizontally by $b$; negatives reflect. Inside transformations act inversely and in reverse order.
    Worked example $g(x) = -2(x - 3)^2 + 5$ from $f(x) = x^2$: shift right 3, stretch vertically ×2, flip over the $x$-axis, shift up 5. Vertex journeys $(0,0)\to(3,0)\to(3,0)\to(3,0)\to(3,5)$.
    Explore

    Apply $a\,f(x - h) + k$ to a base curve and watch each slider perform its move.

    Drill
    1. EASY Describe $g(x) = |x| - 3$ and $h(x) = |x - 3|$.
      Solution
      $g$: the V shifted down 3. $h$: the V shifted right 3 — inside means horizontal.
    2. MED The point $(2, 8)$ lies on $y = f(x)$. Find its image on $y = 3f(x - 1) + 2$.
      Solution
      Input shifts right: $x = 3$; output: $3\cdot8 + 2 = 26$. Image: $(3, 26)$.
    3. HARD Express $g(x) = \sqrt{4x + 8}$ as transformations of $f(x) = \sqrt x$.
      Solution
      $g(x) = \sqrt{4(x + 2)} = 2\sqrt{x + 2}$: shift left 2, then vertical stretch ×2. (Or: horizontal compression by 4 then left-shift — factoring first gives the cleaner story.)

    Translations

    Translations slide a graph rigidly — no distortion, just relocation. Vertical: add to the output. Horizontal: subtract inside the input (the famous backwards direction: $f(x - 3)$ moves right, because inputs must be 3 bigger to produce old outputs).

    Definition $y = f(x - h) + k$ translates the graph of $f$ by the vector $(h, k)$. Every point $(x_0, y_0)$ moves to $(x_0 + h,\ y_0 + k)$.
    Worked example $y = \sqrt{x - 4} + 1$: the half-parabola $\sqrt x$ with its tip moved from $(0,0)$ to $(4, 1)$. Domain shifts too: $[4, \infty)$; range $[1, \infty)$.
    Pitfall $f(x + 2)$ shifts left. Test with one point: for $f(x) = x^2$, the vertex of $(x+2)^2$ is where $x + 2 = 0$, i.e. $x = -2$.
    Drill
    1. EASY Which way does $y = f(x) - 5$ move the graph?
      Solution
      Down 5.
    2. MED Write the equation of $y = x^2$ translated by $(-3, 7)$.
      Solution
      $y = (x + 3)^2 + 7$.
    3. HARD Show that translating $y = 2^x$ up by 0 and right by 1 equals scaling it vertically by $\tfrac12$.
      Solution
      $2^{x - 1} = 2^x \cdot 2^{-1} = \tfrac12\cdot2^x$. For exponentials, horizontal shifts are vertical scalings — the algebraic reason log-plots turn growth-rate changes into slope changes.

    Reflections

    Reflections flip a graph across an axis: negate the output to flip vertically (across the $x$-axis), negate the input to flip horizontally (across the $y$-axis). Combined with the identity $y = x$ mirror (which swaps input and output entirely), reflections generate the symmetry vocabulary of functions.

    Definition $y = -f(x)$: reflection across the $x$-axis. $y = f(-x)$: across the $y$-axis. Reflection across $y = x$ maps the graph of $f$ to the graph of its inverse relation.
    Worked example From $f(x) = \sqrt x$: $-\sqrt x$ hangs below the axis; $\sqrt{-x}$ opens leftward (domain $x \le 0$); $-\sqrt{-x}$ does both — the four quadrant-cousins of one curve.
    Drill
    1. EASY What is the reflection of $y = e^x$ across the $y$-axis?
      Solution
      $y = e^{-x}$ — growth becomes decay.
    2. MED $f(x) = x^2 - 4x$. Find $g$, the reflection of $f$ across the $x$-axis, in standard form.
      Solution
      $g(x) = -f(x) = -x^2 + 4x$. Vertex flips from $(2,-4)$ to $(2, 4)$.
    3. HARD Which functions are unchanged by reflection across the $y$-axis? Across the origin (both axes)?
      Solution
      $f(-x) = f(x)$: even functions ($x^2$, $\cos$, $|x|$). $f(-x) = -f(x)$: odd functions ($x^3$, $\sin$, $x$) — reflecting across both axes lands on itself. These get their own sections below.

    Scaling

    Scaling stretches or compresses a graph: multiply the output by $a$ to scale vertically, the input by $b$ to scale horizontally — and, inside as always, the effect is inverted: $f(2x)$ squeezes by half. Scaling is renormalization: changing units without changing shape.

    Definition $y = a f(x)$: vertical scale by $|a|$ (flip if $a < 0$). $y = f(bx)$: horizontal scale by $\tfrac{1}{|b|}$. Point map: $(x_0, y_0) \mapsto \left(\tfrac{x_0}{b},\ a y_0\right)$.
    Worked example $y = \sin$-like wave $f$ with peak at $(1, 1)$: $3f(2x)$ has peak at $\left(\tfrac12, 3\right)$ — twice as fast, three times as tall. (Amplitude and frequency, formally in Ch 6.)
    Drill
    1. EASY How does $y = \tfrac13 f(x)$ change the graph?
      Solution
      Compresses vertically to one-third height.
    2. MED The graph of $f$ passes through $(6, 10)$. Where does $y = \tfrac12 f(3x)$ pass?
      Solution
      Need $3x = 6$: $x = 2$; output $\tfrac12\cdot10 = 5$: point $(2, 5)$.
    3. HARD For $f(x) = x^2$, show horizontal scaling by $b$ equals a vertical scaling. For which functions does this hold in general?
      Solution
      $f(bx) = (bx)^2 = b^2 x^2 = b^2 f(x)$: horizontal ×$b$ = vertical ×$b^2$. This works exactly for homogeneous functions $f(bx) = b^k f(x)$ — the power laws. It is why power laws "look the same at every scale" (scale-free), the visual signature of scaling laws in ML.

    Function composition

    Composition chains functions: $(g \circ f)(x) = g(f(x))$ — the output of $f$ piped into $g$. Order matters, and depth compounds: a deep network is nothing but a long composition $f_L \circ \cdots \circ f_2 \circ f_1$, which is why the chain rule (Ch 7, 9) — the calculus of composition — is the engine of deep learning.

    Definition $(g\circ f)(x) = g(f(x))$, defined where $x \in \operatorname{dom} f$ and $f(x) \in \operatorname{dom} g$. Composition is associative, generally not commutative. Identity: $\operatorname{id}(x) = x$ composes neutrally.
    Worked example $f(x) = x + 1$, $g(x) = x^2$: $(g\circ f)(x) = (x+1)^2$ but $(f\circ g)(x) = x^2 + 1$. At $x = 2$: $9$ vs $5$ — order is not a formality.
    Think first Decompose $h(x) = \sqrt{3x^2 + 1}$ as a composition of two simpler functions.
    Reveal
    Inner $u(x) = 3x^2 + 1$, outer $v(u) = \sqrt u$: $h = v \circ u$. (Other splits exist; this is the one the chain rule will want.)
    Drill
    1. EASY $f(x) = 2x$, $g(x) = x - 3$: compute $(f\circ g)(5)$ and $(g \circ f)(5)$.
      Solution
      $f(g(5)) = f(2) = 4$; $g(f(5)) = g(10) = 7$.
    2. MED $f(x) = \sqrt x$, $g(x) = x - 4$: find the domain of $f \circ g$ and of $g \circ f$.
      Solution
      $f(g(x)) = \sqrt{x - 4}$: domain $[4,\infty)$. $g(f(x)) = \sqrt x - 4$: domain $[0, \infty)$. Composition order changes even the domain.
    3. HARD Let $f(x) = ax + b$ and $g(x) = cx + d$. When does $f \circ g = g \circ f$?
      Solution
      $f(g(x)) = acx + ad + b$; $g(f(x)) = acx + cb + d$. Equal iff $ad + b = cb + d$, i.e. $b(1 - c) = d(1 - a)$. E.g. shifts commute with shifts ($a = c = 1$) and scalings with scalings ($b = d = 0$), but shifts and scalings generally don't.

    Inverse functions

    The inverse $f^{-1}$ runs $f$ backwards: it takes each output to the input that produced it. It exists exactly when $f$ is one-to-one (no collisions to un-collide), and it satisfies the round-trip laws $f^{-1}(f(x)) = x$ and $f(f^{-1}(y)) = y$. To find it: solve $y = f(x)$ for $x$, then swap the letters.

    Definition If $f: A \to B$ is a bijection, $f^{-1}: B \to A$ is defined by $f^{-1}(b) = $ the unique $a$ with $f(a) = b$. Domain and range trade places. Notation warning: $f^{-1} \ne \tfrac1f$.
    Worked example $f(x) = \dfrac{2x + 1}{x - 3}$ (injective on its domain): set $y = \tfrac{2x+1}{x-3}$, solve: $yx - 3y = 2x + 1 \Rightarrow x(y - 2) = 3y + 1 \Rightarrow x = \dfrac{3y + 1}{y - 2}$. So $f^{-1}(x) = \dfrac{3x + 1}{x - 2}$. Check: $f(4) = 9$ and $f^{-1}(9) = \tfrac{28}{7} = 4$ ✓.
    Pitfall $f^{-1}(x)$ is the inverse function, not the reciprocal $\big(f(x)\big)^{-1}$. For $f(x) = x + 1$: inverse is $x - 1$; reciprocal is $\tfrac{1}{x+1}$. Entirely different objects sharing a cursed notation.
    Drill
    1. EASY Find the inverse of $f(x) = 3x - 6$.
      Solution
      $y = 3x - 6 \Rightarrow x = \tfrac{y + 6}{3}$: $f^{-1}(x) = \tfrac{x + 6}{3}$.
    2. MED $f(x) = x^2$ on $\mathbb{R}$ has no inverse. Fix it by restriction and write the inverse.
      Solution
      Restrict to $[0, \infty)$: now injective, inverse $f^{-1}(x) = \sqrt x$. (Restricting to $(-\infty, 0]$ gives $-\sqrt x$ — a choice must be made.)
    3. HARD Show that if $f$ and $g$ are invertible, $(g\circ f)^{-1} = f^{-1}\circ g^{-1}$.
      Solution
      Check the round trip: $(f^{-1}\circ g^{-1})\circ(g\circ f) = f^{-1}\circ(g^{-1}\circ g)\circ f = f^{-1}\circ f = \operatorname{id}$, and similarly on the other side. Socks-and-shoes: undo in reverse order.

    Inverse function graphs

    The graph of $f^{-1}$ is the graph of $f$ reflected across the line $y = x$ — because inverting swaps every $(a, b)$ into $(b, a)$. You saw the exponential/log mirror in Ch 2; that picture is fully general. Fixed points of $f$ on the line $y = x$ stay put under the flip.

    Definition $(a, b) \in \operatorname{graph}(f) \iff (b, a) \in \operatorname{graph}(f^{-1})$: the two graphs are mirror images across $y = x$. Consequently, if $f$ is increasing so is $f^{-1}$, and intersections of $f$ with $y = x$ are shared with $f^{-1}$.
    Worked example $f(x) = x^3$ passes through $(2, 8)$; $f^{-1}(x) = \sqrt[3]{x}$ passes through $(8, 2)$. Both pass through $(1,1)$, $(0,0)$, $(-1,-1)$ — the fixed points on the mirror line.
    Drill
    1. EASY $f$ passes through $(5, -2)$. What point must $f^{-1}$ pass through?
      Solution
      $(-2, 5)$.
    2. MED The graphs of $f$ and $f^{-1}$ intersect at a point not on $y = x$. Possible?
      Solution
      Yes, for decreasing $f$: $f(x) = -x^3$? Take $f(x) = \tfrac1x$: it is its own inverse, and its whole graph (e.g. $(2, \tfrac12)$) is "intersection" off the line $y=x$. Intersections must be symmetric across $y = x$ as a set, not pointwise.
    3. HARD If $f(x) = x^3 + x + 1$, compute $f^{-1}(3)$ without finding a formula for $f^{-1}$.
      Solution
      Solve $f(x) = 3$: $x^3 + x - 2 = 0$; $x = 1$ works and $f$ is strictly increasing (so the root is unique). $f^{-1}(3) = 1$. Inverting a specific value needs only equation-solving — no closed-form inverse required.

    Even functions

    An even function is mirror-symmetric across the $y$-axis: $f(-x) = f(x)$. The name comes from even powers, whose graphs all have this symmetry. Evenness halves your work — knowing the right half of the graph gives you the left for free.

    Definition $f$ is even iff $f(-x) = f(x)$ for all $x$ in its (symmetric) domain. Examples: $x^2, x^4, |x|, \cos x$, any polynomial with only even-degree terms.
    Worked example Is $f(x) = 3x^4 - 5x^2 + 7$ even? $f(-x) = 3x^4 - 5x^2 + 7 = f(x)$ ✓ — every exponent even (the constant is $x^0$). Is $x^2 + x$ even? $f(-1) = 0 \ne 2 = f(1)$: no.
    Drill
    1. EASY Is $f(x) = x^6 - 4$ even?
      Solution
      Yes: $(-x)^6 - 4 = x^6 - 4$.
    2. MED $f$ is even with $f(3) = 8$. What is $f(-3)$? Can an even function be injective?
      Solution
      $f(-3) = 8$. Injective: no (except on trivial domains) — $\pm x$ always collide.
    3. HARD Show the product of two even functions is even, and even × odd is odd.
      Solution
      $(fg)(-x) = f(-x)g(-x)$. Even·even: $f(x)g(x) = (fg)(x)$ ✓. Even·odd: $f(x)\cdot(-g(x)) = -(fg)(x)$: odd ✓. (Parity multiplies like signs.)

    Odd functions

    An odd function has rotational symmetry about the origin: $f(-x) = -f(x)$ — flip both axes and the graph lands on itself. Odd powers, $\sin$, and $\tanh$ are odd. Any function splits uniquely into an even plus an odd part, a decomposition that returns in Fourier analysis.

    Definition $f$ is odd iff $f(-x) = -f(x)$ for all $x$. If defined at 0, then $f(0) = 0$. Decomposition: $f(x) = \underbrace{\tfrac{f(x) + f(-x)}{2}}_{\text{even}} + \underbrace{\tfrac{f(x) - f(-x)}{2}}_{\text{odd}}$.
    Worked example Split $e^x$: even part $\tfrac{e^x + e^{-x}}{2} = \cosh x$, odd part $\tfrac{e^x - e^{-x}}{2} = \sinh x$. Check: $\cosh + \sinh = e^x$ ✓. The hyperbolic functions are the exponential's parity components.
    Drill
    1. EASY Is $f(x) = x^3 - x$ odd?
      Solution
      $f(-x) = -x^3 + x = -f(x)$ ✓ yes.
    2. MED Classify $f(x) = x^2 + x$: even, odd, or neither?
      Solution
      Neither: $f(1) = 2$, $f(-1) = 0$ — not equal, not opposite. Most functions are neither; parity is special.
    3. HARD Prove the even/odd decomposition is unique.
      Solution
      Suppose $f = e_1 + o_1 = e_2 + o_2$. Then $e_1 - e_2 = o_2 - o_1$ is both even (LHS) and odd (RHS), so it satisfies $g(x) = g(-x) = -g(x)$: $g \equiv 0$. Hence $e_1 = e_2$, $o_1 = o_2$. $\blacksquare$

    Monotonic functions

    A monotonic function never changes direction: always rising (increasing) or always falling (decreasing). Monotonicity is precious: it guarantees injectivity (hence invertibility), it preserves order — applying an increasing function to both sides of an inequality is safe — and it is why maximizing $f$ or $\log f$ gives the same answer.

    Definition $f$ is increasing if $a < b \Rightarrow f(a) \le f(b)$ (strictly, with $<$); decreasing with $\ge$. Strictly monotonic $\Rightarrow$ injective. Compositions: increasing∘increasing = increasing; increasing∘decreasing = decreasing (signs multiply).
    Worked example $\ln$ is strictly increasing, so $\operatorname*{argmax}_\theta L(\theta) = \operatorname*{argmax}_\theta \ln L(\theta)$: maximum likelihood may (and always does) work with the log — the same maximizer, far friendlier algebra (Ch 13).
    Drill
    1. EASY On which intervals is $f(x) = x^2$ increasing / decreasing?
      Solution
      Decreasing on $(-\infty, 0]$, increasing on $[0, \infty)$ — monotonic on each half, not globally.
    2. MED Is $f(x) = \dfrac{1}{x}$ decreasing on its whole domain?
      Solution
      No! It decreases on $(-\infty, 0)$ and on $(0, \infty)$ separately, but $f(-1) = -1 < 1 = f(1)$ jumps up across the gap. Monotonic on each piece $\ne$ monotonic overall.
    3. HARD $f$ is strictly increasing. Show $f(x) < f(y) \iff x < y$, and deduce solving $e^{3x - 1} < e^{x + 5}$.
      Solution
      ($\Leftarrow$) definition. ($\Rightarrow$) contrapositive: $x \ge y \Rightarrow f(x) \ge f(y)$ (equality when $x=y$, else strict). Apply with $f = e^t$: inequality $\iff 3x - 1 < x + 5 \iff x < 3$.

    Bounded functions

    A bounded function never escapes a horizontal band: some $M$ caps $|f(x)|$ for all $x$. Boundedness is a tameness certificate — sigmoids are bounded (outputs stay sane), $x^2$ is not. Bounded above/below can hold separately, and the tightest such bounds are the supremum and infimum.

    Definition $f$ is bounded on $D$ if $\exists M: |f(x)| \le M$ for all $x \in D$; bounded above if $f(x) \le M$; below if $f(x) \ge m$. $\sup f$ is the least upper bound of the range (Ch 1 completeness), attained or not.
    Worked example $f(x) = \dfrac{x^2}{x^2 + 1}$: since $0 \le x^2 < x^2 + 1$, we get $0 \le f(x) < 1$: bounded, $\inf = 0$ (attained at 0), $\sup = 1$ (never attained — approached as $x\to\pm\infty$).
    Drill
    1. EASY Is $f(x) = 5 - x^2$ bounded above? Below?
      Solution
      Above by 5 (attained at 0); not below ($\to -\infty$).
    2. MED Show $f(x) = \dfrac{1}{1 + e^{-x}}$ is bounded and give sup and inf.
      Solution
      $e^{-x} > 0$ so denominator $> 1$: $0 < f < 1$. $\sup = 1$, $\inf = 0$, neither attained. The sigmoid's band is the reason it encodes probabilities.
    3. HARD Is a bounded monotonic function on $\mathbb{R}$ forced to flatten out — i.e. have horizontal asymptotes?
      Solution
      Yes. If $f$ is increasing and bounded above, $L = \sup f$ exists (completeness); for any $\epsilon > 0$ some $f(x_0) > L - \epsilon$, and monotonicity keeps $f(x) \in (L - \epsilon, L]$ for $x > x_0$: $f(x) \to L$. Same at $-\infty$ with the inf. (The monotone convergence idea, previewing Ch 7.)

    Periodic functions

    A periodic function repeats itself exactly after a fixed step: $f(x + T) = f(x)$. One tile of width $T$ contains everything; the rest is copy-paste. Days, seasons, waves, rotations — and positional encodings in transformers — are periodic structure exploited.

    Definition $f$ is periodic with period $T > 0$ if $f(x + T) = f(x)$ for all $x$; the smallest such $T$ (if it exists) is the fundamental period. Sums of periods: if $f, g$ have periods $T_1, T_2$ with $T_1/T_2$ rational, $f + g$ is periodic with period $\operatorname{lcm}$-like $T$.
    Worked example $f(x) = x - \lfloor x\rfloor$ (fractional part): $f(x + 1) = x + 1 - \lfloor x + 1\rfloor = x + 1 - (\lfloor x\rfloor + 1) = f(x)$: period 1. A sawtooth wave built from floor.
    Where this goes Sine and cosine (Ch 6) are the canonical periodics; Fourier analysis (Ch 14) says every reasonable periodic function is a sum of them — and sinusoidal positional encodings feed exactly this into transformers.
    Drill
    1. EASY If $f$ has period 6 and $f(2) = 9$, find $f(20)$.
      Solution
      $20 = 2 + 3\cdot6$: $f(20) = 9$.
    2. MED What is the fundamental period of $f(x) = (-1)^{\lfloor x \rfloor}$?
      Solution
      The value flips every unit step and returns after two: period 2 (a square wave).
    3. HARD Can a non-constant periodic function have arbitrarily small periods?
      Solution
      Yes, if we drop continuity: the Dirichlet function ($1$ on $\mathbb{Q}$, $0$ off it) has every positive rational as a period, so no fundamental period. Continuous non-constant periodic functions do have a smallest period.

    Sequences

    A sequence is a function whose domain is $\mathbb{N}$: an infinite ordered list $a_1, a_2, a_3, \dots$. Everything you know about functions applies, but the discrete domain adds its own questions — most importantly, what happens to $a_n$ as $n \to \infty$. Training runs are sequences: loss per step.

    Definition A sequence is $a: \mathbb{N} \to \mathbb{R}$, written $(a_n)$. It may be given by an explicit formula $a_n = f(n)$ or by recursion. Monotonic, bounded, periodic transfer verbatim from functions.
    Worked example $a_n = \dfrac{n}{n + 1}$: $\tfrac12, \tfrac23, \tfrac34, \tfrac45, \dots$ — increasing (each term closer to 1), bounded above by 1, never reaching it. It converges to 1 (formally in Ch 7).

    Compare an arithmetic and a geometric sequence with your parameters — watch linear vs exponential growth diverge.

    Drill
    1. EASY Write the first four terms of $a_n = n^2 - n$.
      Solution
      $0, 2, 6, 12$ (from $n=1$).
    2. MED Find a formula for $2, 5, 10, 17, 26, \dots$
      Solution
      Differences $3, 5, 7, 9$ — odd numbers: $a_n = n^2 + 1$.
    3. HARD Is $a_n = \dfrac{(-1)^n n}{n+1}$ monotonic? Bounded? Does it settle anywhere?
      Solution
      Not monotonic (alternates sign). Bounded: $|a_n| = \tfrac{n}{n+1} < 1$. It does not converge: even terms approach $+1$, odd terms $-1$ — two "cluster points", no single limit (Ch 7 vocabulary: divergent but bounded).

    Arithmetic sequences

    An arithmetic sequence steps by a constant difference $d$ — the discrete version of a linear function. Its running total has a famous closed form: pair the first and last terms (Gauss's trick) and multiply by half the count.

    Definition $a_n = a_1 + (n-1)d$. Sum of the first $n$ terms: $S_n = \dfrac{n(a_1 + a_n)}{2} = \dfrac{n\big(2a_1 + (n-1)d\big)}{2}$.
    Worked example $5, 9, 13, \dots$: $d = 4$, so $a_{20} = 5 + 19\cdot4 = 81$ and $S_{20} = \tfrac{20(5 + 81)}{2} = 860$.
    Drill
    1. EASY Find $a_{10}$ for the sequence $3, 7, 11, \dots$
      Solution
      $a_{10} = 3 + 9\cdot4 = 39$.
    2. MED An arithmetic sequence has $a_3 = 10$ and $a_8 = 25$. Find $a_1$ and $d$.
      Solution
      $5d = 15 \Rightarrow d = 3$; $a_1 = 10 - 2\cdot3 = 4$.
    3. HARD A theater has 20 rows: 14 seats in row 1, each row 2 more than the last. Total seats?
      Solution
      $a_{20} = 14 + 19\cdot2 = 52$; $S_{20} = \tfrac{20(14 + 52)}{2} = 660$ seats.

    Geometric sequences

    A geometric sequence multiplies by a constant ratio $r$ — the discrete exponential. Its partial sums telescope into a closed form, and when $|r| < 1$ the infinite sum converges: infinitely many terms, finite total. That single fact powers annuities, discounted rewards in RL, and Zeno's arrow.

    Definition $a_n = a_1 r^{\,n-1}$. Partial sum ($r \ne 1$): $S_n = a_1\dfrac{1 - r^n}{1 - r}$. If $|r| < 1$: $\displaystyle\sum_{n=1}^{\infty} a_1 r^{\,n-1} = \dfrac{a_1}{1 - r}$.
    Worked example $\tfrac12 + \tfrac14 + \tfrac18 + \cdots = \dfrac{1/2}{1 - 1/2} = 1$: the halvings of Zeno sum to exactly one whole. And discounted reward $\sum_{t=0}^{\infty} \gamma^t = \tfrac{1}{1-\gamma}$: with $\gamma = 0.99$, the future is "worth" 100 steps (Ch 25).
    Pitfall The infinite-sum formula requires $|r| < 1$. Feeding it $r = 2$ produces the nonsense "$1 + 2 + 4 + \cdots = -1$" — a formula applied outside its warranty.
    Drill
    1. EASY Find $a_6$ for $2, 6, 18, \dots$
      Solution
      $r = 3$: $a_6 = 2\cdot3^5 = 486$.
    2. MED Evaluate $\sum_{k=0}^{\infty} 5\left(\tfrac{2}{3}\right)^k$.
      Solution
      $\dfrac{5}{1 - 2/3} = 15$.
    3. HARD A ball drops from 8 m and rebounds to $\tfrac34$ of each fall. Total vertical distance traveled?
      Solution
      Falls: $8 + 6 + 4.5 + \cdots = \tfrac{8}{1 - 3/4} = 32$. Rises: $6 + 4.5 + \cdots = \tfrac{6}{1-3/4} = 24$. Total $56$ m.
    $0.999\dots$ as a geometric series $\tfrac{9}{10} + \tfrac{9}{100} + \cdots$ sums to:
    $\dfrac{9/10}{1 - 1/10} = 1$ exactly — the same fact as Ch 1's $0.\overline9 = 1$, now with machinery.

    Recurrence relations

    A recurrence defines each term from earlier ones: $a_{n+1} = g(a_n, \dots)$ plus initial conditions. It is the native language of iteration — compound interest, population models, gradient descent steps, RNN states. Solving a recurrence means finding the explicit formula hiding inside the loop.

    Definition A recurrence gives $a_n$ in terms of previous terms, e.g. linear first-order $a_{n+1} = r a_n + c$ with $a_0$ given. Fixed point $a^* = \tfrac{c}{1 - r}$ (for $r \ne 1$); solution $a_n = a^* + (a_0 - a^*) r^n$: converges to $a^*$ iff $|r| < 1$.
    Worked example Loan: balance $B_{n+1} = 1.01 B_n - 500$ (1% monthly interest, \$500 payment), $B_0 = 20\,000$. Fixed point $B^* = \tfrac{-500}{1 - 1.01} = 50\,000$... careful: $B^* = \tfrac{c}{1-r} = \tfrac{-500}{-0.01} = 50\,000$. Since $B_0 < B^*$ and $r > 1$, the gap $B_n - 50\,000 = -30\,000(1.01)^n$ grows negative: the balance decreases — the loan is being paid off. It hits 0 when $(1.01)^n = \tfrac{50000}{30000}$: $n = \tfrac{\ln(5/3)}{\ln 1.01} \approx 51.3$ months.
    Where this goes Recurrences are discrete dynamical systems (Ch 28); solving them systematically (characteristic equations, master theorem) is Ch 17; SGD is a stochastic recurrence (Ch 15).
    Drill
    1. EASY $a_0 = 1$, $a_{n+1} = 2a_n + 1$: compute $a_1, a_2, a_3$ and guess the pattern.
      Solution
      $3, 7, 15$: pattern $a_n = 2^{n+1} - 1$. (Verify: $2(2^{n+1} - 1) + 1 = 2^{n+2} - 1$ ✓.)
    2. MED Solve $a_{n+1} = \tfrac12 a_n + 3$, $a_0 = 10$: formula and limit.
      Solution
      Fixed point $a^* = \tfrac{3}{1/2} = 6$. $a_n = 6 + 4\left(\tfrac12\right)^n \to 6$.
    3. HARD Prove by induction that $a_n = 2^{n+1} - 1$ solves $a_{n+1} = 2a_n + 1$, $a_0 = 1$, and connect to the "towers of Hanoi" recurrence.
      Solution
      Base: $a_0 = 2^1 - 1 = 1$ ✓. Step: assume $a_n = 2^{n+1} - 1$; then $a_{n+1} = 2(2^{n+1} - 1) + 1 = 2^{n+2} - 1$ ✓. Hanoi's minimum moves satisfy $H_n = 2H_{n-1} + 1$, $H_1 = 1$, so $H_n = 2^n - 1$ — same recurrence, shifted index. $\blacksquare$

    Mathematical modeling

    Modeling with functions means choosing the right shape for a relationship: linear for constant rates, quadratic near optima, exponential for compounding, logarithmic for saturation, periodic for cycles, piecewise for regime changes. The chapter you just finished is a catalog of shapes; modeling is knowing which one the world is wearing.

    Definition The function-fitting loop: inspect the data's signature (constant differences → linear; constant ratios → exponential; constant second differences → quadratic; straight on log-log → power law), fit parameters, validate on held-out points, and state the domain where the model claims validity.
    Worked example Data: $(0, 3), (1, 6), (2, 12), (3, 24)$. Ratios: $2, 2, 2$ — exponential: $f(x) = 3\cdot2^x$. Contrast $(0,3),(1,6),(2,9),(3,12)$: differences $3,3,3$ — linear: $f(x) = 3x + 3$. Two tables, two signatures, two shapes.
    Pitfall Extrapolation: a model fit on $[0, 10]$ owes you nothing at $x = 100$. Exponential fits are the most dangerous to extrapolate — and the most tempting.
    Drill
    1. EASY Which shape: "each layer of the network halves the error"?
      Solution
      Exponential decay: $E(n) = E_0 (1/2)^n$.
    2. MED Model: a service costs \$10/month plus \$0.02 per API call up to 10k calls, then \$0.01 per call beyond. Write $C(n)$ and compute $C(25\,000)$.
      Solution
      Piecewise: $C(n) = 10 + 0.02n$ for $n \le 10^4$; $C(n) = 10 + 200 + 0.01(n - 10^4) = 210 + 0.01(n - 10^4)$ beyond. $C(25000) = 210 + 150 = \$360$.
    3. HARD Benchmark accuracy vs training tokens: $(10^9, 42\%), (10^{10}, 54\%), (10^{11}, 66\%)$. Propose a shape, fit it, and predict at $10^{12}$ — then critique.
      Solution
      Equal steps in $\log_{10}$ tokens give equal $+12\%$ steps: logarithmic, $A = 12\log_{10}(T) - 66$. Check: $T = 10^9$: $108 - 66 = 42$ ✓. Predict $10^{12}$: $144 - 66 = 78\%$. Critique: the log model crosses 100% at $T \approx 10^{13.8}$ — impossible; accuracy must saturate (a sigmoid in log-tokens is more honest). Every shape has a domain of validity.

    Three problems that braid the chapter together.

    Problems
    1. MED Let $f(x) = \dfrac{x - 1}{x + 2}$. Find its domain, range, intercepts, asymptotes, and inverse; verify $f^{-1}(f(3)) = 3$.
      Solution
      Domain: $x \ne -2$. Vertical asymptote $x = -2$; horizontal $y = 1$ (degree tie). Intercepts: $x$: $(1, 0)$; $y$: $(0, -\tfrac12)$. Inverse: $y(x+2) = x - 1 \Rightarrow x(y - 1) = -2y - 1 \Rightarrow f^{-1}(x) = \dfrac{-2x - 1}{x - 1}$; range of $f$ = domain of $f^{-1}$ = $\mathbb{R}\setminus\{1\}$. Check: $f(3) = \tfrac25$; $f^{-1}(\tfrac25) = \dfrac{-4/5 - 1}{2/5 - 1} = \dfrac{-9/5}{-3/5} = 3$ ✓.
    2. HARD Let $f(x) = 2x + 3$ and define $a_{n+1} = f(a_n)$ with $a_0 = 1$. (a) Find a closed form for $a_n$. (b) Show $g(x) = \tfrac{x-3}{2}$ inverts $f$, and that iterating $g$ from any start converges to $f$'s fixed point.
      Solution
      (a) Fixed point: $x^* = 2x^* + 3 \Rightarrow x^* = -3$. Then $a_n + 3 = 2^n(a_0 + 3) = 4\cdot2^n$: $a_n = 2^{n+2} - 3$. Check: $a_0 = 1$ ✓, $a_1 = 5 = f(1)$ ✓. (b) $g(f(x)) = \tfrac{2x + 3 - 3}{2} = x$ ✓. Iterating $g$: $b_{n+1} = \tfrac{b_n - 3}{2}$, so $b_n + 3 = (b_0 + 3)\left(\tfrac12\right)^n \to 0$, i.e. $b_n \to -3$, the shared fixed point — contraction (|slope| $\tfrac12 < 1$) pulls in; expansion (slope 2) pushed away. (Ch 18's fixed-point iteration and Ch 28's stability, in miniature.)
    3. HARD GPU cost: provider A charges $c_A(h) = 40 + 2.5h$; provider B charges $c_B(h) = 25\cdot 1.02^{h}$ (compounding congestion). (a) Which is cheaper at $h = 10$ and $h = 100$? (b) Show B eventually exceeds A forever. (c) Solve $c_A(h) = 300$ and $c_B(h) = 300$ exactly.
      Solution
      (a) $h=10$: A $= 65$, B $= 25(1.02)^{10} \approx 25(1.2190) \approx 30.47$ — B cheaper. $h = 100$: A $= 290$, B $= 25(1.02)^{100} \approx 25(7.245) \approx 181$ — B still cheaper. (b) Exponentials beat linear: $\tfrac{c_B(h)}{c_A(h)} \to \infty$ since $1.02^h$ outgrows any linear function ($1.02^h = e^{h\ln1.02}$, and $e^{ch}/h \to \infty$); so past some $h^*$, B $>$ A permanently (numerically $h^* \approx 138$: A $= 385$, B $\approx 25\cdot15.4 \approx 386$). (c) A: $h = \tfrac{300 - 40}{2.5} = 104$. B: $1.02^h = 12 \Rightarrow h = \tfrac{\ln 12}{\ln 1.02} \approx \tfrac{2.4849}{0.019803} \approx 125.5$.

    Task 1 — Function properties tester. Write numerical checkers is_injective(f, xs) (collision search with rounding tolerance), is_even(f), is_odd(f), and is_monotonic(f, xs), and run them on $x^2$, $x^3$, $\tanh$, $|x|$, and $\sigma(x) = 1/(1+e^{-x})$.

    Reference solution
    import numpy as np

xs = np.linspace(-5, 5, 2001)

def is_injective(f, xs, tol=1e-9):
    ys = np.round(f(xs) / tol) * tol
    return len(np.unique(ys)) == len(xs)

def is_even(f, xs=xs):  return np.allclose(f(xs), f(-xs))
def is_odd(f, xs=xs):   return np.allclose(f(xs), -f(-xs))
def is_monotonic(f, xs=xs):
    d = np.diff(f(xs))
    return bool(np.all(d >= 0) or np.all(d <= 0))

sig = lambda x: 1/(1 + np.exp(-x))
sq  = lambda x: x**2
cube = lambda x: x**3

assert not is_injective(sq, xs) and is_injective(cube, xs)
assert is_even(sq) and is_even(np.abs)
assert is_odd(cube) and is_odd(np.tanh)
assert is_monotonic(np.tanh) and is_monotonic(sig)
assert not is_monotonic(sq)

    Task 2 — Numerical inverse by bisection. For a strictly increasing $f$, write inverse(f, y, lo, hi) that solves $f(x) = y$ by bisection to $10^{-10}$. Test on $f(x) = x^3 + x + 1$ (verify $f^{-1}(3) = 1$) and on the sigmoid (recover the logit function).

    Reference solution
    import math

def inverse(f, y, lo, hi, tol=1e-10):
    assert f(lo) <= y <= f(hi)
    while hi - lo > tol:
        mid = (lo + hi) / 2
        if f(mid) < y: lo = mid
        else:          hi = mid
    return (lo + hi) / 2

f = lambda x: x**3 + x + 1
assert abs(inverse(f, 3, -10, 10) - 1.0) < 1e-8

sig = lambda x: 1/(1 + math.exp(-x))
for p in (0.1, 0.5, 0.9):
    x = inverse(sig, p, -50, 50)
    assert abs(x - math.log(p/(1-p))) < 1e-6   # logit = sigmoid^{-1}

    Task 3 — Shape detective. Write classify(xs, ys) that decides whether tabulated data is linear, quadratic, exponential, or a power law by testing constant differences, constant second differences, constant ratios, and log-log linearity; return the fitted parameters. Test on synthetic data from each family.

    Reference solution
    import numpy as np

def classify(xs, ys, rtol=1e-6):
    xs, ys = np.asarray(xs, float), np.asarray(ys, float)
    d1 = np.diff(ys)
    if np.allclose(d1, d1[0], rtol=rtol):
        return 'linear', np.polyfit(xs, ys, 1)
    d2 = np.diff(d1)
    if np.allclose(d2, d2[0], rtol=rtol):
        return 'quadratic', np.polyfit(xs, ys, 2)
    if np.all(ys > 0):
        r = ys[1:] / ys[:-1]
        if np.allclose(r, r[0], rtol=rtol):
            b = r[0] ** (1/(xs[1]-xs[0]))
            return 'exponential', (ys[0] / b**xs[0], b)   # y = a b^x
        if np.all(xs > 0):
            m, c = np.polyfit(np.log(xs), np.log(ys), 1)
            if np.allclose(np.log(ys), m*np.log(xs) + c, rtol=1e-6):
                return 'power', (np.exp(c), m)            # y = a x^m
    return 'unknown', None

x = np.arange(1, 8, dtype=float)
assert classify(x, 3*x + 3)[0] == 'linear'
assert classify(x, x**2 - x)[0] == 'quadratic'
assert classify(x, 3 * 2**x)[0] == 'exponential'
assert classify(x, 5 * x**1.5)[0] == 'power'
