    Functions of several variables

    A function of several variables takes a point in $\mathbb{R}^n$ and returns a number: $f(x,y)=x^2+y^2$ eats a location on a plane and returns a height. Picture a landscape: the input is where you stand, the output is the altitude. Every loss function in machine learning is exactly this — a landscape over millions of parameter dimensions.

    Definition A function $f:\mathbb{R}^n\to\mathbb{R}$ assigns to each vector $\mathbf{x}=(x_1,\dots,x_n)$ in its domain a single real number $f(\mathbf{x})$. Its graph is the set $\{(\mathbf{x},f(\mathbf{x}))\}\subset\mathbb{R}^{n+1}$; its level set at value $c$ is $\{\mathbf{x}: f(\mathbf{x})=c\}$.
    Worked example Let $f(x,y)=x^2+4y^2$. Level set $f=4$: the ellipse $x^2+4y^2=4$, i.e. $\frac{x^2}{4}+y^2=1$, with semi-axes $2$ (in $x$) and $1$ (in $y$). Evaluate: $f(1,-1)=1+4=5$. The graph is an elliptic paraboloid — a bowl stretched twice as steep in the $y$ direction.
    Where this goes Loss surfaces $L(\theta)$ over parameters $\theta\in\mathbb{R}^n$ are the central object of Ch 15 (Optimization) and Ch 21 (Deep Learning).
    Drill
    1. EASY For $f(x,y)=xy$, compute $f(3,-2)$ and describe the level set $f=0$.
      Solution
      $f(3,-2)=-6$. $xy=0$ means $x=0$ or $y=0$: the level set is the union of the two coordinate axes.
    2. MED Find the domain of $f(x,y)=\ln(1-x^2-y^2)$.
      Solution
      Need $1-x^2-y^2>0$, i.e. $x^2+y^2<1$: the open unit disk.
    3. HARD Show that the level sets of $f(x,y)=\frac{y}{x^2}$ (for $x\neq0$) are parabolas through the origin (with the origin removed), and explain why infinitely many level sets "collide" near the origin.
      Solution
      $f=c$ gives $y=cx^2$: a parabola for each $c$ (origin excluded since $x\neq0$). Every parabola $y=cx^2$ passes arbitrarily close to $(0,0)$, so points near the origin lie on level sets of every value $c$ — a preview of why the limit of $f$ at the origin fails to exist.

    Multivariable limits

    In one dimension you can approach a point only from the left or right. In the plane you can approach from infinitely many directions and along infinitely many curves — and the limit exists only if every approach gives the same value. That is what makes multivariable limits subtle: one bad path kills the limit.

    Definition $\lim_{\mathbf{x}\to\mathbf{a}} f(\mathbf{x})=L$ means: for every $\varepsilon>0$ there is $\delta>0$ such that $0<\|\mathbf{x}-\mathbf{a}\|<\delta$ implies $|f(\mathbf{x})-L|<\varepsilon$. The value must not depend on the path of approach.
    Worked example $f(x,y)=\dfrac{xy}{x^2+y^2}$ at $(0,0)$. Along $y=0$: $f=0$. Along $y=x$: $f=\dfrac{x^2}{2x^2}=\dfrac12$. Two paths, two values ($0\neq\tfrac12$), so the limit does not exist. Contrast: $g(x,y)=\dfrac{x^2y}{x^2+y^2}$ satisfies $|g|\le|y|\to0$ (since $x^2\le x^2+y^2$), so $\lim_{(x,y)\to(0,0)}g=0$ by squeeze.
    Pitfall Checking straight lines is never enough. $f(x,y)=\dfrac{x^2y}{x^4+y^2}$ tends to $0$ along every straight line through the origin, yet along the parabola $y=x^2$ it equals $\dfrac{x^4}{2x^4}=\dfrac12$. No limit.
    Drill
    1. EASY Evaluate $\lim_{(x,y)\to(1,2)} (x^2y+3y)$.
      Solution
      Polynomials are continuous: plug in. $1\cdot2+6=8$.
    2. MED Does $\lim_{(x,y)\to(0,0)}\dfrac{x^2-y^2}{x^2+y^2}$ exist?
      Solution
      Along $y=0$: $1$. Along $x=0$: $-1$. Different, so no.
    3. MED Show $\lim_{(x,y)\to(0,0)}\dfrac{x^3+y^3}{x^2+y^2}=0$.
      Solution
      Polar: $x=r\cos\theta$, $y=r\sin\theta$ gives $\dfrac{r^3(\cos^3\theta+\sin^3\theta)}{r^2}=r(\cos^3\theta+\sin^3\theta)$, and $|{\cdot}|\le 2r\to0$ as $r\to0$, uniformly in $\theta$. So the limit is $0$.
    4. HARD For $f(x,y)=\dfrac{xy^2}{x^2+y^4}$, compute the limit along every line through the origin, then find a path giving a different value.
      Solution
      Along $y=mx$: $\dfrac{x\cdot m^2x^2}{x^2+m^4x^4}=\dfrac{m^2x}{1+m^4x^2}\to0$; along $x=0$: $0$. But along $x=y^2$: $\dfrac{y^2\cdot y^2}{y^4+y^4}=\dfrac12$. Limit does not exist.

    Continuity in several variables

    Continuity means what it always meant: no jumps, no holes — the function value equals the limit. A continuous function of two variables is a landscape you could walk on without falling through. Sums, products, quotients (nonzero denominator) and compositions of continuous functions stay continuous, so most formulas are continuous wherever they are defined.

    Definition $f$ is continuous at $\mathbf{a}$ if $\lim_{\mathbf{x}\to\mathbf{a}} f(\mathbf{x})=f(\mathbf{a})$. It is continuous on a set if continuous at every point of the set.
    Worked example Define $f(x,y)=\dfrac{x^2y}{x^2+y^2}$ for $(x,y)\neq(0,0)$ and $f(0,0)=0$. We showed $\lim_{(x,y)\to(0,0)}f=0=f(0,0)$, so $f$ is continuous everywhere. But $g(x,y)=\dfrac{xy}{x^2+y^2}$ with $g(0,0)=0$ is not continuous at the origin: the limit there does not exist, so no choice of $g(0,0)$ can repair it.
    Think first If $f(x,y)$ is continuous in $x$ for each fixed $y$, and continuous in $y$ for each fixed $x$, must it be continuous as a function of $(x,y)$?
    Reveal
    No. $g(x,y)=\dfrac{xy}{x^2+y^2}$ (with $g(0,0)=0$) is continuous in each variable separately — fix $y=0$ and it is identically $0$; fix $y=b\neq0$ and it is a rational function with nonvanishing denominator — yet it is discontinuous at the origin (limit fails along $y=x$). Separate continuity is strictly weaker than joint continuity.
    Drill
    1. EASY Where is $f(x,y)=\dfrac{x+y}{x-y}$ continuous?
      Solution
      Everywhere except the line $x=y$, where the denominator vanishes.
    2. MED Can $f(x,y)=\dfrac{\sin(x^2+y^2)}{x^2+y^2}$ be extended continuously to $(0,0)$?
      Solution
      Yes. With $r^2=x^2+y^2\to0$, $\dfrac{\sin r^2}{r^2}\to1$. Set $f(0,0)=1$.
    3. HARD A continuous $f:\mathbb{R}^2\to\mathbb{R}$ attains a maximum on the closed disk $x^2+y^2\le1$ — which theorem, and why does it matter for optimization?
      Solution
      The Extreme Value Theorem: a continuous function on a compact (closed and bounded) set attains its max and min. This is what guarantees constrained optimization problems over compact feasible sets (Ch 15) have solutions at all.

    Partial derivatives

    Stand on a hillside. Face due east and ask "how steep is it this way?" — that is $\partial f/\partial x$. Face due north — that is $\partial f/\partial y$. A partial derivative freezes every variable but one and takes the ordinary derivative. All the rules of Chapter 7 apply, treating the frozen variables as constants.

    Definition $$\frac{\partial f}{\partial x}(a,b)=\lim_{h\to0}\frac{f(a+h,b)-f(a,b)}{h},\qquad \frac{\partial f}{\partial y}(a,b)=\lim_{h\to0}\frac{f(a,b+h)-f(a,b)}{h}.$$ Also written $f_x$, $f_y$, or $\partial_x f$.
    Worked example $f(x,y)=x^3y^2+e^{xy}+\sin y$. Then $f_x=3x^2y^2+ye^{xy}$ (treat $y$ as constant; chain rule on $e^{xy}$ gives factor $y$) and $f_y=2x^3y+xe^{xy}+\cos y$. At $(1,0)$: $f_x=0+0\cdot e^0=0$, $f_y=0+1\cdot1+\cos0=2$.
    Pitfall Partial derivatives can exist at a point where the function is not even continuous. $g(x,y)=\frac{xy}{x^2+y^2}$, $g(0,0)=0$: both partials at the origin are $0$ (the function is $0$ on both axes), yet $g$ is discontinuous there. Existence of partials is weak; differentiability (below) is the strong notion.
    Drill
    1. EASY $f(x,y)=x^2y+y^3$. Find $f_x$ and $f_y$.
      Solution
      $f_x=2xy$, $f_y=x^2+3y^2$.
    2. MED $f(x,y,z)=\dfrac{xz}{y}+z\ln x$. Find all three partials.
      Solution
      $f_x=\dfrac{z}{y}+\dfrac{z}{x}$, $f_y=-\dfrac{xz}{y^2}$, $f_z=\dfrac{x}{y}+\ln x$.
    3. MED The ideal gas law: $PV=nRT$ (with $n,R$ constant). Compute $\dfrac{\partial P}{\partial V}$ at constant $T$, and interpret its sign.
      Solution
      $P=\dfrac{nRT}{V}$ so $\dfrac{\partial P}{\partial V}=-\dfrac{nRT}{V^2}<0$: at fixed temperature, compressing the gas (smaller $V$) raises pressure.
    4. HARD Use the limit definition to compute $f_x(0,0)$ for $f(x,y)=\begin{cases}\dfrac{x^3}{x^2+y^2}&(x,y)\neq(0,0)\\ 0&(0,0)\end{cases}$.
      Solution
      $f_x(0,0)=\lim_{h\to0}\dfrac{f(h,0)-0}{h}=\lim_{h\to0}\dfrac{h^3/h^2}{h}=\lim_{h\to0}\dfrac{h}{h}=1$.

    Higher partial derivatives

    Differentiate twice, possibly in different directions: $f_{xy}$ means "first the $x$-slope, then how that slope changes as you move in $y$." The miracle is Clairaut's theorem: for smooth functions the order does not matter, $f_{xy}=f_{yx}$ — which is exactly why the Hessian matrix (later this chapter) is symmetric.

    Definition $f_{xx}=\partial_x(\partial_x f)$, $f_{xy}=\partial_y(\partial_x f)$, etc. Theorem (Clairaut/Schwarz) If $f_{xy}$ and $f_{yx}$ exist and are continuous near a point, then $f_{xy}=f_{yx}$ there.
    Worked example $f(x,y)=x^2e^{3y}$. $f_x=2xe^{3y}$, $f_y=3x^2e^{3y}$. Then $f_{xx}=2e^{3y}$, $f_{yy}=9x^2e^{3y}$, $f_{xy}=\partial_y(2xe^{3y})=6xe^{3y}$ and $f_{yx}=\partial_x(3x^2e^{3y})=6xe^{3y}$ — equal, as Clairaut promises.
    Drill
    1. EASY $f(x,y)=x^3y^2$. Compute $f_{xy}$ two ways.
      Solution
      $f_x=3x^2y^2\Rightarrow f_{xy}=6x^2y$; $f_y=2x^3y\Rightarrow f_{yx}=6x^2y$. Same.
    2. MED Verify that $u(x,t)=e^{-t}\sin x$ satisfies the heat equation $u_t=u_{xx}$.
      Solution
      $u_t=-e^{-t}\sin x$; $u_x=e^{-t}\cos x$, $u_{xx}=-e^{-t}\sin x$. Equal. (The heat equation returns in Ch 10.)
    3. HARD Show $u(x,y)=\ln(x^2+y^2)$ is harmonic ($u_{xx}+u_{yy}=0$) away from the origin.
      Solution
      $u_x=\dfrac{2x}{x^2+y^2}$, $u_{xx}=\dfrac{2(x^2+y^2)-2x\cdot2x}{(x^2+y^2)^2}=\dfrac{2(y^2-x^2)}{(x^2+y^2)^2}$. By symmetry $u_{yy}=\dfrac{2(x^2-y^2)}{(x^2+y^2)^2}$. Sum $=0$.

    Gradient

    The gradient bundles all partial derivatives into one vector, and that vector has a beautiful geometric meaning: it points in the direction of steepest ascent, its length is the steepest slope, and it is perpendicular to level sets. "Go downhill" — the whole of gradient descent — means "step along $-\nabla f$."

    Definition $$\nabla f(\mathbf{x})=\left(\frac{\partial f}{\partial x_1},\dots,\frac{\partial f}{\partial x_n}\right).$$ Properties (for differentiable $f$): $\nabla f$ points in the direction of maximal increase; $\|\nabla f\|$ is the maximal rate of increase; $\nabla f(\mathbf{a})\perp$ the level set of $f$ through $\mathbf{a}$.
    Worked example $f(x,y)=x^2+4y^2$ at $(2,1)$: $\nabla f=(2x,8y)=(4,8)$. Steepest-ascent direction: $\frac{1}{\sqrt{80}}(4,8)$; maximal slope $\sqrt{80}=4\sqrt5\approx8.94$. The level ellipse through $(2,1)$ is $x^2+4y^2=8$; the tangent line there is $4(x-2)+8(y-1)=0$, i.e. $x+2y=4$ — and indeed $(4,8)$ is normal to it.

    4. HARD Show that if $\nabla f(\mathbf{a})\neq\mathbf{0}$, then among all unit vectors $\mathbf{u}$ the rate of change $D_{\mathbf u}f(\mathbf a)$ is maximized uniquely by $\mathbf{u}=\nabla f(\mathbf a)/\|\nabla f(\mathbf a)\|$.

    Directional derivative

    Partials only measure slope along the axes. The directional derivative measures slope along any direction $\mathbf u$: walk that way at unit speed and record how fast $f$ changes. For differentiable functions it is just a dot product with the gradient — the gradient contains all directional information.

    Definition For a unit vector $\mathbf u$, $$D_{\mathbf u}f(\mathbf a)=\lim_{h\to0}\frac{f(\mathbf a+h\mathbf u)-f(\mathbf a)}{h}.$$ If $f$ is differentiable at $\mathbf a$, then $D_{\mathbf u}f(\mathbf a)=\nabla f(\mathbf a)\cdot\mathbf u$.
    Worked example $f(x,y)=x^2y$ at $(1,2)$ in the direction of $\mathbf v=(3,4)$. Unit vector: $\mathbf u=(3/5,4/5)$. $\nabla f=(2xy,x^2)=(4,1)$. So $D_{\mathbf u}f=4\cdot\frac35+1\cdot\frac45=\frac{12+4}{5}=\frac{16}{5}=3.2$.
    Pitfall Two classic errors: forgetting to normalize $\mathbf v$ (the formula needs a unit vector), and using $\nabla f\cdot\mathbf u$ when $f$ is not differentiable — all directional derivatives can exist without the dot-product formula holding.
    Drill
    1. EASY $f(x,y)=3x-2y$ at any point, direction $\mathbf u=(\frac{1}{\sqrt2},\frac{1}{\sqrt2})$. Find $D_{\mathbf u}f$.
      Solution
      $\nabla f=(3,-2)$, so $D_{\mathbf u}f=\frac{3-2}{\sqrt2}=\frac{1}{\sqrt2}$.
    2. MED $f(x,y)=e^x\sin y$ at $(0,\pi/3)$, toward the point $(2,\pi/3)$.
      Solution
      Direction $(2,0)-(0,0)... $ precisely: $(2,\pi/3)-(0,\pi/3)=(2,0)$, unit $\mathbf u=(1,0)$. $\nabla f=(e^x\sin y, e^x\cos y)=(\frac{\sqrt3}{2},\frac12)$. $D_{\mathbf u}f=\frac{\sqrt3}{2}$.
    3. HARD At a point, $D_{\mathbf u}f=5$ for $\mathbf u=(1,0)$ and $D_{\mathbf v}f=1$ for $\mathbf v=(0,1)$. Assuming differentiability, find the maximal directional derivative and its direction.
      Solution
      $\nabla f=(5,1)$. Max rate $=\|\nabla f\|=\sqrt{26}$ in direction $(5,1)/\sqrt{26}$.

    Multivariable chain rule

    When $f$ depends on intermediate variables that each depend on $t$, the rates multiply along each route and add across routes. Picture a graph of dependencies: total sensitivity = sum over all paths of the product of edge sensitivities. That single sentence is also the whole idea of backpropagation.

    Definition If $z=f(x,y)$ with $x=x(t)$, $y=y(t)$ differentiable, $$\frac{dz}{dt}=\frac{\partial f}{\partial x}\frac{dx}{dt}+\frac{\partial f}{\partial y}\frac{dy}{dt}.$$ More generally for $z=f(x(s,t),y(s,t))$: $\dfrac{\partial z}{\partial s}=f_x x_s+f_y y_s$ and likewise for $t$.
    Worked example $z=x^2y$ with $x=\cos t$, $y=\sin t$. $$\frac{dz}{dt}=2xy\cdot(-\sin t)+x^2\cdot\cos t=-2\cos t\sin^2 t+\cos^3 t.$$ Check at $t=0$: $x=1,y=0$; formula gives $0+1=1$. Directly, $z(t)=\cos^2t\sin t$, $z'(t)=-2\cos t\sin t\sin t+\cos^2t\cos t$, and $z'(0)=1$. ✓
    Where this goes The "sum over paths" form of the chain rule is literally backpropagation (this chapter) and reverse-mode autodiff (Ch 18).
    Drill
    1. EASY $z=x^2+y^2$, $x=t$, $y=t^2$. Find $dz/dt$ at $t=1$.
      Solution
      $dz/dt=2x\cdot1+2y\cdot2t=2t+4t^3$; at $t=1$: $6$.
    2. MED $z=e^{xy}$, $x=s+t$, $y=st$. Find $\partial z/\partial s$.
      Solution
      $z_s=ye^{xy}\cdot1+xe^{xy}\cdot t=e^{xy}(y+xt)=e^{(s+t)st}\,(st+(s+t)t)$.
    3. MED The radius of a cylinder grows at $2$ cm/s while its height shrinks at $3$ cm/s. How fast is the volume changing when $r=4$, $h=10$?
      Solution
      $V=\pi r^2h$; $\dot V=2\pi rh\,\dot r+\pi r^2\dot h=2\pi\cdot4\cdot10\cdot2+\pi\cdot16\cdot(-3)=160\pi-48\pi=112\pi\approx351.9$ cm³/s.
    4. HARD Suppose $w=f(u,v)$ with $u=x+y$, $v=x-y$. Show $\dfrac{\partial w}{\partial x}\dfrac{\partial w}{\partial y}=\left(\dfrac{\partial f}{\partial u}\right)^2-\left(\dfrac{\partial f}{\partial v}\right)^2$.
      Solution
      $w_x=f_u+f_v$, $w_y=f_u-f_v$ (since $u_x=u_y=1$, $v_x=1$, $v_y=-1$). Product: $(f_u+f_v)(f_u-f_v)=f_u^2-f_v^2$.

    Total derivative

    The right notion of "differentiable" in many variables: $f$ is differentiable at $\mathbf a$ if a linear map approximates it to first order — the change in $f$ is a linear function of the change in input, plus an error that vanishes faster than the step. The total derivative is that linear map; for scalar $f$ its matrix is the row vector $\nabla f^\top$.

    Definition $f:\mathbb{R}^n\to\mathbb{R}^m$ is differentiable at $\mathbf a$ if there is a linear map $Df(\mathbf a):\mathbb{R}^n\to\mathbb{R}^m$ with $$\lim_{\mathbf h\to\mathbf 0}\frac{\|f(\mathbf a+\mathbf h)-f(\mathbf a)-Df(\mathbf a)\mathbf h\|}{\|\mathbf h\|}=0.$$ Then $Df(\mathbf a)$ is the total derivative; its matrix is the Jacobian. If all partials exist and are continuous near $\mathbf a$, $f$ is differentiable there.
    Worked example $f(x,y)=x^2+y^2$ at $(1,2)$: $Df(1,2)=(2,4)$ as a row. The claim is $f(1+h,2+k)\approx f(1,2)+2h+4k=5+2h+4k$. Exactly: $f(1+h,2+k)=5+2h+4k+h^2+k^2$, and the error $h^2+k^2=\|(h,k)\|^2$ indeed vanishes faster than $\|(h,k)\|$. ✓
    Pitfall "All partials exist" $\ne$ "differentiable." $f(x,y)=\frac{xy}{x^2+y^2}$ (0 at origin) has both partials at $(0,0)$ but is not even continuous there, hence not differentiable. Continuity of the partials is the standard sufficient condition.

    1. EASY Write the total derivative (as a row vector) of $f(x,y,z)=xyz$ at $(1,2,3)$.
      Solution
      $(yz,xz,xy)=(6,3,2)$.
    2. MED Use the total derivative of $f(x,y)=\sqrt{x^2+y^2}$ at $(3,4)$ to estimate $f(3.1,3.9)$.
      Solution
      $\nabla f=(x/r,y/r)=(3/5,4/5)$ with $r=5$. Estimate $5+0.6(0.1)+0.8(-0.1)=5+0.06-0.08=4.98$. (True value $\sqrt{9.61+15.21}=\sqrt{24.82}\approx4.9820$.)
    3. HARD Show directly from the definition that $f(x,y)=xy$ is differentiable at every $(a,b)$ with $Df(a,b)=(b,a)$.
      Solution
      $f(a+h,b+k)-f(a,b)-(bh+ak)=(a+h)(b+k)-ab-bh-ak=hk$. And $\dfrac{|hk|}{\|(h,k)\|}\le\dfrac{\|(h,k)\|^2/2}{\|(h,k)\|}\to0$ (using $|hk|\le\frac{h^2+k^2}{2}$). So the definition holds.

    Jacobian matrix

    For a vector-valued map $f:\mathbb{R}^n\to\mathbb{R}^m$, stack the gradients of each output component as rows: that $m\times n$ matrix is the Jacobian. It is the best linear approximation of the map — near a point, $f$ acts like the linear map of Ch 8 given by its Jacobian. Compositions of maps multiply their Jacobians; that is the chain rule in matrix form.

    Definition For $f=(f_1,\dots,f_m):\mathbb{R}^n\to\mathbb{R}^m$, $$J_f=\frac{\partial(f_1,\dots,f_m)}{\partial(x_1,\dots,x_n)}=\begin{pmatrix}\frac{\partial f_1}{\partial x_1}&\cdots&\frac{\partial f_1}{\partial x_n}\\ \vdots&&\vdots\\ \frac{\partial f_m}{\partial x_1}&\cdots&\frac{\partial f_m}{\partial x_n}\end{pmatrix}.$$ Chain rule: $J_{g\circ f}(\mathbf x)=J_g(f(\mathbf x))\,J_f(\mathbf x)$.
    Worked example Polar coordinates $f(r,\theta)=(r\cos\theta,\;r\sin\theta)$: $$J_f=\begin{pmatrix}\cos\theta&-r\sin\theta\\ \sin\theta&r\cos\theta\end{pmatrix},\qquad \det J_f=r\cos^2\theta+r\sin^2\theta=r.$$ At $(r,\theta)=(2,\pi/2)$: $J=\begin{pmatrix}0&-2\\1&0\end{pmatrix}$ — locally the map rotates by $90°$ and stretches the $\theta$ direction by $2$.
    Where this goes $\det J$ rescales volume in change of variables (this chapter), in normalizing flows (Ch 22), and in the change-of-variables formula for densities (Ch 11).
    Drill
    1. EASY $f(x,y)=(x+2y,\;3xy)$. Find $J_f(1,1)$.
      Solution
      $J_f=\begin{pmatrix}1&2\\3y&3x\end{pmatrix}=\begin{pmatrix}1&2\\3&3\end{pmatrix}$ at $(1,1)$.
    2. MED $f(x,y)=(e^x\cos y, e^x\sin y)$. Compute $J_f$ and $\det J_f$.
      Solution
      $J_f=\begin{pmatrix}e^x\cos y&-e^x\sin y\\ e^x\sin y&e^x\cos y\end{pmatrix}$, $\det=e^{2x}(\cos^2y+\sin^2y)=e^{2x}$. (Never zero: the map is locally invertible everywhere.)
    3. HARD Let $f(x,y)=(x^2-y^2,\,2xy)$ and $g(u,v)=(u+v,\,uv)$. Compute $J_{g\circ f}$ at $(1,1)$ using the chain rule.
      Solution
      $f(1,1)=(0,2)$. $J_f=\begin{pmatrix}2x&-2y\\2y&2x\end{pmatrix}=\begin{pmatrix}2&-2\\2&2\end{pmatrix}$ at $(1,1)$. $J_g=\begin{pmatrix}1&1\\v&u\end{pmatrix}=\begin{pmatrix}1&1\\2&0\end{pmatrix}$ at $(u,v)=(0,2)$. Product: $J_gJ_f=\begin{pmatrix}1&1\\2&0\end{pmatrix}\begin{pmatrix}2&-2\\2&2\end{pmatrix}=\begin{pmatrix}4&0\\4&-4\end{pmatrix}$.

    Hessian matrix

    The Hessian is the matrix of second partials — the "curvature machine" of a scalar function. Its eigenvalues tell you how the landscape bends in each principal direction: all positive means a bowl (local min), all negative a dome (local max), mixed signs a saddle. Optimizers care about it constantly, even when they never form it explicitly.

    Definition $$H_f(\mathbf x)=\nabla^2 f(\mathbf x)=\left[\frac{\partial^2 f}{\partial x_i\,\partial x_j}\right]_{ij}.$$ For $f$ with continuous second partials, $H$ is symmetric (Clairaut), hence has real eigenvalues and orthogonal eigenvectors (spectral theorem, Ch 8).
    Worked example $f(x,y)=x^3-3xy^2$ (the "monkey saddle" relative: here a standard example). $f_x=3x^2-3y^2$, $f_y=-6xy$. $$H=\begin{pmatrix}6x&-6y\\-6y&-6x\end{pmatrix}.$$ At $(1,0)$: $H=\begin{pmatrix}6&0\\0&-6\end{pmatrix}$, eigenvalues $6,-6$: a saddle — curving up along $x$, down along $y$.
    Think first For $f(x,y)=x^2+10y^2$, gradient descent zig-zags. What about the Hessian explains this?
    Reveal
    $H=\mathrm{diag}(2,20)$: eigenvalue ratio (condition number) $10$. The bowl is a narrow valley — steep across, shallow along. Gradients point mostly across the valley, so steps overshoot side-to-side while creeping along the floor. Ill-conditioned Hessians are exactly why plain gradient descent is slow (Ch 15).
    Drill
    1. EASY Compute the Hessian of $f(x,y)=x^2+3xy+5y^2$.
      Solution
      $H=\begin{pmatrix}2&3\\3&10\end{pmatrix}$ (constant, since $f$ is quadratic).
    2. MED For the quadratic $f(\mathbf x)=\frac12\mathbf x^\top A\mathbf x+\mathbf b^\top\mathbf x$ with $A$ symmetric, show $\nabla f=A\mathbf x+\mathbf b$ and $H=A$.
      Solution
      $f=\frac12\sum_{ij}A_{ij}x_ix_j+\sum_ib_ix_i$. $\partial_{x_k}f=\frac12\big(\sum_jA_{kj}x_j+\sum_iA_{ik}x_i\big)+b_k=\sum_jA_{kj}x_j+b_k$ using $A_{ik}=A_{ki}$. So $\nabla f=A\mathbf x+\mathbf b$; differentiating again, $H=A$.
    3. HARD $f(x,y)=e^{x}\cos y$. Find the Hessian at $(0,0)$ and classify the point $(0,0)$ for the function $g=f-x$ (i.e. is $(0,0)$ a min/max/saddle of $g$?).
      Solution
      $g=e^x\cos y-x$: $g_x=e^x\cos y-1$, $g_y=-e^x\sin y$; both vanish at $(0,0)$ — a critical point. $g_{xx}=e^x\cos y=1$, $g_{yy}=-e^x\cos y=-1$, $g_{xy}=-e^x\sin y=0$ there. $H=\mathrm{diag}(1,-1)$: eigenvalues of opposite sign, so $(0,0)$ is a saddle.

    Tangent planes

    Zoom in on a smooth surface and it flattens into a plane — the tangent plane, the 2-D analogue of the tangent line. Its slopes in the $x$ and $y$ directions are exactly the partial derivatives. Everything "local" about a surface lives in this plane.

    Definition The tangent plane to $z=f(x,y)$ at $(a,b)$ is $$z=f(a,b)+f_x(a,b)(x-a)+f_y(a,b)(y-b).$$ For a level surface $F(x,y,z)=c$, the tangent plane at $\mathbf p$ is $\nabla F(\mathbf p)\cdot(\mathbf x-\mathbf p)=0$.
    Worked example Surface $z=x^2+4y^2$ at $(2,1,8)$: $f_x=2x=4$, $f_y=8y=8$, so $z=8+4(x-2)+8(y-1)$, i.e. $z=4x+8y-8$. As a level-surface check: $F=x^2+4y^2-z=0$, $\nabla F=(4,8,-1)$ at the point; plane $4(x-2)+8(y-1)-(z-8)=0$ — the same.
    Drill
    1. EASY Tangent plane to $z=xy$ at $(1,2,2)$.
      Solution
      $f_x=y=2$, $f_y=x=1$: $z=2+2(x-1)+1(y-2)=2x+y-2$.
    2. MED Tangent plane to the sphere $x^2+y^2+z^2=14$ at $(1,2,3)$.
      Solution
      $\nabla F=(2x,2y,2z)=(2,4,6)$. Plane: $2(x-1)+4(y-2)+6(z-3)=0$, i.e. $x+2y+3z=14$.
    3. HARD Find all points on $z=x^2-y^2$ where the tangent plane is parallel to the plane $2x+4y-z=0$.
      Solution
      Tangent plane normal is $(f_x,f_y,-1)=(2x,-2y,-1)$; parallel to given plane means proportional to $(2,4,-1)$. Matching the $z$ components (both $-1$) forces $2x=2,\,-2y=4$: $x=1$, $y=-2$, $z=1-4=-3$. Single point $(1,-2,-3)$.

    Linearization

    The tangent plane, used as a calculator: near a base point, replace the function by its first-order approximation. It is the multivariable version of $f(x)\approx f(a)+f'(a)(x-a)$ and the reason deep nets can be analyzed locally as linear maps.

    Definition The linearization of $f$ at $\mathbf a$ is $$L(\mathbf x)=f(\mathbf a)+\nabla f(\mathbf a)\cdot(\mathbf x-\mathbf a),$$ with error $f(\mathbf x)-L(\mathbf x)=O(\|\mathbf x-\mathbf a\|^2)$ for twice continuously differentiable $f$.
    Worked example Estimate $\sqrt{(3.02)^2+(3.97)^2}$. Take $f(x,y)=\sqrt{x^2+y^2}$ at $(3,4)$: $f=5$, $\nabla f=(3/5,4/5)$. $L=5+0.6(0.02)+0.8(-0.03)=5+0.012-0.024=4.988$. (True: $\sqrt{9.1204+15.7609}=\sqrt{24.8813}\approx4.98812$.)
    Where this goes Linearizing dynamics near an equilibrium (Ch 10, Ch 28) turns nonlinear systems into eigenvalue problems; Newton's method (Ch 15, 18) is linearization of $\nabla f$.
    Drill
    1. EASY Linearize $f(x,y)=x^2y$ at $(1,1)$ and estimate $f(1.1,0.9)$.
      Solution
      $\nabla f=(2xy,x^2)=(2,1)$; $L=1+2(0.1)+1(-0.1)=1.1$. (True: $1.21\cdot0.9=1.089$.)
    2. MED Use linearization to estimate $(0.99)^3(2.01)^2$.
      Solution
      $f(x,y)=x^3y^2$ at $(1,2)$: $f=4$, $f_x=3x^2y^2=12$, $f_y=2x^3y=4$. $L=4+12(-0.01)+4(0.01)=4-0.12+0.04=3.92$. (True $\approx3.9209$.)
    3. HARD A neural net layer computes $\sigma(w x)$ with $\sigma(u)=\frac{1}{1+e^{-u}}$. Linearize the output in $(w,x)$ around $w=0,x=1$.
      Solution
      Let $f(w,x)=\sigma(wx)$. At $(0,1)$: $\sigma(0)=\frac12$; $\sigma'(0)=\frac14$. $f_w=\sigma'(wx)\,x=\frac14$, $f_x=\sigma'(wx)\,w=0$. So $f\approx\frac12+\frac14 w$: near zero weights the layer is linear in $w$ with slope $\sigma'(0)x$ — why initialization scales (Ch 21) are chosen to keep pre-activations in this near-linear regime.

    Multivariable Taylor expansion

    One more order beyond linearization: value + gradient·step + ½ step·Hessian·step. The quadratic term is where curvature enters, and it is the workhorse of optimization theory — every convergence proof for gradient descent starts by Taylor-expanding the loss to second order.

    Definition For $f$ twice continuously differentiable at $\mathbf a$: $$f(\mathbf a+\mathbf h)=f(\mathbf a)+\nabla f(\mathbf a)^\top\mathbf h+\tfrac12\,\mathbf h^\top H_f(\mathbf a)\,\mathbf h+o(\|\mathbf h\|^2).$$
    Worked example Expand $f(x,y)=e^{x}\sin y$ to second order at $(0,0)$. $f(0,0)=0$. $\nabla f=(e^x\sin y, e^x\cos y)=(0,1)$. Second partials at origin: $f_{xx}=e^x\sin y=0$, $f_{xy}=e^x\cos y=1$, $f_{yy}=-e^x\sin y=0$. So $$f\approx 0+y+\tfrac12(0\cdot x^2+2\cdot1\cdot xy+0\cdot y^2)=y+xy.$$ Sanity check by multiplying series: $e^x\sin y=(1+x+\dots)(y-\dots)=y+xy+\dots$ ✓
    Drill
    1. EASY Write the second-order Taylor expansion of $f(x,y)=x^2+3xy+y^2$ about $(0,0)$.
      Solution
      The function is its own expansion: $f=x^2+3xy+y^2$ exactly (gradient $0$ at origin, Hessian $\begin{pmatrix}2&3\\3&2\end{pmatrix}$).
    2. MED Second-order expansion of $f(x,y)=\ln(1+x+2y)$ at $(0,0)$.
      Solution
      With $u=x+2y$: $\ln(1+u)=u-\frac{u^2}{2}+\dots$, so $f\approx x+2y-\tfrac12(x+2y)^2=x+2y-\tfrac{x^2}{2}-2xy-2y^2$.
    3. HARD Using $f(\theta+\mathbf h)\approx f(\theta)-\eta\|\nabla f\|^2+\frac{\eta^2}{2}\nabla f^\top H\nabla f$ for a gradient step $\mathbf h=-\eta\nabla f$, show the loss decreases whenever $0<\eta<2/\lambda_{\max}(H)$ (assume $H$ constant positive definite).
      Solution
      Decrease requires $-\eta\|\nabla f\|^2+\frac{\eta^2}{2}\nabla f^\top H\nabla f<0$, i.e. $\eta\,\dfrac{\nabla f^\top H\nabla f}{\|\nabla f\|^2}<2$. The Rayleigh quotient is at most $\lambda_{\max}$, so $\eta\lambda_{\max}<2$ suffices: $\eta<2/\lambda_{\max}$. This is the classic step-size bound of Ch 15.

    Multivariable optimization

    Flat spots first, curvature second. Interior extrema occur where the gradient vanishes; the Hessian then classifies each flat spot as bowl, dome or saddle. On a closed bounded region you must also patrol the boundary — the top of the hill may be on the fence.

    Definition $\mathbf a$ is a critical point if $\nabla f(\mathbf a)=\mathbf 0$. Second derivative test (two variables): let $D=f_{xx}f_{yy}-f_{xy}^2$ at $\mathbf a$. $D>0, f_{xx}>0$: local min. $D>0, f_{xx}<0$: local max. $D<0$: saddle. $D=0$: inconclusive. In general: $H\succ0$ min, $H\prec0$ max, indefinite $H$ saddle.
    Worked example $f(x,y)=x^3-3x+y^2$. $\nabla f=(3x^2-3,\,2y)=\mathbf0$ gives $x=\pm1$, $y=0$. $H=\begin{pmatrix}6x&0\\0&2\end{pmatrix}$. At $(1,0)$: $H=\mathrm{diag}(6,2)\succ0$ — local min, $f=1-3=-2$. At $(-1,0)$: $H=\mathrm{diag}(-6,2)$ indefinite — saddle. No global min: $f\to-\infty$ as $x\to-\infty$.
    Explore

    Run gradient descent on $f(x,y)=x^2+ay^2$. Raise the curvature ratio $a$ and the learning rate and watch the path zig-zag or diverge.

    Pitfall $\nabla f=\mathbf0$ is necessary for interior extrema, not sufficient — and in high dimensions saddles vastly outnumber minima. A random symmetric Hessian almost never has all eigenvalues of one sign when $n$ is large.
    Drill
    1. EASY Find and classify the critical points of $f(x,y)=x^2+y^2-4x+6y$.
      Solution
      $\nabla f=(2x-4,2y+6)=\mathbf0\Rightarrow(2,-3)$. $H=\mathrm{diag}(2,2)\succ0$: local (indeed global) min, $f(2,-3)=4+9-8-18=-13$.
    2. MED Classify all critical points of $f(x,y)=xy(3-x-y)$.
      Solution
      $f=3xy-x^2y-xy^2$. $f_x=3y-2xy-y^2=y(3-2x-y)$, $f_y=x(3-x-2y)$. Critical points: $(0,0)$, $(3,0)$, $(0,3)$, and solving $3-2x-y=0,3-x-2y=0$: $(1,1)$. $f_{xx}=-2y$, $f_{yy}=-2x$, $f_{xy}=3-2x-2y$. At $(1,1)$: $D=(-2)(-2)-(-1)^2=3>0$, $f_{xx}=-2<0$: local max ($f=1$). At $(0,0)$: $D=0-9<0$ saddle; similarly $(3,0)$ and $(0,3)$: $D=0-(3-6)^2=-9<0$, saddles.
    3. HARD Find the extreme values of $f(x,y)=x^2+2y^2$ on the closed disk $x^2+y^2\le1$.
      Solution
      Interior: $\nabla f=(2x,4y)=\mathbf0$ only at $(0,0)$, $f=0$. Boundary $x^2+y^2=1$: $f=x^2+2(1-x^2)=2-x^2$ with $x\in[-1,1]$, max $2$ at $x=0$ ($(0,\pm1)$), min $1$ at $x=\pm1$ ($(\pm1,0)$). Global min $0$ at origin, global max $2$ at $(0,\pm1)$.
    At a critical point the Hessian has eigenvalues $3$ and $-0.2$. The point is a…
    Mixed-sign eigenvalues: the function curves up along one eigenvector and down along the other — a saddle.

    Lagrange multipliers

    To optimize $f$ while staying on a constraint surface $g=c$: at the best point you cannot improve by sliding along the surface, so the gradient of $f$ must have no component along it — $\nabla f$ must be parallel to $\nabla g$. The proportionality constant $\lambda$ is the multiplier, and it prices the constraint: how much the optimum improves per unit of relaxation.

    Definition To find extrema of $f(\mathbf x)$ subject to $g(\mathbf x)=c$ (with $\nabla g\neq\mathbf0$ on the constraint), solve $$\nabla f=\lambda\nabla g,\qquad g(\mathbf x)=c.$$ Equivalently, critical points of the Lagrangian $\mathcal L(\mathbf x,\lambda)=f(\mathbf x)-\lambda\,(g(\mathbf x)-c)$.
    Worked example Maximize $f(x,y)=xy$ on the circle $x^2+y^2=2$. Equations: $y=\lambda\,2x$, $x=\lambda\,2y$, $x^2+y^2=2$. Multiply: $xy=4\lambda^2xy$; if $xy\neq0$, $\lambda=\pm\frac12$. $\lambda=\frac12$: $y=x$, so $2x^2=2$, $x=\pm1$: points $(1,1),(-1,-1)$ with $f=1$ (max). $\lambda=-\frac12$: $y=-x$, points $(1,-1),(-1,1)$, $f=-1$ (min). ($xy=0$ points give $f=0$, not extreme… in fact $x=0\Rightarrow y=\lambda\cdot0=0$, off the circle, so excluded.)
    Explore

    Slide the level value of $f(x,y)=xy$ and watch its hyperbola-shaped level curve grow until it just kisses the constraint circle — tangency is where $\nabla f\parallel\nabla g$.

    Where this goes KKT conditions and duality (Ch 15) generalize this to inequality constraints; the multiplier reappears as the dual variable and as "shadow price."
    Drill
    1. EASY Minimize $f(x,y)=x^2+y^2$ subject to $x+y=4$.
      Solution
      $(2x,2y)=\lambda(1,1)\Rightarrow x=y$; $x+y=4\Rightarrow x=y=2$. Min value $8$ (closest point of the line to origin).
    2. MED Find the extrema of $f(x,y)=3x+4y$ on $x^2+y^2=25$.
      Solution
      $(3,4)=\lambda(2x,2y)$: $x=\frac{3}{2\lambda},y=\frac{4}{2\lambda}$. Constraint: $\frac{9+16}{4\lambda^2}=25\Rightarrow\lambda=\pm\frac12$. Points $(3,4)$ (max, $f=25$) and $(-3,-4)$ (min, $f=-25$).
    3. HARD A box with no top must have volume $32$. Minimize the surface area.
      Solution
      Minimize $S=xy+2xz+2yz$ s.t. $xyz=32$. $\nabla S=\lambda\nabla(xyz)$: $y+2z=\lambda yz$, $x+2z=\lambda xz$, $2x+2y=\lambda xy$. Subtract first two: $(y-x)=\lambda z(y-x)$, so $x=y$ (or $\lambda z=1$, which substituted into the first equation gives $y+2z=yz\lambda z\cdot\frac{1}{z}\cdot z$… take the symmetric branch $x=y$). With $x=y$: third equation $4x=\lambda x^2\Rightarrow\lambda=4/x$; first: $x+2z=\frac{4}{x}xz=4z\Rightarrow x=2z$. Then $xyz=(2z)(2z)z=4z^3=32\Rightarrow z=2$, $x=y=4$. $S=16+16+16=48$.
    4. HARD Maximize the entropy $H=-\sum_{i=1}^n p_i\ln p_i$ subject to $\sum_i p_i=1$.
      Solution
      $\mathcal L=-\sum p_i\ln p_i-\lambda(\sum p_i-1)$. $\partial_{p_i}\mathcal L=-\ln p_i-1-\lambda=0\Rightarrow p_i=e^{-1-\lambda}$: all equal. Normalization gives $p_i=1/n$; the uniform distribution maximizes entropy at $H=\ln n$ ($H$ is concave, so this critical point is the max). Preview of Ch 16.

    Matrix calculus notation

    Once inputs and outputs are vectors and matrices, we need conventions for what "the derivative" is shaped like. This book uses the denominator layout for gradients — $\nabla_{\mathbf x}f$ has the same shape as $\mathbf x$ — which is what deep-learning frameworks return. Keep shapes explicit and half the errors vanish.

    Definition For scalar $f$ and $\mathbf x\in\mathbb{R}^n$: $\nabla_{\mathbf x}f=\dfrac{\partial f}{\partial\mathbf x}\in\mathbb{R}^n$ (column), with $(\nabla_{\mathbf x}f)_i=\partial f/\partial x_i$. For $\mathbf f:\mathbb{R}^n\to\mathbb{R}^m$: the Jacobian $\dfrac{\partial\mathbf f}{\partial\mathbf x}\in\mathbb{R}^{m\times n}$. For scalar $f$ of a matrix $W\in\mathbb{R}^{m\times n}$: $\nabla_W f\in\mathbb{R}^{m\times n}$ with $(\nabla_Wf)_{ij}=\partial f/\partial W_{ij}$. First-order change: $df=\nabla_{\mathbf x}f^\top d\mathbf x$, $df=\mathrm{tr}(\nabla_Wf^\top\,dW)$.
    Worked example Shape bookkeeping for a linear layer $\mathbf y=W\mathbf x$, $W\in\mathbb{R}^{m\times n}$, $\mathbf x\in\mathbb{R}^n$, scalar loss $L(\mathbf y)$. Then $\nabla_{\mathbf y}L\in\mathbb{R}^m$; the Jacobian $\partial\mathbf y/\partial\mathbf x=W\in\mathbb{R}^{m\times n}$; and $\nabla_{\mathbf x}L=W^\top\nabla_{\mathbf y}L\in\mathbb{R}^n$ — shapes force the transpose: $(n\times m)(m\times1)=(n\times1)$. ✓
    Pitfall Numerator vs denominator layout differ by a transpose, and textbooks mix them silently. Always check a formula on shapes: if the shapes don't compose, a transpose is missing.
    Drill
    1. EASY $f(\mathbf x)=\mathbf a^\top\mathbf x$. What is $\nabla_{\mathbf x}f$ and its shape?
      Solution
      $\nabla_{\mathbf x}f=\mathbf a\in\mathbb{R}^n$: same shape as $\mathbf x$, entries $\partial f/\partial x_i=a_i$.
    2. MED For $\mathbf f(\mathbf x)=A\mathbf x$ ($A\in\mathbb{R}^{m\times n}$), give the Jacobian and verify shapes in the chain rule for $L(\mathbf f(\mathbf x))$.
      Solution
      $\partial\mathbf f/\partial\mathbf x=A$. $\nabla_{\mathbf x}L=\left(\frac{\partial\mathbf f}{\partial\mathbf x}\right)^{\!\top}\nabla_{\mathbf f}L=A^\top\nabla_{\mathbf f}L$: $(n\times m)(m\times1)=n\times1$. ✓
    3. HARD Using the differential rule $df=\mathrm{tr}(G^\top dW)\Rightarrow\nabla_Wf=G$, find $\nabla_W\,\mathrm{tr}(AW)$ for $A\in\mathbb{R}^{n\times m}$, $W\in\mathbb{R}^{m\times n}$.
      Solution
      $d\,\mathrm{tr}(AW)=\mathrm{tr}(A\,dW)=\mathrm{tr}((A^\top)^\top dW)$, so $\nabla_W\mathrm{tr}(AW)=A^\top$.

    Gradients of vector expressions

    A small vocabulary of vector-in, scalar-out gradients covers most of machine learning: linear forms, quadratic forms, and norms. Learn these three and derive the rest by the product and chain rules — or by writing everything in indices once and never again.

    Definition Core identities ($\mathbf a$ constant, $A$ constant matrix): $$\nabla_{\mathbf x}(\mathbf a^\top\mathbf x)=\mathbf a,\qquad \nabla_{\mathbf x}(\mathbf x^\top A\mathbf x)=(A+A^\top)\mathbf x,\qquad \nabla_{\mathbf x}\|\mathbf x\|^2=2\mathbf x,$$ $$\nabla_{\mathbf x}\|A\mathbf x-\mathbf b\|^2=2A^\top(A\mathbf x-\mathbf b).$$ If $A$ is symmetric, $\nabla_{\mathbf x}(\mathbf x^\top A\mathbf x)=2A\mathbf x$.
    Worked example Least squares: $L(\mathbf w)=\|X\mathbf w-\mathbf y\|^2$. Expand: $L=\mathbf w^\top X^\top X\mathbf w-2\mathbf y^\top X\mathbf w+\mathbf y^\top\mathbf y$. Gradient: $\nabla L=2X^\top X\mathbf w-2X^\top\mathbf y$. Setting it to zero gives the normal equations $X^\top X\mathbf w=X^\top\mathbf y$ — the closed form of linear regression (Ch 13, 19). Numeric check with $X=\begin{pmatrix}1&0\\0&2\end{pmatrix}$, $\mathbf y=(1,2)^\top$, $\mathbf w=(0,0)^\top$: $\nabla L=-2X^\top\mathbf y=(-2,-8)^\top$; finite differences on $L=(w_1-1)^2+(2w_2-2)^2$ agree: $\partial_{w_1}L=2(w_1-1)=-2$, $\partial_{w_2}L=4(2w_2-2)=-8$. ✓
    Think first Why does $\nabla_{\mathbf x}(\mathbf x^\top A\mathbf x)$ have both $A$ and $A^\top$? Try $n=2$, $A=\begin{pmatrix}0&1\\0&0\end{pmatrix}$.
    Reveal
    $\mathbf x^\top A\mathbf x=x_1x_2$. Gradient $(x_2,x_1)^\top$. And $(A+A^\top)\mathbf x=\begin{pmatrix}0&1\\1&0\end{pmatrix}\mathbf x=(x_2,x_1)^\top$ ✓, while $2A\mathbf x=(2x_2,0)^\top$ ✗. Each $x_i$ appears in the quadratic form both via rows and via columns of $A$; the product rule collects both, giving $A+A^\top$.
    Drill
    1. EASY $f(\mathbf x)=\|\mathbf x\|^2+\mathbf b^\top\mathbf x$. Find $\nabla f$ and the minimizer.
      Solution
      $\nabla f=2\mathbf x+\mathbf b=\mathbf0\Rightarrow\mathbf x^\star=-\mathbf b/2$.
    2. MED Compute $\nabla_{\mathbf x}\,(\mathbf x^\top A\mathbf x)$ by indices for general $A$.
      Solution
      $f=\sum_{ij}A_{ij}x_ix_j$. $\partial_{x_k}f=\sum_jA_{kj}x_j+\sum_iA_{ik}x_i=(A\mathbf x)_k+(A^\top\mathbf x)_k$. So $\nabla f=(A+A^\top)\mathbf x$.
    3. MED Ridge regression: $L(\mathbf w)=\|X\mathbf w-\mathbf y\|^2+\lambda\|\mathbf w\|^2$. Derive the minimizer.
      Solution
      $\nabla L=2X^\top(X\mathbf w-\mathbf y)+2\lambda\mathbf w=\mathbf0\Rightarrow(X^\top X+\lambda I)\mathbf w=X^\top\mathbf y$, so $\mathbf w^\star=(X^\top X+\lambda I)^{-1}X^\top\mathbf y$ (invertible for $\lambda>0$ since $X^\top X\succeq0$).
    4. HARD Softmax–cross-entropy: with logits $\mathbf z$, $p_i=\dfrac{e^{z_i}}{\sum_je^{z_j}}$ and loss $L=-\ln p_c$ for true class $c$. Show $\nabla_{\mathbf z}L=\mathbf p-\mathbf e_c$.
      Solution
      $L=-z_c+\ln\sum_je^{z_j}$. $\partial_{z_k}L=-[k=c]+\dfrac{e^{z_k}}{\sum_je^{z_j}}=p_k-[k=c]$. Stack: $\nabla L=\mathbf p-\mathbf e_c$ — the famous "prediction minus target" gradient used throughout Ch 21–23.

    Gradients with respect to matrices

    In a neural network the unknowns are weight matrices, so we need $\partial L/\partial W$: a matrix of the same shape as $W$, each entry the sensitivity of the loss to that weight. The clean tool is the differential: expand $dL$ and read the gradient off $dL=\mathrm{tr}(G^\top dW)$.

    Definition For scalar $L(W)$, $\nabla_WL\in\mathbb{R}^{m\times n}$ with entries $\partial L/\partial W_{ij}$, characterized by $dL=\mathrm{tr}\!\big((\nabla_WL)^\top dW\big)$. Trace tools: $\mathrm{tr}(AB)=\mathrm{tr}(BA)$, $\mathrm{tr}(A^\top)=\mathrm{tr}(A)$, and $d(\mathrm{tr}\,X)=\mathrm{tr}(dX)$.
    Worked example Linear layer with loss: $L=\tfrac12\|W\mathbf x-\mathbf y\|^2$. Let $\mathbf r=W\mathbf x-\mathbf y$. Then $dL=\mathbf r^\top d(W\mathbf x)=\mathbf r^\top(dW)\mathbf x=\mathrm{tr}(\mathbf x\mathbf r^\top dW)=\mathrm{tr}\big((\mathbf r\mathbf x^\top)^\top dW\big)$. So $$\nabla_WL=\mathbf r\,\mathbf x^\top=(W\mathbf x-\mathbf y)\,\mathbf x^\top,$$ an outer product: (output error) × (input)ᵀ — exactly what backprop computes for every dense layer. Shapes: $(m\times1)(1\times n)=m\times n$ ✓.
    Where this goes $\nabla_WL=\boldsymbol\delta\,\mathbf x^\top$ is the update rule inside every framework; see backpropagation below and Ch 21.
    Drill
    1. EASY $L=\mathbf a^\top W\mathbf b$. Find $\nabla_WL$.
      Solution
      $dL=\mathbf a^\top(dW)\mathbf b=\mathrm{tr}(\mathbf b\mathbf a^\top dW)$, so $\nabla_WL=\mathbf a\mathbf b^\top$.
    2. MED $L=\tfrac12\|W\|_F^2=\tfrac12\mathrm{tr}(W^\top W)$. Find $\nabla_WL$ and connect to weight decay.
      Solution
      $dL=\tfrac12\mathrm{tr}(dW^\top W+W^\top dW)=\mathrm{tr}(W^\top dW)$, so $\nabla_WL=W$. Adding $\frac{\lambda}{2}\|W\|_F^2$ to a loss adds $\lambda W$ to the gradient — L2 regularization shrinks weights toward zero (Ch 15, 21).
    3. HARD Batch version: $L=\tfrac{1}{2}\|WX-Y\|_F^2$ with $X\in\mathbb{R}^{n\times B}$. Show $\nabla_WL=(WX-Y)X^\top$.
      Solution
      Let $R=WX-Y$. $dL=\mathrm{tr}(R^\top dW\,X)=\mathrm{tr}(XR^\top dW)=\mathrm{tr}\big((RX^\top)^\top dW\big)$, hence $\nabla_WL=RX^\top$ — the batch outer-product sum $\sum_b\mathbf r_b\mathbf x_b^\top$.

    Useful matrix derivative identities

    A short table you will use for the rest of the book. Each can be derived with differentials, but memorizing these saves hours: derivatives of traces, determinants, inverses and log-determinants — the last two power Gaussian likelihoods and normalizing flows.

    Definition Key identities (all derivable via $dL=\mathrm{tr}(G^\top dW)$): $$\nabla_X\,\mathrm{tr}(AX)=A^\top\qquad \nabla_X\,\mathrm{tr}(X^\top AX)=(A+A^\top)X$$ $$\nabla_X\ln\det X=(X^{-1})^\top\qquad d(X^{-1})=-X^{-1}(dX)X^{-1}$$ $$\nabla_{\mathbf x}\|\mathbf x\|_2=\frac{\mathbf x}{\|\mathbf x\|_2}\ (\mathbf x\neq\mathbf0),\qquad \nabla_X\,\mathrm{tr}(X^\top X)=2X.$$
    Worked example Gradient of a Gaussian log-likelihood in the precision matrix $\Lambda=\Sigma^{-1}$ (symmetric positive definite): $$\ell(\Lambda)=\tfrac12\ln\det\Lambda-\tfrac12\mathbf x^\top\Lambda\mathbf x+\text{const}.$$ Using the table: $\nabla_\Lambda\ln\det\Lambda=\Lambda^{-1}$ (symmetric, so transpose drops) and $\nabla_\Lambda(\mathbf x^\top\Lambda\mathbf x)=\nabla_\Lambda\mathrm{tr}(\Lambda\mathbf x\mathbf x^\top)=\mathbf x\mathbf x^\top$. So $\nabla_\Lambda\ell=\tfrac12\Sigma-\tfrac12\mathbf x\mathbf x^\top$: the MLE sets $\Sigma=$ average of $\mathbf x\mathbf x^\top$ — the sample covariance (Ch 13).
    Pitfall $\nabla_X\ln\det X=(X^{-1})^\top$, not $X^{-1}$ — they agree only for symmetric $X$. And $\det$ requires $X$ square and (for $\ln\det$) positive determinant.
    Drill
    1. EASY Verify $\nabla_X\ln\det X=(X^{-1})^\top$ for diagonal $X=\mathrm{diag}(x_1,\dots,x_n)$, $x_i>0$.
      Solution
      $\ln\det X=\sum_i\ln x_i$; the derivative in $x_i$ is $1/x_i$, so the gradient is $\mathrm{diag}(1/x_i)=X^{-1}=(X^{-1})^\top$ (diagonal is symmetric). ✓
    2. MED Derive $d(X^{-1})=-X^{-1}(dX)X^{-1}$.
      Solution
      Differentiate $XX^{-1}=I$: $(dX)X^{-1}+X\,d(X^{-1})=0$, so $d(X^{-1})=-X^{-1}(dX)X^{-1}$.
    3. HARD Show $\nabla_X\,\mathrm{tr}(AX^{-1})=-(X^{-1}AX^{-1})^\top$.
      Solution
      $d\,\mathrm{tr}(AX^{-1})=\mathrm{tr}(A\,d(X^{-1}))=-\mathrm{tr}(AX^{-1}(dX)X^{-1})=-\mathrm{tr}(X^{-1}AX^{-1}dX)$, so the gradient is $-(X^{-1}AX^{-1})^\top$.

    Backpropagation as the chain rule

    A deep network is a composition $L=\ell(f_k(\cdots f_2(f_1(\mathbf x))))$. The chain rule says the derivative is a product of Jacobians. Backpropagation is just the observation that multiplying them right-to-left — starting from the scalar loss — means every intermediate product is a vector, never a matrix. One forward pass, one backward pass, and you have the gradient with respect to every parameter at roughly twice the cost of evaluating the loss.

    Definition Let $\mathbf h_0=\mathbf x$, $\mathbf h_i=f_i(\mathbf h_{i-1};\theta_i)$, $L=\ell(\mathbf h_k)$. Define the adjoint $\boldsymbol\delta_i=\nabla_{\mathbf h_i}L$. Then $$\boldsymbol\delta_k=\nabla_{\mathbf h_k}\ell,\qquad \boldsymbol\delta_{i-1}=\Big(\frac{\partial\mathbf h_i}{\partial\mathbf h_{i-1}}\Big)^{\!\top}\boldsymbol\delta_i,\qquad \nabla_{\theta_i}L=\Big(\frac{\partial\mathbf h_i}{\partial\theta_i}\Big)^{\!\top}\boldsymbol\delta_i.$$
    Worked example Two-layer net, all numbers concrete. $\mathbf x=(1,2)^\top$, $W_1=\begin{pmatrix}1&0\\-1&1\end{pmatrix}$, ReLU, $\mathbf w_2=(1,1)^\top$, loss $L=\tfrac12(y-t)^2$ with target $t=2$.
    Forward: $\mathbf z=W_1\mathbf x=(1,1)^\top$; $\mathbf h=\mathrm{ReLU}(\mathbf z)=(1,1)^\top$; $y=\mathbf w_2^\top\mathbf h=2$… let's make it interesting: take $t=3$, so $L=\tfrac12(2-3)^2=\tfrac12$.
    Backward: $\dfrac{\partial L}{\partial y}=y-t=-1$. $\nabla_{\mathbf w_2}L=(y-t)\,\mathbf h=(-1,-1)^\top$. $\nabla_{\mathbf h}L=(y-t)\,\mathbf w_2=(-1,-1)^\top$. Through ReLU (both $z_i=1>0$, derivative 1): $\nabla_{\mathbf z}L=(-1,-1)^\top$. $\nabla_{W_1}L=\nabla_{\mathbf z}L\,\mathbf x^\top=\begin{pmatrix}-1&-2\\-1&-2\end{pmatrix}$. Check one entry by hand: nudge $(W_1)_{11}$ by $\epsilon$: $z_1=1+\epsilon$, $h_1=1+\epsilon$, $y=2+\epsilon$, $L=\tfrac12(\epsilon-1)^2\approx\tfrac12-\epsilon$: slope $-1$ ✓.
    Explore

    A 3-node chain $x\to u=wx\to h=\tanh u\to L=\frac12(h-t)^2$. Slide the weight and watch forward values (top) and backward adjoints (bottom) flow through the graph.

    Pitfall Backprop is not numerical differentiation (no $\epsilon$, exact up to float error) and not symbolic differentiation (no formula blow-up). It is the chain rule evaluated at numbers, cached on a graph. Also: adjoints are multiplied by $J^\top$, not $J$ — forward-mode uses $J$ (Ch 18).
    Where this goes Reverse-mode autodiff and computational graphs get a full treatment in Ch 18; vanishing/exploding products of Jacobians drive architecture design in Ch 21.
    Drill

      Solution
      $y=6$, $\partial L/\partial y=y-t=1$, $\partial y/\partial w=x=3$: $\partial L/\partial w=3$.

      Solution
      Each backward step multiplies by $a$, so $\delta_0=a^k\delta_k$. $|a|<1\Rightarrow a^k\to0$ (vanishing); $|a|>1\Rightarrow$ explosion.     4. HARD Explain why reverse mode costs $O(1)$ backward passes for a scalar loss with $n$ parameters, while forward mode would cost $O(n)$.
      Solution

Forward mode propagates one directional derivative per input direction, so covering $n$ parameters needs $n$ passes. With $n$ in the billions and one loss, reverse mode wins; forward mode wins for few inputs, many outputs (Ch 18).
    In backprop, the adjoint at layer $i-1$ equals the adjoint at layer $i$ multiplied by…

    Multiple integrals

    A single integral sums $f(x)\,dx$ over a line segment; a multiple integral sums $f\,dA$ or $f\,dV$ over a region of the plane or space. Picture tiling the region with tiny rectangles, weighting each tile by the function value, and adding up. Total probability, total mass, expected values — all are multiple integrals.

    Definition For $f$ continuous on a bounded region $R\subset\mathbb{R}^2$, $$\iint_R f\,dA=\lim_{\|\Delta\|\to0}\sum_{ij} f(x_{ij},y_{ij})\,\Delta A_{ij}.$$ Fubini's theorem: over a rectangle $[a,b]\times[c,d]$, the double integral equals either iterated integral: $\int_a^b\!\!\int_c^d f\,dy\,dx=\int_c^d\!\!\int_a^b f\,dx\,dy$.
    Worked example $\displaystyle\iint_{[0,1]\times[0,2]}(x+y^2)\,dA=\int_0^1\!\!\int_0^2(x+y^2)\,dy\,dx=\int_0^1\Big[xy+\tfrac{y^3}{3}\Big]_0^2dx=\int_0^1\Big(2x+\tfrac83\Big)dx=1+\tfrac83=\tfrac{11}{3}.$
    Drill
    1. EASY Compute $\iint_R xy\,dA$ over $R=[0,2]\times[0,3]$.
      Solution
      $\int_0^2x\,dx\int_0^3y\,dy=2\cdot\frac92=9$ (product of separated integrals).
    2. MED Compute $\iint_R e^{x+y}dA$ over $[0,1]^2$.
      Solution
      $\left(\int_0^1e^xdx\right)^2=(e-1)^2\approx2.952$.
    3. HARD A joint density is $f(x,y)=cxy$ on $[0,1]^2$ (0 outside). Find $c$ and $P(X+Y\le1)$.
      Solution
      $c\int_0^1\!\int_0^1xy\,dxdy=c\cdot\frac14=1\Rightarrow c=4$. $P=4\int_0^1\!\int_0^{1-x}xy\,dy\,dx=4\int_0^1x\frac{(1-x)^2}{2}dx=2\int_0^1(x-2x^2+x^3)dx=2(\tfrac12-\tfrac23+\tfrac14)=2\cdot\tfrac{1}{12}=\tfrac16$.

    Double integrals

    The practical craft: turn a 2-D region into iterated 1-D integrals with the right limits. For non-rectangular regions the inner limits depend on the outer variable, and sometimes swapping the order turns an impossible integral into an easy one.

    Definition If $R=\{(x,y): a\le x\le b,\ g_1(x)\le y\le g_2(x)\}$ (type I), then $$\iint_Rf\,dA=\int_a^b\!\!\int_{g_1(x)}^{g_2(x)}f(x,y)\,dy\,dx.$$ Type II regions swap the roles of $x$ and $y$.
    Worked example $\displaystyle\int_0^1\!\!\int_x^1 e^{y^2}\,dy\,dx$ is stuck — $e^{y^2}$ has no elementary antiderivative. Swap the order: the region is $0\le x\le y\le1$, so $$\int_0^1\!\!\int_0^y e^{y^2}\,dx\,dy=\int_0^1 y\,e^{y^2}dy=\Big[\tfrac12e^{y^2}\Big]_0^1=\tfrac{e-1}{2}.$$
    Pitfall When you swap the order of integration, you must redraw the region and rederive the limits — never just swap the symbols $dx\,dy$.
    Drill
    1. EASY Integrate $f=1$ over the triangle with vertices $(0,0),(1,0),(1,1)$.
      Solution
      $\int_0^1\!\int_0^x dy\,dx=\int_0^1x\,dx=\frac12$ — the triangle's area. ✓
    2. MED Compute $\iint_R (x+y)\,dA$ where $R$ is bounded by $y=x^2$ and $y=x$.
      Solution
      Curves meet at $x=0,1$; $x^2\le y\le x$ on $[0,1]$. $\int_0^1\!\int_{x^2}^{x}(x+y)dy\,dx=\int_0^1\Big[xy+\tfrac{y^2}{2}\Big]_{x^2}^{x}dx=\int_0^1\big(x^2+\tfrac{x^2}{2}-x^3-\tfrac{x^4}{2}\big)dx=\tfrac12+\tfrac16-\tfrac14-\tfrac1{10}=\tfrac{3}{10}$.
    3. HARD Evaluate $\int_0^1\!\!\int_{\sqrt{y}}^{1}\sin(x^3)\,dx\,dy$ by reversing the order.
      Solution
      Region: $\sqrt y\le x\le1$, $0\le y\le1$ ⟺ $0\le y\le x^2$, $0\le x\le1$. So $\int_0^1\!\int_0^{x^2}\sin(x^3)dy\,dx=\int_0^1x^2\sin(x^3)dx=\Big[-\tfrac13\cos(x^3)\Big]_0^1=\tfrac{1-\cos1}{3}\approx0.1533$.

    Triple integrals

    Same idea, one more dimension: chop a solid into boxes, weight, sum. Choosing the right coordinate system (Cartesian, cylindrical, spherical) is most of the battle; the integrand and region symmetry tell you which.

    Definition $\displaystyle\iiint_E f\,dV=\int\!\!\int\!\!\int f(x,y,z)\,dz\,dy\,dx$ over a solid $E$, iterated in any convenient order. Cylindrical: $dV=r\,dz\,dr\,d\theta$. Spherical: $dV=\rho^2\sin\phi\,d\rho\,d\phi\,d\theta$.
    Worked example Volume of the ball of radius $a$: $$\int_0^{2\pi}\!\!\int_0^{\pi}\!\!\int_0^{a}\rho^2\sin\phi\,d\rho\,d\phi\,d\theta=2\pi\cdot\Big[-\cos\phi\Big]_0^\pi\cdot\frac{a^3}{3}=2\pi\cdot2\cdot\frac{a^3}{3}=\frac{4}{3}\pi a^3.$$
    Drill
    1. EASY Compute $\iiint_E dV$ for the box $[0,1]\times[0,2]\times[0,3]$.
      Solution
      $1\cdot2\cdot3=6$.
    2. MED Find the volume under $z=4-x^2-y^2$ above the $xy$-plane.
      Solution
      Cylindrical: $z=4-r^2\ge0$ for $r\le2$. $V=\int_0^{2\pi}\!\int_0^2(4-r^2)r\,dr\,d\theta=2\pi\Big[2r^2-\tfrac{r^4}{4}\Big]_0^2=2\pi(8-4)=8\pi$.

      Solution
      Spherical with $z=\rho\cos\phi$: $\int_0^{2\pi}\!\int_0^{\pi/2}\!\int_0^1\rho\cos\phi\,\rho^2\sin\phi\,d\rho\,d\phi\,d\theta=2\pi\cdot\frac14\cdot\int_0^{\pi/2}\sin\phi\cos\phi\,d\phi=2\pi\cdot\frac14\cdot\frac12=\frac{\pi}{4}$.

    Change of variables

    Substitution in many dimensions: warp the region into a simpler one via a map $T$, and pay for the warping with the absolute value of the Jacobian determinant — the local area/volume stretch factor. Polar, cylindrical and spherical coordinates are all special cases.

    Definition If $T:(u,v)\mapsto(x,y)$ is one-to-one and continuously differentiable on a region $S$ with image $R$, then $$\iint_R f(x,y)\,dx\,dy=\iint_S f(T(u,v))\,\left|\det\frac{\partial(x,y)}{\partial(u,v)}\right|\,du\,dv.$$
    Worked example The Gaussian integral $I=\int_{-\infty}^{\infty}e^{-x^2}dx$. Square it and go polar: $$I^2=\iint_{\mathbb{R}^2}e^{-(x^2+y^2)}dA=\int_0^{2\pi}\!\!\int_0^{\infty}e^{-r^2}\,r\,dr\,d\theta=2\pi\cdot\Big[-\tfrac12e^{-r^2}\Big]_0^\infty=\pi.$$ So $I=\sqrt\pi$ — the normalizing constant of the Gaussian distribution (Ch 11) in one line, courtesy of the Jacobian factor $r$.
    Drill
    1. EASY Use polar coordinates to compute $\iint_{x^2+y^2\le4}(x^2+y^2)\,dA$.
      Solution
      $\int_0^{2\pi}\!\int_0^2r^2\cdot r\,dr\,d\theta=2\pi\cdot\frac{16}{4}=8\pi$.
    2. MED Evaluate $\iint_R(x-y)^2\,dA$ over the square with vertices $(1,0),(0,1),(-1,0),(0,-1)$ using $u=x+y$, $v=x-y$.
      Solution
      The square is $|u|\le1,|v|\le1$. $x=\frac{u+v}{2},y=\frac{u-v}{2}$, $\det\frac{\partial(x,y)}{\partial(u,v)}=\begin{vmatrix}1/2&1/2\\1/2&-1/2\end{vmatrix}=-\tfrac12$, so $dA=\frac12du\,dv$. Integral $=\frac12\int_{-1}^1\!\int_{-1}^1v^2du\,dv=\frac12\cdot2\cdot\frac23=\frac23$.
    3. HARD Show that if $\mathbf y=A\mathbf x$ with invertible $A$, the uniform density on a set $S$ maps to a density scaled by $1/|\det A|$ on $AS$ — and connect to the change-of-variables formula for probability densities.
      Solution
      Volumes scale by $|\det A|$: $\mathrm{vol}(AS)=|\det A|\,\mathrm{vol}(S)$. Probability mass is conserved, so density $=$ mass/volume must shrink by $|\det A|$: $p_Y(\mathbf y)=p_X(A^{-1}\mathbf y)/|\det A|$. In general for $\mathbf y=g(\mathbf x)$: $p_Y(\mathbf y)=p_X(g^{-1}(\mathbf y))\,|\det J_{g^{-1}}(\mathbf y)|$ — the identity behind normalizing flows (Ch 22).

    Jacobian determinant

    The determinant of the Jacobian is a single number with a vivid meaning: how much the map stretches area (2-D) or volume ($n$-D) near a point, with sign recording orientation flip. $|\det J|>1$ expands, $<1$ compresses, $=0$ flattens — where the map is not locally invertible.

    Definition For $T:\mathbb{R}^n\to\mathbb{R}^n$ differentiable, the Jacobian determinant at $\mathbf u$ is $\det J_T(\mathbf u)$. A small region of volume $dV$ near $\mathbf u$ maps to a region of volume $|\det J_T(\mathbf u)|\,dV$. Inverse function theorem: if $\det J_T(\mathbf u)\neq0$ and $T$ is continuously differentiable, $T$ is locally invertible near $\mathbf u$, with $J_{T^{-1}}=(J_T)^{-1}$.
    Worked example Spherical coordinates $x=\rho\sin\phi\cos\theta$, $y=\rho\sin\phi\sin\theta$, $z=\rho\cos\phi$: expanding the $3\times3$ determinant gives $\det J=\rho^2\sin\phi$ — the factor in every spherical integral. Check dimensions: $\rho^2\sin\phi\,d\rho\,d\phi\,d\theta$ has units of volume ✓, and it vanishes on the $z$-axis ($\phi=0,\pi$) where spherical coordinates degenerate.
    Explore

    The linear map $\begin{pmatrix}a&b\\c&d\end{pmatrix}$ sends the unit square to a parallelogram. Slide the entries; the shaded area is $|\det|$, and it collapses when the columns align.

    Where this goes $\ln|\det J|$ is the exact log-density correction in normalizing flows (Ch 22) and in the change-of-variables formula for densities (Ch 11).

    Vector fields

    A vector field attaches an arrow to every point: wind on a weather map, gradients on a loss surface, flow of a differential equation. Two big questions about any field: does it swirl (curl), and does it spread (divergence)? And is it secretly the gradient of some potential function?

    Definition A vector field on $\mathbb{R}^n$ is a map $\mathbf F:\mathbb{R}^n\to\mathbb{R}^n$, written $\mathbf F=(P,Q)$ in 2-D or $(P,Q,R)$ in 3-D. $\mathbf F$ is conservative if $\mathbf F=\nabla f$ for a scalar potential $f$; in 2-D on a simply connected domain this holds iff $\partial P/\partial y=\partial Q/\partial x$.
    Worked example Is $\mathbf F=(2xy+3,\;x^2+4y)$ conservative? $\partial_y(2xy+3)=2x$ and $\partial_x(x^2+4y)=2x$ — equal on all of $\mathbb{R}^2$, so yes. Find $f$: $f_x=2xy+3\Rightarrow f=x^2y+3x+g(y)$; then $f_y=x^2+g'(y)=x^2+4y\Rightarrow g=2y^2$. Potential: $f=x^2y+3x+2y^2$.
    Explore

    Blend a purely rotating field with a purely expanding one. The readouts show curl and divergence; watch the arrows change character.

    1. EASY Sketch/describe the field $\mathbf F(x,y)=(-y,x)$.
      Solution
      At each point the arrow is perpendicular to the position vector, length $=$ distance from origin: rigid counterclockwise rotation.
    2. MED Is $\mathbf F=(-y,x)$ conservative?
      Solution
      $\partial_y(-y)=-1\neq1=\partial_x(x)$. No — a rotating field cannot be a gradient (gradients have zero circulation on loops).
    3. HARD $\mathbf F=\left(\dfrac{-y}{x^2+y^2},\dfrac{x}{x^2+y^2}\right)$ satisfies $P_y=Q_x$ away from the origin, yet its circulation around the unit circle is $2\pi\neq0$. Reconcile.
      Solution
      Compute: $P_y=\frac{-(x^2+y^2)+2y^2}{(x^2+y^2)^2}=\frac{y^2-x^2}{(x^2+y^2)^2}=Q_x$. But the domain $\mathbb{R}^2\setminus\{0\}$ is not simply connected — the equality of crossed partials only guarantees a potential on domains without holes. Locally $\mathbf F=\nabla\theta$ (the angle), but $\theta$ cannot be defined continuously around the origin; each loop gains $2\pi$.

    Line integrals

    Integrate along a curve instead of an interval: either a scalar (mass of a wire, $\int f\,ds$) or the tangential component of a field (work done by a force, $\int\mathbf F\cdot d\mathbf r$). For conservative fields, work depends only on endpoints — the fundamental theorem of calculus, upgraded to curves.

    Definition For a curve $C$ parametrized by $\mathbf r(t)$, $t\in[a,b]$: $$\int_C f\,ds=\int_a^b f(\mathbf r(t))\,\|\mathbf r'(t)\|\,dt,\qquad \int_C\mathbf F\cdot d\mathbf r=\int_a^b\mathbf F(\mathbf r(t))\cdot\mathbf r'(t)\,dt.$$ Fundamental theorem for line integrals: if $\mathbf F=\nabla f$, then $\int_C\mathbf F\cdot d\mathbf r=f(\mathbf r(b))-f(\mathbf r(a))$.
    Worked example Work by $\mathbf F=(y,\,x^2)$ along $\mathbf r(t)=(t,t^2)$, $t\in[0,1]$: $\mathbf r'=(1,2t)$, $\mathbf F(\mathbf r)=(t^2,t^2)$. $$W=\int_0^1(t^2\cdot1+t^2\cdot2t)\,dt=\int_0^1(t^2+2t^3)dt=\tfrac13+\tfrac12=\tfrac56.$$
    Drill
    1. EASY Compute $\int_C x\,ds$ where $C$ is the segment from $(0,0)$ to $(3,4)$.
      Solution
      $\mathbf r(t)=(3t,4t)$, $\|\mathbf r'\|=5$. $\int_0^13t\cdot5\,dt=\frac{15}{2}$.
    2. MED Compute $\int_C\mathbf F\cdot d\mathbf r$ for the conservative $\mathbf F=(2xy+3,\,x^2+4y)$ from $(0,0)$ to $(1,2)$ (any path).
      Solution
      Potential $f=x^2y+3x+2y^2$ (from the vector-fields example). $W=f(1,2)-f(0,0)=2+3+8=13$.
    3. HARD Compute the circulation of $\mathbf F=(-y,x)$ around the circle $x^2+y^2=R^2$ (counterclockwise) and interpret.
      Solution
      $\mathbf r=(R\cos t,R\sin t)$, $\mathbf r'=(-R\sin t,R\cos t)$, $\mathbf F\cdot\mathbf r'=R^2\sin^2t+R^2\cos^2t=R^2$. Circulation $=\int_0^{2\pi}R^2dt=2\pi R^2$ — twice the enclosed area times the field's rotation rate; consistent with curl $=2$ over area $\pi R^2$ via Green's theorem.

    Surface integrals

    Now integrate over a curved 2-D surface sitting in 3-D: total of a scalar over the surface ($\iint f\,dS$), or the flux of a field through it ($\iint\mathbf F\cdot d\mathbf S$) — how much of the field pokes through per unit time. Flux through closed surfaces is the star of the divergence theorem.

    Definition For a surface parametrized by $\mathbf r(u,v)$ on domain $D$: $$\iint_S f\,dS=\iint_D f(\mathbf r)\,\|\mathbf r_u\times\mathbf r_v\|\,du\,dv,\qquad \iint_S\mathbf F\cdot d\mathbf S=\iint_D\mathbf F(\mathbf r)\cdot(\mathbf r_u\times\mathbf r_v)\,du\,dv,$$ orientation chosen by the direction of $\mathbf r_u\times\mathbf r_v$.
    Worked example Flux of $\mathbf F=(0,0,z)$ up through the disk $x^2+y^2\le1$, $z=1$? Parametrize $\mathbf r(u,v)=(u,v,1)$ over the unit disk; $\mathbf r_u\times\mathbf r_v=(0,0,1)$. $\mathbf F=(0,0,1)$ on the disk. Flux $=\iint_D1\,dA=\pi$. Now flux of the same field out of the sphere $x^2+y^2+z^2=1$: by symmetry use the divergence theorem preview — $\nabla\cdot\mathbf F=1$, so flux $=\mathrm{vol}=\frac43\pi$.

    Divergence

    Put a tiny box at a point: divergence measures net outflow per unit volume. Positive = source (field spreads out), negative = sink, zero = incompressible flow. It converts a vector field into a scalar field of "spreadiness."

    Definition $$\nabla\cdot\mathbf F=\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}.$$ Equivalently $\nabla\cdot\mathbf F(\mathbf p)=\lim_{V\to0}\frac{1}{|V|}\oint_{\partial V}\mathbf F\cdot d\mathbf S$ over shrinking volumes around $\mathbf p$.
    Worked example $\mathbf F=(x,y,z)$ (radial explosion): $\nabla\cdot\mathbf F=1+1+1=3$ everywhere — a uniform source. $\mathbf F=(-y,x,0)$ (rotation): $\nabla\cdot\mathbf F=0+0+0=0$ — spinning flow neither creates nor destroys volume.
    Where this goes The divergence of a probability flow appears in the Fokker–Planck equation (Ch 12) and in the continuity equation behind diffusion models (Ch 22); $\mathrm{tr}(J)=\nabla\cdot\mathbf f$ gives the volume growth of ODE flows (Ch 10).
    Drill
    1. EASY Compute $\nabla\cdot\mathbf F$ for $\mathbf F=(x^2,\,xy,\,z^3)$.
      Solution
      $2x+x+3z^2=3x+3z^2$.
    2. MED Show $\nabla\cdot(\nabla f)=\nabla^2f=f_{xx}+f_{yy}+f_{zz}$ (the Laplacian) for $f=x^2y+z^2$.
      Solution
      $\nabla f=(2xy,x^2,2z)$; divergence $=2y+0+2=2y+2$. Directly: $f_{xx}=2y$, $f_{yy}=0$, $f_{zz}=2$. ✓
    3. HARD For the inverse-square field $\mathbf F=\dfrac{\mathbf r}{\|\mathbf r\|^3}$ ($\mathbf r=(x,y,z)$), show $\nabla\cdot\mathbf F=0$ for $\mathbf r\neq\mathbf0$.
      Solution
      With $r=\|\mathbf r\|$: $\partial_x\!\left(\dfrac{x}{r^3}\right)=\dfrac{1}{r^3}-\dfrac{3x^2}{r^5}$. Summing over $x,y,z$: $\dfrac{3}{r^3}-\dfrac{3(x^2+y^2+z^2)}{r^5}=\dfrac{3}{r^3}-\dfrac{3}{r^3}=0$. All the "source" of gravity/Coulomb fields is concentrated at the origin.

    Curl

    Drop a tiny paddle wheel into the flow: curl measures how fast it spins, and about which axis. It converts a 3-D field into another 3-D field of local rotation. Zero curl (plus a hole-free domain) means the field is a gradient — no swirl, pure descent/ascent.

    Definition $$\nabla\times\mathbf F=\begin{vmatrix}\hat{\mathbf i}&\hat{\mathbf j}&\hat{\mathbf k}\\ \partial_x&\partial_y&\partial_z\\ P&Q&R\end{vmatrix}=\big(R_y-Q_z,\;P_z-R_x,\;Q_x-P_y\big).$$ In 2-D the scalar curl is $Q_x-P_y$. Identities: $\nabla\times(\nabla f)=\mathbf0$ and $\nabla\cdot(\nabla\times\mathbf F)=0$.
    Worked example $\mathbf F=(-y,x,0)$: $\nabla\times\mathbf F=(0-0,\;0-0,\;1-(-1))=(0,0,2)$ — uniform rotation about the $z$-axis at angular rate $1$, curl magnitude twice the angular velocity. And $\mathbf F=\nabla(x^2+y^2)=(2x,2y,0)$: curl $=(0,0,0)$ — gradients never swirl.
    Pitfall Curl-free implies conservative only on simply connected domains — recall the punctured-plane field whose loop integral is $2\pi$ despite zero curl everywhere it is defined.
    Drill
    1. EASY Compute $\nabla\times\mathbf F$ for $\mathbf F=(yz,\,xz,\,xy)$.
      Solution
      $(\partial_y(xy)-\partial_z(xz),\ \partial_z(yz)-\partial_x(xy),\ \partial_x(xz)-\partial_y(yz))=(x-x,\,y-y,\,z-z)=\mathbf0$. Indeed $\mathbf F=\nabla(xyz)$.
    2. MED Verify $\nabla\cdot(\nabla\times\mathbf F)=0$ for $\mathbf F=(x^2y,\,z^3,\,xy)$.
      Solution
      $\nabla\times\mathbf F=(\partial_y(xy)-\partial_z(z^3),\ \partial_z(x^2y)-\partial_x(xy),\ \partial_x(z^3)-\partial_y(x^2y))=(x-3z^2,\,-y,\,-x^2)$. Divergence: $\partial_x(x-3z^2)+\partial_y(-y)+\partial_z(-x^2)=1-1+0=0$ ✓.
    3. HARD A 2-D field $\mathbf F=(P,Q)$ has scalar curl $c(x,y)=Q_x-P_y$. Show the circulation around a tiny square of side $h$ centered at $\mathbf p$ is $\approx c(\mathbf p)h^2$.
      Solution
      Sum the four sides. Bottom ($y-\frac h2$, rightward) and top ($y+\frac h2$, leftward) contribute $\approx h[P(x,y-\frac h2)-P(x,y+\frac h2)]\approx-h^2P_y$. Right and left similarly give $h[Q(x+\frac h2,y)-Q(x-\frac h2,y)]\approx h^2Q_x$. Total $\approx(Q_x-P_y)h^2$ — the differential statement of Green's theorem.

    Green's theorem

    Circulation around a closed loop equals the total curl inside it. All the internal swirling cancels along shared edges of tiny cells; only the boundary survives. It is the 2-D member of the great boundary-equals-interior family.

    Theorem (Green) For a positively oriented, piecewise-smooth simple closed curve $C$ bounding a region $D$, with $P,Q$ continuously differentiable on an open set containing $D$: $$\oint_C P\,dx+Q\,dy=\iint_D\Big(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\Big)\,dA.$$
    Worked example $\oint_C(x^2-y)\,dx+(x+y^2)\,dy$ around the unit circle. $Q_x-P_y=1-(-1)=2$, so the integral is $2\times\pi=2\pi$ — no parametrization needed. Bonus: taking $P=-y/2$, $Q=x/2$ gives the area formula $A=\frac12\oint x\,dy-y\,dx$.
    Drill
    1. EASY Use Green's theorem to evaluate $\oint_C -y\,dx+x\,dy$ around any simple closed curve enclosing area $A$.
      Solution
      $Q_x-P_y=1+1=2$: integral $=2A$.
    2. MED Evaluate $\oint_C y^2dx+3xy\,dy$ around the boundary of the upper half-disk $x^2+y^2\le1,y\ge0$.
      Solution
      $Q_x-P_y=3y-2y=y$. $\iint_D y\,dA=\int_0^\pi\!\int_0^1 r\sin\theta\,r\,dr\,d\theta=\frac13\cdot2=\frac23$.
    3. HARD Compute the area of the ellipse $x=a\cos t$, $y=b\sin t$ via $A=\frac12\oint x\,dy-y\,dx$.
      Solution
      $x\,dy-y\,dx=a\cos t\cdot b\cos t\,dt-b\sin t\cdot(-a\sin t)\,dt=ab\,dt$. $A=\frac12\int_0^{2\pi}ab\,dt=\pi ab$.

    Stokes' theorem

    Green's theorem lifted into 3-D: the circulation of a field around the rim of a surface equals the flux of its curl through the surface — any surface with that rim. Swirl inside cancels; the boundary keeps the score.

    Theorem (Stokes) For an oriented piecewise-smooth surface $S$ with boundary curve $\partial S$ (oriented compatibly, right-hand rule): $$\oint_{\partial S}\mathbf F\cdot d\mathbf r=\iint_S(\nabla\times\mathbf F)\cdot d\mathbf S.$$
    Worked example $\mathbf F=(-y,x,z^2)$, $S$ the upper unit hemisphere, boundary the unit circle in the plane $z=0$. $\nabla\times\mathbf F=(0,0,2)$. Easiest surface with the same rim: the flat disk. Flux of $(0,0,2)$ up through the disk $=2\pi$. Check by direct circulation: on the rim, $\mathbf F\cdot d\mathbf r$ reduces to the 2-D rotation computation $=2\pi$ ✓. Freedom to swap surfaces is the practical power of the theorem.
    Drill
    1. EASY If $\nabla\times\mathbf F=\mathbf 0$ everywhere, what is $\oint_C\mathbf F\cdot d\mathbf r$ around any closed curve bounding a surface?
      Solution
      Zero, by Stokes — curl-free fields have no circulation on contractible loops.
    2. MED Use Stokes to evaluate $\oint_C\mathbf F\cdot d\mathbf r$ for $\mathbf F=(z,x,y)$ around the triangle $(1,0,0)\to(0,1,0)\to(0,0,1)\to(1,0,0)$.
      Solution
      $\nabla\times\mathbf F=(\partial_yy-\partial_zx,\ \partial_zz-\partial_xy,\ \partial_xx-\partial_yz)=(1,1,1)$. The triangle lies in $x+y+z=1$ with unit normal $(1,1,1)/\sqrt3$ and area $\frac{\sqrt3}{2}$. Flux $=(1,1,1)\cdot\frac{(1,1,1)}{\sqrt3}\cdot\frac{\sqrt3}{2}=\frac{3}{2}$.
    3. HARD Two different surfaces $S_1,S_2$ share the same boundary curve. Show $\iint_{S_1}(\nabla\times\mathbf F)\cdot d\mathbf S=\iint_{S_2}(\nabla\times\mathbf F)\cdot d\mathbf S$ two ways.
      Solution
      (1) Both equal the boundary circulation by Stokes. (2) $S_1\cup(-S_2)$ is a closed surface; by the divergence theorem its total flux of $\nabla\times\mathbf F$ is $\iiint\nabla\cdot(\nabla\times\mathbf F)\,dV=0$ since div curl $=0$; hence the two fluxes agree.

    Divergence theorem

    Total outflow through a closed surface equals total source strength inside. Sum the microscopic outflows (divergence) over the volume; interior flows cancel across shared faces, leaving only flux through the skin. Conservation laws — of mass, heat, charge, probability — are all this theorem in action.

    Theorem (Gauss/divergence) For a solid region $E$ with outward-oriented boundary surface $\partial E$: $$\oiint_{\partial E}\mathbf F\cdot d\mathbf S=\iiint_E\nabla\cdot\mathbf F\,dV.$$
    Worked example Flux of $\mathbf F=(x^3,y^3,z^3)$ out of the unit sphere. $\nabla\cdot\mathbf F=3(x^2+y^2+z^2)=3\rho^2$. $$\iiint_E3\rho^2\,dV=3\int_0^{2\pi}\!\!\int_0^\pi\!\!\int_0^1\rho^2\cdot\rho^2\sin\phi\,d\rho\,d\phi\,d\theta=3\cdot2\pi\cdot2\cdot\tfrac15=\tfrac{12\pi}{5}.$$ Direct surface computation would be painful; the theorem makes it three lines.
    Where this goes Applied to probability flux, this is how the Fokker–Planck equation (Ch 12) conserves total probability, and how the continuity equation underlies the probability-flow ODE of diffusion models (Ch 22).
    Drill
    1. EASY Flux of $\mathbf F=(x,y,z)$ out of any region of volume $V$?
      Solution
      $\nabla\cdot\mathbf F=3$, so flux $=3V$.
    2. MED Compute the flux of $\mathbf F=(xy,\,y z,\,zx)$ out of the unit cube $[0,1]^3$.
      Solution
      $\nabla\cdot\mathbf F=y+z+x$. $\iiint_{[0,1]^3}(x+y+z)dV=3\cdot\frac12=\frac32$.
    3. HARD Heat with density $u(\mathbf x,t)$ flows with flux $\mathbf q=-k\nabla u$. Use the divergence theorem on an arbitrary region to derive the heat equation $u_t=k\nabla^2u$.
      Solution
      Energy in region $E$: $\frac{d}{dt}\iiint_Eu\,dV=-\oiint_{\partial E}\mathbf q\cdot d\mathbf S$ (outflow decreases energy) $=-\iiint_E\nabla\cdot\mathbf q\,dV=\iiint_Ek\nabla^2u\,dV$. Since $E$ is arbitrary and the integrands continuous, $u_t=k\nabla^2u$ pointwise — the PDE of Ch 10.
    Green's, Stokes' and the divergence theorem all say the same kind of thing. Which?
    Each is a case of the generalized Stokes theorem: $\int_{\Omega}d\omega=\int_{\partial\Omega}\omega$ — interior accumulation of a derivative shows up entirely on the boundary, just like the fundamental theorem of calculus.

    Manifolds and the manifold hypothesis

    A manifold is a shape that looks flat if you zoom in far enough — a curve is a 1-D manifold, a sphere's surface a 2-D manifold living in 3-D. The manifold hypothesis says real data (images, speech, text embeddings) lives near a low-dimensional manifold inside its huge ambient space: a million-pixel face image has maybe a few hundred true degrees of freedom (pose, lighting, identity). This is why learning is possible at all in high dimensions — and why moving "along the data manifold" (interpolating faces) differs from moving randomly in pixel space (producing noise).

    Definition A $k$-dimensional manifold $M\subset\mathbb{R}^n$ is a set that is locally diffeomorphic to $\mathbb{R}^k$: every point has a neighborhood on $M$ parametrized smoothly and invertibly by $k$ coordinates (a chart). The tangent space $T_pM$ at $p$ is the $k$-dimensional linear space of velocity vectors of curves through $p$ on $M$; for a level set $M=\{F=c\}$ with $\nabla F\neq0$, $T_pM=\{\mathbf v:\nabla F(p)\cdot\mathbf v=0\}$. Manifold hypothesis: natural high-dimensional data concentrates near a manifold with $k\ll n$.
    Worked example The unit circle $S^1=\{(x,y):x^2+y^2=1\}$ is a 1-D manifold in $\mathbb{R}^2$. Charts: $\theta\mapsto(\cos\theta,\sin\theta)$ on overlapping arcs (no single chart covers it all — a global angle is discontinuous somewhere). Tangent space at $p=(\frac{\sqrt2}{2},\frac{\sqrt2}{2})$: vectors orthogonal to $\nabla(x^2+y^2)=2p$, i.e. multiples of $(-1,1)$. Data version: grayscale $64\times64$ images of a clock face showing different times live in $\mathbb{R}^{4096}$ but form (approximately) a 1-D manifold parametrized by the time.
    Think first Take two natural images and average them pixel by pixel. Why does the result look like a ghostly double exposure rather than a natural image?
    Reveal
    The straight line between two points of a curved manifold leaves the manifold. Natural images occupy a thin curved set in pixel space; chords cut through the off-manifold interior. Generative models (Ch 22) fix this by interpolating in a learned latent space, where the decoder maps straight latent lines to curves along the data manifold.
    Where this goes Latent spaces of VAEs and diffusion models (Ch 22), representation learning (Ch 21), and latent world models (Ch 29) are all attempts to find coordinates (charts) for data manifolds.
    Drill
    1. EASY What is the dimension of the manifold of $2\times2$ rotation matrices $\begin{pmatrix}\cos\theta&-\sin\theta\\ \sin\theta&\cos\theta\end{pmatrix}$ inside $\mathbb{R}^4$?
      Solution
      One parameter $\theta$: a 1-D manifold (a circle) in 4-D space.
    2. MED Find the tangent space to the sphere $x^2+y^2+z^2=9$ at $(2,2,1)$.
      Solution
      Orthogonal complement of $\nabla F=(4,4,2)$, i.e. $\{(u,v,w):2u+2v+w=0\}$ — a 2-D plane, as expected for a 2-D manifold.
    3. HARD Images of a rigid object under all 3-D rotations and translations, at fixed lighting, form approximately a manifold of what dimension? What does this predict about the number of latent variables needed to model them?
      Solution
      Rigid motions have $3$ rotational $+$ $3$ translational $=6$ degrees of freedom, so a 6-D manifold (whatever the pixel count). A generative model should need only ~6 latent coordinates to traverse this family — the manifold hypothesis quantified. Real data adds dimensions for lighting, deformation, texture, but still $k\ll n$.

    Task 1 — Gradient checking Implement analytic gradients for $L(\mathbf w)=\tfrac12\|X\mathbf w-\mathbf y\|^2$ and verify them against central finite differences to ~8 significant digits.
    Reference solution
    import numpy as np
rng = np.random.default_rng(0)
X, y = rng.normal(size=(50, 8)), rng.normal(size=50)

def loss(w):   return 0.5 * np.sum((X @ w - y) ** 2)
def grad(w):   return X.T @ (X @ w - y)

w = rng.normal(size=8)
g = grad(w)
eps = 1e-6
g_num = np.array([(loss(w + eps*e) - loss(w - eps*e)) / (2*eps)
                  for e in np.eye(8)])
rel = np.abs(g - g_num) / (np.abs(g) + np.abs(g_num) + 1e-12)
print("max relative error:", rel.max())   # ~1e-9
assert rel.max() < 1e-6
    Task 2 — Backprop for a 2-layer MLP from scratch Implement forward and backward passes for $\mathbf h=\mathrm{ReLU}(W_1\mathbf x+\mathbf b_1)$, $\hat y=W_2\mathbf h+\mathbf b_2$, MSE loss, and check against PyTorch autograd.
    Reference solution
    import numpy as np, torch
rng = np.random.default_rng(1)
W1, b1 = rng.normal(size=(16, 4)), rng.normal(size=16)
W2, b2 = rng.normal(size=(1, 16)), rng.normal(size=1)
x, t = rng.normal(size=4), np.array([0.7])

# forward
z = W1 @ x + b1
h = np.maximum(z, 0)
yhat = W2 @ h + b2
L = 0.5 * np.sum((yhat - t) ** 2)

# backward (chain rule, right to left)
d_yhat = yhat - t                    # dL/dyhat
dW2 = np.outer(d_yhat, h)
db2 = d_yhat
d_h = W2.T @ d_yhat
d_z = d_h * (z > 0)                  # ReLU mask
dW1 = np.outer(d_z, x)
db1 = d_z

# autograd check
tp = lambda a: torch.tensor(a, requires_grad=True, dtype=torch.float64)
TW1, Tb1, TW2, Tb2 = map(tp, (W1, b1, W2, b2))
tx, tt = torch.tensor(x), torch.tensor(t)
Th = torch.relu(TW1 @ tx + Tb1)
TL = 0.5 * torch.sum((TW2 @ Th + Tb2 - tt) ** 2)
TL.backward()
for ours, theirs in [(dW1, TW1.grad), (db1, Tb1.grad),
                     (dW2, TW2.grad), (db2, Tb2.grad)]:
    assert np.allclose(ours, theirs.numpy(), atol=1e-10)
print("backprop matches autograd; L =", L)
    Task 3 — Monte Carlo change of variables Sample uniformly from the unit square, push samples through $T(u,v)=(u+0.5v,\ v)$ (a shear) and through polar coordinates, and confirm empirically that densities scale by $1/|\det J|$.
    Reference solution
    import numpy as np
rng = np.random.default_rng(2)
N = 1_000_000
u, v = rng.uniform(size=N), rng.uniform(size=N)

# shear: det J = 1 -> area preserved
x, y = u + 0.5 * v, v
box = (x > 0.5) & (x < 0.6) & (y > 0.2) & (y < 0.3)
print("shear density in box:", box.mean() / 0.01)   # ~1.0

r, th = u, 2 * np.pi * v
x, y = r * np.cos(th), r * np.sin(th)
