    Sample spaces

    Before you can reason about chance, list what can happen. The sample space is the set of all possible outcomes of an experiment — every die face, every coin sequence, every possible dataset. Choosing it well is half the modeling.

    Definition The sample space $\Omega$ is the set of all possible outcomes $\omega$ of an experiment. It may be finite ($\{H,T\}$), countably infinite (number of emails today: $\{0,1,2,\dots\}$), or uncountable ($[0,1]$, $\mathbb{R}^n$).
    Worked example Toss two distinguishable coins: $\Omega=\{HH,HT,TH,TT\}$, $|\Omega|=4$. If instead we only record the number of heads, $\Omega'=\{0,1,2\}$ — a different (coarser) sample space, and outcomes are no longer equally likely: $P(1)=\frac12$ but $P(0)=P(2)=\frac14$ in the fair-coin model.
    Pitfall "Equally likely" is a modeling assumption about $\Omega$, not a law. The coarse space $\{0,1,2\}$ above is a legitimate sample space whose outcomes are not equally likely.
    Drill
    1. EASY Write the sample space for rolling one die then flipping one coin. How many outcomes?
      Solution
      $\Omega=\{1,\dots,6\}\times\{H,T\}$: pairs like $(3,H)$; $|\Omega|=12$.
    2. MED Give a natural sample space for "flip a coin until the first head." Is it finite?
      Solution
      $\Omega=\{H,TH,TTH,TTTH,\dots\}\cup\{TTT\cdots\}$: countably infinite (plus the probability-zero never-head sequence).
    3. HARD An experiment picks a uniformly random point on a circle's circumference. Propose $\Omega$ and explain why $P(\{\omega\})=0$ for every single outcome yet $P(\Omega)=1$.
      Solution
      $\Omega=[0,2\pi)$ (the angle). Any single angle has probability 0 — uncountably many outcomes must share total mass 1, and uniformity forces each to 0. Probability lives on sets (arcs get mass proportional to length); countable additivity cannot sum uncountably many zeros to 1, which is why continuous probability is built on measure, not on outcome-counting.

    Events

    An event is a yes/no question about the outcome: "the die is even," "the loss is below 0.1." Formally it is just a subset of the sample space, and logic becomes set algebra: AND is intersection, OR is union, NOT is complement.

    Definition An event $A\subseteq\Omega$ occurs iff the realized outcome $\omega\in A$. Operations: $A\cap B$ (both), $A\cup B$ (at least one), $A^c=\Omega\setminus A$ (not $A$). $A,B$ are disjoint (mutually exclusive) if $A\cap B=\varnothing$. De Morgan: $(A\cup B)^c=A^c\cap B^c$.
    Worked example One die: $A=$ even $=\{2,4,6\}$, $B=$ greater than 3 $=\{4,5,6\}$. Then $A\cap B=\{4,6\}$, $A\cup B=\{2,4,5,6\}$, $A^c=\{1,3,5\}$. Probabilities (fair die): $P(A)=\tfrac12$, $P(B)=\tfrac12$, $P(A\cap B)=\tfrac13$, $P(A\cup B)=\tfrac12+\tfrac12-\tfrac13=\tfrac23$ ✓ (matching the 4 outcomes).
    Drill
    1. EASY Two coins. Express "at least one head" as a set and find its probability.
      Solution
      $\{HH,HT,TH\}$; $P=\frac34$ (or $1-P(TT)=1-\frac14$).
    2. MED Show that "exactly one of $A,B$" is $(A\cap B^c)\cup(A^c\cap B)$ and compute its probability in terms of $P(A),P(B),P(A\cap B)$.
      Solution
      The two disjoint pieces cover the cases ($A$ only), ($B$ only). $P=P(A)+P(B)-2P(A\cap B)$ (each of $P(A),P(B)$ counts the overlap once; subtract it twice).
    3. HARD For events $A_1,\dots,A_n$, write "infinitely often would need infinite $n$ — instead: none occur" and "all occur" using set operations, and verify De Morgan connects them.
      Solution
      None: $\bigcap_iA_i^c$. All: $\bigcap_iA_i$. De Morgan: $\big(\bigcup_iA_i\big)^c=\bigcap_iA_i^c$ — "not (at least one)" $=$ "none," and $\big(\bigcap_iA_i\big)^c=\bigcup_iA_i^c$ — "not all" $=$ "at least one fails."

    Probability axioms

    All of probability rests on three rules: probabilities are nonnegative, the whole space has probability 1, and the probability of a disjoint union is the sum. Everything else — complements, inclusion-exclusion, continuity — is a theorem.

    Definition (Kolmogorov axioms) A probability measure $P$ assigns each event a number with: (1) $P(A)\ge0$; (2) $P(\Omega)=1$; (3) countable additivity: for pairwise disjoint $A_1,A_2,\dots$, $P\big(\bigcup_iA_i\big)=\sum_iP(A_i)$. Consequences: $P(A^c)=1-P(A)$; $P(\varnothing)=0$; monotonicity $A\subseteq B\Rightarrow P(A)\le P(B)$; inclusion–exclusion $P(A\cup B)=P(A)+P(B)-P(A\cap B)$.
    Worked example In a class, 60% take math (M), 45% take physics (Ph), 25% take both. Probability a random student takes at least one: $P(M\cup Ph)=0.60+0.45-0.25=0.80$. Neither: $1-0.80=0.20$. Exactly one: $0.80-0.25=0.55$.
    Think first Can $P(A)=0.7$, $P(B)=0.6$, and $A,B$ disjoint?
    Reveal
    No: disjointness would give $P(A\cup B)=1.3>1$, violating $P(\Omega)=1$ and monotonicity. In fact $P(A\cap B)\ge P(A)+P(B)-1=0.3$: heavily probable events are forced to overlap.
    Drill
    1. EASY $P(A)=0.3$, $P(B)=0.5$, disjoint. Find $P(A\cup B)$ and $P(A^c\cap B^c)$.
      Solution
      $0.8$; complement of the union: $0.2$.
    2. MED Prove $P(A\cup B)\le P(A)+P(B)$ (union bound) from the axioms.
      Solution
      $A\cup B=A\cup(B\setminus A)$, disjoint, so $P(A\cup B)=P(A)+P(B\setminus A)\le P(A)+P(B)$ by monotonicity ($B\setminus A\subseteq B$). The union bound scales to any countable collection — the workhorse of Ch 20's generalization proofs.
    3. HARD Derive the 3-set inclusion–exclusion formula and use it: of 100 programs, 50 use tool A, 40 tool B, 30 tool C, 20 A&B, 15 A&C, 10 B&C, 5 all three. How many use none?
      Solution
      $P(A\cup B\cup C)=P(A)+P(B)+P(C)-P(AB)-P(AC)-P(BC)+P(ABC)$. Count: $50+40+30-20-15-10+5=80$. None: $20$.

    Conditional probability

    New information shrinks the world. Given that event $B$ happened, throw away every outcome outside $B$ and renormalize what remains: that is conditioning. Almost every probability you actually care about — a diagnosis given a test, the next token given the context — is conditional.

    Definition For $P(B)>0$: $$P(A\mid B)=\frac{P(A\cap B)}{P(B)}.$$ Chain rule: $P(A\cap B)=P(A\mid B)P(B)$, and generally $P(A_1\cap\cdots\cap A_n)=P(A_1)P(A_2\mid A_1)\cdots P(A_n\mid A_1\cdots A_{n-1})$.
    Worked example Two dice. Given the sum is 8, what is the probability the first die shows 6? Outcomes with sum 8: $(2,6),(3,5),(4,4),(5,3),(6,2)$ — five, equally likely. First die 6: one of them. $P=\frac15$. Note the unconditional $P(\text{first}=6)=\frac16\neq\frac15$: information moved the needle.
    Where this goes A language model is one long chain rule: $P(w_1\cdots w_n)=\prod_tP(w_t\mid w_{<t})$ (Ch 21, 23).
    Drill
    1. EASY From a standard deck, draw one card. $P(\text{king}\mid\text{face card})$?
      Solution
      Face cards: J,Q,K — 12 cards. Kings: 4. $P=\frac{4}{12}=\frac13$.
    2. MED Draw two cards without replacement. Find $P(\text{both aces})$ by the chain rule.
      Solution
      $\frac{4}{52}\cdot\frac{3}{51}=\frac{12}{2652}=\frac{1}{221}$.
    3. HARD A family has two children (each independently boy/girl with prob ½). Compare: (a) $P(\text{two girls}\mid\text{elder is a girl})$; (b) $P(\text{two girls}\mid\text{at least one girl})$.
      Solution
      Space $\{BB,BG,GB,GG\}$ (elder first). (a) Condition on $\{GB,GG\}$: $P=\frac12$. (b) Condition on $\{BG,GB,GG\}$: $P=\frac13$. Different information, different answers — "which girl you learned about" matters, the classic conditioning trap.

    Independence

    Two events are independent when learning one tells you nothing about the other — the conditional probability equals the unconditional. Multiplication of probabilities is the algebraic signature. Independence is an assumption you must justify, and the single most common source of silent modeling errors.

    Definition $A\perp B$ iff $P(A\cap B)=P(A)P(B)$ (equivalently $P(A\mid B)=P(A)$ when $P(B)>0$). Events $A_1,\dots,A_n$ are mutually independent if the product rule holds for every sub-collection — pairwise independence is not enough.
    Worked example One die: $A=\{2,4,6\}$ (even), $B=\{1,2,3,4\}$ ($\le4$). $P(A)=\frac12$, $P(B)=\frac23$, $P(A\cap B)=P(\{2,4\})=\frac13=\frac12\cdot\frac23$ ✓ independent — even though both are statements about the same die. Independence is about probabilities, not physical separation.
    Pitfall Disjoint ≠ independent — disjoint events with positive probability are maximally dependent (one happening forbids the other). And pairwise independence does not imply mutual: flip two fair coins, let $A$=first is H, $B$=second is H, $C$=they agree; any two are independent, but $P(A\cap B\cap C)=\frac14\neq\frac18$.
    Drill
    1. EASY Two independent components each fail with probability 0.1. $P(\text{both fail})$? $P(\text{at least one fails})$?
      Solution
      $0.01$; $1-0.9^2=0.19$.
    2. MED If $A\perp B$, show $A\perp B^c$.
      Solution
      $P(A\cap B^c)=P(A)-P(A\cap B)=P(A)-P(A)P(B)=P(A)(1-P(B))=P(A)P(B^c)$.
    3. HARD A test suite has 20 independent flaky tests, each passing with probability 0.99. What is the probability a full run is green? How many reruns until the first green run (expected)?
      Solution
      $0.99^{20}=e^{20\ln0.99}\approx e^{-0.201}\approx0.818$. Reruns are geometric with $p=0.818$: expected $1/p\approx1.22$ runs. Moral: independence compounds — per-test reliability must be far better than per-suite tolerance.

    Bayes theorem

    Bayes' theorem reverses the direction of conditioning: from "probability of evidence given hypothesis" — usually what a model gives you — to "probability of hypothesis given evidence" — what you actually want. Prior beliefs times likelihood, renormalized: that's inference in one line.

    Theorem (Bayes) For $P(B)>0$: $$P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)},\qquad P(B)=\sum_iP(B\mid A_i)P(A_i)$$ over a partition $\{A_i\}$ (law of total probability). Mnemonic: posterior $\propto$ likelihood × prior.
    Worked example A disease affects 1% of people. A test catches it 95% of the time (sensitivity) and false-alarms 5% of the time. You test positive. $$P(D\mid +)=\frac{0.95\times0.01}{0.95\times0.01+0.05\times0.99}=\frac{0.0095}{0.0095+0.0495}=\frac{0.0095}{0.059}\approx0.161.$$ Only 16%! The 1% prior dominates: among 10,000 people, ~95 true positives drown in ~495 false ones.
    Explore

    Drag the prior and the test's error rates and watch the posterior — and the population picture of true vs false positives — respond.

    Where this goes Bayesian inference (Ch 13), Bayesian decision theory (Ch 24), and every posterior in this book start here.
    Drill
    1. EASY Urn I has 3 red, 1 blue; urn II has 1 red, 3 blue. Pick an urn at random, draw red. $P(\text{urn I}\mid\text{red})$?
      Solution
      $\frac{\frac34\cdot\frac12}{\frac34\cdot\frac12+\frac14\cdot\frac12}=\frac{3/8}{4/8}=\frac34$.
    2. MED Spam filter: 40% of mail is spam; "free" appears in 25% of spam and 2% of ham. $P(\text{spam}\mid\text{"free"})$?
      Solution
      $\frac{0.25\cdot0.4}{0.25\cdot0.4+0.02\cdot0.6}=\frac{0.1}{0.112}\approx0.893$.
    3. HARD Repeat the disease example but the positive person immediately takes a second, independent test, also positive. New posterior?
      Solution
      Use the first posterior $0.161$ as the new prior: $\frac{0.95\times0.161}{0.95\times0.161+0.05\times0.839}=\frac{0.1530}{0.1530+0.0420}\approx0.785$. Two pieces of evidence, sequentially absorbed — Bayesian updating in action. (Same as batching: likelihood ratio $19^2$ against prior odds $1/99$: odds $361/99\approx3.65$, $P=0.785$ ✓.)
    A rare condition (prior 0.1%) has a very accurate test (99% sensitivity, 1% false-positive). After one positive, the probability of the condition is closest to…
    $\frac{0.99\times0.001}{0.99\times0.001+0.01\times0.999}\approx0.09$. When the prior is tiny, even excellent tests yield mostly false positives — the base-rate fallacy.

    Random variables

    A random variable is a number attached to each outcome — the sum of the dice, the loss of the model, the number of heads. It converts raw outcomes into quantities you can average, compare and transform, and it is the object all the machinery below (expectation, variance, distributions) acts on.

    Definition A random variable is a function $X:\Omega\to\mathbb{R}$. Its distribution is the collection of probabilities $P(X\in S)=P(\{\omega:X(\omega)\in S\})$. Notation: $\{X=x\}$ and $\{X\le x\}$ abbreviate the corresponding events.
    Worked example Two fair coins, $X=$ number of heads. As a function: $X(TT)=0$, $X(HT)=X(TH)=1$, $X(HH)=2$. Distribution: $P(X=0)=\frac14$, $P(X=1)=\frac12$, $P(X=2)=\frac14$. A different random variable on the same space, $Y=1$ if the flips agree else $0$: $P(Y=1)=\frac12$. Same $\Omega$, different lenses.
    Drill
    1. EASY One die, $X=$ the face squared. List the values of $X$ and $P(X=x)$ for each.
      Solution
      Values $1,4,9,16,25,36$, each with probability $\frac16$.
    2. MED Two dice, $X=$ maximum. Find $P(X\le x)$ for $x=1,\dots,6$ and then $P(X=4)$.
      Solution
      $P(X\le x)=(x/6)^2$. $P(X=4)=P(X\le4)-P(X\le3)=\frac{16-9}{36}=\frac{7}{36}$.
    3. HARD Let $X$ be any random variable and $g$ any function. Explain why $g(X)$ is also a random variable, and compute the distribution of $g(X)$ where $X$ uniform on $\{-2,-1,0,1,2\}$ and $g(x)=x^2$.
      Solution
      $g\circ X:\Omega\to\mathbb{R}$ is a function on outcomes, hence a random variable. $P(X^2=0)=\frac15$, $P(X^2=1)=P(X\in\{-1,1\})=\frac25$, $P(X^2=4)=\frac25$. Note the transformation folds the distribution — two $x$'s per value — a preview of the change-of-variables bookkeeping.

    Discrete random variables

    Discrete means the values can be listed: counts, categories, token ids. All probability questions reduce to summing the masses of the listed values — no calculus needed, just bookkeeping.

    Definition $X$ is discrete if it takes values in a finite or countable set $\{x_1,x_2,\dots\}$. Its distribution is determined by the probabilities $p_i=P(X=x_i)$ with $p_i\ge0$, $\sum_ip_i=1$; and $P(X\in S)=\sum_{x_i\in S}p_i$.
    Worked example A biased four-sided die has $P(X=k)\propto k$ for $k=1,2,3,4$. Normalize: $\sum k=10$, so $P(X=k)=k/10$. Then $P(X\ge3)=\frac{3+4}{10}=0.7$ and $P(X\text{ even})=\frac{2+4}{10}=0.6$.
    Drill
    1. EASY $P(X=k)=c/2^k$ for $k=1,2,3,\dots$. Find $c$.
      Solution
      $\sum_{k\ge1}2^{-k}=1$, so $c=1$.
    2. MED With that $X$, compute $P(X\text{ odd})$.
      Solution
      $\sum_{j\ge0}2^{-(2j+1)}=\frac12\cdot\frac{1}{1-1/4}=\frac{2}{3}$.
    3. HARD A language model's next-token distribution puts $p$ on the top token and splits $1-p$ evenly over the other $V-1$. For $V=50{,}000$, $p=0.9$: what is the probability that greedy decoding is wrong (token drawn ≠ top token), and how many tokens carry 99% of the remaining mass?
      Solution
      $P(\text{not top})=0.1$. The remaining mass is uniform: each other token has $\frac{0.1}{49999}\approx2\times10^{-6}$; 99% of that mass needs $0.99\times49999\approx49{,}499$ tokens — a heavy flat tail, which is why top-$p$/top-$k$ truncation (Ch 23) changes samples so much.

    Continuous random variables

    Heights, times, activations: values that vary over a continuum. Individual points carry zero probability; probability lives in intervals, computed as areas under a density curve. Sums become integrals and everything else carries over.

    Definition $X$ is continuous if there is a density $f\ge0$ with $$P(a\le X\le b)=\int_a^bf(x)\,dx,\qquad\int_{-\infty}^{\infty}f(x)\,dx=1.$$ Then $P(X=x)=0$ for every point, and endpoints don't matter: $P(a\le X\le b)=P(a<X<b)$.
    Worked example $f(x)=2x$ on $[0,1]$ (0 elsewhere) — a valid density: $\int_0^12x\,dx=1$ ✓. $P(X\le\tfrac12)=\int_0^{1/2}2x\,dx=\tfrac14$: even though $[0,\frac12]$ is half the range, it holds only a quarter of the mass — the density tilts toward 1.
    Pitfall A density is not a probability: $f(x)$ can exceed 1 (e.g. uniform on $[0,\tfrac12]$ has $f=2$). Only integrals of $f$ are probabilities.
    Drill
    1. EASY For $f(x)=3x^2$ on $[0,1]$: verify it's a density and find $P(X>\tfrac12)$.
      Solution
      $\int_0^13x^2=1$ ✓. $P=1-(1/2)^3=\frac78$.
    2. MED Find $c$ so $f(x)=c e^{-3x}$ on $[0,\infty)$ is a density, then compute $P(1<X<2)$.
      Solution
      $c\cdot\frac13=1\Rightarrow c=3$. $P=e^{-3}-e^{-6}\approx0.0473$.
    3. HARD $X$ has density $f(x)=\frac{1}{\pi(1+x^2)}$ (Cauchy). Show it integrates to 1 but has divergent mean integral, and explain the practical warning.
      Solution
      $\int\frac{dx}{\pi(1+x^2)}=\frac{1}{\pi}[\arctan x]_{-\infty}^{\infty}=1$ ✓. But $\int|x|f\,dx=\frac{2}{\pi}\int_0^\infty\frac{x}{1+x^2}dx=\frac{1}{\pi}\ln(1+x^2)\big|_0^\infty=\infty$: no mean exists. Averages of Cauchy samples never settle down (the LLN needs a finite mean) — heavy tails can break the most basic statistics.

    Probability mass functions

    The PMF is the complete spec of a discrete random variable: a bar per value, heights summing to 1. Every discrete question is answered by adding bars.

    Definition The PMF of discrete $X$ is $p_X(x)=P(X=x)$, with $p_X(x)\ge0$ and $\sum_xp_X(x)=1$.
    Worked example Sum $S$ of two fair dice: $p_S(s)=\frac{6-|s-7|}{36}$ for $s=2,\dots,12$ — the triangle: $p_S(2)=\frac{1}{36}$, up to $p_S(7)=\frac{6}{36}$, back down. Check total: $\frac{1+2+3+4+5+6+5+4+3+2+1}{36}=\frac{36}{36}=1$ ✓.
    Drill
    1. EASY Write the PMF of a fair coin's number of heads in one flip.
      Solution
      $p(0)=p(1)=\frac12$ — Bernoulli(½).
    2. MED Using the two-dice PMF, compute $P(5\le S\le9)$.
      Solution
      $\frac{4+5+6+5+4}{36}=\frac{24}{36}=\frac23$.
    3. HARD $X,Y$ independent, each uniform on $\{0,1,2\}$. Derive the PMF of $Z=X+Y$ by convolution: $p_Z(z)=\sum_kp_X(k)p_Y(z-k)$.
      Solution
      $p_Z(0)=\frac19$, $p_Z(1)=\frac29$, $p_Z(2)=\frac39$, $p_Z(3)=\frac29$, $p_Z(4)=\frac19$ — a discrete triangle; sums of independents convolve their PMFs (Ch 14 makes this a theorem about transforms).

    Probability density functions

    The PDF is the continuous analogue of the PMF: not probability per value but probability per unit length — a rate. $f(x)\,dx$ is the chance of landing in the sliver $[x,x+dx]$. Modes, tails, and skew are all read off its graph.

    Definition $f_X$ is the density of $X$ if $P(X\in S)=\int_Sf_X(x)\,dx$ for all (measurable) $S$. Where $F_X$ is differentiable, $f_X=F_X'$. Under a change of units $Y=aX$ ($a>0$), $f_Y(y)=\frac{1}{a}f_X(y/a)$ — densities carry units of $1/x$.
    Worked example Standard Gaussian density $\varphi(x)=\frac{1}{\sqrt{2\pi}}e^{-x^2/2}$. Its maximum is $\varphi(0)=\frac{1}{\sqrt{2\pi}}\approx0.399$; the probability of a sliver of width $0.01$ near 0 is $\approx0.399\times0.01=0.4\%$; near $x=2$ it is $\varphi(2)\approx0.054$, so $0.054\%$ — the density directly compares how "popular" regions are.
    Drill
    1. EASY Sketch (describe) the density of Uniform$[2,5]$ and give its height.
      Solution
      Flat at $f=\frac13$ on $[2,5]$, zero outside.
    2. MED $f(x)=\lambda e^{-\lambda x}$ ($x\ge0$). At what $x$ is the density half its peak?
      Solution
      Peak $\lambda$ at $x=0$; half: $e^{-\lambda x}=\frac12\Rightarrow x=\frac{\ln2}{\lambda}$ — the half-life again.
    3. HARD $X$ has density $f$, and $Y=X^2$ where $X$ is standard Gaussian. Show $f_Y(y)=\frac{1}{\sqrt{2\pi y}}e^{-y/2}$ for $y>0$ (chi-squared with 1 dof).
      Solution
      $F_Y(y)=P(X^2\le y)=P(-\sqrt y\le X\le\sqrt y)=2\Phi(\sqrt y)-1$. Differentiate: $f_Y(y)=2\varphi(\sqrt y)\cdot\frac{1}{2\sqrt y}=\frac{1}{\sqrt y}\cdot\frac{1}{\sqrt{2\pi}}e^{-y/2}$ ✓ — both branches $\pm\sqrt y$ contribute, folded into the factor 2.

    Cumulative distribution functions

    The CDF answers one universal question — "what's the chance of being at most $x$?" — and works identically for discrete, continuous and mixed variables. It climbs from 0 to 1, and every probability of an interval is a difference of two CDF values.

    Definition $F_X(x)=P(X\le x)$. Properties: nondecreasing; right-continuous; $F(-\infty)=0$, $F(\infty)=1$; $P(a<X\le b)=F(b)-F(a)$. Continuous case: $F(x)=\int_{-\infty}^xf$; discrete case: a staircase with jump $p_X(x)$ at each atom.
    Worked example $f(x)=2x$ on $[0,1]$: $F(x)=x^2$ there (0 below, 1 above). Then $P(0.3<X\le0.8)=0.64-0.09=0.55$, and the median solves $x^2=\frac12$: $x=\frac{1}{\sqrt2}\approx0.707$.
    Drill
    1. EASY For a fair die, evaluate $F(3)$, $F(3.7)$, $F(6)$.
      Solution
      $F(3)=\frac12$; $F(3.7)=\frac12$ (staircase is flat between atoms); $F(6)=1$.
    2. MED Exponential($\lambda$): derive $F(x)=1-e^{-\lambda x}$ and use it for $P(X>t)$.
      Solution
      $F(x)=\int_0^x\lambda e^{-\lambda u}du=1-e^{-\lambda x}$; survival $P(X>t)=e^{-\lambda t}$.
    3. HARD $X$ has continuous, strictly increasing CDF $F$. Show $U=F(X)$ is Uniform$[0,1]$ (probability integral transform).
      Solution
      For $u\in(0,1)$: $P(U\le u)=P(F(X)\le u)=P(X\le F^{-1}(u))=F(F^{-1}(u))=u$ — the uniform CDF. This is why sorting p-values against the uniform diagonal works (Ch 13) and why inverse-CDF sampling works (next topic).

    Quantile functions

    Run the CDF backwards: give me a probability level, I'll give you the threshold. Medians, percentiles, "p99 latency," and the standard sampling trick — feed uniform random numbers through the inverse CDF — all live here.

    Definition The quantile function is $Q(u)=F^{-1}(u)=\inf\{x:F(x)\ge u\}$ for $u\in(0,1)$. $Q(\tfrac12)$ is the median; $Q(0.25),Q(0.75)$ the quartiles. Inverse-CDF sampling: if $U\sim$ Uniform$[0,1]$ then $Q(U)$ has CDF $F$.
    Worked example Exponential($\lambda$): $F(x)=1-e^{-\lambda x}$, so $Q(u)=-\frac{\ln(1-u)}{\lambda}$. Median: $Q(\tfrac12)=\frac{\ln2}{\lambda}$ — below the mean $\frac{1}{\lambda}$, because the right tail drags the mean up. To sample: draw $u=0.37$, $\lambda=2$: $x=-\frac{\ln0.63}{2}\approx0.231$.
    Drill
    1. EASY Find the quantile function of Uniform$[a,b]$.
      Solution
      $Q(u)=a+(b-a)u$.
    2. MED For $F(x)=x^2$ on $[0,1]$, compute $Q(u)$ and the interquartile range.
      Solution
      $Q(u)=\sqrt u$. IQR $=\sqrt{0.75}-\sqrt{0.25}=0.866-0.5=0.366$.
    3. HARD Your service's latency is Exponential with mean 100 ms. Compute the p50, p95 and p99 latencies, and explain why p99 ≫ mean here.
      Solution
      $\lambda=0.01/\text{ms}$. $Q(u)=-100\ln(1-u)$: p50 $=69.3$, p95 $=299.6$, p99 $=460.5$ ms. The exponential's memoryless tail decays only exponentially, so extreme quantiles sit several means out — tail metrics, not means, describe user pain.

    Expectation

    The expectation is the center of mass of a distribution: each value weighted by its probability. It is the long-run average under repetition, it is linear even when variables are dependent, and it is the quantity every loss function in ML asks you to minimize.

    Definition $\mathbb{E}[X]=\sum_xx\,p(x)$ (discrete) or $\int xf(x)\,dx$ (continuous), when the sum/integral converges absolutely. LOTUS: $\mathbb{E}[g(X)]=\sum_xg(x)p(x)$ or $\int g(x)f(x)dx$. Linearity: $\mathbb{E}[aX+bY]=a\mathbb{E}[X]+b\mathbb{E}[Y]$ always — no independence needed.
    Worked example Expected number of distinct faces in 3 die rolls: let $I_k$ indicate face $k$ appears. $\mathbb{E}[I_k]=1-(5/6)^3=\frac{91}{216}$. By linearity, $\mathbb{E}[\text{distinct}]=6\cdot\frac{91}{216}=\frac{91}{36}\approx2.528$ — computed without ever finding the messy distribution of the count. Indicators + linearity is the single most useful trick in applied probability.
    Pitfall $\mathbb{E}[g(X)]\neq g(\mathbb{E}[X])$ in general (see Jensen, later): the average of $X^2$ is not the square of the average.
    Drill
    1. EASY Expected value of one fair die roll? Of the sum of two?
      Solution
      $3.5$; by linearity $7$.
    2. MED For $f(x)=2x$ on $[0,1]$, compute $\mathbb{E}[X]$ and $\mathbb{E}[1/X]$.
      Solution
      $\mathbb{E}[X]=\int_0^1x\cdot2x\,dx=\frac23$. $\mathbb{E}[1/X]=\int_0^1\frac1x2x\,dx=2$. Note $1/\mathbb{E}[X]=1.5\neq2$.
    3. MED 100 people leave hats; hats are returned uniformly at random. Expected number who get their own hat?
      Solution
      Indicators: $P(\text{person }i\text{ matched})=\frac{1}{100}$; linearity: $100\cdot\frac{1}{100}=1$ — regardless of the (strong!) dependence between matches.
    4. HARD Show $\mathbb{E}[X]=\int_0^\infty P(X>t)\,dt$ for nonnegative continuous $X$, and verify on Exponential($\lambda$).
      Solution
      $\int_0^\infty P(X>t)dt=\int_0^\infty\!\!\int_t^\infty f(x)\,dx\,dt=\int_0^\infty f(x)\int_0^xdt\,dx=\int_0^\infty xf(x)dx=\mathbb{E}[X]$ (swap order over $\{0<t<x\}$, Ch 9). Exponential: $\int_0^\infty e^{-\lambda t}dt=\frac1\lambda$ ✓.

    Variance

    Variance measures spread: the average squared distance from the mean. Squaring punishes big deviations, keeps everything positive, and — crucially — makes variances of independent variables add, which is the engine behind the $\sqrt n$ in every error bar.

    Definition $\operatorname{Var}(X)=\mathbb{E}[(X-\mu)^2]=\mathbb{E}[X^2]-\mu^2$ where $\mu=\mathbb{E}[X]$. Rules: $\operatorname{Var}(aX+b)=a^2\operatorname{Var}(X)$; for independent (or merely uncorrelated) $X,Y$: $\operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)$.
    Worked example One die: $\mathbb{E}[X^2]=\frac{1+4+9+16+25+36}{6}=\frac{91}{6}$, $\mu=3.5$, so $\operatorname{Var}=\frac{91}{6}-12.25=\frac{35}{12}\approx2.917$. Sum of 10 independent dice: variance $\frac{350}{12}\approx29.17$, standard deviation $\approx5.40$ — the sum spreads like $\sqrt{10}$, not 10.
    Drill
    1. EASY Bernoulli($p$): show $\operatorname{Var}=p(1-p)$ and find where it peaks.
      Solution
      $\mathbb{E}[X^2]=\mathbb{E}[X]=p$, so $\operatorname{Var}=p-p^2$; maximal at $p=\frac12$ (most unpredictable coin).
    2. MED $f(x)=2x$ on $[0,1]$: compute the variance.
      Solution
      $\mathbb{E}[X^2]=\int_0^12x^3dx=\frac12$; $\operatorname{Var}=\frac12-\left(\frac23\right)^2=\frac12-\frac49=\frac{1}{18}$.
    3. HARD $\bar X_n=\frac1n\sum X_i$ with i.i.d. $X_i$, variance $\sigma^2$. Show $\operatorname{Var}(\bar X_n)=\sigma^2/n$ and explain the $\sqrt n$ law of error bars.
      Solution
      $\operatorname{Var}\big(\frac1n\sum X_i\big)=\frac{1}{n^2}\sum\operatorname{Var}(X_i)=\frac{n\sigma^2}{n^2}=\frac{\sigma^2}{n}$. Standard deviation $\sigma/\sqrt n$: to halve your error bar you need 4× the data — the tyranny and mercy of averaging (LLN and CLT below; Ch 13 estimators).

    Standard deviation

    The square root of variance restores the original units: if $X$ is in meters, $\sigma$ is in meters. It is the natural yardstick of a distribution — "how far from the mean is typical" — and the unit in which z-scores, confidence intervals and normalized activations are measured.

    Definition $\sigma_X=\sqrt{\operatorname{Var}(X)}$. Standardization: $Z=\frac{X-\mu}{\sigma}$ has mean 0 and standard deviation 1. For Gaussians, the 68–95–99.7 rule: about 68% of mass within $1\sigma$, 95% within $2\sigma$, 99.7% within $3\sigma$.
    Worked example Exam scores: $\mu=70$, $\sigma=8$, approximately normal. A score of 86 is $z=\frac{86-70}{8}=2$: two standard deviations up, so roughly the top $2.5\%$ ($95\%$ within $\pm2\sigma$, half of the remaining 5% above). A score of 62 is $z=-1$: about the 16th percentile.
    Drill
    1. EASY $X$ has $\mu=10$, $\sigma=2$. Give the mean and standard deviation of $3X-5$.
      Solution
      Mean $25$; standard deviation $|3|\cdot2=6$ (shifts don't spread).
    2. MED Batch normalization (Ch 21) computes $z=\frac{x-\hat\mu}{\hat\sigma}$ per feature. What are the mean and variance of the normalized feature, and why does that help optimization?
      Solution
      Mean 0, variance 1 by construction. It equalizes scales across features, improving the conditioning of the loss Hessian (Ch 9, 15) so one learning rate fits all directions.
    3. HARD Show that $\sigma$ minimizes $\sqrt{\mathbb{E}[(X-c)^2]}$ over $c$ at $c=\mu$, i.e. the mean is the best constant predictor under squared error.
      Solution
      $\mathbb{E}[(X-c)^2]=\mathbb{E}[(X-\mu)^2]+(\mu-c)^2$ (expand; cross term vanishes since $\mathbb{E}[X-\mu]=0$). Minimized at $c=\mu$ with value $\operatorname{Var}(X)$. Squared-error regression is estimating conditional means for exactly this reason (Ch 13, 19).

    Covariance

    Do two quantities move together? Covariance averages the product of their deviations: positive when they rise together, negative when one rises as the other falls, zero when deviations are unrelated (on average). It is the off-diagonal ingredient of every covariance matrix and portfolio-risk formula.

    Definition $\operatorname{Cov}(X,Y)=\mathbb{E}[(X-\mu_X)(Y-\mu_Y)]=\mathbb{E}[XY]-\mu_X\mu_Y$. Properties: bilinear; $\operatorname{Cov}(X,X)=\operatorname{Var}(X)$; $\operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)+2\operatorname{Cov}(X,Y)$. Independence $\Rightarrow\operatorname{Cov}=0$; the converse fails.
    Worked example Joint PMF: $P(X=0,Y=0)=0.4$, $P(1,0)=0.1$, $P(0,1)=0.1$, $P(1,1)=0.4$. Marginals: $P(X=1)=P(Y=1)=0.5$. $\mathbb{E}[XY]=0.4$. $\operatorname{Cov}=0.4-0.25=0.15>0$: the variables like to agree.
    Pitfall Zero covariance ≠ independence: $X$ uniform on $\{-1,0,1\}$, $Y=X^2$. $\mathbb{E}[XY]=\mathbb{E}[X^3]=0=\mathbb{E}[X]\mathbb{E}[Y]$, covariance 0 — yet $Y$ is a deterministic function of $X$. Covariance only sees linear association.
    Drill
    1. EASY $\operatorname{Var}(X)=4$, $\operatorname{Var}(Y)=9$, $\operatorname{Cov}(X,Y)=-3$. Find $\operatorname{Var}(X+Y)$.
      Solution
      $4+9-6=7$ — anticorrelation cancels spread (hedging).
    2. MED Show $\operatorname{Cov}(aX+b,\,cY+d)=ac\operatorname{Cov}(X,Y)$.
      Solution
      Shifts drop out of deviations; scalars factor: $\mathbb{E}[(a(X-\mu_X))(c(Y-\mu_Y))]=ac\operatorname{Cov}(X,Y)$.
    3. HARD Two dice: $S=X+Y$, $D=X-Y$. Compute $\operatorname{Cov}(S,D)$ and discuss.
      Solution
      $\operatorname{Cov}(X+Y,X-Y)=\operatorname{Var}(X)-\operatorname{Cov}(X,Y)+\operatorname{Cov}(Y,X)-\operatorname{Var}(Y)=\operatorname{Var}(X)-\operatorname{Var}(Y)=0$. Sum and difference of i.i.d. variables are uncorrelated — but not independent (e.g. $S=12$ forces $D=0$); another covariance-blindness example.

    Correlation

    Covariance has awkward units (meters × kilograms); correlation divides them out, leaving a pure number in $[-1,1]$: the strength of linear association. $\pm1$ means an exact line; 0 means no linear trend — possibly plenty of nonlinear structure.

    Definition $$\rho_{XY}=\frac{\operatorname{Cov}(X,Y)}{\sigma_X\sigma_Y}\in[-1,1],$$ with $|\rho|=1$ iff $Y=aX+b$ exactly ($a\neq0$, sign of $a$ = sign of $\rho$). Bound from Cauchy–Schwarz (Ch 8).
    Worked example From the covariance example: $\operatorname{Cov}=0.15$, $\operatorname{Var}(X)=\operatorname{Var}(Y)=0.25$ (Bernoulli(½)), so $\rho=\frac{0.15}{0.5\times0.5}=0.6$ — a strong tendency to agree, now unit-free and comparable across problems.
    Where this goes Correlation ≠ causation gets its own machinery in Ch 27; the correlation matrix is PCA's raw material (Ch 8, 19).
    Drill
    1. EASY $\sigma_X=2$, $\sigma_Y=5$, $\rho=-0.8$. Find $\operatorname{Cov}(X,Y)$.
      Solution
      $-0.8\times10=-8$.
    2. MED Show correlation is invariant to positive affine rescaling of each variable.
      Solution
      $\operatorname{Cov}(aX+b,cY+d)=ac\operatorname{Cov}$, $\sigma_{aX+b}=|a|\sigma_X$: for $a,c>0$ the factors cancel: $\rho$ unchanged. (Negative $a$ flips the sign.)
    3. HARD Prove $|\rho|\le1$ via $\operatorname{Var}\!\big(\frac{X}{\sigma_X}\pm\frac{Y}{\sigma_Y}\big)\ge0$.
      Solution
      Expanding: $1+1\pm2\rho\ge0\Rightarrow\rho\ge-1$ and $\rho\le1$. Equality forces the standardized sum/difference to have zero variance, i.e. be constant: $Y$ an exact affine function of $X$.

    Moments

    Moments are the summary statistics ladder: the 1st is the mean, the 2nd gives variance, the 3rd (standardized) is skewness — lopsidedness — and the 4th is kurtosis — tail weight. Matching moments is a classical way to fit distributions, and moments are what generating functions package.

    Definition The $k$-th moment is $\mathbb{E}[X^k]$; the $k$-th central moment is $\mu_k=\mathbb{E}[(X-\mu)^k]$. Skewness $\gamma_1=\mu_3/\sigma^3$; (excess) kurtosis $\gamma_2=\mu_4/\sigma^4-3$ (0 for a Gaussian).
    Worked example Exponential($\lambda=1$): $\mathbb{E}[X^k]=k!$ (integrate by parts repeatedly). So $\mu=1$, $\mathbb{E}[X^2]=2\Rightarrow\sigma^2=1$, $\mu_3=\mathbb{E}[X^3]-3\mu\mathbb{E}[X^2]+2\mu^3=6-6+2=2$, skewness $\gamma_1=2$ — strongly right-skewed, matching the long right tail.
    Drill
    1. EASY Compute the first two moments of Uniform$[0,1]$.
      Solution
      $\mathbb{E}[X]=\frac12$, $\mathbb{E}[X^2]=\frac13$ (variance $\frac1{12}$).
    2. MED Why is the skewness of any symmetric distribution (with finite third moment) zero?
      Solution
      Symmetry about $\mu$ means $X-\mu$ and $-(X-\mu)$ have the same distribution, so $\mu_3=\mathbb{E}[(X-\mu)^3]=-\mu_3$, forcing $\mu_3=0$.
    3. HARD A distribution has $\gamma_2\gg0$ (heavy tails). Explain concretely what this means for gradient noise in SGD and why gradient clipping (Ch 15) exists.
      Solution
      High kurtosis: rare, huge deviations dominate the fourth moment — occasional gradient samples are orders of magnitude larger than typical. Averages converge slowly and single steps can be catastrophic; clipping caps the influence of these tail events, trading a little bias for much smaller variance.

    Moment generating functions

    Package every moment into a single function: $M(t)=\mathbb{E}[e^{tX}]$. Differentiate at 0 to pop out moments; multiply MGFs to add independent variables; and the exponential moments it encodes are exactly what concentration inequalities (Chernoff/Hoeffding) feed on.

    Definition $M_X(t)=\mathbb{E}[e^{tX}]$ (where finite). Then $M^{(k)}(0)=\mathbb{E}[X^k]$. If $X\perp Y$: $M_{X+Y}(t)=M_X(t)M_Y(t)$. An MGF finite on an interval around 0 determines the distribution.
    Worked example Gaussian $N(\mu,\sigma^2)$: $M(t)=e^{\mu t+\sigma^2t^2/2}$. Check moments: $M'(t)=(\mu+\sigma^2t)M(t)$, $M'(0)=\mu$ ✓; $M''(0)=\mu^2+\sigma^2=\mathbb{E}[X^2]$ ✓. Sum of independent Gaussians: MGFs multiply — $e^{(\mu_1+\mu_2)t+(\sigma_1^2+\sigma_2^2)t^2/2}$: again Gaussian, means and variances adding. Closure under sums, proved in one line.
    Drill
    1. EASY Compute the MGF of Bernoulli($p$).
      Solution
      $M(t)=1-p+pe^{t}$.
    2. MED Use MGFs to find the distribution of a sum of $n$ i.i.d. Bernoulli($p$).
      Solution
      $M(t)=(1-p+pe^t)^n$ — the Binomial($n,p$) MGF (binomial theorem on $\mathbb{E}[e^{tX}]=\sum_k\binom nkp^k(1-p)^{n-k}e^{tk}$). Sums of coins are binomial, certified by transform.
    3. HARD Derive the Poisson($\lambda$) MGF and use it to show that independent Poissons add: $X\sim\mathrm{Poi}(\lambda),Y\sim\mathrm{Poi}(\mu)\Rightarrow X+Y\sim\mathrm{Poi}(\lambda+\mu)$.
      Solution
      $M(t)=\sum_k e^{tk}e^{-\lambda}\frac{\lambda^k}{k!}=e^{-\lambda}\sum_k\frac{(\lambda e^t)^k}{k!}=e^{\lambda(e^t-1)}$. Product: $e^{(\lambda+\mu)(e^t-1)}$ — the Poisson($\lambda+\mu$) MGF; by uniqueness, done.

    Characteristic functions

    The MGF's bulletproof sibling: $\varphi(t)=\mathbb{E}[e^{itX}]$ always exists (the integrand has modulus 1), uniquely determines the distribution, and turns sums into products. It is the Fourier transform of the density (Ch 14), and it is the tool that proves the Central Limit Theorem.

    Definition $\varphi_X(t)=\mathbb{E}[e^{itX}]$. Properties: $\varphi(0)=1$, $|\varphi|\le1$; $\varphi_{aX+b}(t)=e^{itb}\varphi_X(at)$; independence: $\varphi_{X+Y}=\varphi_X\varphi_Y$; uniqueness and Lévy continuity (pointwise convergence of $\varphi$'s ⟺ convergence in distribution).
    Worked example Standard Gaussian: $\varphi(t)=e^{-t^2/2}$ — its own shape, the Fourier fixed point. CLT sketch: standardized sum $S_n=\frac{1}{\sqrt n}\sum(X_i-\mu)/\sigma$ has $\varphi_{S_n}(t)=\big(\varphi_Z(t/\sqrt n)\big)^n$ where $\varphi_Z(s)=1-\frac{s^2}{2}+o(s^2)$; then $\big(1-\frac{t^2}{2n}+o(\tfrac1n)\big)^n\to e^{-t^2/2}$ — Gaussianity emerges from any finite-variance start.
    Drill
    1. EASY Compute $\varphi(t)$ for a fair coin valued $\pm1$.
      Solution
      $\frac{e^{it}+e^{-it}}{2}=\cos t$.
    2. MED Why does every distribution have a characteristic function even when the MGF diverges (e.g. Cauchy)?
      Solution
      $|e^{itX}|=1$, so $\mathbb{E}[e^{itX}]$ is an average of unit-modulus numbers — always finite. $e^{tX}$ by contrast can explode against heavy tails. (Cauchy: $\varphi(t)=e^{-|t|}$, no MGF, no mean.)
    3. HARD Using $\varphi$'s, show the sum of two independent Cauchy variables is Cauchy with doubled scale, and reconcile with the failure of the LLN.
      Solution
      $\varphi_{X+Y}=e^{-|t|}e^{-|t|}=e^{-2|t|}$: Cauchy with scale 2. Then $\bar X_n=\frac{1}{n}\sum X_i$ has $\varphi(t)=\big(e^{-|t|/n}\big)^n=e^{-|t|}$: the average of $n$ Cauchys is exactly Cauchy again — averaging buys nothing, consistent with the LLN's finite-mean hypothesis being violated.

    Joint distributions

    Real problems involve several random quantities at once, and the joint distribution is the full contract: the probability of every combination. Everything else — marginals, conditionals, covariance, independence — is derived from it by summing, slicing or integrating.

    Definition Discrete: joint PMF $p(x,y)=P(X=x,Y=y)$, $\sum_{x,y}p=1$. Continuous: joint density $f(x,y)\ge0$ with $P((X,Y)\in S)=\iint_Sf\,dA$ and $\iint f=1$ (a double integral, Ch 9).
    Worked example $f(x,y)=x+y$ on $[0,1]^2$. Valid: $\int_0^1\!\int_0^1(x+y)dxdy=\frac12+\frac12=1$ ✓. $P(X+Y\le1)=\int_0^1\!\int_0^{1-x}(x+y)\,dy\,dx=\int_0^1\big(x(1-x)+\frac{(1-x)^2}{2}\big)dx=\int_0^1\frac{1-x^2}{2}dx=\frac12-\frac16=\frac13$.
    Drill
    1. EASY A joint PMF has $p(0,0)=0.2,p(0,1)=0.3,p(1,0)=0.1,p(1,1)=k$. Find $k$ and $P(X=Y)$.
      Solution
      $k=0.4$; $P(X=Y)=0.2+0.4=0.6$.
    2. MED For $f(x,y)=4xy$ on $[0,1]^2$, compute $P(Y>X)$.
      Solution
      By the symmetry $x\leftrightarrow y$ of the density, $P(Y>X)=\frac12$ (ties have probability 0).
    3. HARD For $f(x,y)=6e^{-2x-3y}$ on $x,y\ge0$, verify it is a density and compute $P(X<Y)$.
      Solution
      $\int_0^\infty2e^{-2x}dx\cdot\int_0^\infty3e^{-3y}dy=1$ ✓ (it factors — independent exponentials). $P(X<Y)=\int_0^\infty2e^{-2x}P(Y>x)dx=\int_0^\infty2e^{-2x}e^{-3x}dx=\frac{2}{5}$.

    Marginal distributions

    To get the distribution of $X$ alone from a joint, sum or integrate the other variable out — collapse the table onto its margin (hence the name). Marginalization is the "forget what you don't care about" operation, and it is everywhere: mixture models, Bayesian evidence, attention over latent choices.

    Definition $p_X(x)=\sum_yp(x,y)$; $f_X(x)=\int f(x,y)\,dy$. In general, for any latent $z$: $p(x)=\sum_zp(x,z)$ or $\int p(x,z)\,dz$.
    Worked example $f(x,y)=x+y$ on $[0,1]^2$: $f_X(x)=\int_0^1(x+y)dy=x+\tfrac12$ — a tilted marginal even though the joint looks symmetric in form. Check: $\int_0^1(x+\tfrac12)dx=1$ ✓. By symmetry $f_Y(y)=y+\tfrac12$. Note $f(x,y)\neq f_X(x)f_Y(y)$: not independent.
    Drill
    1. EASY From the PMF $p(0,0)=0.2,p(0,1)=0.3,p(1,0)=0.1,p(1,1)=0.4$, find both marginals.
      Solution
      $p_X(0)=0.5,p_X(1)=0.5$; $p_Y(0)=0.3,p_Y(1)=0.7$.
    2. MED For $f(x,y)=2$ on the triangle $0\le y\le x\le1$, find $f_X$ and $f_Y$.
      Solution
      $f_X(x)=\int_0^x2\,dy=2x$ on $[0,1]$; $f_Y(y)=\int_y^12\,dx=2(1-y)$ on $[0,1]$.
    3. HARD A mixture: $Z\sim$Bernoulli(0.3); given $Z=0$, $X\sim N(0,1)$; given $Z=1$, $X\sim N(4,1)$. Write the marginal density of $X$ and its mean.
      Solution
      $f_X(x)=0.7\,\varphi(x)+0.3\,\varphi(x-4)$ — a bimodal mixture; marginalization = weighted overlay of components. Mean: $0.7\cdot0+0.3\cdot4=1.2$. (Gaussian mixtures: Ch 19.)

    Conditional distributions

    Freeze one variable at an observed value and renormalize the slice: that is the conditional distribution of the other. It is the probabilistic answer to "given what I've seen, what do I believe about the rest?" — the core object of prediction.

    Definition Discrete: $p_{Y\mid X}(y\mid x)=\dfrac{p(x,y)}{p_X(x)}$. Continuous: $f_{Y\mid X}(y\mid x)=\dfrac{f(x,y)}{f_X(x)}$ (for $f_X(x)>0$). Product rule: $f(x,y)=f_X(x)\,f_{Y\mid X}(y\mid x)$.
    Worked example $f(x,y)=x+y$ on $[0,1]^2$, condition on $X=\tfrac12$: $f_{Y\mid X}(y\mid\tfrac12)=\dfrac{\tfrac12+y}{\tfrac12+\tfrac12}=\tfrac12+y$ — a proper density on $[0,1]$ ($\int_0^1(\tfrac12+y)dy=1$ ✓), tilted toward large $y$. Conditional mean: $\int_0^1y(\tfrac12+y)dy=\tfrac14+\tfrac13=\tfrac{7}{12}$.
    Drill
    1. EASY From $p(0,0)=0.2,p(0,1)=0.3,p(1,0)=0.1,p(1,1)=0.4$: find $p_{Y|X}(\cdot\mid X=1)$.
      Solution
      $p_X(1)=0.5$: $p(0\mid1)=0.2$, $p(1\mid1)=0.8$.
    2. MED For $f(x,y)=2$ on $0\le y\le x\le1$: find $f_{Y|X}(y\mid x)$ and describe it.
      Solution
      $\frac{2}{2x}=\frac1x$ on $[0,x]$: given $X=x$, $Y$ is Uniform$[0,x]$.
    3. HARD Show that sampling $X\sim f_X$ then $Y\sim f_{Y|X}(\cdot\mid X)$ produces a pair with joint density $f(x,y)$ — and connect to autoregressive generation.
      Solution
      The sampling scheme's joint density is by construction $f_X(x)f_{Y|X}(y\mid x)$, which equals $f(x,y)$ by the product rule. Chaining this over many variables — sample $w_1$, then $w_2\mid w_1$, etc. — is exactly how autoregressive LLMs generate from the full joint one token at a time (Ch 21–23).

    Independence of random variables

    Random variables are independent when their joint distribution factors into the product of marginals — knowing one changes nothing about the other. The i.i.d. assumption (independent, identically distributed) underlies nearly every statistical guarantee; knowing when it breaks (time series, shuffled-badly data, users appearing twice) is a superpower.

    Definition $X\perp Y$ iff $p(x,y)=p_X(x)p_Y(y)$ for all $x,y$ (densities: $f(x,y)=f_X(x)f_Y(y)$), equivalently $P(X\in A,Y\in B)=P(X\in A)P(Y\in B)$ for all $A,B$. Consequences: $\mathbb{E}[XY]=\mathbb{E}[X]\mathbb{E}[Y]$, $\operatorname{Cov}=0$, $g(X)\perp h(Y)$ for any functions $g,h$.
    Worked example $f(x,y)=6e^{-2x-3y}$ ($x,y\ge0$) factors as $(2e^{-2x})(3e^{-3y})$: independent Exponential(2) and Exponential(3). But $f(x,y)=x+y$ on $[0,1]^2$ does not factor (marginals multiply to $(x+\frac12)(y+\frac12)\neq x+y$): dependent. Quick test: if the formula for $f$ separates and the domain is a product set, independent.
    Pitfall The domain matters: $f(x,y)=2$ on the triangle $0\le y\le x\le1$ looks "constant-separable," but the triangular support couples the variables — $Y\le X$ always. Not independent.
    Drill
    1. EASY $X,Y$ independent dice. $P(X=6,Y=6)$?
      Solution
      $\frac{1}{36}$.
    2. MED $f(x,y)=cxy$ on $[0,1]\times[0,2]$. Find $c$ and determine independence.
      Solution
      $c\int_0^1x\,dx\int_0^2y\,dy=c\cdot\frac12\cdot2=1\Rightarrow c=1$. $f=xy=(2x)(y/2)$: factors on a product domain — independent, with $f_X=2x$, $f_Y=y/2$.
    3. HARD $X_1,\dots,X_n$ i.i.d. Uniform$[0,1]$. Find the distribution of $M=\max_iX_i$ and $\mathbb{E}[M]$.
      Solution
      $P(M\le m)=P(\text{all}\le m)=m^n$ (independence). Density $nm^{n-1}$; $\mathbb{E}[M]=\int_0^1m\cdot nm^{n-1}dm=\frac{n}{n+1}$ — the max of many uniforms crowds the ceiling.

    Change of variables for densities

    Transform a random variable and its density warps: mass is conserved, so where the map stretches space the density thins, and where it compresses, the density piles up. The correction factor is the (inverse) Jacobian determinant from Ch 9 — the identity that powers normalizing flows.

    Definition If $Y=g(X)$ with $g$ strictly monotone and differentiable: $$f_Y(y)=f_X\big(g^{-1}(y)\big)\left|\frac{d}{dy}g^{-1}(y)\right|.$$ Vector version, $\mathbf y=g(\mathbf x)$ invertible: $f_Y(\mathbf y)=f_X(g^{-1}(\mathbf y))\,\big|\det J_{g^{-1}}(\mathbf y)\big|$.
    Worked example $X\sim$Uniform$[0,1]$, $Y=-\ln X$. Inverse: $x=e^{-y}$, $\left|\frac{dx}{dy}\right|=e^{-y}$. $f_Y(y)=1\cdot e^{-y}$ for $y>0$: Exponential(1) — the inverse-CDF sampler derived by change of variables. Sanity check: small $X$ (rare region near 0 stretched over huge $y$) maps to large $Y$ with thin density ✓.
    Where this goes Normalizing flows (Ch 22) train invertible networks by maximizing $\ln f_X(g^{-1}(y))+\ln|\det J_{g^{-1}}|$; the reparameterization trick (Ch 22) is this formula run in reverse.
    Drill
    1. EASY $X\sim N(0,1)$, $Y=3X+2$. Find $f_Y$.
      Solution
      $f_Y(y)=\frac{1}{3}\varphi\!\left(\frac{y-2}{3}\right)$: $N(2,9)$.
    2. MED $X\sim$Uniform$[0,1]$, $Y=X^2$. Find $f_Y$ and explain the spike near 0.
      Solution
      $x=\sqrt y$, $\frac{dx}{dy}=\frac{1}{2\sqrt y}$: $f_Y(y)=\frac{1}{2\sqrt y}$ on $(0,1]$. Squaring compresses $[0,1]$ toward 0, so density piles up there (integrable spike).

    Conditional expectation

    The best guess of $Y$ after seeing $X=x$ is the mean of the conditional distribution: $\mathbb{E}[Y\mid X=x]$, a function of $x$ called the regression function. All of supervised learning with squared loss is an attempt to learn this function from samples.

    Definition $\mathbb{E}[Y\mid X=x]=\sum_yy\,p_{Y|X}(y\mid x)$ or $\int y\,f_{Y|X}(y\mid x)\,dy$. As a random variable, $\mathbb{E}[Y\mid X]$ is this function evaluated at $X$. Key property: $\mathbb{E}[Y\mid X]$ minimizes $\mathbb{E}[(Y-h(X))^2]$ over all functions $h$.
    Worked example $f(x,y)=2$ on $0\le y\le x\le1$ (so $Y\mid X=x$ is Uniform$[0,x]$): $\mathbb{E}[Y\mid X=x]=\frac{x}{2}$ — the regression function is the line $y=x/2$. As a random variable, $\mathbb{E}[Y\mid X]=X/2$.
    Where this goes Least-squares regression (Ch 13, 19) estimates $\mathbb{E}[Y\mid X]$; the denoiser in a diffusion model estimates $\mathbb{E}[\mathbf x_0\mid\mathbf x_t]$ (Ch 22).

    Law of total expectation

    Average the conditional averages, weighted by how likely each condition is, and you recover the overall average: $\mathbb{E}[\mathbb{E}[Y\mid X]]=\mathbb{E}[Y]$. The tower rule lets you compute expectations by divide and conquer — condition on whatever makes the problem easy.

    Theorem (tower rule) $\mathbb{E}[Y]=\mathbb{E}\big[\mathbb{E}[Y\mid X]\big]$; discretely, $\mathbb{E}[Y]=\sum_x\mathbb{E}[Y\mid X=x]\,P(X=x)$. More generally $\mathbb{E}[\mathbb{E}[Y\mid X,Z]\mid Z]=\mathbb{E}[Y\mid Z]$.
    Worked example A miner faces three tunnels: one exits in 3 hours; one loops back in 5 hours; one loops back in 7. He picks uniformly (and forgets). Expected time $T$: $\mathbb{E}[T]=\frac13(3)+\frac13(5+\mathbb{E}[T])+\frac13(7+\mathbb{E}[T])$. Solve: $\mathbb{E}[T]=5+\frac23\mathbb{E}[T]\Rightarrow\frac13\mathbb{E}[T]=5\Rightarrow\mathbb{E}[T]=15$ hours. Conditioning on the first choice turned a nasty recursion into one line.

    Law of total variance

    Uncertainty splits into two honest parts: the average wobble within each condition, plus the wobble between the conditions' means. "Unexplained + explained" — the decomposition behind ANOVA, mixture-model variance, and the epistemic/aleatoric split in uncertainty quantification.

    Theorem $$\operatorname{Var}(Y)=\underbrace{\mathbb{E}\big[\operatorname{Var}(Y\mid X)\big]}_{\text{within (unexplained)}}+\underbrace{\operatorname{Var}\big(\mathbb{E}[Y\mid X]\big)}_{\text{between (explained)}}.$$
    Worked example Mixture: with prob 0.5, $Y\sim N(0,1)$; else $Y\sim N(4,1)$. Within: $\mathbb{E}[\operatorname{Var}(Y|Z)]=1$. Between: $\mathbb{E}[Y|Z]$ is $0$ or $4$ equally, variance $=\mathbb{E}[(\cdot)^2]-2^2=8-4=4$. Total: $\operatorname{Var}(Y)=1+4=5$. The bimodal split contributes 4 of the 5 units of variance.
    Drill
    1. EASY If $\mathbb{E}[Y\mid X]$ is constant (X tells nothing about the mean), what does the law reduce to?
      Solution
      Between-term $=0$: $\operatorname{Var}(Y)=\mathbb{E}[\operatorname{Var}(Y|X)]$ — all variance is within-condition.
    2. MED $N\sim$Poisson($\lambda$), and given $N$, $Y\sim$Binomial($N,p$) (thinning). Compute $\operatorname{Var}(Y)$.
      Solution

      Solution
      Treat $\theta$ as random (posterior over models). $\operatorname{Var}(Y)=\mathbb{E}_\theta[\operatorname{Var}(Y\mid\theta)]+\operatorname{Var}_\theta(\mathbb{E}[Y\mid\theta])$: the first term is average within-model noise — aleatoric, irreducible; the second is disagreement between models' means — epistemic, shrinkable with more data. This decomposition drives uncertainty-aware decisions (Ch 13, 24).

    Bayesian updating

    Bayes' theorem applied repeatedly, as evidence streams in: today's posterior is tomorrow's prior. Beliefs are a state that each observation updates multiplicatively (then renormalize). With conjugate families the update is just parameter arithmetic — count successes, add to pseudo-counts.

    Definition With prior $p(\theta)$ and i.i.d. data $x_{1:n}$: $$p(\theta\mid x_{1:n})\propto p(\theta)\prod_{i=1}^np(x_i\mid\theta),$$ and sequentially $p(\theta\mid x_{1:t})\propto p(\theta\mid x_{1:t-1})\,p(x_t\mid\theta)$ — the same answer in any order (for i.i.d. data, exchangeability).
    Worked example Coin with unknown $p$, prior Beta$(2,2)$ (mildly fair). Observe H,H,T,H. Posterior: Beta$(2+3,\,2+1)=$Beta$(5,3)$; posterior mean $\frac{5}{8}=0.625$, versus the raw frequency $0.75$ — shrunk toward the prior's $0.5$. After 100 flips with 75 heads: Beta$(77,27)$, mean $0.740$ — data has overwhelmed the prior.

    Bernoulli distribution

    The atom of randomness: one trial, success or failure. Every binary label, every coin flip, every "did the user click" is a Bernoulli, and richer discrete distributions are built by combining them.

    Definition $X\sim\mathrm{Bern}(p)$: $P(X=1)=p$, $P(X=0)=1-p$. $\mathbb{E}[X]=p$, $\operatorname{Var}(X)=p(1-p)$. PMF in one formula: $p^x(1-p)^{1-x}$.
    Worked example A classifier is right with probability $p=0.9$ per (independent) example. For one example: mean $0.9$, variance $0.09$, standard deviation $0.3$ — a single binary outcome is noisy; that's why accuracy on 10 examples (±10 percentage points of standard error!) means little, and evaluation sets need thousands (Hoeffding, below).

    Binomial distribution

    Count the successes in $n$ independent identical trials. The counts cluster around $np$ with spread $\sqrt{np(1-p)}$, and for large $n$ the histogram bends into the bell curve — the CLT's original example.

    Definition $X\sim\mathrm{Bin}(n,p)$: $$P(X=k)=\binom{n}{k}p^k(1-p)^{n-k},\quad k=0,\dots,n.$$ $\mathbb{E}[X]=np$, $\operatorname{Var}(X)=np(1-p)$. $X$ is a sum of $n$ i.i.d. Bernoulli($p$)'s.
    Worked example 10 questions, guessing with $p=0.25$: $P(\text{exactly }3)=\binom{10}{3}(0.25)^3(0.75)^7=120\times0.015625\times0.13348\approx0.2503$. Passing (≥5): $\sum_{k=5}^{10}\binom{10}{k}0.25^k0.75^{10-k}\approx0.0781$ — guessing rarely clears half.

    Geometric distribution

    How many trials until the first success? The geometric distribution decays by a factor $(1-p)$ per step and has a startling property: it is memoryless — having failed 10 times tells you nothing about how much longer you'll wait. It models retries, gacha pulls, and rejection sampling.

    Definition $X\sim$Geom($p$), trials until first success: $P(X=k)=(1-p)^{k-1}p$, $k=1,2,\dots$. $\mathbb{E}[X]=\frac1p$, $\operatorname{Var}(X)=\frac{1-p}{p^2}$. Memoryless: $P(X>m+n\mid X>m)=P(X>n)$, with $P(X>n)=(1-p)^n$.
    Worked example Rolling a die until the first six: $p=\frac16$, expected rolls $6$. $P(X>6)=(5/6)^6\approx0.335$: a full third of players wait longer than the "expected" 6 rolls — the distribution is right-skewed, median $=\lceil\ln0.5/\ln(5/6)\rceil=4$.

    Poisson distribution

    Counts of rare events in a fixed window — typos per page, requests per second, mutations per genome — follow the Poisson law: one parameter $\lambda$ that is simultaneously the mean and the variance. It is the $n\to\infty$, $p\to0$ limit of the binomial with $np=\lambda$ fixed: many opportunities, each tiny.

    Definition $X\sim$Poi($\lambda$): $$P(X=k)=e^{-\lambda}\frac{\lambda^k}{k!},\quad k=0,1,2,\dots$$ $\mathbb{E}[X]=\operatorname{Var}(X)=\lambda$. Sums: independent Poissons add their $\lambda$'s. Binomial limit: Bin($n,\lambda/n$) → Poi($\lambda$).
    Worked example A server receives $\lambda=3$ errors/hour. $P(0)=e^{-3}\approx0.0498$; $P(\ge5)=1-e^{-3}\left(1+3+\frac92+\frac{27}{6}+\frac{81}{24}\right)=1-e^{-3}\cdot16.375\approx1-0.8153=0.1847$. A "quiet hour" happens once a day; a "bad hour" (≥5) roughly once every 5–6 hours.

    Categorical and multinomial distributions

    Uniform distribution

    Total indifference over an interval: every subinterval of equal length gets equal probability. It is the raw material of simulation — every random number generator starts by emitting (pseudo-)uniforms, and every other distribution is carved from them.

    Definition $X\sim U[a,b]$: $f(x)=\frac{1}{b-a}$ on $[a,b]$. $\mathbb{E}[X]=\frac{a+b}{2}$, $\operatorname{Var}(X)=\frac{(b-a)^2}{12}$; CDF $F(x)=\frac{x-a}{b-a}$ on $[a,b]$.

    Exponential distribution

    The waiting time between Poisson events: continuous, memoryless, decaying at constant rate $\lambda$. Component lifetimes, radioactive decays, and time-to-next-request all wear this shape; "memoryless" means a part that has survived 5 years is statistically as good as new.

    Definition $X\sim$Exp($\lambda$): $f(x)=\lambda e^{-\lambda x}$, $x\ge0$. $\mathbb{E}[X]=\frac1\lambda$, $\operatorname{Var}(X)=\frac{1}{\lambda^2}$, survival $P(X>t)=e^{-\lambda t}$, memoryless: $P(X>s+t\mid X>s)=P(X>t)$ — the only continuous distribution with this property.

    Gamma distribution

    Wait for the $k$-th Poisson event, not the first: sums of exponentials give the Gamma family, a flexible positive-valued distribution with a shape and a rate knob. It also happens to be the conjugate prior for Poisson rates and precision parameters.

    Definition $X\sim$Gamma($\alpha,\beta$) (shape, rate): $$f(x)=\frac{\beta^\alpha}{\Gamma(\alpha)}x^{\alpha-1}e^{-\beta x},\quad x>0,$$ where $\Gamma(\alpha)=\int_0^\infty u^{\alpha-1}e^{-u}du$ ($\Gamma(n)=(n-1)!$). $\mathbb{E}[X]=\frac{\alpha}{\beta}$, $\operatorname{Var}(X)=\frac{\alpha}{\beta^2}$. Gamma($1,\beta$)=Exp($\beta$); sum of $k$ i.i.d. Exp($\beta$) = Gamma($k,\beta$); independent Gammas with same rate add shapes.
    Worked example Requests at $\lambda=2$/min; time until the 3rd request is Gamma($3,2$): mean $\frac32$ min, variance $\frac34$. $P(T>2)$: for integer shape, $P(T>t)=e^{-\beta t}\sum_{j=0}^{\alpha-1}\frac{(\beta t)^j}{j!}=e^{-4}(1+4+8)=13e^{-4}\approx0.238$ — equivalently, fewer than 3 Poisson(4) events in 2 minutes.

    Beta distribution

    A distribution over probabilities themselves: supported on $[0,1]$, shaped by two pseudo-counts $\alpha$ (successes) and $\beta$ (failures). It is the conjugate prior of the Bernoulli/binomial — Bayesian coin-flipping is just Beta arithmetic — and the posterior sharpens as counts grow.

    Definition $X\sim$Beta($\alpha,\beta$): $$f(x)=\frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)}\,x^{\alpha-1}(1-x)^{\beta-1},\quad 0<x<1.$$ $\mathbb{E}[X]=\frac{\alpha}{\alpha+\beta}$, $\operatorname{Var}(X)=\frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$; mode $\frac{\alpha-1}{\alpha+\beta-2}$ for $\alpha,\beta>1$. Beta(1,1) is uniform. Conjugacy: Beta($\alpha,\beta$) prior + $k$ successes in $n$ trials → Beta($\alpha+k,\beta+n-k$).
    Worked example A/B test: variant shows 7 conversions in 20 views; prior Beta(1,1).     Dirichlet distribution

    The Beta's $K$-dimensional sibling: a distribution over entire probability vectors (points of the simplex). Its parameters are pseudo-counts per category, and it is the conjugate prior of the categorical/multinomial — the Bayesian way to smooth histograms and topic mixtures.

    Definition $\mathbf p\sim$Dir($\boldsymbol\alpha$), $\boldsymbol\alpha=(\alpha_1,\dots,\alpha_K)$, on the simplex $\{p_k\ge0,\sum p_k=1\}$: $$f(\mathbf p)=\frac{\Gamma(\sum_k\alpha_k)}{\prod_k\Gamma(\alpha_k)}\prod_{k=1}^Kp_k^{\alpha_k-1}.$$ $\mathbb{E}[p_k]=\frac{\alpha_k}{\alpha_0}$, $\alpha_0=\sum_j\alpha_j$; larger $\alpha_0$ = tighter around the mean; marginals are Beta($\alpha_k,\alpha_0-\alpha_k$). Conjugacy: Dir($\boldsymbol\alpha$) + multinomial counts $\mathbf n$ → Dir($\boldsymbol\alpha+\mathbf n$).
    Worked example Language model smoothing: token counts $(3,0,1)$ over a 3-word vocabulary with prior Dir$(1,1,1)$ (uniform on the simplex). Posterior Dir$(4,1,2)$: posterior means $\left(\frac47,\frac17,\frac27\right)$ — the unseen word gets probability $\frac17$ instead of the MLE's 0. This is exactly add-one (Laplace) smoothing, unmasked as Bayesian inference.
    Drill
    1. EASY Dir(2,2,2): what is $\mathbb{E}[\mathbf p]$, and is the density peaked or flat around it compared to Dir(20,20,20)?
      Solution
      $(\frac13,\frac13,\frac13)$ both; Dir(20,20,20) is much more concentrated ($\alpha_0=60$ vs 6).
    2. MED Show the $K=2$ Dirichlet reduces to the Beta.
      Solution
      With $\mathbf p=(p,1-p)$: $f\propto p^{\alpha_1-1}(1-p)^{\alpha_2-1}$ — Beta($\alpha_1,\alpha_2$), constants matching.
    3. HARD With $\alpha_k=c<1$ for all $k$, describe qualitatively where Dir($\boldsymbol\alpha$) puts its mass, and why that makes small-$\alpha$ Dirichlets useful as sparsity priors.
      Solution
      For $c<1$ each factor $p_k^{c-1}$ blows up as $p_k\to0$: the density concentrates on the simplex's edges and corners — vectors with most coordinates near zero. A Dir(0.1,…,0.1) prior thus prefers sparse mixtures (few active topics/classes), which is why LDA-style topic models use it.

    Gaussian distribution

    The bell curve: the distribution that sums converge to (CLT), the maximum-entropy shape for a fixed mean and variance, the noise model behind least squares, and the default assumption when all you know is a center and a spread. Two parameters, endless reach.

    Definition $X\sim N(\mu,\sigma^2)$: $$f(x)=\frac{1}{\sigma\sqrt{2\pi}}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right).$$ Standardize: $Z=\frac{X-\mu}{\sigma}\sim N(0,1)$ with CDF $\Phi$. Closure: $aX+b\sim N(a\mu+b,a^2\sigma^2)$; independent Gaussians sum to Gaussian. 68–95–99.7 within $1,2,3\sigma$.
    Worked example Adult heights $N(170,7^2)$ cm. $P(X>180)=P\!\left(Z>\frac{10}{7}\right)=1-\Phi(1.43)\approx0.0764$. Between 160 and 180: $\Phi(1.43)-\Phi(-1.43)=2\Phi(1.43)-1\approx0.847$. Top 1% cutoff: $z_{0.99}\approx2.326$: $170+2.326\times7\approx186.3$ cm.

    Where this goes Least squares = Gaussian MLE (Ch 13); Gaussian noise defines diffusion models (Ch 12, 22); max-entropy claim proved in Ch 16.

    Multivariate Gaussian

    The bell curve in $n$ dimensions: an ellipsoidal cloud whose center is the mean vector and whose shape is the covariance matrix. Its level sets are the ellipsoids of $\Sigma$'s eigenvectors (Ch 8); its marginals, conditionals and linear images are all Gaussian — the closure properties that make it the workhorse of tractable multivariate probability.

    Definition $\mathbf X\sim N(\boldsymbol\mu,\Sigma)$, $\Sigma$ symmetric positive definite: $$f(\mathbf x)=\frac{1}{(2\pi)^{n/2}(\det\Sigma)^{1/2}}\exp\!\left(-\tfrac12(\mathbf x-\boldsymbol\mu)^\top\Sigma^{-1}(\mathbf x-\boldsymbol\mu)\right).$$ Linear maps: $A\mathbf X+\mathbf b\sim N(A\boldsymbol\mu+\mathbf b,\,A\Sigma A^\top)$. Sampling: $\mathbf x=\boldsymbol\mu+L\mathbf z$ with $LL^\top=\Sigma$ (Cholesky), $\mathbf z\sim N(\mathbf0,I)$.
    Worked example $\boldsymbol\mu=(0,0)$, $\Sigma=\begin{pmatrix}2&1.2\\1.2&1\end{pmatrix}$. Eigen: $\lambda^2-3\lambda+(2-1.44)=0$: $\lambda=\frac{3\pm\sqrt{9-2.24}}{2}=\frac{3\pm2.6}{2}$: $2.8$ and $0.2$. The cloud is a tilted ellipse, long axis along the $\lambda=2.8$ eigenvector, axis lengths in ratio $\sqrt{2.8/0.2}\approx3.74$. Correlation: $\rho=\frac{1.2}{\sqrt{2}\cdot1}\approx0.849$.

    Covariance matrices

    The covariance matrix is the multivariate spread-o-meter: variances on the diagonal, covariances off it. Its eigenvectors are the principal axes of the data cloud and its eigenvalues the variances along them — diagonalize it and you have run PCA.

    Definition $\Sigma=\operatorname{Cov}(\mathbf X)=\mathbb{E}[(\mathbf X-\boldsymbol\mu)(\mathbf X-\boldsymbol\mu)^\top]$, with $\Sigma_{ij}=\operatorname{Cov}(X_i,X_j)$. Always symmetric positive semidefinite. Sample version: $\hat\Sigma=\frac{1}{n-1}\sum_i(\mathbf x_i-\bar{\mathbf x})(\mathbf x_i-\bar{\mathbf x})^\top$. Under $\mathbf Y=A\mathbf X$: $\Sigma_Y=A\Sigma_XA^\top$.
    Worked example Data points $(1,2),(3,3),(2,4),(4,5),(5,6)$. Means: $\bar x=3$, $\bar y=4$. Deviations: $(-2,-2),(0,-1),(-1,0),(1,1),(2,2)$. $\hat\Sigma_{11}=\frac{4+0+1+1+4}{4}=2.5$; $\hat\Sigma_{22}=\frac{4+1+0+1+4}{4}=2.5$; $\hat\Sigma_{12}=\frac{4+0+0+1+4}{4}=2.25$. $\hat\Sigma=\begin{pmatrix}2.5&2.25\\2.25&2.5\end{pmatrix}$: eigenvalues $2.5\pm2.25$ = $4.75$ and $0.25$, eigenvectors $(1,1)/\sqrt2$ and $(1,-1)/\sqrt2$ — the cloud stretches along the diagonal, 19× more variance than across it.

    Conditional Gaussian distributions

    Slice a Gaussian cloud along an observed coordinate and the slice is again Gaussian, with a mean shifted linearly by the observation and a variance reduced by a fixed amount (independent of what you observed). This closed form is the beating heart of Kalman filters, Gaussian processes and linear-Gaussian everything.

    Theorem Partition $\mathbf X=(\mathbf X_1,\mathbf X_2)\sim N\!\left(\begin{pmatrix}\boldsymbol\mu_1\\\boldsymbol\mu_2\end{pmatrix},\begin{pmatrix}\Sigma_{11}&\Sigma_{12}\\\Sigma_{21}&\Sigma_{22}\end{pmatrix}\right)$. Then $$\mathbf X_1\mid\mathbf X_2=\mathbf x_2\ \sim\ N\!\big(\boldsymbol\mu_1+\Sigma_{12}\Sigma_{22}^{-1}(\mathbf x_2-\boldsymbol\mu_2),\ \Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}\big).$$ The conditional mean is linear in $\mathbf x_2$; the conditional covariance (the Schur complement) never depends on $\mathbf x_2$.
    Worked example Bivariate, $\mu=(0,0)$, $\sigma_1=\sigma_2=1$, $\rho=0.8$. Observe $X_2=2$: $$X_1\mid X_2=2\sim N(0.8\times2,\ 1-0.64)=N(1.6,\,0.36).$$ The best guess of $X_1$ moved to 1.6 (regression toward the mean: less than 2!) and the uncertainty dropped from sd 1 to sd 0.6. With $\rho=0$: no update at all.
    Where this goes This formula is the Kalman filter update (Ch 28) and the Gaussian process posterior (Ch 19).

      Solution
      $N(-0.5,\ 0.75)$.
    2. MED Explain "regression toward the mean" from the formula when $\sigma_1=\sigma_2$.
      Solution
      Conditional mean $=\rho x_2$ with $|\rho|\le1$: the predicted $X_1$ is always closer to its mean (in sd units) than the observed $X_2$ was to its own. Tall parents, slightly-less-tall children — Galton's original observation.
    3. HARD Noisy measurement: $X\sim N(0,\sigma^2)$ (state), $Y=X+\varepsilon$, $\varepsilon\sim N(0,\tau^2)$ independent. Derive $X\mid Y=y$.
      Solution
      Jointly Gaussian with $\operatorname{Var}(Y)=\sigma^2+\tau^2$, $\operatorname{Cov}(X,Y)=\sigma^2$. Conditional: mean $\frac{\sigma^2}{\sigma^2+\tau^2}y$, variance $\sigma^2-\frac{\sigma^4}{\sigma^2+\tau^2}=\frac{\sigma^2\tau^2}{\sigma^2+\tau^2}$. The weight $\frac{\sigma^2}{\sigma^2+\tau^2}$ is the Kalman gain: trust the measurement in proportion to signal-to-noise.

    Markov inequality

    The crudest tail bound, from almost nothing: a nonnegative variable can't exceed $k$ times its mean more than $\frac1k$ of the time — otherwise those excursions alone would push the mean up. Weak but universal, and the seed from which Chebyshev and Chernoff grow.

    Theorem (Markov) For $X\ge0$ and $a>0$: $$P(X\ge a)\le\frac{\mathbb{E}[X]}{a}.$$
    Worked example Average inference latency is 50 ms. Fraction of requests over 500 ms: at most $\frac{50}{500}=10\%$ — whatever the distribution. (Proof in one line: $\mathbb{E}[X]\ge\mathbb{E}[X\cdot\mathbf1_{X\ge a}]\ge a\,P(X\ge a)$.) If you additionally know the variance, Chebyshev will do much better.
    Drill
    1. EASY $X\ge0$, $\mathbb{E}[X]=3$. Bound $P(X\ge12)$.
      Solution
      $\le\frac{3}{12}=0.25$.
    2. MED Exhibit a distribution that makes Markov exactly tight for $a=10$, mean 1.
      Solution
      $X=10$ with probability $0.1$, else $0$: mean 1, $P(X\ge10)=0.1=\frac{1}{10}$. Markov is tight only for such two-point extremes — hence its looseness in practice.
    3. HARD Derive Chebyshev's inequality from Markov.
      Solution
      Apply Markov to the nonnegative variable $(X-\mu)^2$ with threshold $a^2$: $P(|X-\mu|\ge a)=P((X-\mu)^2\ge a^2)\le\frac{\mathbb{E}[(X-\mu)^2]}{a^2}=\frac{\sigma^2}{a^2}$. The same trick with $e^{tX}$ gives Chernoff bounds — Markov is the template for all of them.

    Chebyshev inequality

    Add one fact — the variance — and tails shrink quadratically: being $k$ standard deviations from the mean has probability at most $1/k^2$, for any distribution. It is the inequality that proves the weak law of large numbers in three lines.

    Theorem (Chebyshev) For any $X$ with mean $\mu$, variance $\sigma^2$, and $k>0$: $$P(|X-\mu|\ge k\sigma)\le\frac{1}{k^2}.$$
    Worked example Reviews average 4.2 stars with sd 0.5, distribution unknown. Fraction of items rated below 3.2 or above 5.2 (i.e. ≥2 sd away): at most $\frac14$. Compare the Gaussian answer, ≈4.6% — Chebyshev pays for universality with slack, but it can never be fooled by weird distributions.

    1. EASY $\mu=100$, $\sigma=10$. Bound $P(|X-100|\ge30)$.

    2. MED Use Chebyshev on $\bar X_n$ (i.i.d., mean $\mu$, variance $\sigma^2$) to bound $P(|\bar X_n-\mu|\ge\epsilon)$.
      Solution

    Jensen inequality

    For a convex function, the function of the average lies below the average of the function — the chord sits above the curve. This one geometric fact generates half of information theory: the nonnegativity of KL divergence, the direction of the ELBO bound, and why $\log$ of an average beats average of $\log$.

    Theorem (Jensen) If $\varphi$ is convex, $\varphi(\mathbb{E}[X])\le\mathbb{E}[\varphi(X)]$; if concave, the inequality flips. Equality (for strictly convex/concave $\varphi$) iff $X$ is a constant.
    Worked example An investment returns ×0.5 or ×1.6 with equal probability each year. Arithmetic mean factor: $1.05$ — looks profitable. But the long-run growth is governed by $\mathbb{E}[\ln X]=\frac12(\ln0.5+\ln1.6)=\frac12\ln0.8<0$: you lose ~11% per year almost surely. Jensen ($\ln$ concave): $\mathbb{E}[\ln X]\le\ln\mathbb{E}[X]$ — the gap between them is the volatility drag.
    Think first Which is larger: $\mathbb{E}[X^2]$ or $(\mathbb{E}[X])^2$? What familiar quantity is the difference?
    Reveal
    $x^2$ is convex, so $\mathbb{E}[X^2]\ge(\mathbb{E}[X])^2$. The difference is the variance — Jensen's gap for the square function, always $\ge0$, zero iff $X$ constant.

    Hoeffding inequality

    For bounded variables, averages concentrate exponentially fast: the probability that a sample mean strays $\epsilon$ from the true mean dies like $e^{-2n\epsilon^2}$. This is the inequality that tells you how big an eval set you need, and the engine inside PAC learning bounds and UCB bandit algorithms.

    Theorem (Hoeffding) $X_1,\dots,X_n$ independent with $X_i\in[a_i,b_i]$, $\bar X=\frac1n\sum X_i$: $$P\big(|\bar X-\mathbb{E}[\bar X]|\ge\epsilon\big)\le2\exp\!\left(-\frac{2n^2\epsilon^2}{\sum_i(b_i-a_i)^2}\right)\ \overset{[0,1]}{=}\ 2e^{-2n\epsilon^2}.$$
    Worked example Model accuracy estimated on $n$ i.i.d. test examples (each 0/1). Want the estimate within $\pm2\%$ of the truth with 95% confidence: $2e^{-2n(0.02)^2}\le0.05\Rightarrow n\ge\frac{\ln40}{2\times0.0004}=\frac{3.689}{0.0008}\approx4611$. About 4600 examples — and to halve the margin you need 4×: eval sets are expensive by law, not by accident.
    Where this goes Generalization bounds (Ch 20) are Hoeffding + union bound over a hypothesis class; UCB exploration bonuses (Ch 24, 25) are inverted Hoeffding bounds.

    Concentration inequalities

    The theme uniting Markov, Chebyshev, Hoeffding, Chernoff and friends: in high dimensions and large samples, random quantities are nearly deterministic — sums, averages, and smooth functions of many independent variables concentrate tightly around their expectations. This is why statistics works, why high-dimensional geometry is weird, and why fixed eval numbers are trustworthy at all.

    Definition A concentration inequality bounds $P(|Z-\mathbb{E}Z|\ge t)$. The ladder: Markov (mean only, $1/t$), Chebyshev (variance, $1/t^2$), Chernoff/Hoeffding (MGF/boundedness, $e^{-ct^2}$), McDiarmid (bounded differences: any function where changing one coordinate moves the value by $\le c_i$ concentrates like $\exp\!\big(-2t^2/\sum c_i^2\big)$).
    Worked example High-dimensional sphere weirdness: for $\mathbf z\sim N(\mathbf0,I_n)$, $\|\mathbf z\|^2=\sum z_i^2$ has mean $n$ and variance $2n$, so $\|\mathbf z\|$ concentrates around $\sqrt n$ with $O(1)$ fluctuations: in $n=1000$ dimensions virtually all Gaussian samples live in a thin shell of radius $\approx31.6$ — nowhere near the "center" where the density is largest. Sampling in latent spaces (Ch 22) respects this shell, not the origin.
    Pitfall Concentration needs independence (or weak dependence) and control of tails/boundedness. Heavy tails (Cauchy) or strong correlations (one shared latent factor) can destroy it completely — check the hypotheses before trusting an error bar.
    Drill
    1. EASY Rank Markov, Chebyshev, Hoeffding by tail decay and by hypotheses needed.
      Solution

      Solution

    Law of Large Numbers

    Averages settle down: as you take more i.i.d. samples, the sample mean converges to the true mean. This is the license that lets frequencies estimate probabilities, Monte Carlo estimate integrals, and training losses estimate expected risk. It says nothing about how fast — that's the CLT's job.

    Theorem $X_1,X_2,\dots$ i.i.d. with $\mathbb{E}|X_1|<\infty$, mean $\mu$. Weak LLN: $\bar X_n\xrightarrow{P}\mu$ (for every $\epsilon$, $P(|\bar X_n-\mu|>\epsilon)\to0$). Strong LLN: $\bar X_n\to\mu$ almost surely.
    Worked example Monte Carlo integration: to estimate $\pi$, drop $n$ uniform points in the unit square; the fraction inside the quarter circle estimates $\frac\pi4$. With $n=10^4$: sd of the estimate of $\pi$ is $4\sqrt{\frac{p(1-p)}{n}}\approx4\sqrt{\frac{0.785\cdot0.215}{10^4}}\approx0.0164$ — the LLN guarantees convergence, the variance formula prices it.
    Pitfall Two ways it fails: no finite mean (Cauchy — averages never settle), and no independence (one shared random factor keeps fluctuating forever: averaging $n$ copies of the same noisy measurement removes nothing).

    1. EASY A die is rolled 10,000 times. Around what value will the average settle, and why?
      Solution
      $3.5=\mathbb{E}[X]$, by the LLN.
    2. MED Explain why "the empirical risk converges to the true risk for a fixed model" is exactly the LLN, and what breaks when the model was selected using the same data.
      Solution

    3. HARD $X_i$ i.i.d. taking value $2^k$ with probability $2^{-k}$ ($k=1,2,\dots$; the St. Petersburg game). Does the LLN apply? What happens to $\bar X_n$?

      $\mathbb{E}[X]=\sum_k2^k2^{-k}=\sum_k1=\infty$: no finite mean, LLN inapplicable. In fact $\bar X_n/\log_2n\to1$ in probability — averages grow forever, slowly; no fair finite price exists for the game. Infinite means are not a technicality.

    Central Limit Theorem

    Not only do averages settle — their fluctuations take a universal shape. Center a sum of many i.i.d. contributions, divide by $\sqrt n$, and the distribution approaches the Gaussian no matter what you started from (finite variance is all that's asked). This is why the bell curve is everywhere: it is the fixed point of adding up small independent effects.

    Theorem (CLT) $X_1,X_2,\dots$ i.i.d., mean $\mu$, variance $\sigma^2\in(0,\infty)$: $$\frac{\bar X_n-\mu}{\sigma/\sqrt n}\ \xrightarrow{d}\ N(0,1),$$ i.e. $P\!\left(\frac{\bar X_n-\mu}{\sigma/\sqrt n}\le z\right)\to\Phi(z)$ for all $z$.
    Worked example 100 die rolls, $S$ their sum. $\mu_S=350$, $\sigma_S=\sqrt{100\times35/12}\approx17.08$. $P(S>380)\approx P\!\left(Z>\frac{380.5-350}{17.08}\right)=P(Z>1.786)\approx3.7\%$ (with continuity correction). The exact distribution of $S$ is a monstrous 100-fold convolution; the CLT reads it off a normal table.

    Pitfall The CLT is an approximation near the center. Far tails converge slowly (especially for skewed bases), and heavy-tailed (infinite-variance) summands converge to stable laws, not Gaussians. Never use a normal table for 6σ events without a large-deviations argument.

    1. EASY 400 i.i.d. samples, each mean 10, sd 2. Approximate the distribution of $\bar X$.
      Solution
      $N(10,\,(2/\sqrt{400})^2)=N(10,0.01)$: sd 0.1.
    2. MED A fair coin is flipped 10,000 times. Approximate $P(\text{heads}\ge5100)$.
      Solution
      $\mu=5000$, $\sigma=\sqrt{2500}=50$: $z=\frac{5100-5000}{50}=2$: $P\approx1-\Phi(2)\approx2.3\%$.
    3. HARD An estimator's error bar is quoted as $\bar X\pm1.96\,s/\sqrt n$. Derive the 1.96 and name the two theorems that justify the recipe.
      Solution
      CLT: $\frac{\bar X-\mu}{\sigma/\sqrt n}\approx N(0,1)$, and $P(|Z|\le1.96)=0.95$ ($\Phi(1.96)\approx0.975$), giving $\mu\in\bar X\pm1.96\sigma/\sqrt n$ with ~95% coverage. Replacing unknown $\sigma$ by the sample sd $s$ is justified by the LLN ($s\to\sigma$, Slutsky's lemma). The 95% confidence interval of Ch 13, assembled from this chapter's two capstone theorems.

    1. MED Noisy channel, full Bayes. A bit $B\in\{0,1\}$ is sent with $P(B=1)=0.6$; the channel flips it with probability 0.1. You receive $R=1$. (a) Find $P(B=1\mid R=1)$. (b) The same bit is retransmitted independently and you receive $1$ again; update. (c) How many consecutive received 1's make you 99.9% sure?
      Solution
      (a) $\frac{0.9\cdot0.6}{0.9\cdot0.6+0.1\cdot0.4}=\frac{0.54}{0.58}\approx0.931$. (b) Odds form: prior odds $\frac{0.6}{0.4}=1.5$; each received 1 multiplies odds by $\frac{0.9}{0.1}=9$: after two, odds $=1.5\times81=121.5$, $P=\frac{121.5}{122.5}\approx0.992$. (c) Need odds $\ge999$: $1.5\times9^k\ge999\Rightarrow9^k\ge666\Rightarrow k\ge\frac{\ln666}{\ln9}\approx2.96$: $k=3$ receptions.
    2. HARD Gaussian pipeline. $X\sim N(0,4)$ is a signal; the sensor reports $Y=X+\varepsilon$, $\varepsilon\sim N(0,1)$ independent. (a) Give the joint distribution of $(X,Y)$. (b) Derive $X\mid Y=3$. (c) The downstream system acts only if $X>2$; compute the probability it should act given $Y=3$.
      Solution
      (a) Jointly Gaussian, mean $\mathbf0$, $\operatorname{Var}(X)=4$, $\operatorname{Var}(Y)=5$, $\operatorname{Cov}=4$: $\Sigma=\begin{pmatrix}4&4\\4&5\end{pmatrix}$. (b) Mean $\frac{4}{5}\cdot3=2.4$, variance $4-\frac{16}{5}=0.8$: $X\mid Y=3\sim N(2.4,0.8)$. (c) $P(X>2\mid Y=3)=P\!\left(Z>\frac{2-2.4}{\sqrt{0.8}}\right)=P(Z>-0.447)=\Phi(0.447)\approx0.673$.
    3. HARD How big an eval? A benchmark has $n$ i.i.d. questions; a model's true accuracy is $p$. (a) Give the exact distribution, mean and sd of the measured accuracy $\hat p$. (b) With $p\approx0.8$, how large must $n$ be so a 95% CLT interval has half-width 1%? (c) Model A truly beats model B by 2 points (0.80 vs 0.78) and they are evaluated on the same $n=1000$ questions independently. Approximate the probability the eval ranks them backwards, and comment.
      Solution
      (a) $n\hat p\sim$Bin($n,p$): $\mathbb{E}[\hat p]=p$, sd $\sqrt{p(1-p)/n}$. (b) $1.96\sqrt{0.16/n}\le0.01\Rightarrow n\ge1.96^2\cdot0.16\cdot10^4\approx6147$. (c) $\hat p_A-\hat p_B$ has mean 0.02, variance $\frac{0.16+0.1716}{1000}\approx3.32\times10^{-4}$, sd $\approx0.0182$. $P(\hat p_A<\hat p_B)=P\!\left(Z<\frac{-0.02}{0.0182}\right)=\Phi(-1.10)\approx13.6\%$: a 1-in-7 chance the leaderboard is upside down at $n=1000$ — treat small benchmark gaps as noise unless $n$ is large (and correlated-question evals need paired analysis).

    Task 1 — Build distributions from uniforms Using only rng.uniform(), sample Exponential(λ) by inverse CDF and standard Gaussians by Box–Muller; verify means, variances and histogram shapes.
    Reference solution
    import numpy as np
rng = np.random.default_rng(0)
N = 200_000

# exponential via inverse CDF: X = -ln(1-U)/lam
lam = 2.0
u = rng.uniform(size=N)
x = -np.log1p(-u) / lam
print("exp  mean %.4f (1/λ=%.4f)  var %.4f (1/λ²=%.4f)"
      % (x.mean(), 1/lam, x.var(), 1/lam**2))

# gaussian via Box-Muller: Z = sqrt(-2 ln U1) cos(2π U2)
u1, u2 = rng.uniform(size=N), rng.uniform(size=N)
z = np.sqrt(-2*np.log(u1)) * np.cos(2*np.pi*u2)
print("gauss mean %.4f  var %.4f" % (z.mean(), z.var()))
within = [(np.abs(z) < k).mean() for k in (1, 2, 3)]
print("within 1,2,3 sd:", np.round(within, 4))  # ~0.683 0.954 0.997
    Task 2 — CLT and concentration, empirically For a skewed base distribution, plot-free-verify the CLT (standardized means vs Φ) and check Hoeffding's bound against reality.
    Reference solution
    import numpy as np
rng = np.random.default_rng(1)

# CLT: means of n exponentials, standardized
n, reps, lam = 40, 100_000, 1.0
xs = rng.exponential(1/lam, size=(reps, n))
zs = (xs.mean(axis=1) - 1/lam) / ((1/lam) / np.sqrt(n))
for q in (-2, -1, 0, 1, 2):
    from math import erf
    phi = 0.5 * (1 + erf(q / np.sqrt(2)))
    print(f"P(Z<={q}): empirical {np.mean(zs <= q):.4f}  normal {phi:.4f}")

# Hoeffding: coin, n=1000, eps=0.05
n, eps, reps = 1000, 0.05, 200_000

    Task 3 — Bayesian A/B testing Simulate two variants with true rates 0.10 and 0.12, run Beta–Bernoulli updating over 2000 visitors each, and compute $P(p_B>p_A)$ from posterior samples.
    Reference solution
    import numpy as np
rng = np.random.default_rng(2)
pA, pB, n = 0.10, 0.12, 2000
convA = rng.random(n) < pA
convB = rng.random(n) < pB

aA, bA = 1 + convA.sum(), 1 + n - convA.sum()   # Beta(1,1) prior
aB, bB = 1 + convB.sum(), 1 + n - convB.sum()
print(f"posterior A: Beta({aA},{bA})  mean {aA/(aA+bA):.4f}")
print(f"posterior B: Beta({aB},{bB})  mean {aB/(aB+bB):.4f}")

S = 500_000
prob = (rng.beta(aB, bB, S) > rng.beta(aA, bA, S)).mean()
print(f"P(pB > pA | data) = {prob:.4f}")
# also: posterior of the lift
lift = rng.beta(aB, bB, S) - rng.beta(aA, bA, S)
print("95% credible interval for lift:",
      np.round(np.percentile(lift, [2.5, 97.5]), 4))
